# 화면 정렬 검사

Codex가 사용자가 의도한 기준선을 실제 화면에서 측정해 편차와 위치를 설명한다. 등록된 Figma 플러그인은 기존 Design 읽기 경로를 사용한다. 결과에 사용한 규칙과 화면 범위를 남긴다. [기능 그래프](graph.json)

| 사용자 장면 | 통과 조건 | 근거 |
|---|---|---|
| 현재 로컬 화면의 표 머리글과 행이 맞는지 확인 | 같은 화면 상태에서 지정 폭마다 기준 하나와 실제로 보이는 대상을 측정한다. 기준 누락·중복, 대상 누락은 미확인이다. | 폭별 원본·가이드 이미지와 규칙 해시, 부호 있는 거리, 허용 오차를 담은 JSON |
| 의도한 들여쓰기 확인 | 목표 간격을 부호 있는 값으로 지정하고 실측 거리에서 목표를 뺀 편차를 판정한다. | 기준, 대상, 축·가장자리, 목표 간격 |
| 같은 CSS 상자 안의 글자와 아이콘 잉크 비교 | `measurement: "paint"`를 선언한 웹 규칙은 간단한 텍스트 요소와 SVG의 실제 브라우저 픽셀 경계를 측정한다. 기준·대상 상자는 별도로 보존하고 부호 있는 잉크 경계 차이에 `expectedOffset`과 `tolerance`를 적용한다. | 기준·대상의 CSS `rect`, 픽셀에서 계산한 `paintedRect`, 전·숨김·복원 캡처, 규칙 해시 |
| 두 노드가 동일한 선에 있는지 Design 파일에서 확인 | 파일·페이지·작업 버전이 일치하는 읽기 영수증의 절대 바운딩 박스를 사용한다. 요청한 ID만 읽고 선택과 디자인 값을 보존한다. | 노드 ID, 좌표계, 절대값, 편차와 영수증 식별 정보 |
| 공통 여백을 고친 후 비교 | 동일한 규칙·브라우저·논리 화면 경로·뷰포트에서 다시 측정한다. 접속 포트가 달라진 로컬 화면은 Codex가 같은 대상임을 확인한다. | 독립적으로 열리는 전후 HTML과 검증 상태 |

기본 웹 검사는 요소의 CSS 상자를 측정한다. `measurement: "paint"`를 선언하면 보이는 간단한 텍스트 요소와 지원되는 SVG에 한해 CSS 상자와 실제 화면 픽셀에서 관찰한 잉크 경계를 함께 기록한다. 픽셀 경계는 대상 하나를 보이는 상태, 숨긴 상태, 복원한 상태에서 캡처한 이미지로 계산한다. 복원 전후 대상 영역이 달라지거나 대상이 비어 있거나, 동적·잘림·지원하지 않는 요소이면 미확인이다. 장식된 HTML 요소는 배경과 테두리가 잉크로 섞이지 않도록 거부한다. `paintedRect`는 실제 픽셀 변화의 경계이며 시각적 무게중심이나 광학 균형 판정이 아니다. 보고서의 `perceivedBalance`는 `not-assessed`로 남긴다.

Figma의 페이지 좌표계 검사에는 읽기 영수증의 축 정렬 바운딩 박스를 사용한다. 웹 픽셀 검사는 Figma 노드의 광학 측정으로 확대 해석하지 않는다. 디자인 수정이 요청된 경우 Codex는 공통 컨테이너, 디자인 토큰 또는 해당 프로젝트 graph에서 값을 소유하는 곳을 수정한다. 의도한 광학 보정은 규칙의 목표 간격이나 범위에 명시한다.

등록 뷰어의 브랜드, 본문과 선택 표에는 같은 안쪽 여백을 사용한다. 320px와 400px에서 기준선 편차 0.5px 이하, 가로 넘침 없음, 열별 헤더와 데이터의 정렬을 인수 조건으로 둔다. [등록 뷰어 규칙](../../tools/relay_alignment_rules.json) · [검토 워크스페이스 예제 규칙](owned-workspace.rules.json)
