# 웹 탭 전환을 편집 가능한 Figma 프로토타입으로 변환하기

Figma Flow 0.34.0은 탭을 누르면 옆 패널이 바뀌는 화면을 브라우저에서 관찰하고, 관찰한 클릭만 Figma Design 프로토타입으로 연결한다. 디자이너는 상태별 프레임의 탭과 코드 레이어를 편집한다. 기획자는 같은 시작 프레임에서 A→B→A를 재생한다. 개발자는 그래프에서 상태별 패널 내용 해시, 누른 요소 ID와 목적지를 확인한다. [사용 안내](../../docs/guide.md#web-tabs-quickstart) · [관찰 입력 형식](../../docs/web-tabs-input.md) · [정본 그래프](graph.json)

## 실행과 인수 경로

1. 사용자가 로컬 Node 명령 `tools/web_tabs_capture.mjs`를 실행한다. 격리 프로필의 headless Chromium이 페이지를 열고, 진입 애니메이션이 끝날 때까지 기다린다. 이어서 지정한 탭을 차례로 누른다. Computer Use, hook, 공식 Figma MCP와 API 토큰이 필요 없다.
2. 상태는 `--panel`의 보이는 글자 해시로 구분한다. CSS 클래스로 선택 상태를 추측하지 않는다. 클릭할 때마다 탭 중앙의 hit test, 패널 변화와 스크롤 고정을 확인한다. 출발 화면에서 누른 탭과 같은 상자의 frame 요소 ID를 기록한다.
3. `native_edit.py web-tabs`가 관찰 기록을 정본 그래프에 결합한다. 관찰하지 않은 전이, 같은 상태로의 클릭, frame이 아닌 대상, 화면 밖 대상은 거절한다.
4. 자체 플러그인이 상태별 프레임을 만든다. 누른 탭 위에는 투명한 최상위 `Click · 목적지` 프레임을 두고, 즉시 `NAVIGATE`하는 `ON_CLICK` 반응을 연결한다. 첫 상태는 흐름 시작점이 된다. 재적용은 기존 프레임과 반응을 비교하고, 편집된 반응을 덮어쓰지 않는다.
5. 실제 읽기로 프레임과 반응을 확인한다. Figma 프레젠테이션에서 같은 입력을 재생해 브라우저와 대조한다.

## 실제 Devtool 홈에서 관찰한 결과

Magic UI Devtool 템플릿을 1440 × 900 CSS px, DPR 1의 데스크톱 레이아웃으로 열었다. 측정 시점 화면 폭은 1435 px이다. 5 px은 세로 스크롤바다. 상태 A의 화면 요소는 159개, 상태 B는 175개다.

| 입력 | 브라우저 (Chrome) | Figma Design 프레젠테이션 |
| --- | --- | --- |
| 시작 | 첫 번째 탭(상태 A) 선택, 초기 코드 패널 표시 | 같은 탭과 코드 |
| 두 번째 탭(상태 B) 클릭 | 두 번째 탭의 코드 패널로 바뀜 | 같은 코드의 프레임으로 이동 |
| 첫 번째 탭(상태 A) 클릭 | 첫 번째 탭의 초기 코드 패널로 복귀 | 시작 프레임으로 복귀 |
| 상태 A에서 세 번째 미관찰 탭 클릭 | 이번 관찰 순서에 없음 | 그래프에 없는 전이라 연결하지 않음. 상태 A 유지 |

브라우저 측은 캡처 CLI의 headless Chromium 마우스 입력과, 로그인하지 않은 Chrome 창의 직접 클릭으로 확인했다. Figma 측은 Figma Desktop의 Figma Flow로 적용했다. 그다음 같은 Chrome에서 프로토타입 URL을 열어 마우스로 클릭했다. 적용 직후 읽기와 별도 읽기 모두 두 상태 프레임, 두 hotspot, 흐름 시작점이 `current`였다.

## 확인한 한계

- 탭 레이어에 반응을 직접 넣는 첫 구현은 Figma Desktop에서 두 번 모두 `setReactionsAsync` 10초 연결 시간 초과로 거절됐다. 두 번 모두 새 노드는 롤백됐다. 같은 장면에서 최상위 hotspot에 같은 반응을 넣으면 성공했다. 탭이 화면 최상단에 있는 작은 합성 장면에서는 탭 레이어 직접 연결도 성공했다. 이 Figma 동작의 내부 원인은 확인하지 않았다.
- 로고 띠는 탭과 무관하게 계속 바뀐다. 상태 프레임에는 각 캡처 순간의 로고가 남아, 상태 B 프레임의 로고 칸은 대부분 비어 있다. 무한 반복 애니메이션도 같은 이유로 픽셀이 다르다. 상태의 동일성은 패널 글자로 판정한다.
- 브라우저는 패널을 애니메이션 없이 바꾸므로 Figma 전환도 즉시 이동이다. 코드 패널 안의 스크롤, 키보드 포커스와 스크린리더 의미는 이 프로토타입에 포함하지 않는다.
- 연결 검증에 쓴 합성 탭 프레임 2개와 진단용 hotspot 프레임 2개가 같은 페이지에 남아 있다. 별도 그래프 ID를 쓰므로 이 작업의 읽기와 섞이지 않는다.
