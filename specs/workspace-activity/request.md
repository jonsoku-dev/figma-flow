# 사용자 요청 · 이력 중심의 Figma 패널

2026-11-12 사용자는 Figma plugin UI를 이력 확인 중심으로 개선하고, 필요한 애니메이션과 차트를 사용하며 작업 목록에서 인과관계가 보이기를 요청했다. 이어 컴포넌트 재사용과 Frame·Group 선택 등 Figma 전문 사용법을 조사해 개선 항목을 찾도록 요청했다.

이번 제품 변경은 관측 상태 분포와 한 실행의 요청·결과 연결에 한정한다. 명시적인 작업 간 의존성과 Figma 제작 개선은 [개발 계획](../../docs/development-roadmap/README.md)에서 후속 기능으로 관리한다. 요청의 존재가 해당 후속 기능 구현이나 실제 제품 인수를 뜻하지 않는다.
