# 작업 이력 화면과 동작

이 문서는 [graph.json](graph.json)의 사람이 읽는 설명이다.

## SCR-ACTIVITY-01 · 작업 목록과 이력

작업 목록과 이력의 상단은 현재 revision별 상태를 가로 분포와 텍스트 수로 보여준다. 색만으로 의미를 전달하지 않는다. 이력에서는 작업 필터 아래에 실행별 요청·진행·결과를 펼칠 수 있다. summary는 작업 이름·최종 관측·동작·시각을 보여준다. 내부 연결은 같은 실제 실행 ID와 task/revision 범위에 한정한다.

ID 없는 옛 이력은 별도 시간순 disclosure에 남긴다. 전체 원시 event 요약도 별도 disclosure에서 읽을 수 있다. 해당 task가 변경됐으면 이전 버전으로 표시하고 현재 작업을 여는 기존 동작을 유지한다. 아직 task나 이력이 없으면 빈 상태를 보여준다.

## ACT-ACTIVITY-01 · 실행 이력 조회

작업 목록의 이력 버튼은 해당 task를 선택하고 history로 이동한다. 키보드 초점은 해당 실행 summary로 이동한다. 필터를 모든 작업으로 바꾸면 범위를 다시 넓힌다. summary 펼침·접힘, 프로젝트 선택과 이력 조회는 생성·적용 요청을 하지 않는다.

테마는 기존 CSS token을 따른다. summary toggle과 connector의 짧은 animation은 문맥을 설명하며 reduced motion에서 제거된다. 실패·읽기·검증은 서로 다른 이름으로 남는다. 차트와 이력은 전체 제품 승인이나 Figma 클라우드 저장을 표시하지 않는다.
