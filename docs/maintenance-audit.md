# 저장소 유지보수 감사

| 발견 사항 | 현재 막는 층 | 적용할 층과 결과 | 규모 |
| --- | --- | --- | --- |
| 그래프를 원시 JSON으로 읽는 소비 경계가 반복됨 | 코드 일부와 아카이브 검사 | 공통 디코더를 토큰, 명세, 공개 CLI, 예제 감사, 배치, 웹 설계 등 그래프 입구에서 사용. 등록한 입구에 직접 호출·별칭 차단 | 중 |
| 그래프 검토·웹 내보내기의 복제는 JSON 직렬화에 의존 | 코드 관습 | 자료 복제는 deepcopy. 외부 데이터 해석은 지정된 디코더 | 소 |
| 리뷰 컴포넌트가 네트워크와 화면 상태를 함께 처리 | 제품 설명과 테스트 | 준비된 로컬 전송을 모듈에 격리. 화면 빌드는 직접 네트워크 및 호스트 메시지와 승인되지 않은 모듈 의존을 거절 | 중 |
| 저널이 배열·객체를 문자열 집합과 바로 비교 | HTTP 핸들러의 넓은 예외 처리 | 자료 경계에서 정확한 거절과 쓰기 없음. 상태 재제출과 관측 커서를 생성 테스트에서 확인 | 중 |
| 검증 원본이 작업 디렉터리·백업과 함께 쌓임 | 정리 절차의 권고 | 검증 도구가 소유한 임시 디렉터리에서만 로그·캡처를 만들고 종료 시 정리. 작은 결과 영수증만 지속 | 중 |
| 파일 경로·흐름별 재현 명령이 담당자에게만 있음 | 산문·리뷰 | 그래프, CLI, API, Chromium UI, 릴리스 프로필에서 재실행. PR에 근거를 앞에 둠 | 소 |

| 규칙 위치 | 결정적으로 확인할 조건 | 사람 또는 실제 환경에서 확인할 조건 |

| AGENTS 경로, 헌법 검증 산출물, CONTRIBUTING 배포 | 추적 및 아카이브 검사, 소스 기록 지문, 관리된 임시 파일 정리 및 외부 파일 보존 | 사용자 원본과 최종 인수 자료의 보관 여부 |
| AGENTS 기본 환경, 헌법 기능 채택 | 상태와 증거의 정본 그래프 연결, 실제 CLI·패널·제어 검증 프로필 | 실제 Design 파일에서의 수락 및 디자인 품질 |
| Figma Flow·Graph SSOT 스킬과 그래프 참조 | 그래프 디코더, 관계 타입, 동기화 및 네이티브 읽기 계약 | 의도·사용자 선택을 적용하는 판단 |
| Plugin Setup 스킬과 브라우저 참조 | 매니페스트 투영, 출처 설정, 사용 범위와 시작 분기 검사 | 대상 파일, 로그인 및 설치 동의 |
| Campaign Identity·디자인 참조 | 에셋 영수증, 핀, 폰트 및 패키지 검증 | 브랜드 방향과 타깃의 시각적 적합성 |
| Patch Knowledge 스킬과 기여 가이드 | Git 원본 지문, 불변 기준 재현, 릴리스 추적과 증거 검사 | 기록 내용과 주장 범위에 대한 독립 리뷰 |

## 정리한 것과 보존할 것

| 분류 | 위치 또는 경계 | 판정 |
| --- | --- | --- |
| 반복 설명 | Graph Review 가져오기 앞의 설명 | 실제 변환에 해당하지 않는 위치에서 제거했다. 공통 디코더로 직접 연결한다. |
| 우회·중복 | 선택된 그래프 소비 함수와 리뷰 패널 | 파서 호출과 전송 책임을 구조에 옮겼다. JSON 복제 우회는 자료 복제로 바꿨다. |
| 현재와 다른 설명 | 유지보수 검증 가이드의 원본 로그·UI 캡처 보존 | 기록 방식과 같은 작은 영수증·즉시 정리 규칙으로 바꿨다. |
| 필요한 근거 | 외부 라이선스, 호스트 승인, 계정·권한 제약, 모델이나 타임아웃 해석 | 소스 또는 스킬의 도메인 설명을 유지한다. |

전체 Git 추적 규칙 경로, Python 주석과 원시 디코더의 위치는 `python3 -B tools/maintenance.py audit`에서 재현한다. 정적 검색에 나타난 일반 JSON 설정과 호환성 기록은 의미를 확인한 뒤 판정한다. 자동 결과는 후보 분류이며 검색 결과만으로 기존 위반이나 삭제 대상을 판정하지 않는다.
