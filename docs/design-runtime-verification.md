# Figma Design 실측 기록

Figma Flow는 Design에서 피그마 컴포넌트를 편집하고 프로토타입을 재생하며, 기획·개발 근거를 같은 파일에서 확인한다. 독립 보드나 슬라이드 덱을 만드는 경로는 0.32.0에서 제거했다. [제품 헌법](../CONSTITUTION.md) · [전용 설계서](../specs/design-specialization/spec.md)

## 클라우드와 프로토타입

Desktop에서 미동기화 안내를 확인하고 로컬 Design 사본을 별도 저장했다. 저장한 파일의 ZIP 무결성과 `canvas.fig` 항목을 확인한 후 원래 문서를 다시 연결했다. 자체 플러그인이 새로 만든 프레임 ID를 사용해 별도 Chrome 세션에서 같은 파일을 열었다. 웹 편집기가 같은 ID와 레이어 이름을 선택했다. 이 검사는 해당 프레임이 서버에 도달했음을 확인한다. 검사 후 Desktop이 다른 보류 변경의 안내를 다시 표시해 파일 전체의 저장 완료 상태는 미확인으로 남긴다. [Figma의 오프라인 저장 안내](https://help.figma.com/hc/en-us/articles/360040328553-What-can-I-do-offline-in-Figma)

대상 편집 계정의 팀 선택 목록에는 무료 팀만 있었다. Figma 공식 예제의 기존 영상 채우기로 Design 프로토타입을 열어 재생 상태, 해상도 1920×1080, 길이 18.033초를 확인했다. 연속 표본의 재생 시점은 16.378초, 17.681초, 반복 후 0.863초였다. 영상 영역의 픽셀도 함께 바뀌었다. 공급된 Portfolio MP4의 신규 업로드는 해당 초안에서 요금제 조건으로 거절됐고, 이 영상들은 원본에서 추출한 프레임으로 표시된다. [Figma 영상 예제](https://www.figma.com/community/file/1155152691809198766) · [지원 요금제와 기존 채우기 편집](https://help.figma.com/hc/en-us/articles/8878274530455-Use-videos-in-prototypes)

## 복합 마스크와 필터

[브라우저 기준 예제](../examples/web-design-css-effects/index.html)는 선형·래디얼 알파 마스크를 `intersect`로 결합하고, 블러 뒤에 그림자를 적용한다. 마스크 레이어별로 정본에 모양과 색 정지점을 남기고 Figma에서 중첩한 네이티브 마스크를 읽었다. CSSOM이 기본 중심을 생략한 래디얼 배경을 처음에 빠뜨려 브라우저의 색 면이 Figma에서 흰색으로 나왔다. 기본 중심을 복원한 뒤 같은 영역에서 6개 표본을 비교했다.

| 영역 | 수정 전 | 수정 후 |
|---|---:|---:|
| 래디얼·선형 마스크의 교차 | 119 | 2 |
| 블러와 그림자 | 167.5 | 2 |
| 필터 없는 래디얼 원본 | 167 | 1.5 |
| 단색 면의 밝기·채도 필터 | 0 | 0 |

수치는 표본별 RGB 채널 최대 차이의 중앙값이며 단위는 0~255다. 단색 면에 `brightness(120%) saturate(150%)`를 적용한 중심은 양쪽 모두 `#825e3a`였다. 이미지 전체에 걸친 색 행렬, 마스크의 합집합·차집합·배타합, 지원되지 않는 복합 필터는 캡처 제한에 남긴다. 지원하는 효과만 임의로 꺼내 잘못된 합성 결과를 만들지 않는다.

## Canvas

Magic UI SaaS의 실제 800×800 canvas를 브라우저에서 PNG로 읽어 해시를 고정했다. Figma에서는 위치·클리핑·원형 알파 마스크를 유지한 이미지 레이어로 가져왔다. 반투명 점 영역 1,830픽셀의 브라우저 대비 RGB 평균 절대 차이는 2.913/255였다. 점이 나타나는 좌우 경계는 축소한 내보내기에서 1픽셀 이내였다. 애니메이션은 측정 시점의 정지 화면으로 보존된다. 새 이미지의 최초 내보내기와 재실행 결과를 구분해 두었다.

실제 교차 출처 이미지로 오염된 canvas에서는 브라우저가 픽셀 읽기를 거절했다. 사용자가 제공한 동일 뷰포트 스크린샷에서 캔버스의 측정된 영역만 잘라 입력으로 사용했다. 240×120 원본 crop이 스크린샷의 해당 픽셀과 일치했다. 안정된 Figma 내보내기의 비교 영역은 평균 절대 차이 0.181/255였다. 화면에 합성된 결과와 원시 canvas는 출처·자르기 좌표·해시로 구분한다. [캡처 및 대체 절차](web-design-capture.md)

## Design 서비스 검사

```sh
python3 tools/design_api_inspect.py --file-key FILE_KEY --page-id PAGE_ID \
  --plugin-id FIGMA_ISSUED_ID --out PRIVATE_NEW_DIRECTORY
```

새 디렉터리의 그래프에서 검사할 멤버와 생성 코드를 검토하고 manifest를 Design 개발 플러그인으로 등록한다. 지정한 페이지에 표본 프레임과 샘플 스타일·변수가 생성된다. 같은 그래프를 다시 실행하면 마커가 일치하는 표본을 찾는다. 다른 문서의 노드 콘텐츠, 변수 값, 사용자 문자열이나 토큰은 공개 영수증에 담지 않는다. 서비스 속성·반환값·메서드는 정적 정책에 등록된 정확한 선언으로 연결한다. 선택되지 않은 편집기의 타입과 인터페이스를 단순 열거해 성공 수에 넣지 않는다. [서비스 증거 그래프](../specs/design-inspection/service-observations.json) · [Design 노드 증거 그래프](../specs/design-inspection/scene-observations.json)

## API 우선순위와 남은 범위

0.31.0 시점에는 고정된 공식 선언 1,382개 중 189개를 관측했고 1,193개가 미관측이었다. 이번에는 중복을 제외한 368개 멤버에 새 실행 근거가 생겼다. 누적 557개, 잔여 825개다. 계정·편집기 제약, 실행 시나리오가 필요한 메서드와 수신 객체가 없는 타입을 포함한 전체 목록을 보관한다. Design 전용 제작 범위와 기존 릴리스의 역사적 누계는 별도 필드로 표시한다.

- Design 페이지, 문서 루트, 텍스트 경로, 슬롯과 컴포넌트 등 실제 객체에서 속성을 읽었다. 같은 플러그인에서 소유 마커를 확인한 컴포넌트의 인스턴스 1개와 연결된 메인을 읽었다. 서로 다른 플러그인의 개인 마커로는 이 읽기가 거절된 사실도 보존한다. [장면별 영수증](../specs/design-inspection/scene-observations.json)
- 서비스 검사에서는 269개 고유 항목 중 241개가 성공했다. 15개는 값 미제공, 13개는 런타임 오류였다. 표본을 다시 사용한 검사는 새 멤버로 중복 집계하지 않았다. [서비스 관측 그래프](../specs/design-inspection/service-observations.json)
- 별도 표본에서 그리드 행·열, 텍스처·유리·블러, 벡터 경로 및 프로토타입의 실제 반환값을 검사했다. 네이티브 필드 62개를 확인했고, 클릭·드래그와 DISSOLVE·MOVE_IN의 실제 반환 분기도 기록했다. 선언에 별도 멤버 키가 없는 분기는 API 누계에 더하지 않는다. [반환값 관측 그래프](../specs/design-inspection/value-observations.json)

```sh
python3 tools/review_api_coverage.py
python3 tools/api_priority.py build --out .figma-flow/design-inventory.json
python3 tools/api_priority.py queue --inventory .figma-flow/design-inventory.json --design-only --format graph
```

## 이전 제작 경로 정리

FigJam·Slides의 생성기·레시피·사용법과 해당 전용 테스트를 제거했다. 기존 보드 2개와 덱 3개는 먼저 전체 로컬 사본을 보관했다. 이전 레시피의 원본 그래프 해시, 노드 마커 및 실제 슬라이드 ID 명단에 맞는 보드 객체 129개와 슬라이드 111개(행 37개)를 정리했다. 파일 자체와 백업, 고정된 과거 릴리스는 보존했다. 과거 릴리스의 API 실측은 역사적 누계를 재현할 수 있도록 그 버전에 연결한다.
