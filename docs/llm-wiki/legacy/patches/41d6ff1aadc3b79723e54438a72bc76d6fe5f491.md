## 문제와 계기

동일 px 크기의 서로 다른 텍스트 역할이 값만으로 혼동되고 호환되지 않는 속성이 컴파일에서 조용히 사라지거나 표기 충돌할 수 있었다.

## 결과 동작

JS는 font size 역할을 실제 variable 연결로 식별한다. bridge는 token-type 불일치와 fontSize/font-size 또는 borderColor/border-color 중복 지정을 compile 시 거부한다.
