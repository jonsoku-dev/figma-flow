# Codex 작업 보존과 선택 표의 패치 기록

## 문제와 계기

등록한 Figma 패널을 단순하게 만든 뒤 기존 작업이 어디서 실행되는지와 실제로 확인한 결과를 함께 남길 필요가 있었다.

## 결과 동작

`be4e79f2e9a6cdc4495dc0874e60b6261ddbce39`에서 Codex 경로를 추가한 소스와 실제 Figma의 읽기·선택 결과를 Wiki에 연결했다.

## 변경 파일과 인터페이스

`CHANGELOG.md`, `docs/llm-wiki/releases.md`와 Git catalog, 커밋별 문서를 바꿨다.

## 설계 이유와 출처

준비물, 범위가 고정된 명령, 기기 이력과 서버 결과를 각각 추적한다.

## 호환성·이관·복구

이 커밋은 기록 발행이며 등록한 작업이나 디자인 편집에 영향을 주지 않는다.

## 검증과 미검증

Git에서 변경 경로와 대상 소스 커밋을 확인했다.

## 한계와 후속 개선

Present 재생 및 유료 Dev Mode 실기 여부는 당시 기능 기록의 검증 범위를 따른다.
