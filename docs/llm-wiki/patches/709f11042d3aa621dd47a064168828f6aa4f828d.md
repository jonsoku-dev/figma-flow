# feat(semantic-components): implement NF-01 six-family additive workbench, property bindings, override/placement preservation, and readback

## 문제와 계기

개별 컴포넌트 속성 API 호출을 넘어 6개 정본 패밀리(`field`, `input`, `checkbox`, `radio`, `table-row`, `table-cell`)를 기존 캔버스와 충돌 없는 가산(additive) 워크벤치로 조립하고, 재적용 시 사용자 오버라이드(`TEXT`/`BOOLEAN`/`INSTANCE_SWAP`)와 위치 배치를 보존하며 readback까지 검증할 런타임 모듈이 필요했다.

## 결과 동작

커밋 `709f11042d3aa621dd47a064168828f6aa4f828d`는 기존 `figma-bridge/semantic_components.js`의 `ensureSemanticComponents` 경로를 크게 확장하고 `tests/nf01_semantic_family_runtime.cjs`를 신설해 6패밀리 가산 워크벤치, preflight 검증(허용되지 않은 패밀리·미선언 변형 거부), 재적용 시 오버라이드·좌표 보존, readback 수집을 구현했다. 최종 실기 결과의 `19`변형·`8`인스턴스 수치는 이후 인수 근거다.

## 변경 파일과 인터페이스

`figma-bridge/semantic_components.js`(수정), `tests/nf01_semantic_family_runtime.cjs`(신규).

## 설계 이유와 출처

기존 페이지 위의 사용자 컴포넌트(`radius=16` 등)를 덮어쓰지 않는 독립 워크벤치 이름 공간과 재적용 시 편집 보존을 런타임 단위로 캡슐화하기 위함이다.

## 호환성·이관·복구

기존 일반 프레임/프로토타입 적용 경로와 별도 모듈로 분리되어 있다. 중복 표시명 실제 키 보전 및 보호된 자식 노드 제거 실패 시 최상위 롤백 root 제한은 후속 `974b5de7`에서 강화됐다.

## 검증과 미검증

`tests/nf01_semantic_family_runtime.cjs` 단위/통합 테스트와 이후 `f9ba8978` 무조건 통합 테스트가 통과했으며 최종 실기 Figma Desktop에서 `6`패밀리/`19`변형/`8`인스턴스(`108`노드), 수동 편집 3종+이동(`60,48`) 재적용 보존을 직접 확인했다.

## 한계와 후속 개선

초기 커밋에서는 `examples/owned-component-families/design.json` 부재 시 일부 통합 테스트가 skip 조건을 갖고 있었고(`f9ba8978`에서 무조건 실행 전환), 중복 표시명/최상위 롤백 엣지는 `974b5de7`에서 수정됐다.
