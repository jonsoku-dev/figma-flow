# release: document and version the no-hook carousel workflow for 0.33.0

## 문제와 계기

캐러셀의 수동 사용법과 실제 재생 기준, 배포 버전이 기존 안내에서 식별되지 않았다.

## 결과 동작

헌법·에이전트 규칙·설계 그래프에 기본 사용 환경을 명시하고 0.33.0 설치/실행 예제를 갱신한다.

## 변경 파일과 인터페이스

변경 경로는 `.codex-plugin/plugin.json`, `AGENTS.md`, `CONSTITUTION.md`, `README.md`, `docs/guide.md`, `docs/next-roadmap/NF-09-interactive-web-design.md`, `plugin.json`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

사용자는 로컬 Chromium과 작업 패널만으로 진행할 수 있어야 하므로 Computer Use와 hook은 개발 검증 환경에만 사용했다.

## 호환성·이관·복구

포크는 이 커밋과 부모의 변경 경로를 대조해 적용할 수 있다. 캐러셀 CMS나 외부 계정 연결은 필요하지 않다. 원본 화면과 사설 영수증은 로컬에 보존한다.

## 검증과 미검증

네 카드를 390×844에서 관찰해 총 열두 전이와 실제 Figma 프레젠테이션을 대조했다. 자동재생과 수동 양 끝 동작은 별도로 검증했다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
