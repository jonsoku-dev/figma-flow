# test: pin filtered SVG logo import

## 문제와 계기

Magic UI Devtool의 외부 로고가 단색 필터를 잃고 원래 브랜드 색으로 나타났다.

## 결과 동작

측정된 필터 순서, 단색 결과와 알파를 보존하는 기준을 제품 코드보다 먼저 고정했다.

## 변경 파일과 인터페이스

변경 파일: `tests/test_web_design_svg_capture.cjs`, `tests/test_web_design_svg_filter.py`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

기존 벡터의 채우기·선·none 처리를 비교해 원본의 투명 영역이 새 색으로 채워지는 경우를 잡는다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

기존 코드에서 캡처 필드와 단색 변환이 유지되지 않았다. 후속 구현 후 같은 기준 파일로 성공했다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
