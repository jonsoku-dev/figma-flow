# test: follow the retained Design acceptance node in the shared review graph

## 문제와 계기

공유 review graph가 `TEST-plan` 대신 `OBS-plan`을 보존하도록 바뀌어, 선택 projection 검사가 더는 현재 정본 ID를 따라가지 않았다.
## 결과 동작

selection regression은 현재 graph의 실제 관측 근거 노드 `OBS-plan`을 선택하고, 같은 source에서 다른 노드 집합을 선택했을 때 selection hash가 다름을 확인한다. 빈 ID 목록은 전체 graph 선택을 뜻하므로 잘못된 빈 목록 사례도 검증 입력에서 제외한다.
## 변경 파일과 인터페이스

변경은 `tests/test_review_graph_projection.py`의 선택 ID와 거절 사례에 한정된다. 제품 recipe, SDK API, 기존 graph 파일은 바꾸지 않았다.
## 설계 이유와 출처

검사는 이동한 대상 ID를 고정하지 않고 현재 Design review graph의 정본 노드를 선택한다. 그래프 projection은 선택한 노드와 그 사이의 직접 관계만 보존한다.
## 호환성·이관·복구

제품 동작이나 Figma 파일을 변경하지 않는다. 원래 graph와 이전 릴리스의 테스트 근거는 그대로 남는다.
## 검증과 미검증

`python3 -m unittest tests.test_review_graph_projection`에서 현재 source graph의 선택 projection과 잘못된 선택 거절을 확인했다. 이 검사는 graph projection만 실행하며 Figma 런타임을 주장하지 않는다.
## 한계와 후속 개선

이 수정은 테스트가 현재 source graph를 따라가게 한다. 실제 화면 작성·선택 identity는 별도 Design runtime 경로에서 확인해야 한다.
