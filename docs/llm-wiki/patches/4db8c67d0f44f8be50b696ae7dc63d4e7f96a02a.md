# fix: fingerprint file identifiers in distributable font observations

## 문제와 계기

0.27.1부터 버전 관리된 두 글꼴 보정 fixture와 생성된 DOM 맵에 실제 Figma 파일 식별자가 포함돼 있었다. 0.28.0 ZIP을 만들며 이를 발견했다.

## 결과 동작

보정 자료와 새 DOM 맵은 원본 파일의 SHA-256 지문만 보관한다. 같은 원본을 대조할 수 있으며 사용자 파일로 이동 가능한 식별자를 배포하지 않는다.

## 변경 파일과 인터페이스

`apps/little-hands/design/source.py`, 두 native-font-calibration JSON 및 `apps/little-hands/design/dom-map.json`의 보정 provenance 필드를 교체했다.

## 설계 이유와 출처

폭·높이·글꼴·원본 증거 해시는 보존하면서 개인 문서로 이동하는 식별자를 공개 배포에서 제거했다. 기존 자료에서 파일 키를 읽을 때도 출력에는 동일한 해시를 사용한다.

## 호환성·이관·복구

이전 형식의 개인 보정 자료도 계속 읽는다. 로컬 원본을 보존하고 과거 공개 태그와 Git 이력은 다시 쓰지 않았다. 과거 R6 보호 자료의 역사적 SHA는 그대로 둔다.

## 검증과 미검증

수정 전 ZIP 스캔은 기존 3개 파일을 식별했다. 수정 후 44개 실제 캡처로 재생성하고 디자인 18개 검사를 통과했다. 동일 graph SHA를 유지했으며 새 ZIP의 파일 트리와 7개 실제 비공개 문자열을 검사해 일치 0건을 확인했다.

## 한계와 후속 개선

이 수정은 새 checkout·설치 ZIP의 파일 내용을 바꾼다. 과거 태그나 이미 다운로드된 ZIP은 이전 바이트를 보존한다. Figma 파일 접근 제어와 공유 권한은 편집기에서 관리한다.
