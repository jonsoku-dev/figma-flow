# 화면별 관측 영수증 독립 검사 초안

## 문제와 계기

서로 다른 화면에 속한 관측의 연결 오류를 포착하는 기준이 필요했다.

## 결과 동작

`a7c6d59b76929d375d7f11c0a88b716cb352adf1`에서 화면 두 개와 실제 형식의 프레임·영수증으로 교차 연결을 재현하는 사례를 추가했다.

## 변경 파일과 인터페이스

`tests/test_spec_paired_receipts.py`가 합성 자료를 사용해 잘못된 연결의 거절을 요구했다.

## 설계 이유와 출처

정상 사례와 교차 연결·치수·다이제스트 변경을 분리했다.

## 호환성·이관·복구

기존 사용자 그래프나 측정 기록은 수정하지 않는다.

## 검증과 미검증

초기 검사에서 루트 메타데이터 키가 잘못돼 실제 기능 검사가 실행되지 않는 결함을 발견했다.

## 한계와 후속 개선

이 초안만으로는 원래 검사기의 거절 실패를 증명할 수 없다. 바로 다음 기준 커밋에서 루트 등록까지 검증했다.
