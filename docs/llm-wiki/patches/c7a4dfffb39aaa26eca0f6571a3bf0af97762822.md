# test: require hug fill and fixed sizing to follow text and parent resize

## 문제와 계기

선언한 hug, fill, fixed는 처음 배치한 뒤 긴 한글 문구나 부모 Frame 크기가 바뀌어도 다시 계산되지 않았다. 이 커밋 c7a4dfffb39aaa26eca0f6571a3bf0af97762822의 검사는 refreshDeclaredContainerSizing이 없어 `declared hug fill and fixed sizing must follow text and parent resize`로 실패한다.

## 결과 동작

tests/rd02_container_sizing_oracle.cjs는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 제목 높이가 커져도 copy의 fixed 너비는 유지되고 hug 높이는 자식 상자 끝을 따른다. actions의 fill 너비는 부모 card 너비를 따른다. 저장 instance의 type과 main id, 화면 Frame의 ID와 clip은 유지된다.

## 변경 파일과 인터페이스

tests/rd02_container_sizing_oracle.cjs만 추가했다. figma-bridge/direction_review.js는 이 커밋에서 바꾸지 않았다. 검사는 node tests/rd02_container_sizing_oracle.cjs로 직접 실행한다.

## 설계 이유와 출처

RD-02 작업 5는 resize와 긴 한글 문구에서 선언한 크기 관계를 확인한다. 글꼴 엔진을 추가하지 않고, 호출자가 준 현재 상자를 hug/fill/fixed 규칙으로 다시 적용한다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 네이티브 노드를 만들지 않는다. containers가 없는 기존 패킷은 이 파일만으로는 바뀌지 않는다.

## 검증과 미검증

로컬 실행은 종료 코드 1이고 stderr의 마지막 assertion은 `declared hug fill and fixed sizing must follow text and parent resize`다. 실제 글꼴 측정과 Figma reflow는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 mock 상자다. 구현은 별도 커밋 4ebdb77a73746f95dc985507b2ba0d704975cf9c에서 검사 blob을 유지한 채 추가한다. AC-03의 실제 편집기 관찰은 통과로 기록하지 않는다.
