# docs: define observed web interactions and prototype acceptance

## 문제와 계기

모션과 스와이퍼가 있는 웹 화면을 한 번의 정지 화면 가져오기와 동일하게 취급할 수 없었다.

## 결과 동작

관찰한 입력·상태·전이와 편집 가능한 Design 표현을 연결하는 설계 및 Cursor 인수 절차를 추가했다.

## 변경 파일과 인터페이스

변경 파일: `docs/next-roadmap/NF-09-interactive-web-design.md`, `docs/next-roadmap/README.md`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

실제 Devtool 탭 왕복을 예로 들고 자유 스크롤, 카드 스냅, 원본 시뮬레이션을 구분했다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

Devtool 브라우저에서 카드 클릭 후 표시 코드가 변했다가 원래 상태로 복원됐다. 해당 동작의 Figma 자동 변환 및 프레젠테이션 재생은 미검증이다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
