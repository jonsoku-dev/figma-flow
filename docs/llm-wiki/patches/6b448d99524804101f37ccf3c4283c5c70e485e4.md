# test: pin SVG root opacity import

## 문제와 계기

SVG 벡터의 CSS 불투명도가 그래프에 있어도 네이티브 루트는 전부 불투명했다.

## 결과 동작

실제 JSX나 브라우저 렌더러 없이도 가져오기 경로에서 루트 opacity와 내부 SVG가 구별되는지 검사하는 독립 기준을 고정했다.

## 변경 파일과 인터페이스

변경 파일: `tests/test_web_design_svg_root_opacity.cjs`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

중첩 그룹의 opacity나 SVG 내부 채우기를 모두 고치는 접근은 원본의 알파 합성을 훼손한다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

수정 전에 네이티브 루트 기대값 0.4가 1이었고, 내부 그룹 마크업은 동일했다.
