# test: pin orphan candidate preservation across blocked epoch and retry

## 문제와 계기

독립 검증에서 CSS epoch 차단 후 삭제 후보 근거가 사라졌으므로 재현 조건을 고정할 필요가 있었다.

## 결과 동작

실제 작은손 디자인을 임시 복사하고 REQ-006에 메모를 남긴 뒤 소스에서 제거한다. 매니페스트 불일치와 정상 복원을 거쳐 상태 보고를 검사한다.

## 변경 파일과 인터페이스

apps/little-hands/design/test_regeneration.py에 실패·복원 시나리오를 추가했다.

## 설계 이유와 출처

후보가 처음 생성된 시점과 다음 재시도의 상태를 재생성 명령의 실제 출력으로 연결한다.

## 호환성·이관·복구

회귀 검사만 추가하는 커밋으로, 원본 그래프·기존 런타임 동작은 그대로다.

## 검증과 미검증

부모 구현의 차단 상태에서 orphan_candidates가 누락되는 증상을 앞선 독립 재현으로 확인했다. 이 최초 테스트 커밋만의 별도 실행은 이 검토에서 재측정하지 않았다.
