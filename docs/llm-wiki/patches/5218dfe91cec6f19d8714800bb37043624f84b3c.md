# RC3 명시적 등록의 첫 기록

커밋 `5218dfe91cec6f19d8714800bb37043624f84b3c`

## 문제와 계기

임시 workspace를 PC의 기본값으로 저장하던 동작과 복수 후보의 암묵 선택을 바로잡고 첫 기록을 묶었다.

## 결과 동작

CHANGELOG와 Wiki에 명시적 remember, 선택이 필요한 setup-status, 저장소 테스트 실행기의 범위를 남겼다.

## 변경 파일과 인터페이스

이 커밋은 CHANGELOG.md, docs/llm-wiki/catalog.json, releases.md, 패치 페이지 세 개를 갱신한다.

## 설계 이유와 출처

부모 제품 커밋과의 차이는 기록뿐이다. 직접 실행하는 검사 프로세스는 이후 별도 근거로 추적한다.

## 호환성·이관·복구

이 후보와 최초 검사 결과는 보존한다. 사용자의 PC 설치나 원격 배포 상태를 바꾸는 커밋이 아니다.

## 검증과 미검증

합성 CLI 시험에서는 등록 의도가 없는 경로의 원래 레지스트리가 보존됐다. 이후 독립 검수에서는 직접 검증기 세 개에서 XDG 상속 문제가 재현됐다.

## 한계와 후속 개선

이전 후보에서 열었다 닫은 패널을 후속 제품의 왕복 성공 근거로 사용하지 않는다.
