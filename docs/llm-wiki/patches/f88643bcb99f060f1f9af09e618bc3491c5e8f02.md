# test(bridge): add frozen Node-to-Python readback test for disambiguated property keys

## 문제와 계기

JS 런타임은 충돌 안전·Figma 정규화 실제 키를 기록하게 됐지만 Python `compare_declared_component_properties`는 표시명 접두 개수를 요구해 같은 결과를 거절할 수 있었다. 수정 전에 언어 간 고정 검사가 필요했다.

## 결과 동작

커밋 `f88643bcb99f060f1f9af09e618bc3491c5e8f02`는 `tests/test_bridge_declared_property_compare.py`를 추가했다. 실제 `code.js` 실행 snapshot을 Python 비교기에 넣어 `test_accepts_disambiguated_duplicate_display_keys_from_real_code_js_snapshot`, `test_accepts_figma_auto_renamed_keys_from_real_code_js_snapshot`, `test_rejects_shared_keys_contract_mismatches_missing_definitions_and_unsuffixed_keys`를 검사한다.

## 변경 파일과 인터페이스

`tests/test_bridge_declared_property_compare.py`(신규, 393줄)만 추가했다.

## 설계 이유와 출처

실패 기반 개선 절차에 따라 검사를 먼저 고정하고, 같은 검사로 base 실패와 target 통과를 비교하는 공식 gate의 base로 사용했다.

**공식 Python gate와 checker pin.** 독립 공식 개선 gate는 base `f88643bcb99f060f1f9af09e618bc3491c5e8f02` → target `e6f4fd848a11cd292d9f8d9f50dad54ccb53ea10`, scope `tools/figma_bridge.py`, 고정 검사 `tests/test_bridge_declared_property_compare.py`, criterion `READBACK-KEY`로 실행됐다. base는 `Lists differ` 2건으로 `rc=1`, target은 3개 테스트 통과로 `rc=0`이었다. gate checker는 `tools/patch_knowledge_check.py` blob `1b8ff502f08a8edd61c599afdf504943df46d9f1`이며, 이 blob은 `452acf1302bdc37269a31977773a7f277e45d212` 트리의 같은 파일과 동일하다. 앞선 gate 시도는 호스트 디스크 부족(`No space left on device`)으로 실행 실패했고, 그 로그는 보존하되 성공으로 소급하지 않는다. 이후 격리 환경 재시도가 통과했다.

## 호환성·이관·복구

테스트 전용 커밋이다. 이 커밋의 제품 코드에서는 수용 테스트 2개가 실패하는 것이 의도된 기준선이다.

## 검증과 미검증

공식 gate base로 실행돼 `Lists differ` 2건 `rc=1`을 기록했다. 최종 `e6f4fd8`에서는 이 파일을 포함한 NF-01 Python 비교기 suite `24/24 OK`와 CI Run `43599181267`이 통과했다.

## 한계와 후속 개선

snapshot은 고정된 `code.js` 출력이므로 이후 JS 키 형식이 바뀌면 snapshot과 검사도 함께 갱신해야 한다.
