# test: pin the full native read beside the getters it actually uses

## 문제와 계기

같은 fixture의 full 네이티브 읽기와 실제 getter 목록이 함께 고정되어 있지 않았다. 이 커밋 f943bc9f1f316f0f7c6624087e1bba2c1b6f45eb의 검사는 nativeReadGetterLedger가 없어 `full native read must record the getters it uses`로 실패한다.

## 결과 동작

tests/rd06_full_getter_ledger.cjs는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 full.nodes의 rect.width는 12이고 fills는 빈 배열이다. getters에는 rect.width와 rect.fills가 있고 rect.exportAsync는 없다. 같은 fixture를 다시 읽어도 getter 목록은 같다. readNativeSemantics(figma, page) 서명은 유지된다.

## 변경 파일과 인터페이스

tests/rd06_full_getter_ledger.cjs를 추가했다. reader 구현은 이 커밋에서 바꾸지 않았다. 검사는 node tests/rd06_full_getter_ledger.cjs로 실행한다.

## 설계 이유와 출처

RD-06 작업 1은 요약 profile 전에 full 반환과 실제 getter 목록을 고정한다. 기존 호출은 인자 없는 full이다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 기존 reader 반환 schema는 바꾸지 않는다.

## 검증과 미검증

로컬 node 실행은 종료 코드 1이고 stderr의 assertion은 `full native read must record the getters it uses`다. 실제 Figma 문서는 읽지 않았다.

## 한계와 후속 개선

실패 기준은 mock 노드다. 구현은 별도 커밋 9c9d5575eea6d883620407e591972c7e92cc244f에서 검사 blob을 유지한 채 ledger를 추가한다. 요약 profile은 아직 없다.
