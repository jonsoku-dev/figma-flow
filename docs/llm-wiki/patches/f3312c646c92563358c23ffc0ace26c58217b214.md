# feat: bind reviewed external media to verified local SVG, video and raster bytes

## 문제와 계기

브라우저에서 본 SVG·비디오·외부 이미지 URL만 graph에 보관하면 가져오기 시점의 바이트, MIME 유형, redirect 대상과 안전성을 재현할 수 없었다. SVG 안의 외부 reference와 사설 host도 그대로 전달될 수 있었다.

## 결과 동작

`tools/web_design_media.py`는 캡처에 기록된 정확한 request URL을 제한된 정책으로 수집해 SHA-256과 MIME·signature를 함께 고정한다. redirect를 거절하고 credential URL·사설/loopback host를 차단하며, 승인된 정확한 localhost origin만 예외로 둔다. Raster는 signature를 확인하고 SVG는 허용 요소와 attribute 및 내부 gradient/clip reference만 정규화한다. Video는 source, bounded MP4 derivative, metadata와 0.5초 frame fallback을 별도 hash로 기록한다.

## 변경 파일과 인터페이스

`tools/web_design_media.py`가 asset index를 만들고 `tools/web_design_source.py`가 capture origin과 request target의 정확한 조합, 로컬 경로, SHA 및 MIME을 확인해 canonical graph에 바인딩한다. `tests/test_web_design_media.py`는 redirect refusal, host policy, signature, SVG allowlist와 exact-source binding을 검사한다.

## 설계 이유와 출처

네트워크 요청은 브라우저가 관측한 request target과 response bytes 사이를 재현 가능하게 연결한다. DNS 주소가 모두 public인지 확인하며 응답의 redirect URL이 원래 request와 다르면 사용하지 않는다. SVG는 제한된 language subset으로 변환하고 video는 metadata·크기·duration bound를 확인한 결과만 사용한다.

## 호환성·이관·복구

기존 local raster asset은 계속 지원한다. 외부 media는 검토된 asset index와 바이트 근거를 제공해야 한다. 일반 이미지 응답 한도는 8 MB, video는 100 MB다. 누락·redirect·지원하지 않는 type은 omission으로 남기고 원래 capture를 덮어쓰지 않는다.

## 검증과 미검증

이 commit만 검사했을 때 media test는 8/9 통과했다. 마지막 SVG gradient test는 이전 `validate_svg`가 internal gradient paint를 허용하지 않아 실패했다. 후속 `1c8427e`가 내부 gradient/clip 검증을 추가했다. 최신 frozen candidate에서 67개 관련 Python과 web-design Node 19개, workspace-control Node 9개가 통과했다. 최종 verification은 27 browser case와 54 signed renderings을 기록한다.

## 한계와 후속 개선

Figma는 native video paint를 유료 팀 파일에서 거절했다. 가져오기는 hash-pinned first-frame fallback을 사용했고 native video import를 성공으로 세지 않았다. 비공개 host, redirect된 URL, 미지원 SVG syntax와 signature가 맞지 않는 media는 계속 제한된다.
