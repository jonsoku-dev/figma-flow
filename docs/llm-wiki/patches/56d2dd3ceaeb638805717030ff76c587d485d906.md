# feat: build a reusable native typography component from exact ranked API members

## 문제와 계기

The exact ranked API candidates needed a small, reproducible real editor task to inspect native typography operations and verify that a reusable component retained its structure after updates.

## 결과 동작

A graph-declared typography lab creates a reusable native component, exercises selected font and text-range APIs, and checks the main component plus four text children on repeat. The API list and evidence graph remain exact-key linked.

## 변경 파일과 인터페이스

`docs/design-type-review.md`, `library/figma-recipes/design-type-review.graph.json`, `design-type-review.ts`, generated bundle, `tools/design_type_review_graph.py`, `tools/figma_feature.py`, and SDK build integration add the use case.

## 설계 이유와 출처

The lab starts from API rows with reviewed receiver and scenario requirements. It separates actual Figma reads/writes from type declarations and emits a sanitized observation graph for exact API members.

## 호환성·이관·복구

The feature is additive to the recipe registry. Existing recipe IDs, install data and other task history are preserved. Regenerate and pin bundles through the existing recipe build process.

## 검증과 미검증

The typography lab read 19 exact member IDs and added 10 distinct members to the 140-member set. The current total is 150 of 1382, leaving 1232 unobserved. Repeat reads preserved native range metadata and the component’s four text children.

## 한계와 후속 개선

This is a bounded specimen workflow, not a claim that all API members or all font families work. GeistSans alias requests resolved to actual Geist styles, and receipts retain the family alias notice.
