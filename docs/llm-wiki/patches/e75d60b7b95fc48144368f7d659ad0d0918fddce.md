# docs: record 0.27.1 fixes and release evidence

## 문제와 계기

0.27.1 변경을 기록할 때 canonical 이력 219개와 보존 계보 39개를 함께 설명하고, 제품 변경·문서 발행·실행 결과를 분리할 필요가 있었다. 이 커밋은 제품 코드를 바꾸지 않고 Wiki의 6개 추적 파일에 patch 상세와 릴리스 기록을 추가·갱신했다. 이 커밋 뒤 시작한 원격 CI에서는 앱 workflow가 PostgreSQL 연결에서 실패했고 전체 검사 workflow는 WOFF2 변환 의존성 누락으로 실패해 후속 수정이 필요해졌다.

## 결과 동작

Wiki에는 0.27.1의 기존 startup/YAML 수정, 고정 재현 검사, 후속 CI 문제와 릴리스 근거를 연결하는 설명이 생겼다. `catalog.json`은 이력 인덱스를 갱신하고, patch 페이지들은 각 전체 SHA의 변경과 검증 경계를 기록하며, `releases.md`는 제품 소스와 문서 발행을 구별한다. 이는 기록 발행이며, 그 자체로 0.27.1 전체 검사나 배포·설치·Figma 인수를 뜻하지 않는다.

## 변경 파일과 인터페이스

첫 부모 `ee4f40a0eb3ceef5b87697a13b2768ae0dc1a67e` 대비 여섯 변경 경로는 `docs/llm-wiki/catalog.json`, 네 개 patch 페이지(`23b44e3…`, `25b6f75…`, `e0aeed2…`, `ee4f40a…`), `docs/llm-wiki/releases.md`다. 공개 도구 인터페이스나 제품 설정은 바뀌지 않았다. 기록은 기존 `docs/llm-wiki/README.md`의 metadata 및 8개 본문 항목 계약을 따른다.

## 설계 이유와 출처

전체 Git SHA를 페이지 식별자로 사용하고, 제품 소스 커밋과 Wiki 발행 커밋을 구분해 같은 버전의 변경을 합치지 않는다. 이 페이지는 실제 변경 파일과 첫 부모 대비 diff를 `git show e75d60b7b95fc48144368f7d659ad0d0918fddce`로 대조했다. 원격 후속 실패의 구체적인 분류도 실행된 workflow의 결과에 한정한다: 앱 run `43339869591`은 DB 접속 단계에서 포트 55439에 연결하지 못했고, 전체 검사 run `43339869559`는 WOFF2 변환에 필요한 Brotli 모듈 부재로 실패했다. 이는 당시 원인 기록이지 이 문서 커밋이 해당 문제를 수정했다는 뜻은 아니다.

## 호환성·이관·복구

Wiki JSON과 Markdown의 저장 형식은 유지된다. 제품 파일, 사용자 프로젝트 데이터, 설치 파일에는 마이그레이션이 없다. 이 문서만으로 누락된 Git 객체를 복구하거나 배포 상태를 바꾸지 않는다. 페이지를 다른 저장소로 옮길 때는 해당 저장소의 Git 객체와 링크 존재 여부를 다시 확인해야 한다.

## 검증과 미검증

실제 커밋 diff는 metadata에 적힌 여섯 경로 및 첫 부모와 일치한다. 이 발행은 당시 219 canonical 및 39 legacy 기록과 0.27.1 문서 변경을 반영했다. 후속 앱 CI 실패는 `DATABASE_URL`만 설정되고 앱이 소비하는 `LH_DB_*`가 제공되지 않아 로컬 기본 포트 55439가 선택된 문제로 확인됐다. 전체 검사 실패는 당시 환경의 Brotli 부재였다. 현재 부모 작업은 clean archive의 새 가상환경에서 글꼴 변환, design 16, Python 전체 검사, finalize 75, Node 299, demo 2를 확인 중이며 아직 결과가 모두 확정되지 않았다. 따라서 이 페이지는 그 검사들의 최종 통과, 세 원격 workflow의 후속 성공, 0.27.1 tag/ZIP/install/native 재읽기를 주장하지 않는다. 이전 0.27 제품의 Figma 관찰은 이번 커밋의 새 native 검증이 아니다.

## 한계와 후속 개선

Wiki의 설명과 기록 검사만으로 실행 결과의 진실성이나 제품 인수를 보장하지 않는다. `catalog.json`에 표시된 커버리지와 각 항목의 상세 근거를 함께 읽고, 원격 CI·패키지·설치·native 결과는 실제 후속 영수증이 나온 뒤 판단해야 한다. 사용자의 개인 경로, 인증값, 원시 사용자 데이터는 이 페이지에 포함하지 않는다.
