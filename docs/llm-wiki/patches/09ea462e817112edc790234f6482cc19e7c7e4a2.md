# fix: preserve filtered SVG logo silhouettes

## 문제와 계기

네이티브 루트 opacity만 적용해도 브라우저가 brightness(0)과 invert(1)로 흰색 처리한 로고는 여전히 여러 색이었다.

## 결과 동작

허용된 CSS 색 함수 순서를 그래프에 기록한다. 단색임이 확정될 때만 외부 SVG의 단순 색을 바꾸고, 그렇지 않으면 원본과 시각적 한계를 남긴다.

## 변경 파일과 인터페이스

변경 파일: `tests/test_web_design_svg_capture_limits.cjs`, `tests/test_web_design_svg_filter_limits.py`, `tools/web_design.py`, `tools/web_design_capture.js`, `tools/web_design_media.py`, `tools/web_design_source.py`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

해시가 고정된 SVG를 기반으로 투명·none·클립 및 경로를 유지한다. 긴 체인이나 지원하지 않는 페인트는 전체 화면 거절로 이어지지 않아야 한다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

캡처·바인딩·범위 검사를 통과했다. 실제 Devtool 로고 6개는 네이티브 벡터 경로 26개를 유지했고 이전에 채도가 남았던 5개 영역도 브라우저처럼 고채도 픽셀 0개였다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
