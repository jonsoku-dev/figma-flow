# Chromium 채팅 오류 메시지의 반영 시점 검증

커밋 `06ce2b5439d18b0d0b2483cabce4f097a5b68945`

## 문제와 계기

아카이브 재실행 중 비동기 채팅 오류 이벤트가 React에 반영되기 전에 직전 안내를 읽어 간헐적으로 실패했다.

## 결과 동작

같은 메시지와 로케일 적용을 확인하고, 기존 예상 문구가 정확히 렌더링되면 카탈로그와 진단 검증을 마친다.

## 변경 파일과 인터페이스

tests/test_panel_browser_witness.cjs에서 기존 bounded until로 한국어·영어의 채팅 오류 상태를 기다린다.

## 설계 이유와 출처

오류 입력과 두 로케일의 정확한 비교값을 유지한다. 비동기 전달과 렌더 사이를 동기화한다.

## 호환성·이관·복구

제품 코드와 실제 채팅 내용을 유지한다. 테스트 소스가 바뀌어 영향을 받는 패널 증거는 이후 현행 아카이브에서 재실행한다.

## 검증과 미검증

이전 소스는 같은 아카이브의 두 번째 실행에서 직전 안내 문구를 읽어 실패했다. 교정 후 Chromium 여섯 번 연속 통과했다. Astra Ultra가 잘못된 오류 코드와 잘못된 언어도 각각 실패한 것을 확인했다.

## 한계와 후속 개선

Chromium의 컴파일 패널과 합성 호스트 메시지를 사용한다. 실제 Figma 문서의 편집 동작은 별도 검증이다.
