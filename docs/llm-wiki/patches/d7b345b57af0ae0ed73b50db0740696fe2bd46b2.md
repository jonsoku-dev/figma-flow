# d7b345b · CI에 Codex sandbox CLI 설치

이 기록은 원본 커밋 `d7b345b57af0ae0ed73b50db0740696fe2bd46b2`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

기존 CI의 sandbox 검사가 Codex CLI 실행 파일을 전제로 하는데, 워크플로가 이를 설치하지 않아 검사 재현성이 부족했다.

## 결과 동작

.github/workflows/test.yml에 @openai/codex@0.165.0 전역 설치와 codex sandbox 읽기 전용 호출을 추가했다. CONTRIBUTING.md는 해당 버전과 실행 파일 의존성을 알린다.

## 변경 파일과 인터페이스

CI job에서 codex sandbox -P :read-only -C ... -- node --version을 실행한다. 개발자 문서에는 Python·Node·Codex CLI 환경 요구가 추가됐다.

## 설계 이유와 출처

검사 환경에 명시적 CLI를 제공해 CI와 로컬 전제의 차이를 줄이려는 변경이다.

## 호환성·이관·복구

제품 API·데이터 형식은 바뀌지 않는다. 이후 macOS 네이티브 바이너리 설치로 교체되는 단계가 있으므로 이 CI 설치법은 후속 커밋 기준으로만 역사적이다.

## 검증과 미검증

워크플로 정의와 문서 diff만 확인했다. 실제 CI 성공 여부는 커밋 기록만으로 알 수 없다.

## 한계와 후속 개선

npm 전역 패키지의 실행 환경 차이와 OS별 샌드박스 동작은 이 패치에서 증명되지 않는다.
