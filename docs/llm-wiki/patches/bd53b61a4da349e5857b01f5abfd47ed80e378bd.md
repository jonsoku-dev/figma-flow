# test: require declared task dependencies to be normalized before publish

## 문제와 계기

서명된 catalogue가 명시적 dependency의 cycle과 잘못된 artifact를 publish 전에 거절하지 않았다. 이 커밋 bd53b61a4da349e5857b01f5abfd47ed80e378bd의 검사는 normalize_task_dependencies가 없어 `declared task dependencies must be normalized before publish`로 실패한다.

## 결과 동작

tests/test_rd03_task_dependencies.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 import-task의 uses-output edge만 남고 같은 project의 notes에는 선이 없다. 없는 target, self edge, 현재가 아닌 revision, 다른 relation, 등록되지 않은 artifact, hash 불일치, 중복 edge, cycle은 ValueError다. 실제 prepare는 그 edge를 서명된 catalogue에 저장하고 cycle publish는 거절한다.

## 변경 파일과 인터페이스

tests/test_rd03_task_dependencies.py만 추가했다. tools/figma_workspace.py는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd03_task_dependencies로 실행한다.

## 설계 이유와 출처

RD-03 작업 2는 선택적 dependency 입력, 정규화, DAG 검사를 서명된 catalogue에 둔다. 같은 project는 dependency가 아니다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 기존 catalogue를 바꾸지 않는다. depends_on이 없는 task의 revision 계산은 그대로다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `declared task dependencies must be normalized before publish`다. 작업 목록 UI는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 로컬 catalogue다. 구현은 별도 커밋 1f90f63bfeb1fa30a4dacd311daa9720dc25ae8f에서 검사 blob을 유지한 채 추가한다. 화면의 edge 목록은 아직 없다.
