# 규범 문서의 단일 절을 릴리스 근거로 사용하는 회귀 검사

## 문제와 계기

그래프의 필드 소유권은 규범 문서에서 정한 경우에도 정확한 위치와 실행 가능한 근거에 연결되어야 했다.

## 결과 동작

`283c9c2353bf54bb3938fe85ceb4ea0214b3fb15`에서 실제 Markdown 제목에 연결된 단일 unittest 사례를 기존 검수기를 통해 재현한다.

## 변경 파일과 인터페이스

`tests/test_major_document_authority.py`는 별도 임시 트리에 규칙 문서, 적용 파일, 테스트와 영수증을 생성한다.

## 설계 이유와 출처

정상 절 및 비어 있거나 중복된 절, 코드 블록에만 들어 있는 제목을 같은 함수로 검증한다.

## 호환성·이관·복구

독립 기준의 Git blob과 파일 모드를 고정해 제품 변경 뒤에도 같은 테스트를 재실행한다.

## 검증과 미검증

수정 전의 정상 제목 사례가 AssertionError로 실패했다. 수정 뒤 비교 결과는 제품 패치에서 추적한다.

## 한계와 후속 개선

임시 트리의 근거는 한 규칙의 해석 범위에 한정된다.
