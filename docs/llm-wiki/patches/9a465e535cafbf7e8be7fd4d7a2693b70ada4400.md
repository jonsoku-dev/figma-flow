# feat: place declared parents after existing leaf authoring

## 문제와 계기

기준 b40d9db3300bf8d7de01a0d70fef408d16f43b98는 선언한 부모를 기존 leaf에 붙이는 함수가 없어 `declared parents must reuse authored leaves`로 실패했다.

## 결과 동작

placeDeclaredLayerParents는 containers가 없으면 leaf를 옮기지 않는다. 선언한 트리는 화면 Frame 안에 card Frame, copy와 actions Auto Layout, ornament Group을 만들고 leaf의 화면 기준 좌표를 유지한다. 화면 Frame의 ID·크기·clip은 바꾸지 않는다. 없는 target은 새 노드 전에 거절한다. Group 생성이 실패하면 새 컨테이너만 제거하고 leaf를 원래 부모와 좌표로 되돌린다. prototype destination이 새 컨테이너 ID와 같으면 실패로 되돌린다. makeDraft는 기존 layer 작성 다음에만 이 함수를 호출하고, 선언한 fill은 기존 paint 경로로 칠한다.

## 변경 파일과 인터페이스

figma-bridge/direction_review.js에 placeDeclaredLayerParents를 추가하고 makeDraft의 leaf 루프 뒤에서 호출한다. 기하 검사는 선언한 부모와 화면 Frame 기준 절대 상자를 본다. containers가 없으면 기대 부모는 기존 화면 Frame이다. docs/development-roadmap/RD-02-layer-structure/tasks.md에 이 범위를 적었다. tests/rd02_container_placement_oracle.cjs blob은 기준과 같다.

## 설계 이유와 출처

RD-02는 좌표로 Group을 추정하지 않고 선언한 부모만 추가한다. Auto Layout 자식은 이 mock에서 layoutPositioning ABSOLUTE로 두어 화면 기준 상자를 유지한다. Group은 figma.group으로 기존 자식을 묶고 fill·clip·layout을 비운다.

## 호환성·이관·복구

containers가 없는 기존 패킷은 leaf 부모와 좌표를 바꾸지 않는다. 선언에 없는 노드는 화면 Frame에 남는다. 배치 실패는 기존 페이지 전체를 지우기 전에 새 컨테이너와 leaf 위치만 되돌린다.

## 검증과 미검증

종료 게이트가 기준 node 검사 종료 코드 1과 대상 9a465e535cafbf7e8be7fd4d7a2693b70ada4400의 종료 코드 0을 다시 실행했다. direction geometry·정렬·텍스트 측정 검사 33개도 통과했다. 실제 Figma 레이어 트리, prototype 왕복, resize와 긴 한글 문구는 관찰하지 않았다.

## 한계와 후속 개선

Auto Layout의 실제 reflow와 hug/fill의 문구 증가 동작은 아직 확인하지 않았다. 명세·주석·prototype reader 대조는 다음 단위다. AC-01은 통과로 기록하지 않는다.
