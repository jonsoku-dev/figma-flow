# feat: join real editor receipts into the default member coverage and priority graph

## 문제와 계기

API inventory rankings needed to use current, actual editor observations by default. The first queue knew declarations and a baseline graph but not the newly received typed probe receipts.

## 결과 동작

The default API priority build joins the sanitized exact-member observation graph and updates its observed/unobserved totals. It retains all audit members and marks observation only when a validated evidence node links to the exact member key.

## 변경 파일과 인터페이스

`tools/api_priority.py`, `tools/review_api_coverage.py`, `docs/api-priority.md`, and `specs/editable-web/api-observations.json` connect the receipts to the priority inventory. `--baseline-only` keeps the earlier queue available for comparison.

## 설계 이유와 출처

The evidence overlay is separate from the pinned API audit and from the priority score. Receipt metadata and member IDs are checked before status is promoted. A score remains only an order for future research.

## 호환성·이관·복구

Existing `build()` library calls retain baseline-only behavior. The CLI explicitly joins the observations graph. No probe method or product API is silently invoked during rank generation.

## 검증과 미검증

The updated baseline joins 50 distinct members from 253 typed-probe calls, increasing the prior 127 observed set to 140. The typography lab commit later adds 19 exact member IDs, 10 net new, for 150 observed and 1232 unobserved of 1382. Eight before/after graph audits passed.

## 한계와 후속 개선

A graph receipt stores a SHA and observation summary, not the raw Figma response. Overlay validation does not independently authenticate the origin of a supplied receipt.
