# 예약 버튼 인계 실패를 재현하는 기준

## 문제와 계기

실제 Design 페이지에서는 큰 읽기 결과가 릴레이에 전달되지 않았고, 수동 저장한 자료에도 인계 CLI와 작은 화면의 문제가 남았다.

## 결과 동작

검사 기준 커밋 `e69bc58d0ef5e0d7a2e127924d2ce23f6963cae5`은 큰 UTF-8 읽기와 이스케이프된 요청, 이미지 참조가 섞인 내보내기, 좁은 브라우저 표시를 재현한다.

## 변경 파일과 인터페이스

`tests/test_booking_result_transport.cjs`는 fetch에 전달된 경로와 호출 수를 확인한다. `tests/test_booking_handoff_regressions.py`는 임시 입력으로 CLI와 브라우저를 실행한다.

## 설계 이유와 출처

합성 자료를 사용해 실제 파일과 사용자 정보를 공유하지 않고 같은 경계와 인계 동작을 재현했다.

## 호환성·이관·복구

기준 커밋의 변경은 검사 파일 두 개에 한정된다. 플러그인과 서버는 당시의 소스를 그대로 실행한다.

## 검증과 미검증

구현 전 CLI의 혼합 자료 정렬 오류와 모바일의 가로 넘침을 관찰했다. UTF-8 읽기 전송은 일반 한도에서 실패했다.

## 한계와 후속 개선

브라우저가 없는 환경에서는 렌더링 검사를 건너뛸 수 있다. Figma 원본 수신은 별도의 실기 확인이 필요하다.
