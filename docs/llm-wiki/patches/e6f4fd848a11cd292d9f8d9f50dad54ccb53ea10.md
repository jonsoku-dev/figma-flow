# fix(bridge): accept collision-safe and Figma-normalized property keys in readback compare

## 문제와 계기

`tools/figma_bridge.py`의 `compare_declared_component_properties`가 `display#` 접두 후보 수와 표시명 개수 일치를 요구해, 중복 표시명 충돌 안전 키와 Figma 자동 정규화 키를 거절했다.

## 결과 동작

커밋 `e6f4fd848a11cd292d9f8d9f50dad54ccb53ea10`는 표시명 개수 계산을 제거하고, `declared_property_keys`의 실제 키가 `name#suffix` 형식이며 서로 겹치지 않고 `componentPropertyDefinitions`에 존재하는지, `declared_property_contracts`가 있으면 `id`·`name`·`actual_key`·`type`이 일치하는지로 키를 판정한다. 정의 맵은 변형마다 한 번만 읽는다.

## 변경 파일과 인터페이스

`tools/figma_bridge.py`(14줄 추가, 8줄 삭제)만 수정했다. 함수 시그니처와 결과 레코드 형식은 유지된다.

## 설계 이유와 출처

JS 런타임(`974b5de7`)이 기록한 실제 키 계약을 Python readback의 정본 판정 기준으로 써서 두 언어의 결과를 일치시킨다.

**공식 Python gate와 checker pin.** 독립 공식 개선 gate는 base `f88643bcb99f060f1f9af09e618bc3491c5e8f02` → target `e6f4fd848a11cd292d9f8d9f50dad54ccb53ea10`, scope `tools/figma_bridge.py`, 고정 검사 `tests/test_bridge_declared_property_compare.py`, criterion `READBACK-KEY`로 실행됐다. base는 `Lists differ` 2건으로 `rc=1`, target은 3개 테스트 통과로 `rc=0`이었다. gate checker는 `tools/patch_knowledge_check.py` blob `1b8ff502f08a8edd61c599afdf504943df46d9f1`이며, 이 blob은 `452acf1302bdc37269a31977773a7f277e45d212` 트리의 같은 파일과 동일하다. 앞선 gate 시도는 호스트 디스크 부족(`No space left on device`)으로 실행 실패했고, 그 로그는 보존하되 성공으로 소급하지 않는다. 이후 격리 환경 재시도가 통과했다.

## 호환성·이관·복구

기존 고유 표시명 키는 계속 통과한다. 계약이 없는 이전 메타데이터는 형식·중복·존재 검사만으로 판정한다.
