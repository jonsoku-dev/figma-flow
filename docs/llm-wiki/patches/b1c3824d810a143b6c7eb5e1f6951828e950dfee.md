# docs: record the refreshed Codex review handoff

## 문제와 계기

직전 Wiki 발행 df65b642와 그 뒤 Codex 최종 검토 handoff 142dfd97가 새 커밋으로 남아 카탈로그와 상세 기록을 다시 맞출 필요가 있었다.

## 결과 동작

catalog.json의 source_commit은 142dfd97로 이동하고 두 커밋의 metadata·본문 해시·상세 페이지가 추가된다. 문서 발행 자체를 기록하는 커밋이며 제품·테스트·버전은 바꾸지 않는다.

## 변경 파일과 인터페이스

catalog.json 및 patches/142dfd97…md, patches/df65b642…md의 세 파일이 변경되었다. metadata의 Git commit/tree/diff와 본문을 저장하고 원격 관측 항목을 확장했다.

변경 경로: [docs/llm-wiki/catalog.json](../../../docs/llm-wiki/catalog.json), [docs/llm-wiki/patches/142dfd97ed5bba73e787d99924a2693a3a86b61a.md](../../../docs/llm-wiki/patches/142dfd97ed5bba73e787d99924a2693a3a86b61a.md), [docs/llm-wiki/patches/df65b64205ed85644acf075f0acab8f37f2ac371.md](../../../docs/llm-wiki/patches/df65b64205ed85644acf075f0acab8f37f2ac371.md).

## 설계 이유와 출처

Wiki 발행과 handoff 갱신도 실제 Git 계보에서 누락하지 않는다는 기록 계약에 따른다. handoff는 후속 실행 권한이나 제품 성공의 증거가 아니다.

## 호환성·이관·복구

기존 Wiki와 legacy 계보를 교체하지 않고 두 기록을 추가한다. manifest 버전은 당시 0.26.3 그대로이며 protocol·실행 경로·설치 데이터 이관은 없다.

## 검증과 미검증

실제 diff를 정적으로 대조했다. 추가된 페이지는 142dfd97 당시 verify의 미기록 커밋 거절과 df65b642 당시 176 commits/문서 발행 1개 검증을 과거 결과로 기록한다. 그 보고를 이번 실행 영수증이나 제품 인수로 재사용하지 않는다.

## 한계와 후속 개선

이 발행 뒤의 checker baseline들과 미커밋 제품 개선은 별도 기록 대상이다. 이 커밋만으로 native Figma 재로드나 전체 앱 import가 검증되지 않는다.
