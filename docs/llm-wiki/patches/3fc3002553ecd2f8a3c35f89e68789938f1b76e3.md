# test: pin graph review admission and mapped asset evidence before release

## 문제와 계기

0.28.0의 네이티브 작업 CLI에는 일반 제품 graph를 기존 페이지의 검토 보드 작업으로 만드는 진입점이 없었다. HTML 입력에서도 캡처 URL을 로컬 바이트와 다시 대조할 수 있어야 했다.

## 결과 동작

제품 변경에 앞서 실제 선언된 입력과 CLI의 접근 가능성을 증명할 회귀 기준을 저장했다.

## 변경 파일과 인터페이스

`tests/test_native_graph_review.py`가 public graph-review 명령과 선택·소스 SHA 경계를 확인한다. `tests/test_input_effect_html_asset_map.py`는 동일 출처의 원본 및 변환 결과, 해시 변경과 격리 조건을 검사한다.

## 설계 이유와 출처

재현 입력과 기대 결과를 별도 커밋에서 보존하면 구현이 끝난 뒤 같은 기준을 다시 실행할 수 있다.

## 호환성·이관·복구

이 커밋 하나만으로 기존 설치본의 동작은 변하지 않는다. 후속 구현 전에는 새로운 경로의 실패가 예상된다.

## 검증과 미검증

기존 CLI에 graph-review --help를 전달한 독립 검사는 실제로 종료 2로 실패했다. 구현 커밋에서 동일한 테스트 파일과 모드로 종료 0을 확인했다.

## 한계와 후속 개선

명령의 존재 및 입력 핀 검증은 Figma 동작 인수와 별개다. 세 실제 편집기 검사와 매핑된 에셋의 정상 workspace 입장을 후속 기록에서 확인한다.
