# feat: read the partial token fixture without writing values

## 문제와 계기

기준 3f642cea8eaa461f35508b151b448233a0a4272a는 부분 적용 로더가 없어 `partial token selection must keep the unselected value and the alias bundle`로 실패했다.

## 결과 동작

load_selective_sync_fixture는 tests/fixtures/rd04/partial-apply.json을 읽어 selective_sync_condition에 넘긴다. 기본 선택은 color/action #0055ff와 color/quiet #8899aa만 applied이고 space/gap은 before 8로 preserved다. alias 묶음 type/body·type/size는 partial_allowed가 false이고 target은 button.font·text.font다. 묶음의 한쪽만 고르면 partial alias bundle, 빈 선택은 empty selection이다. 두 함수는 import_values와 _atomic_write를 호출하지 않는다.

## 변경 파일과 인터페이스

tools/graph_sync.py에 selective_sync_condition과 load_selective_sync_fixture를 추가했다. docs/development-roadmap/RD-04-selective-sync/tasks.md에 범위를 적었다. tests/test_rd04_selective_fixture.py와 tests/fixtures/rd04/partial-apply.json blob은 기준과 같다. build_plan은 이 로더를 호출하지 않는다.

## 설계 이유와 출처

RD-04의 첫 단위는 독립 token root의 부분 적용 조건과 alias 원자 묶음을 쓰기 전에 고정한다. 고르지 않은 값은 after가 아니라 before로 남는다.

## 호환성·이관·복구

기존 protocol v1 전체 적용은 그대로다. 이 함수는 fixture를 읽고 조건을 계산할 뿐 catalogue나 native 값을 바꾸지 않는다.

## 검증과 미검증

종료 게이트는 `python3 -B -m unittest tests.test_rd04_selective_fixture`를 기준 3f642cea8eaa461f35508b151b448233a0a4272a에서 종료 코드 1, 대상 5fb07911e3a1b1530f34aee2cca47f9df7319910에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 마지막 assertion은 `partial token selection must keep the unselected value and the alias bundle`이다. 조건은 RD-04-AC-01이다. 같은 구현에서 graph sync 검사도 종료 코드 0이었다. Figma에서 두 값만 바뀌는 적용은 관찰하지 않았다.

## 한계와 후속 개선

stable change identity와 선택 직렬화, 실제 transaction 적용은 아직이다. AC의 Figma 관찰은 통과로 기록하지 않는다.
