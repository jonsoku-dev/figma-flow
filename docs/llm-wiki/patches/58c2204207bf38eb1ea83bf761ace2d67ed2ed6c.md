# docs: publish 0.28.0 patch and verification records

## 문제와 계기

제품 소스와 위키의 연결을 확정한 뒤 개발 환경에서 실행한 검증 범위와 한계를 포크에서도 찾아볼 수 있어야 했다.

## 결과 동작

0.28.0의 실제 앱·Figma 검증과 API 판정 기준이 CHANGELOG 요약, Wiki 릴리스 항목, 각 커밋의 상세 기록에 연결된다.

## 변경 파일과 인터페이스

`CHANGELOG.md`, `docs/llm-wiki/releases.md`, `docs/llm-wiki/catalog.json`과 개별 patch 문서를 갱신했다. 제품 실행 인터페이스는 직전 소스 tree를 따른다.

## 설계 이유와 출처

실제 네이티브/브라우저 확인과 정적 선언·컴파일·미확인을 혼동하지 않도록 별도 출처와 SHA를 기록했다.

## 호환성·이관·복구

기존 0.27.1 원격 tag와 역사적 wiki를 보존했다. v0.28.0 요약에서 변경 이유와 재실행 방법을 확인할 수 있다.

## 검증과 미검증

발행 시점에 Wiki verify는 235개 소스 커밋과 문서 전용 발행 하나를 확인했다. GitHub 패치 지식과 운영 앱 검사도 성공했다. 실제 릴리스 ZIP 및 최종 태그 검증은 이후 별도 기록으로 남긴다.

## 한계와 후속 개선

문서 발행과 설치본 배포 시점은 다르다. 배포 파일 검사에서 발견한 과거 보정 자료의 Figma 파일 식별자에 대해서는 다음 수정과 새 설치본에서 확인한다.
