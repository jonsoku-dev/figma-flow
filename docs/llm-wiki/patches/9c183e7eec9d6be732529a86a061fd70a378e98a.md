# docs(wiki): record P1 NF-01, NF-03, and acceptance commits through 452acf1

## 문제와 계기

P1 NF-01·NF-03 제품 커밋과 인수 기록 커밋(`452acf1`까지)이 패치 카탈로그에 없어 `patch_knowledge.py verify --ref HEAD`가 미기록 커밋을 보고했다.

## 결과 동작

커밋 `9c183e7eec9d6be732529a86a061fd70a378e98a`는 P1 구간의 패치 페이지 28개를 8개 항목으로 작성하고 `docs/llm-wiki/catalog.json`을 동기화했다. `CHANGELOG.md` 미배포 절에 NF-01, NF-03, P1 CI 결과를 추가하고 `docs/llm-wiki/releases.md`에 `p1-design-acceptance` 절을 추가했다.

## 변경 파일과 인터페이스

`CHANGELOG.md`, `docs/llm-wiki/catalog.json`, `docs/llm-wiki/releases.md`, `docs/llm-wiki/patches/` 아래 페이지 28개, 모두 31개 파일만 바꿨다. 제품 소스·검사·인터페이스 변경은 없다.

## 설계 이유와 출처

[기록 계약](../README.md)은 모든 커밋을 전체 SHA로 식별하고 본문을 실제 diff로 채우도록 요구한다. 개별 페이지는 각 커밋의 diff와 [P1 인수 영수증](../../next-roadmap/p1-acceptance.md)을 근거로 했다.

## 호환성·이관·복구

기록 문서만 추가했다. 되돌리면 해당 커밋들이 다시 미기록으로 보고된다.

## 검증과 미검증

이 페이지 작성 시점에 이 커밋의 당시 `verify` 실행 출력은 보존돼 있지 않아 미검증이다. 후속 기록 커밋에서 `verify --ref HEAD` 통과 여부를 다시 확인한다.

## 한계와 후속 개선

기록 커밋은 자기 자신을 카탈로그에 넣을 수 없다. 바로 다음 커밋 `9962afa`는 카탈로그 두 줄만 바꿨고, 이 페이지는 P2 1차 Wiki 발행에서 처음 작성됐다.
