# perf: reuse bounded native font discovery during graph verification

## 문제와 계기

기존 프레임의 글꼴 별칭이나 대체 스타일을 실제 폰트 목록과 대조할 때 동일한 네이티브 목록이 중복 조회될 수 있었다.

## 결과 동작

같은 플러그인 실행에서 가용 글꼴 목록을 제한된 크기로 한 번 확보하고, 텍스트의 실제 표기와 정본이 일치하는 경우에는 조회 없이 진행한다.

## 변경 파일과 인터페이스

`figma-bridge/web_design.js`의 등록된 런타임마다 검증한 결과를 WeakMap에 보관한다. `tests/test_web_design.cjs`는 재사용 시 조회 횟수와 이미지 재사용을 함께 확인한다.

## 설계 이유와 출처

문서에서 읽은 로컬 글꼴 정보를 공유하는 범위를 현재 런타임으로 한정한다. 비동기 목록 읽기가 실패하면 다음 재시도에서 복구할 수 있다.

## 호환성·이관·복구

이 수정은 원본 그래프 형식이나 Figma 파일의 소유 범위를 바꾸지 않는다. 올바른 이전 프레임과 동일한 입력을 재사용할 수 있다.

## 검증과 미검증

네이티브 브리지의 9개 테스트가 통과했다. 이전 20/20/20px 프레임을 검출하고 현재 프레임의 실제 20/24/20px를 다시 읽었다. 출시 소스에 맞춰 타입스크립트 정적 API 기준도 재생성했다.

## 한계와 후속 개선

이 캐시는 한 실행 안의 글꼴 발견에만 적용한다. 다른 컴퓨터에서 같은 폰트 파일이나 렌더 픽셀이 제공된다는 의미로 사용하지 않는다.
