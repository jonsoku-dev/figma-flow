# test: require declared container links to match the native reader

## 문제와 계기

부모 배치 뒤에는 명세, 주석, prototype destination, 화면 기준 geometry가 실제 native reader와 같은지 보는 함수가 없었다. 이 커밋 8421b31163333c0b75e24e096ad6975d07138a33의 검사는 그 함수가 없어 `declared container links must match the native reader`로 실패한다.

## 결과 동작

tests/rd02_container_readback_oracle.cjs는 readDeclaredContainerLinks가 없으면 위 문구로 끝난다. 함수가 있으면 readNativeSemantics로 card Frame, copy·actions Auto Layout, ornament Group의 부모와 layout을 읽고, title의 화면 기준 상자, save의 주석·명세 상태·prototype destination을 대조한다. destination이 컨테이너 ID이면 실패한다.

## 변경 파일과 인터페이스

tests/rd02_container_readback_oracle.cjs만 추가했다. figma-bridge/direction_review.js는 이 커밋에서 바꾸지 않았다. 검사는 node tests/rd02_container_readback_oracle.cjs로 직접 실행한다.

## 설계 이유와 출처

RD-02 작업 4는 명세·주석·prototype과 geometry를 실제 reader로 대조한다. 작성기가 기억한 좌표가 아니라 readNativeSemantics의 부모 체인을 사용한다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 네이티브 노드를 만들지 않는다. containers가 없는 기존 패킷의 작성 경로는 이 파일만으로는 바뀌지 않는다.

## 검증과 미검증

로컬 실행은 종료 코드 1이고 stderr의 마지막 assertion은 `declared container links must match the native reader`다. 실제 Figma 레이어 트리와 prototype 왕복은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 mock reader다. 구현은 별도 커밋 946717804fcf45d0d4c85c3e624132ed0c48455f에서 검사 blob을 유지한 채 추가한다. AC-02의 실제 prototype 왕복은 통과로 기록하지 않는다.
