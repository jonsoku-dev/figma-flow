# f64d9a9 · 활성 네이티브 작업 동안 게시 차단

## 문제와 계기
워크스페이스 task 게시가 실행 중 native mutation과 겹치면 manifest/task revision 교체 시점과 편집이 충돌할 수 있었다.

## 결과 동작
`tools/figma_workspace.py`가 `require_idle_publication`으로 active native run을 확인하고 작업 중에는 게시를 거부한다.

## 변경 파일과 인터페이스
`figma_workspace.py`, guide/changelog, `tests/test_figma_control.py`, 신규 `tests/test_workspace_publish_guard.py`. publish 입력은 유지하고 precondition을 추가한다.

## 설계 이유와 출처
근거: 전체 커밋 `f64d9a9e592343a0910cec236d358cd841b8e207`; publication guard와 그 테스트. native 작업과 publication의 동시 변경을 막는다.

## 호환성·이관·복구
idle 상태에서 기존 publish는 동일하다. active 또는 uncertain mutation을 먼저 해결한 뒤 다시 게시해야 하며 이관은 없다.

## 검증과 미검증
새 guard 테스트가 추가됐지만 실행 결과와 실제 race 실행은 미검증이다.

## 한계와 후속 개선
모든 게시 경로가 공통 guard를 거치는지가 정확성 조건이다. 외부 수동 파일 교체는 이 경로로 제어되지 않는다.
