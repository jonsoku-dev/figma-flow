# docs: align FAQ selector, traversal, flow start, and independent gate evidence

## 문제와 계기

가이드가 실제 수집기와 다른 선택자를 예로 들고, 시작점 표시 이름과 순회 방법을 고정해 설명했다.

## 결과 동작

실제 아코디언 선택자를 사용하고 Figma가 자동으로 붙이는 이름 대신 시작 프레임 ID로 인수하도록 설명을 바꿨다.

## 변경 파일과 인터페이스

docs/guide.md의 세 언어 예제, specs/interactive-web/disclosure.md 및 설계 그래프, 후속 로드맵이 바뀌었다.

## 설계 이유와 출처

실제 소스는 스택에서 상태를 꺼낸다. 도달 가능 여부가 계약이며 탐색 순서나 표시 이름을 제품 계약으로 만들지 않는다.

## 호환성·이관·복구

기존 파일이나 시작점을 변경할 필요가 없다. 초기 좌표 오류와 성공한 재시도를 따로 기록했다.

## 검증과 미검증

한국어 안내의 두 명령을 그대로 실행해 실제 로컬 사이트에서 3화면·6전이 그래프 및 네이티브 계획을 생성했다. 동결한 검사에서 이전 공개 진입점의 실패와 수정 후 성공을 확인했다.

## 한계와 후속 개선

별도 수집은 새 타임스탬프를 생성한다. 같은 바이트라는 검사는 원본 관측을 재컴파일한 그래프와 계획, 별도 수집은 PNG와 입력 결과에 각각 적용된다.
