## 문제와 계기

선택 속성 변경을 이미 보고한 뒤에 기준값을 다시 설정하면 늦게 온 SDK 변경이 중복 기록될 수 있었다.

## 결과 동작

동일 값의 기준 갱신을 사이에 두고 늦은 같은 속성 이벤트와 다른 속성 이벤트를 준다.

## 변경 파일과 인터페이스

## 설계 이유와 출처

두 경로가 같은 값의 한 사건을 관측할 때 범위를 좁혀 검사한다.

## 호환성·이관·복구

기존 별도 속성 변화 또는 실제 다음 편집은 검증에 포함된다.

## 검증과 미검증

기준 코드에서 opacity가 중복됐고 같은 사례가 구현 수정 뒤 통과했다.
