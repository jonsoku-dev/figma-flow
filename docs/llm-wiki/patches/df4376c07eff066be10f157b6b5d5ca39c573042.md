# 검증 대용량 원본의 독립 재현

## 문제와 계기

검증이 끝나도 실행 로그와 화면 캡처가 결과 디렉터리에 쌓였다.

## 결과 동작

검증이 소유한 임시 자료와 사용자가 소유한 파일을 구별하는 실패 재현을 고정했다.

## 변경 파일과 인터페이스

`tests/test_verification_retention.py`에서 1MB 합성 원본과 인접 백업을 만든다.

## 설계 이유와 출처

성공, 오류, 시간 초과와 UI 캡처에 동일한 수명 규칙을 적용한다.

## 호환성·이관·복구

검증 외부의 사용자 파일은 읽거나 이동하는 대상으로 취급하지 않는다.

## 검증과 미검증

기준 코드는 원본 폐기와 단일 결과 파일 단언에서 실패했다. 동일 파일로 정상·실패·시간 초과를 검증했다.

## 한계와 후속 개선

테스트는 검증 러너가 만든 파일과 사전에 만들어 둔 외부 합성 파일을 사용한다.
