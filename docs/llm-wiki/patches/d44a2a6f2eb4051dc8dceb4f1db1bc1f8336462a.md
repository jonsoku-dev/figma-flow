# feat: replay exact previously observed members without reopening the ranked queue

## 문제와 계기

After the responsive-web evidence entered the default overlay, the safe probe correctly exhausted the unobserved keys covered by its static property and method allowlist. Repeating one already observed member on a currently installed version then required rebuilding an exception around the ranked queue.

## 결과 동작

A private selection can now supply 1–16 `recheck_member_ids`. Every key must already have successful audited evidence, be supported by the selected real receiver and static output projection, and use candidate offset zero. Ordinary selections still come from the current feasible unobserved queue.

## 변경 파일과 인터페이스

`tools/native_api_probe.py` validates exact recheck IDs against the observed inventory and each selected receiver before creating a plan. `tests/test_native_api_probe.py` proves the explicit recheck path and rejects keys outside the admitted observations or receivers. `docs/api-priority.md` documents the private selection contract.

## 설계 이유와 출처

Rechecks are kept separate from exploration: the user names exact audit keys and selected native receivers, while the normal queue continues to omit already observed members. The probe does not accept arbitrary property names or allow a recheck to manufacture new evidence just because a key was requested.

## 호환성·이관·복구

The field, method and safe projection allowlists remain shared. No API member changes its status or role in the priority queue; read-only recheck plans retain the current file/page scope and bounded getter budget.

## 검증과 미검증

On the frozen d44a2a6 source, `PYTHONPATH=tests python3 -B -m unittest tests.test_native_api_probe tests.test_api_priority` passed 15 tests. This verifies planning and rejection behavior; the commit does not contain a new native Figma recheck receipt.

## 한계와 후속 개선

A recheck confirms only the selected member on the selected receiver under the bounded projection. It does not make the rest of the 1,193-member unobserved queue observed or prove wider plugin/API support.
