# chore: refresh static API source hashes for the carousel release

## 문제와 계기

캐러셀의 신규 플러그인 경로와 수정된 호스트 소스의 현재 해시가 기존 고정 기준과 달랐다.

## 결과 동작

공식 SDK 선언과 대응되는 현재 소스의 정적 검사 기준을 다시 생성했다.

## 변경 파일과 인터페이스

변경 경로는 `library/figma-api/coverage-baseline.json`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

소스 언급 수와 실제 네이티브 호출 근거는 구분한다. 공식 Figma MCP를 사용하지 않는다.

## 호환성·이관·복구

포크는 이 커밋과 부모의 변경 경로를 대조해 적용할 수 있다. 캐러셀 CMS나 외부 계정 연결은 필요하지 않다. 원본 화면과 사설 영수증은 로컬에 보존한다.

## 검증과 미검증

고정한 TypeScript 컴파일러로 기준을 다시 읽고 기존 Design 레시피를 재생성했다. 레시피 파일의 내용이 유지됐음을 Git에서 대조했다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
