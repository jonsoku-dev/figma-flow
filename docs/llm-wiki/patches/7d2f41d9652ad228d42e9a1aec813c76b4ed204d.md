# 7d2f41d · 접근성 React 워크벤치와 범위 제한 제어 릴레이

## 문제와 계기
플러그인 패널의 기능별 UI와 워크스페이스 제어 흐름이 분산돼 다국어 적용 및 유지보수가 어려웠다. React 패널 패키지와 scoped relay를 한 릴리스 흐름에 도입했다.

## 결과 동작
`panel-ui/src/`에 Chat, Graph, Import, Review, Workspace UI를 분리하고 `build.mjs`로 정적 패널을 만든다. bridge UI가 이를 호스트하며 `workspace_control.js`와 `workspace_host.js`가 native task relay를 연결한다. locale JSON과 공용 panel helpers도 추가됐다.

## 변경 파일과 인터페이스
`panel-ui/src/ChatPanel.jsx`·`GraphPanel.jsx`·`ImportPanel.jsx`·`ReviewPanel.jsx`·`Workspace.jsx`, `panel-ui/build.mjs`, `figma-bridge/assets/panels.js`·`panels.css`를 함께 배포한다. `tools/figma_control.py`·`figma_workspace.py`와 `figma-bridge/workspace_control.js`가 정확한 파일·페이지·리비전의 허용된 작업을 요청하고 실제 읽기 결과와 로컬 영수증을 반환한다. `tools/figma_draft.py`는 실제 글꼴·텍스트 범위 바인딩을 확인한 뒤 텍스트 스타일을 연결한다. locale JSON·공용 액션/미리보기/내비게이션과 키보드 상태, 파일별 실행 이력·다음 작업도 포함한다.

## 설계 이유와 출처
근거: 전체 커밋 `7d2f41d9652ad228d42e9a1aec813c76b4ed204d`; `ChatPanel.jsx`, `GraphPanel.jsx`, `ImportPanel.jsx`, `workspace_control.js`, `workspace_host.js`, workflow 설정. UI 분리와 host-scoped 실행 경로를 추가한다.

## 호환성·이관·복구
manifest와 bundle을 함께 배포해야 한다. 로컬 relay는 workspace task 범위와 허용 작업을 따른다. 실제 host 설정은 사용자 환경에서 맞춰야 하며 Figma 데이터 migration은 없다.

## 검증과 미검증
CI workflow 및 패널 테스트 경로가 추가됐지만 커밋 내 실행 성공 기록은 없다. 실제 Figma UI 접근성 및 relay 연결은 미검증이다.

## 한계와 후속 개선
변경 규모가 커서 개별 기능별 회귀를 이 기록만으로 판단하기 어렵다. 접근성 의도와 실사용 검증은 구분해야 한다.
