# governance: bind the product constitution, agent instructions and authoring routes to Figma Design

## 문제와 계기

특화 범위가 말로만 남으면 일반 플러그인 카탈로그에 다른 에디터의 생성 기능이 다시 들어갈 수 있었다.

## 결과 동작

제품 헌법과 에이전트 작업 규칙, 직군별 Design 설계서 및 정본 graph를 연결했다. 모든 레시피를 공통 입구에서 Design/default로 검사한다.

## 변경 파일과 인터페이스

변경 파일은 `AGENTS.md`, `CONSTITUTION.md`, `README.md`, `docs/next-roadmap/README.md`, `library/figma-recipes/build.py`, `skills/figma-flow/references/figma-feature-routes.md`, `specs/README.md`, `specs/design-specialization/graph.json`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

브라우저 입력, 개발자 인계와 기획 검토는 Design 작업에 연결된 경우에 유지한다. 독립 제작·게시 기능은 카탈로그에서 제외한다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

일반 메뉴 외 레시피에 다른 editor를 넣는 경우도 거절하는 회귀, SDK·위젯 실제 manifest와 정본 설정 대조를 확인했다.

## 한계와 후속 개선

위 관측은 명시된 사용 장면에 해당한다. 다른 파일의 권한이나 실제 런타임 결과는 그 환경의 별도 영수증으로 확인한다.
