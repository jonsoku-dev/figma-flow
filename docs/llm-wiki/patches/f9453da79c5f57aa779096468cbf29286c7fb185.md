# docs: publish commit-linked release evidence and fork guidance for 0.30.0

## 문제와 계기

0.30 제품 코드와 실제 검증이 완료된 뒤 CHANGELOG·release evidence·fork 기록을 태그에 맞춰 보존할 발행 단계가 필요했다.

## 결과 동작

이 문서 전용 커밋은 0.30.0 변경 요약, patch catalog와 release page를 추가하고 `v0.30.0` 태그를 가리킨다. 제품 소스는 부모의 `c1541b8129bdf3e175dd905cddfed39acd52bc2e`에 있고 이 커밋 자체는 Plugin API나 런타임 코드를 바꾸지 않는다.

## 변경 파일과 인터페이스

변경은 `CHANGELOG.md`, `docs/llm-wiki/catalog.json`, 커밋별 patch 기록과 `docs/llm-wiki/releases.md`에 한정된다. release page는 제품 소스 기준과 문서·태그 커밋을 별도로 설명한다.

## 설계 이유와 출처

태그 대상은 문서 발행 커밋이며 제품 버전의 실제 소스 기준은 그 부모다. 두 SHA를 따로 기록해 docs-only publication을 기능 코드 변경으로 세지 않는다.

## 호환성·이관·복구

추가 설치 변경이나 데이터 migration은 없다. `v0.30.0` 태그는 f9453da를 가리키고, release asset 및 설치 검증은 기존 0.30 release page의 별도 evidence를 따른다.

## 검증과 미검증

`git show --stat f9453da`는 변경 범위가 changelog와 patch catalog/release 문서뿐임을 보인다. Git inventory에서 `v0.30.0`의 대상은 f9453da, manifest 버전은 0.30.0이다. 이 발행 커밋은 runtime 테스트나 설치를 다시 실행하지 않았다.

## 한계와 후속 개선

문서의 release evidence는 별도의 제품 source·CI·ZIP·설치 readback 결과를 대체하지 않는다. 0.30.0의 상세 인수 한계는 아래 버전 절에 기록한다.
