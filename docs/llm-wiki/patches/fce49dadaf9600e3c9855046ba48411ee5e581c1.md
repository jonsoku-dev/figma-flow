# feat: add activity viewer with pinned history oracle

## 문제와 계기

사용자는 Figma 패널을 실행 이력·차트·인과관계 중심으로 개선하고 향후 기능·최적화·아키텍처 작업을 Cursor에서 이어 갈 개별 문서를 요청했다. 컴포넌트 재사용과 Frame/Group 사용법도 공식 자료와 현재 코드로 조사했다. 이 커밋은 UI와 문서 및 다음 수정의 실패 기준을 함께 고정한 로컬 기준이며 그 자체로 릴리스 인수를 완료하지 않았다.

## 결과 동작

현재 task revision의 마지막 상태 분포, 실행 ID로 묶은 요청·진행·결과, 작업별 필터와 키보드 초점, 옛 비연결 이력과 전체 시간순 요약을 제공한다. 다운로드·채팅·이전 revision은 현재 완료 수로 집계하지 않는다. 현재 준비 작업들 사이의 dependency는 추정하지 않는다. 후속 개발8항목을 기능서·설계서·작업서와 공통 전달서로 나눈27문서로 제공한다.

## 변경 파일과 인터페이스

Workspace.jsx와 새 WorkspaceActivity.mjs/WorkspaceActivity.jsx는 집계와 표시를 분리한다. workspace_host/control은 실제 dispatch executionId를 추가하고 history는 안전한 선택적 ID를 저장한다. locale ko/en/ja와 생성 React 자산, guide, workspace-activity 스펙·graph, 두 plugin manifest의0.26.3 버전과 CHANGELOG를 갱신했다. Python journal과 실행 권한 API는 바꾸지 않았다.

## 설계 이유와 출처

UI history는 telemetry이므로 claimed나 시간순을 원인 증거로 올리지 않는다. 같은 task/revision/executionId만 연결하고 legacy는 시간순으로 남긴다. 별도 차트·animation dependency 없이 기존 token·Action/Section을 사용한다. 컴포넌트는 이미 재사용되지만 일반 TEXT 속성, 크기별 Layout 분화와 평평한 레이어를 개선 대상으로 구분했다. 공식 출처와 현재 심볼은 development-roadmap의 각 design.md에 있다.

## 호환성·이관·복구

최근80건 file-scoped 요약과 기존 task 실행을 유지한다. 잘못된 ID만 제거하고 legacy event를 지우지 않는다. runtime 재발행은15개 task key를 보존하되 UI artifact가 달라 revision을 재생성한다. 옛 실행은 이전 revision으로 남긴다. 원시 readback·secret과 private 경로는 공유 문서에 포함하지 않는다. 제안 API는 아직 구현되지 않았다.

## 검증과 미검증

실제 브라우저에서320/560/840px, light/dark, 필터·keyboard·실행 summary와 빈 상태를 관찰했다. 실제 Figma의 새 UI와 read 흐름은 후속 수정 소스에서 별도 확인했다. 이 기준에는 자동 validation 실패가 요청됨으로 남고 observed+throw 실패가 두 번 기록되는 두 재현이 의도적으로 남았다. tests/workspace_history_failure_oracle.cjs를 고정해 다음 구현 diff가 기준을 바꿀 수 없게 했다. 이 기준의 실패를 성공으로 발행하지 않는다.

## 한계와 후속 개선

차트는 전체 제품 인수나 클라우드 저장의 완료율이 아니다. 실제 작업 간 산출물 dependency는 RD-03, 영속 phase journal은 RD-08 제안이다. reduced-motion CSS는 포함하지만 OS 설정 전환의 실제 효과는 관찰하지 않았다. 미래8기능, 전체61개 회귀·실기기·font binary 검증을 완료한 것으로 표시하지 않는다.
