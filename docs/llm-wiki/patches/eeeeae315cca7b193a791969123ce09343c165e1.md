# feat: audit all 1382 Plugin API members against two pinned releases

## 문제와 계기

공식 타입 선언의 수와 단순 소스 참조만으로는 사용자가 실행할 수 있는 기능이나 실제 Figma에서 확인한 범위를 알기 어려웠다.

## 결과 동작

공개 Plugin API 1.142.0의 owner·member·signature 1,382개를 모두 기록하고, 0.27.1 배포 시점과 0.28.0 개발 후보에 대해 구현, 컴파일, 실제 관측, 명시적 미구현, 지원 조건, 미확인을 구분한다.

## 변경 파일과 인터페이스

`tools/figma_api_audit.py generate|verify`, `library/figma-api/audit/members.json`, `report.md` 및 `evidence/`를 추가했다. CI에 두 시점의 Git 기록과 TypeScript 5.9.3으로 결과를 재생성하는 검사를 추가했다.

## 설계 이유와 출처

v0.27.1 태그의 실제 커밋·트리와 4c3b392 후보 트리를 고정하고 정적 호출·테스트 문자열·실행 근거를 분리했다. 같은 메서드명 또는 미발견을 완료나 미구현의 근거로 사용하지 않는다.

## 호환성·이관·복구

포크는 출처 Git 객체와 태그, 공용 타입 선언을 보존해 결과를 재생성한다. 배포 ZIP에서는 인벤토리와 보고서를 그대로 읽을 수 있다. 실제 API 계정 권한은 Figma의 편집기·제품 접근 조건을 따른다.

## 검증과 미검증

독립적으로 고정 선언 1,382개와 인벤토리의 모든 owner·이름·서명 집합이 같은지 대조했다. 실제 compiler로 비디자인 예제 세 종류를 빌드했다. 0.28.0 대상 78개 관측, 3개 추가 구현, 12개 컴파일만 확인, 6개 제한된 내장 경로 미구현, 1개 경로 미지원, 1,282개 미확인이며 합계는 1,382다.

## 한계와 후속 개선

확인한 전체 멤버 구현 하한은 81/1,382, 실제 관측은 78/1,382이다. 실행 가능한 것으로 분류한 736개 중에는 각각 80개와 77개다. v0.27.1은 소스·검사 14개를 입증했고 동일 태그 대상 실제 실행 판정은 0개다. 남은 항목의 진짜 구현률은 정해지지 않았다.
