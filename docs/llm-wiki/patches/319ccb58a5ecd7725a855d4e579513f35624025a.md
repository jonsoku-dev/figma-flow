# Node 계약 검사와 나머지 제품군의 공통 실행 경계

커밋 `319ccb58a5ecd7725a855d4e579513f35624025a`

## 문제와 계기

직접 release 검사 네 경로 중 graph_governance.contract_proof만 부모의 설정 경로를 그대로 전달했다.

## 결과 동작

명명된 계약 검사와 나머지 Node 테스트 스위트가 같은 실행 함수를 거치며 각 호출에 독립된 임시 XDG를 전달한다.

## 변경 파일과 인터페이스

tools/graph_governance.py는 두 테스트 경로의 환경 소유권을 모은다. 문서·검토 지문과 tests/test_graph_governance.py를 가리키는 인수 간선을 함께 보강했다.

## 설계 이유와 출처

계약 검사는 기존 캡처·시간 제한·TAP 처리로 실행하고, 나머지 suite는 기존 스트리밍 출력과 종료 코드를 유지한다. 일반 Node 명령은 기존 실행기를 그대로 사용한다.

## 호환성·이관·복구

CLI의 명령명이나 계약 증인의 출력 스키마는 바뀌지 않는다. 외부 실행기 없이 직접 호출해도 같은 설정 격리가 적용된다.

## 검증과 미검증

같은 독립 프로브에서 유지보수, 아카이브 증인, 일반 Node 스위트, 명명된 Node 계약까지 네 경로 모두 private와 cleaned가 true였다.

## 한계와 후속 개선

파일 접근 자체를 차단하는 OS 보호와 임시 XDG를 분리하는 제품 동작은 별도 근거다. 전체 제품군·ZIP·독립 리뷰는 상위 검수 범위다.
