# 패키지에서 불러오는 명세 검사 경로 유지

## 문제와 계기

명세 검사를 Python 패키지로 직접 불러오는 단일 테스트는 스크립트 검색 경로에 의존할 수 없다.

## 결과 동작

f4e138702df5ae8e517d347a215de032416109b9에서 Python 모듈과 독립 CLI가 같은 그래프 원본 구현을 불러오게 했다.

## 변경 파일과 인터페이스

`tools/spec_graph_coverage.py`의 명시적 가져오기 경로를 갱신했다.

## 설계 이유와 출처

패키지 진입에서 유지한 동작을 묶음 테스트의 모듈 로드 순서에 맡기지 않는다.

## 호환성·이관·복구

기존 등록 명세 검사와 Python CLI 동작을 유지한다.

## 검증과 미검증

두 명세 검사 모듈을 독립 프로세스로 실행했다. 가져오기 오류와 수정 이후의 통과 결과를 확인했다.

## 한계와 후속 개선

이 수정은 브라우저나 Figma를 호출하지 않는다.
