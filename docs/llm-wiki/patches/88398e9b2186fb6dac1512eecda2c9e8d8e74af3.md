# test: require the selection count, select-all, and affected targets

## 문제와 계기

변경 행의 선택 수, 전체 선택, 영향 target이 고정되어 있지 않았다. 이 커밋 88398e9b2186fb6dac1512eecda2c9e8d8e74af3의 검사는 graphSelection이 없어 `selection rows must show the count and affected targets`로 실패한다.

## 결과 동작

tests/test_rd04_selection_rows.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 identity a만 고르면 count는 1이고 button.fill이 target이다. 선택이 없으면 count는 0이고, 전체 identity를 넘기면 count는 3이다. 입력 changes는 바뀌지 않는다.

## 변경 파일과 인터페이스

tests/test_rd04_selection_rows.py를 추가했다. 패널 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd04_selection_rows로 실행한다.

## 설계 이유와 출처

RD-04 작업 3은 기존 변경 행에 선택·전체 선택·선택 수·영향 target을 붙인다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 변경 목록이 비어 있는 기존 적용 메시지는 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `selection rows must show the count and affected targets`다. Figma 패널은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 changes다. 구현은 별도 커밋 d85d6388ae1c50a853278af33ca790a411b1e59e에서 검사 blob을 유지한 채 행과 번들을 추가한다. transaction 적용은 아직 없다.
