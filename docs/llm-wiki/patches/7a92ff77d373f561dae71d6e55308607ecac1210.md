# 숫자 루프백에서 직접 시작하는 제어 서버

커밋 `7a92ff77d373f561dae71d6e55308607ecac1210`

## 문제와 계기

macOS 실행기에서 표준 HTTPServer가 서버 이름을 구하며 역방향 DNS 조회를 기다렸다.

## 결과 동작

로컬 릴레이가 TCP 바인딩을 끝내면 이름 조회 없이 준비 요청에 응답한다.

## 변경 파일과 인터페이스

tools/figma_control.py의 제어 서버에서 숫자 주소를 바인딩하고 정책의 호스트 이름과 할당된 포트를 보관한다.

## 설계 이유와 출처

원격 스택 표본이 HTTPServer.server_bind 안의 socket.getfqdn에서 반복 관측됐다.

## 호환성·이관·복구

접속 주소와 인증, 명령행 결과, 준비 시간 제한은 기존 계약을 따른다.

## 검증과 미검증

실제 자식 CLI의 배너와 인증된 HTTP 200 응답 및 구현 지문을 확인했다.

## 한계와 후속 개선

검증 범위는 제어 서버의 로컬 시작이며 다른 HTTP 서버의 이름 처리에는 적용하지 않는다.

## 관련 기록

[릴리스 버전과 변경 근거](../releases.md#v1.1.1)에서 해당 버전의 검증 범위를 확인한다.
