# 동적 Design 페이지 변경 누락의 회귀 기준

소스 커밋 `2c67289ffe5599db2fb5dca835324a3549f340b6`

## 문제와 계기

P1의 저장된 저널에 세션 전환만 남고 노드 변경이 기록되지 않았다.

## 결과 동작

로딩 전 구독, 페이지 객체 교체, 늦은 로딩 완료, 임시로 비는 범위와 늦은 응답을 검증한다.

## 변경 파일과 인터페이스

`tests/test_workspace_changes.cjs`에 해당 경계를 재현하는 사례를 기록했다.

## 설계 이유와 출처

런타임 코드를 VM에서 실행해 단순 연결 여부와 실제 이벤트 수신을 구분한다.

## 호환성·이관·복구

비공개 디자인 파일의 내용 없이 작은 생성 입력으로 재현한다.

## 검증과 미검증

같은 검사 파일은 수정 전 13건 중 6건이 실패했다. 수정 뒤 동일한 검사 파일로 13건이 통과했다.

## 한계와 후속 개선

VM은 확인된 손실 조건을 재현한다. 과거 P1 세션에서 어느 분기가 발생했는지는 단정할 수 없다.
