# release: version 0.31.0 with 54 responsive screen receipts and route-linked evidence

## 문제와 계기

After screen-scoped reads, receipt validation, priority API observations and native-media work were committed, the 0.31 source needed one commit-linked graph and acceptance summary. The version change had to remain distinct from tag, artifact and installation evidence.

## 결과 동작

This commit updates the manifests and usage guides to 0.31.0, adds the route-linked responsive graph and records a 54-screen acceptance matrix. It reports 20 ordinary ZIP pages plus 7 error paths across desktop/mobile viewports, 7,481 editable nodes and 88 instances; 1,435 native VECTOR descendants are counted separately. It does not claim remote CI or installation completion.

## 변경 파일과 인터페이스

`plugin.json` and `.codex-plugin/plugin.json` set 0.31.0. `specs/responsive-web/graph.json` holds the route/viewport evidence. `docs/responsive-web-verification.md`, `docs/web-design-capture.md`, `docs/guide.md`, `README.md` and `specs/README.md` link the results and supported boundaries.

## 설계 이유와 출처

The screen graph connects the measured route and viewport to exact receipt evidence. Counts separate editable nodes, instances and VECTOR descendants. Browser-vs-native image differences are recorded as measurements, not treated as pixel equality.

## 호환성·이관·복구

The source version is updated without asserting a GitHub release tag or installed package. All evidence remains in repository-relative paths; the graph and report omit private file locators and raw user workspace identifiers.

## 검증과 미검증

In the candidate acceptance report, the 54 frames reuse the same IDs on reapply, exact media request pins are rechecked, 72 native masks have per-channel sample delta at most 1, and Figma readbacks count 1,978 DROP_SHADOW, 4 INNER_SHADOW, 106 LAYER_BLUR, 155 image fills and 1,435 vectors. The actual suite check on the frozen candidate passed 67 related Python tests, 19 web-design Node tests and 9 workspace-control Node tests. The separate full runtime release CI and installer verification remain pending.

## 한계와 후속 개선

Of 27 browser cases, four apps return generic 404 for unknown routes; Portfolio also returns a dynamic 404 and Devtool/SaaS return their source 500 state for missing dynamic records. These are recorded source responses, not importer successes. The current Figma account rejected native VIDEO paint and used the exact pinned raster fallback. The graph does not claim native-video playback or support for arbitrary CSS/media.
