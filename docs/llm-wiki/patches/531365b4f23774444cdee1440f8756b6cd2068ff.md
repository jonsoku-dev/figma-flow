# SDK가 콜백을 보내지 않는 선택 편집 재현

## 문제와 계기

로드가 끝난 P1 페이지에서 화면의 불투명도는 바뀌었지만 SDK 변경이 보고되지 않았다.

## 결과 동작

## 변경 파일과 인터페이스

`tests/test_workspace_changes.cjs`에 콜백 없는 편집과 SDK 이벤트 중복의 회귀 사례를 추가했다.

기존 이벤트 허용 목록과 선택 노드 수의 공통 한도를 시험한다.
