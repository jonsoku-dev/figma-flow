# fix: reject tab keys the Figma bridge would refuse at compile time

## 문제와 계기

독립 검수에서 Python은 `_tabs`나 한글 frame key를 받아들이고, Figma 브리지는 같은 계획을 거절하는 차이를 찾았다. 실패가 Figma 실행 단계에서야 드러났다.

## 결과 동작

컴파일러의 `TAB_KEY`와 캡처 CLI가 브리지와 같은 ASCII 규칙을 쓴다. frame key, 상태 ID, 전이 ID는 영문자나 숫자로 시작해야 한다.

## 변경 파일과 인터페이스

`tools/web_design.py`(`TAB_KEY`, `validate_tabs`), `tools/web_tabs_capture.mjs`, `tests/test_web_design.py`를 바꿨다.

## 설계 이유와 출처

엄격한 쪽인 브리지 규칙에 맞춰 계획 단계에서 거절한다. Python `\w`는 유니코드 글자를 포함하므로 명시적인 ASCII 문자 집합을 쓴다.

## 호환성·이관·복구

이미 만든 0.34 Devtool 그래프의 키는 새 규칙을 만족한다. 규칙 밖의 키로 만든 그래프는 새 ID로 다시 컴파일해야 한다.

## 검증과 미검증

`_tabs`와 `탭`은 frame key 오류로 거절되고 `devtool-examples`는 결합됨을 출력으로 확인했다. `tests.test_web_design`이 통과했다.

## 한계와 후속 개선

캐러셀 계약의 키 규칙은 이 변경에 포함하지 않았다.
