# feat: show a partial native summary in the import panel

## 문제와 계기

기준 e0f34c2d2db5673cc17a63bf8bb99489445c2492는 summary profile이 없어 `summary profile must name its partial coverage`로 실패했다. 작은 패널 조회가 전체 snapshot과 구분되지 않았다.

## 결과 동작

readNativeSemantics(figma, page)는 그대로 full snapshot을 반환한다. 세 번째 인자의 profile이 summary이고 필드가 x·y·width·height·visible뿐이면 schema figma-flow-native-read-summary-v1을 반환한다. coverage.complete는 false이고 styles·variables·rasterImages는 omitted에 있다. 요청한 rect.width는 full과 같은 12다. fills 요청은 이미지 closure가 필요하므로 full snapshot으로 돌아간다. summary getter에는 rect.width가 있고 rect.fills는 없으며 개수는 full보다 적다. ImportPanel의 NativeSummary는 그 결과만 보여주고, 너비와 높이 요청은 별도 버튼이 보낸다.

## 변경 파일과 인터페이스

figma-bridge/native_semantic_read.js의 공유 reader가 summary를 투영하고 nativeReadGetterLedger가 같은 요청을 전달한다. figma-bridge/code.js는 message.type이 native-summary일 때만 그 요청을 읽고 summary schema만 패널로 보낸다. panel-ui/src/nativeSummary.mjs의 nativeSummaryView와 panel-ui/src/ImportPanel.jsx의 NativeSummary, figma-bridge/assets/panels.js가 그 표시를 담는다. tests/rd06_summary_coverage.cjs blob은 기준과 같다.

## 설계 이유와 출처

RD-06 설계는 요약과 full verifier를 다른 reader로 복제하지 않고, full schema를 complete false로 조용히 줄여 전달하지 않는다. 선언 인자는 (figma, page)로 남아 기존 호출과 기존 검사가 같은 서명을 본다.

## 호환성·이관·복구

옵션이 없으면 full이다. discovery, import, export, native-edit의 기존 호출은 인자를 추가하지 않는다. 요약 버튼은 읽기 요청만 보내고 문서에 쓰지 않는다. 플러그인 버전은 0.26.3이다.

## 검증과 미검증

종료 게이트는 `node tests/rd06_summary_coverage.cjs`를 기준 e0f34c2d2db5673cc17a63bf8bb99489445c2492에서 종료 코드 1, 대상 4cf19fe6d9e8f20e9f256c238fca3f5a072ca9c3에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 assertion은 `summary profile must name its partial coverage`다. 조건은 RD-06-REQ-02다. 같은 구현에서 getter ledger, raster asset, readable spec native mock, 패널 bundle, bridge UI 검사는 종료 코드 0이었다. 실제 Figma 문서의 속도와 화면은 측정하지 않았다.

## 한계와 후속 개선

허용 필드 밖의 요청은 full로 돌아가며, 그 full 결과는 요약 UI로 보내지 않는다. full 소비자가 partial을 거절하는 negative test와 session cache는 아직이다. wall-clock 개선율은 통과로 기록하지 않는다.
