# docs: publish tracking, first preview and component edit evidence

## 문제와 계기

0.32.1의 회귀와 출시 근거를 포크에서 추적할 기록이 필요했다.

## 결과 동작

자간과 첫 미리보기의 실측, 메인·인스턴스 연결, 변경 감지 결과를 Wiki와 CHANGELOG에 발행했다.

## 변경 파일과 인터페이스

변경 파일: `CHANGELOG.md`, `docs/llm-wiki/catalog.json`, `docs/llm-wiki/patches/1430fdfbed0cc7862ff2bbf9648c2faf468cf3de.md`, `docs/llm-wiki/patches/4de75426dcdeeaccb336b227bbade370ae2dffdc.md`, `docs/llm-wiki/patches/91eb4ce74dc14d3160669bf1e96e329fbae5356c.md`, `docs/llm-wiki/patches/925aa87a8b7b16d7f7a7b64671bc3699933b091b.md`, `docs/llm-wiki/patches/abd3af873fa7cf47a02f7c8aeaa1825f46ac7e1c.md`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

이 발행 커밋의 원격 태그와 이전 소스 커밋을 구분한다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

실제 배포 ZIP의 1,587개 파일, 별도 Chrome의 새 프레임, 설치본에서 일곱 프레임을 다시 읽은 기록을 대조했다. 본문은 이전 버전에 해당한다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
