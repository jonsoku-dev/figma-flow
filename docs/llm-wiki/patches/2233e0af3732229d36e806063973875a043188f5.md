# 2233e0a · 네이티브 버튼 아이콘과 컨트롤 레이블 보존

## 문제와 계기
플러그인과 review controls의 버튼 아이콘·레이블이 업데이트 때 빠지거나 정렬이 틀어지는 것을 확인 가능한 계약으로 만들 필요가 있었다.

## 결과 동작
`figma-bridge/direction_review.js`와 palette/draft tooling이 native controls를 갱신하고, 테스트가 아이콘 존재·label 및 geometry를 검사한다. 설치·사용 가이드와 버전이 함께 조정됐다.

## 변경 파일과 인터페이스
22개 파일: bridge, `tools/figma_draft.py`, `tools/draft_token_plan.py`, plugin/panel manifests, docs, CJS·Python tests. 사용자 packet의 주요 schema 변화는 확인되지 않는다.

## 설계 이유와 출처
근거: 전체 커밋 `2233e0af3732229d36e806063973875a043188f5`; `direction_review.js`, `test_native_control_icons.cjs`, `test_native_control_icons.py`, native geometry 테스트. 검토 컨트롤의 의미와 정렬을 확인한다.

## 호환성·이관·복구
plugin/panel 버전을 함께 갱신한다. 기존 Figma 문서의 migration은 명시돼 있지 않으며 새 draft 경로로 재생성할 수 있다.

## 검증과 미검증
아이콘·레이블·geometry 테스트 코드가 추가됐다. 테스트 실행 및 실제 Figma 렌더 결과는 미검증이다.

## 한계와 후속 개선
정적 geometry는 실제 화면 크기·플랫폼 표시를 대체하지 않는다.
