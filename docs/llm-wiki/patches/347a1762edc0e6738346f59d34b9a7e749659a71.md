# 347a176 · 가이드 통합과 전용 브라우저 접근 설정

## 문제와 계기
사용 안내가 여러 파일로 중복돼 일관성을 유지하기 어렵고, 전용 브라우저 접근 설정이 분산돼 있었다.

## 결과 동작
기존 사용/설치 문서를 `docs/guide.md`로 통합하고 references를 갱신했다. `tools/browser_access.py`와 `skills/figma-flow/references/browser-access.md`가 localhost 및 Figma Flow 작업에 필요한 사이트의 격리 브라우저 접근 설정을 다룬다.

## 변경 파일과 인터페이스
문서 다수 삭제·추가 및 `browser_access.py`, `tests/test_browser_access.py`, skills/examples 링크 변경. 사용자 진입 문서가 `docs/guide.md`로 통일됐다.

## 설계 이유와 출처
근거: 전체 커밋 `347a1762edc0e6738346f59d34b9a7e749659a71`; guide, browser access tool/reference와 테스트. 접근 허용 설정과 사이트 행위 권한은 별개라는 원칙을 문서화한다.

## 호환성·이관·복구
기존 문서 경로 링크는 통합 문서 경로로 갱신됐다. browser 설정은 허용된 페이지 접근에 적용되며 게시·구매·계정 변경은 허용하지 않는다.

## 검증과 미검증
browser access 테스트 파일 추가는 확인되지만 실행 결과는 없다. 실제 브라우저 적용 설정도 커밋 증거로 확인되지 않는다.

## 한계와 후속 개선
하나의 큰 guide로 통합되어 문서 탐색성 유지가 필요하다. 자동 허용 대상과 실설정 일치 여부는 별도 확인 대상이다.
