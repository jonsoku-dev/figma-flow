# test: pin two independent token changes apart from one alias bundle

## 문제와 계기

독립 token 두 개만 적용하고 나머지 값을 남기며 alias 묶음을 쪼개지 않는 조건이 고정되어 있지 않았다. 이 커밋 3f642cea8eaa461f35508b151b448233a0a4272a의 검사는 load_selective_sync_fixture가 없어 `partial token selection must keep the unselected value and the alias bundle`로 실패한다.

## 결과 동작

tests/test_rd04_selective_fixture.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 tests/fixtures/rd04/partial-apply.json의 color/action과 color/quiet만 after가 적용되고 space/gap은 before 8이 남는다. type/body만 고르면 partial alias bundle이고 빈 선택은 empty selection이다. 묶음 전체는 type/body와 type/size를 함께 적용 조건으로 본다.

## 변경 파일과 인터페이스

tests/test_rd04_selective_fixture.py와 tests/fixtures/rd04/partial-apply.json을 추가했다. tools/graph_sync.py는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd04_selective_fixture로 실행한다.

## 설계 이유와 출처

RD-04 작업 1은 독립 token과 alias 묶음의 부분 적용 조건을 fixture로 고정한다. 표시 index가 아니라 key가 선택 identity다.

## 호환성·이관·복구

이 커밋은 fixture와 검사를 고정할 뿐 기존 전체 적용 경로를 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `partial token selection must keep the unselected value and the alias bundle`이다. Figma 적용 결과는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 fixture다. 구현은 별도 커밋 5fb07911e3a1b1530f34aee2cca47f9df7319910에서 검사와 fixture blob을 유지한 채 로더를 추가한다. stable change identity는 아직 없다.
