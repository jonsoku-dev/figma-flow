# PC 등록과 테스트 격리의 고정 재현

커밋 `13ddf9a3ad3d4419ca7f873e41ff549b24659b4d`

## 문제와 계기

작업공간 생성 경로가 시스템 임시 폴더 밖에 있거나 XDG가 지정되면 일회성 작업도 PC 기본 경로가 될 수 있었다.

## 결과 동작

실제 CLI와 API에서 초기화·제어 활성화·갱신·서비스 시작을 실행하고 가짜 PC 설정 루트의 파일과 기본 경로를 대조한다.

## 변경 파일과 인터페이스

tests/test_registry_intent.py가 명시적 등록·재시도·동시 등록, 손상 파일 보존, 다중 후보 선택, 격리 실행기 자손과 CI 연결을 검사한다.

## 설계 이유와 출처

테스트는 실제 계정의 HOME 또는 CODEX_HOME을 변경하지 않는다. 레지스트리 모듈에 한정한 XDG 부재와 가상 Path.home을 사용하고 다른 코드에는 격리 환경을 유지한다.

## 호환성·이관·복구

RC2 형식의 레지스트리를 직접 구성해 유효 기본값과 유일 후보 조회의 호환성을 확인한다.

## 검증과 미검증

수정 전 후보의 일반 실행에서 가짜 PC 기본 경로와 파일이 변경됐다. 손상된 파일을 명시적 API가 덮어쓰는 사례도 검출했다.

## 한계와 후속 개선

별도 OS 보호 하에 XDG가 실제로 없는 자식 CLI도 검수했다. 저장소의 이식 가능한 검사는 일반 실행자 환경을 변경하지 않는다.
