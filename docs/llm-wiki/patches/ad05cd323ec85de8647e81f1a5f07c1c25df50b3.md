# ad05cd3 · 새 텍스트를 측정하고 live readiness 갱신 제한

## 문제와 계기
clone 측정으로는 최신 텍스트/타이포그래피 상태를 명시하기 어려웠다. control host도 같은 세션의 실제 최신 runtime 결과와 무관하게 readiness freshness를 갱신할 수 있었다.

## 결과 동작
`direction_review.js`는 관찰된 font, size, lineHeight, letterSpacing, characters를 유효성 확인한 후 새 `figma.createText()`에 복사해 자연 폭/높이를 잰다. 혼합/불완전 입력은 거부한다. `figma_control.py`는 동일 session의 runtime identity가 현재 설치 상태와 맞는 result에 대해서만 client freshness를 갱신한다.

## 변경 파일과 인터페이스
bridge, `tools/figma_control.py`, text measurement/control tests, changelog. 구형 poll 필드는 유지하면서 선택 runtime identity를 검증한다.

## 설계 이유와 출처
근거: 전체 커밋 `ad05cd323ec85de8647e81f1a5f07c1c25df50b3`; `measureDraftNaturalWidth`, control `poll()`/`result()`, 관련 tests. 실제 최신 텍스트로 측정하고 readiness를 세션/구현 identity에 묶는다.

## 호환성·이관·복구
runtime 없는 기존 poll은 허용된다. 혼합 타이포그래피는 자동으로 정규화하지 않고 오류로 반환된다.

## 검증과 미검증
텍스트 측정 및 control 테스트가 확장됐다. 실행 기록과 실제 Figma 측정은 미검증이다.

## 한계와 후속 개선
폰트 제공 여부와 native layout에 측정 결과가 의존한다. host freshness lifecycle의 모든 재시작/expiry 동작은 이 변경만으로 입증되지 않는다.
