# nf01: add BOOLEAN/INSTANCE_SWAP/TEXT selective CAS sync and finalize NF-01 spec

## 문제와 계기

그래프 토큰 동기화(`tools/graph_sync.py`, `figma-bridge/graph_token_sync.js`)가 `BOOLEAN`·`INSTANCE_SWAP`·`TEXT` 컴포넌트 속성에 대해 선택적 CAS 동기화를 지원하지 못했고 NF-01 설계서의 최종 계약 확정이 남아 있었다.

## 결과 동작

커밋 `fd1a9d28551e9101fa5f5bc1e0d42570b385aa31`은 `tools/graph_sync.py`, `tools/graph_design_system.py`, `figma-bridge/graph_token_sync.js`에 3종 선언형 속성 선택적 CAS 동기화를 구현하고 `docs/next-roadmap/NF-01-component-families.md`와 테스트(`tests/test_component_families.py`, `tests/nf01_component_properties.cjs`)를 확장했다.

## 변경 파일과 인터페이스

`docs/next-roadmap/NF-01-component-families.md`, `figma-bridge/graph_token_sync.js`, `tools/graph_design_system.py`, `tools/graph_sync.py`, `tests/test_component_families.py`, `tests/nf01_component_properties.cjs`를 수정했다.

## 설계 이유와 출처

재적용 시 디자이너가 수동 편집한 속성·인스턴스 오버라이드와 충돌 없이 선언형 기본값/매개변수 변경만 안전하게 CAS 동기화하기 위함이다.

## 호환성·이관·복구

선택적 CAS 대상이 아닌 기존 토큰 동기화 흐름에는 영향을 주지 않는다.

## 검증과 미검증

`tests.test_component_families`·`tests/nf01_component_properties.cjs`가 이후 `e6f4fd8`까지 통과했다. 6개 시맨틱 패밀리 워크벤치 전체 런타임은 후속 `709f1104`에서 완성됐다.

## 한계와 후속 개선

최상위 워크벤치 증분 배치 및 기존 `MAIN` 컴포넌트 보호 보장은 이어지는 `709f1104`·`8af6db43`·`974b5de7` 커밋 범위다.
