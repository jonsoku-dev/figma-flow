# 공통 ARM 러너 검증을 배포 소스에 연결

소스 커밋 `5e9e227fd6f307ba03dfb899c036f939a52b858b`

## 문제와 계기

전체 테스트와 배포 검사에 사용할 네이티브 러너를 한 곳에서 정하므로 기존 배포·도구 지문이 달라졌다.

## 결과 동작

보호된 Codex CLI 설치와 워크플로 투영이 같은 정본을 읽고 실제 동작 검사를 재실행한다.

## 변경 파일과 인터페이스

`release/reviews/delivery.json`과 `release/reviews/tooling.json` 및 해당 증거를 현재 소스에 다시 연결했다.

## 설계 이유와 출처

두 워크플로에 정본의 runner 값이 전파되고 손상된 CLI 파일은 설치·PATH 반영 전에 거절되는지 확인한다.

## 호환성·이관·복구

제품 제약, Figma 패널 값, 실제 DB 예약 조건과 공개 배포의 필수 확인을 유지한다.

## 검증과 미검증

배포와 도구 검토를 Git 아카이브에서 재실행해 통과했다. 기록의 적용 소스는 각 증거의 지문에서 읽는다.

## 한계와 후속 개선

공개 배포의 최종 결과는 실행한 GitHub 워크플로와 게시된 ZIP에서 다시 대조한다.
