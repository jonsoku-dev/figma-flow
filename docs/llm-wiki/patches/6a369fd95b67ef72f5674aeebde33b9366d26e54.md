# release: version 0.30.0 with verified editable screens and native member evidence

## 문제와 계기

The 0.30 candidate combined editable web imports, actual API observations and a new typography task, but the user-facing graph, version, verification summary and install guide needed one consistent release record.

## 결과 동작

Both plugin manifests and the README/guide target 0.30.0. The release graph connects capture requirements, native imports, API evidence and test results without exposing Figma identifiers. The verification record separates observed outputs from open limits.

## 변경 파일과 인터페이스

Changes cover `.codex-plugin/plugin.json`, `plugin.json`, `README.md`, `docs/guide.md`, `docs/editable-web-verification.md`, and `specs/editable-web/graph.json`.

## 설계 이유와 출처

Release metrics point to actual local receipts and keep separate counts for captured elements, native editable nodes, instances, API lookup calls and unique members. Unsupported media, font aliases and unobserved API members stay visible.

## 호환성·이관·복구

Version metadata now names 0.30.0, but tag, installer UI, remote CI and public release remain separate checks. Existing 0.29 tags and history are retained.

## 검증과 미검증

Final receipts report 508/492/38/20 captured elements and 512/526/41/23 native editable nodes, 1102 total excluding VECTOR descendants. The full local stable-clone suite passes Python 1215, Node 323, finalize 75, design 18 and demo 2, all with zero skips. Three prior skip cases replayed with original private evidence; the API inventory reports 150 observed and 1232 unobserved of 1382.

## 한계와 후속 개선

Four final Figma preview PNGs were visually compared with browser outputs, not measured for pixel equality. CSS masks, filters, shadows, external media, and three external Portfolio SVGs remain unsupported or omitted. Devtool reports family-alias fallback notices.
