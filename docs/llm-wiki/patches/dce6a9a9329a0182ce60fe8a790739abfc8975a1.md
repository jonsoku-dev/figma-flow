# 첫 원격 아카이브 실패와 교정의 기록

소스 커밋 `dce6a9a9329a0182ce60fe8a790739abfc8975a1`

## 문제와 계기

첫 1.0.0 후보가 GitHub의 Linux Gate에서 세 사례가 막혀 로컬 통과와 원격 결과를 구분할 필요가 있었다.

## 결과 동작

네이티브 러너 전환의 출처, 과거 후보의 해시와 공개 태그가 보류됐던 상태를 남겼다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`, `docs/llm-wiki/releases.md`와 배포 환경 패치의 기록을 발행했다.

## 설계 이유와 출처

이전 후보의 검증 결과를 현재 공개 패키지의 결과로 대체하지 않는다.

## 호환성·이관·복구

최초 ZIP의 출처는 기록으로 보존한다. 외부에 공개하지 않은 임시 커밋 태그는 거둬들였다.

## 검증과 미검증

GitHub에서 첫 Ubuntu 게이트의 차단 세 건을 대조했다. 변경 소스의 Git Wiki를 검증했다.

## 한계와 후속 개선
