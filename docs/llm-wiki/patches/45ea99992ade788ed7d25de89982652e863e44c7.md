# test: track final safe Design property observations and verified instance-link recovery

## 문제와 계기

최초 Design scene probe는 일부 safe fields만 표준 scene receiver에서 읽었다. 추가 run에서 이미 소유한 section, frame, component, text path의 표시·배경·guide 속성을 확인해야 했다.
## 결과 동작

Design 전용 property allowlist를 확장해 `backgrounds`, `guides`, `expanded`, `devStatus`를 해당되는 Design node type에서 bounded summary로 읽는다. 실제 getter 결과와 exact API member를 sanitized observation graph로 연결한다. Mixed 또는 값이 제공되지 않은 경우는 성공으로 세지 않는다.
## 변경 파일과 인터페이스

`tools/native_api_probe.py`의 `SAFE_FIELDS`가 허용 receiver와 output shape를 정한다. `specs/design-inspection/scene-observations.json`에는 새 member node와 `OBS-scene-final-safe-properties-v032` evidence node, 그리고 exact `observed member` edges가 추가됐다. `specs/README.md`는 추가 receipt 범위를 기록한다.
## 설계 이유와 출처

기존 fixture marker와 bounded projection을 유지한다. Nested API object는 허용 필드만 읽고 원시 node reference와 사용자 텍스트를 노출하지 않는다. Editor-only, type-only, 미해결 receiver는 Design queue 밖에 둔다.
## 호환성·이관·복구

기존 selection·page 범위는 유지한다. 이 commit은 probe 정책과 sanitized evidence만 넓힌다. 다른 Design node나 파일을 대상으로 할 때는 새 exact selection과 receipt가 필요하다.
## 검증과 미검증

이번 receipt는 23개의 getter 성공, 2개의 미제공 값을 보고하며 9개의 exact successful member edge를 추가한다. 각 성공은 현재 Figma API catalog의 member key에 연결됐다. 이전 scene receipt와 겹치는 값은 새 전체 관측 합계로 다시 세지 않는다.
## 한계와 후속 개선

두 값은 실제 getter가 제공하지 않았다. 나머지 API 값 경로와 service overlay가 추가되는 중이므로 현재 receipt만으로 0.32의 전체 unique-key 합계를 확정하지 않는다.
