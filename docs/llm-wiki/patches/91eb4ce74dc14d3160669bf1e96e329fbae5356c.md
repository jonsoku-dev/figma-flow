# docs: publish the Design-only release contract, patch history and measured acceptance

## 문제와 계기

0.32.0에서 Design 전문화와 실제 렌더·API 관측의 근거를 포크가 따라갈 기록이 필요했다.

## 결과 동작

헌법·설계·패치 이력을 공개 문서와 배포 버전에 연결했다.

## 변경 파일과 인터페이스

CHANGELOG.md, docs/llm-wiki/catalog.json, docs/llm-wiki/releases.md 및 커밋별 Wiki 페이지가 갱신됐다.

## 설계 이유와 출처

0.32.0 코드와 그 이후 발행 기록은 Git 객체가 다르다. 당시 배포가 참조한 전체 SHA를 기준으로 구별한다.

## 호환성·이관·복구

과거에 배포한 원본 문서·설치본은 기존 태그에서 확인할 수 있다.

## 검증과 미검증

0.32.0 태그가 가리킨 문서 커밋과 현재 로컬 수집물의 설치·원격 CI 영수증을 대조했다.

## 한계와 후속 개선
