# docs: record the Devtool tab A→B→A replay in Chrome and Figma Present

## 문제와 계기

탭 기능의 사용 절차, 입력 형식, 실제 인수 결과가 문서와 graph에 없었다.

## 결과 동작

가이드에 한국어·영어·일본어 탭 quickstart를 추가했다. 입력 형식 문서, 탭 인수 기록, NF-09 현황, interactive-web graph의 검증 상태와 코드·한계 노드를 갱신했다.

## 변경 파일과 인터페이스

`docs/guide.md`, `docs/web-tabs-input.md`, `specs/interactive-web/tabs.md`, `specs/interactive-web/graph.json`, `docs/next-roadmap/NF-09-interactive-web-design.md`, `docs/next-roadmap/README.md`, `specs/README.md`를 바꿨다.

## 설계 이유와 출처

graph를 정본으로 두고 AC-REPLAY와 TEST-REPLAY를 실제 재생 근거와 연결했다. 관찰하지 않은 브라우저 결과는 표에 쓰지 않았다.

## 호환성·이관·복구

문서와 spec graph만 바꿨다.

## 검증과 미검증

`tests.test_design_specialization`과 `tests.test_review_graph_projection`이 통과했다.

## 한계와 후속 개선

graph는 관찰 결과의 요약이며 원시 스크린샷과 읽기 결과는 로컬 `.figma-flow/after-033/`에 있다.
