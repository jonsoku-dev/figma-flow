# docs: publish final 0.27.1 verification receipts

## 문제와 계기

0.27.1 제품 소스의 개별 수정 기록과 clean 환경 검증이 끝난 뒤에도 tag, 원격 CI, 실제 ZIP, 설치본과 Figma 재읽기 결과가 한곳에 모여 있지 않았다. 이 커밋은 해당 최종 영수증을 릴리스 문서에 추가하며 제품 소스는 바꾸지 않는다.

## 결과 동작

`releases.md`는 0.27.1의 원격 전체 도구·앱·Wiki CI, 배포 ZIP, Codex 설치, 등록 workspace/runtime, 실제 Figma 읽기와 버전 기록을 결과별로 구분해 적는다. 제품 코드 검증, 패키지 관찰, 설치, native 관찰이 서로를 대신하지 않는다.

## 변경 파일과 인터페이스

첫 부모 `42379a56d677ad29296ae3ae6495742a11fbaf43` 대비 바뀐 파일은 `docs/llm-wiki/releases.md` 하나다. 추가된 영수증은 `v0.27.1` 절에 있고 플러그인 API나 파일 형식은 변경하지 않는다.

## 설계 이유와 출처

문서는 제품 소스 `aa8b7191405b160d1119c403510152a12e0ae801`, tag를 가리키는 문서 발행 커밋, 그리고 발행 후 실행을 구분한다. 실제 결과에는 세 원격 Actions run 링크, 다운로드 ZIP의 바이트 수와 SHA-256, 설치 결과, 보호된 Figma readback 요약과 일반 UI version-history 관찰이 포함된다. 비공개 운영 경로와 원시 readback은 기록하지 않는다.

## 호환성·이관·복구

릴리스 문서만 추가되므로 패키지와 설치 상태는 바뀌지 않는다. 기록을 되돌릴 때도 이미 게시된 release·tag·ZIP 또는 설치본이 자동으로 되돌아가지 않으며, 외부 상태는 이 문서 커밋의 범위 밖이다.

## 검증과 미검증

이 페이지는 `releases.md`에 기재된 원격 CI success, ZIP sidecar/hash 일치, 설치 manifest 및 실제 readback/UI 결과를 각자 근거로 기록한다. ZIP의 checksum은 문서에 명시되어 있다. 0.27.1 이전에 실행한 검사를 이 커밋에서 다시 실행한 것은 아니며, 릴리스 문서만으로 재현성이나 모든 사용자 환경을 증명하지 않는다.

## 한계와 후속 개선

실제 Figma 읽기와 일반 UI 저장 관찰은 기록된 파일·계정·시점에 한정된다. native 실행이나 원격 서비스에 대한 독립 attestation을 뜻하지 않는다. 배포 뒤 변경은 별도 전체 SHA와 새 증거로 기록해야 한다.
