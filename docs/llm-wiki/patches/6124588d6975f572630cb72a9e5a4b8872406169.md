# 선택 속성 비교의 중복과 실행 중 상태 경계

소스 커밋 `6124588d6975f572630cb72a9e5a4b8872406169`

## 문제와 계기

실행 중 선택 변경이나 동일 값 재측정이 앞서 감지한 변경을 다시 보고할 수 있었다.

## 결과 동작

값이 같은 늦은 콜백의 중복 방지를 유지하고 활성 명령 중에는 선택 비교를 건너뛴다.

## 변경 파일과 인터페이스

`figma-bridge/workspace_changes.js`와 `figma-bridge/workspace_host.js`를 갱신했다.

## 설계 이유와 출처

짧은 범위에서 동일 선택·속성·값의 중복을 없애고 다른 변경은 계속 보고한다.

## 호환성·이관·복구

기존 SDK 변경과 UI 문맥 전달을 유지한다.

## 검증과 미검증

관련 Node 검사 65개가 통과했다. P1 실기에 사용한 실행판에는 앞선 선택 비교 구성이 적용돼 있었다.

## 한계와 후속 개선

추가 중복 방지 수정이 로드됐는지는 Desktop에서 같은 등록을 다시 열어 확인한다.
