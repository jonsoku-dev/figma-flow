# P1에서 SDK 콜백이 없는 직접 편집 감지

소스 커밋 `6deaaf123c4f65d436fe5bb75a8f9f5711ee72f7`

## 문제와 계기

SDK가 사용 가능으로 표시돼도 P1 직접 편집에서 콜백을 전달하지 않았다.

## 결과 동작

정상 구독 외에 선택된 노드의 허용 값 변화를 당사자 로컬 폴링에서 감지한다.

## 변경 파일과 인터페이스

`figma-bridge/workspace_changes.js`, `figma-bridge/workspace_control.js`, `figma-bridge/workspace_host.js`를 갱신했다.

## 설계 이유와 출처

선택 한도를 재사용하고 비교 값은 메모리에 둔다. 저널에는 노드 ID와 속성명을 전달한다.

## 호환성·이관·복구

현재 범위의 실제 SDK 이벤트와 기존 검증 예산을 유지한다. 새 선택에는 기준값을 잡는다.

## 검증과 미검증

기존 등록 작업공간의 P1에서 직접 92% 변경과 100% 원복을 각각 관측했고 실제 값을 다시 읽었다.

## 한계와 후속 개선

비선택 노드의 보완 관측이나 연속 편집의 실시간 SLA를 보장하지 않는다.
