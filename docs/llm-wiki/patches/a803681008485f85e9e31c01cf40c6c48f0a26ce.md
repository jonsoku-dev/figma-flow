# test: compare full orphan and authored classifications on retry

## 문제와 계기

후보 개수나 일부 ID만 비교하면 메모·연결 근거가 교체되거나 사람이 추가한 항목으로 재분류된 오류를 놓칠 수 있었다.

## 결과 동작

고정 검사에서 삭제 후보 전체와 재시도 stdout의 분류를 이전 성공 결과와 직접 비교한다.

## 변경 파일과 인터페이스

apps/little-hands/design/test_regeneration.py의 차단·재시도 테스트가 검증 기준이다.

## 설계 이유와 출처

같은 테스트 파일을 보존한 채 다음 커밋의 제품 코드만 변경하여 수정 전후를 분리했다.

## 호환성·이관·복구

테스트 기준을 고정한 커밋으로 데이터 파일이나 생성 API는 바뀌지 않는다.

## 검증과 미검증

bfb5e8f와 테스트 blob 및 파일 모드가 같다. 이 기준 커밋에서 차단 시 후보 목록 대신 None이 반환되어 테스트가 실패했다.

## 한계와 후속 개선

이 회귀는 실제 stylesheet epoch 거부 경로를 대상으로 한다. 모든 저장 중 중단에 대한 원자성을 보증하지 않는다.
