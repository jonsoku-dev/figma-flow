# test: pin current enqueue poll result timeout and recovery transitions

## 문제와 계기

제어 journal에 lifecycle 단계를 더하기 전에, 현재 enqueue·poll·result와 timeout·recovery 전이가 고정되어 있지 않았다. 이 커밋 dc8c23c4357aba18dc6a074b00107d52c8a1d7a9의 검사는 pinned_operation_transitions가 없어 `current operation transitions must be pinned before lifecycle changes`로 실패한다.

## 결과 동작

tests/test_rd08_operation_transitions.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 읽기는 pending·claimed·ok로 끝나고, claim 전 timeout은 expired, claim 후 timeout은 uncertain이다. 읽기 timeout은 다음 명령을 막지 않고, claim된 mutation timeout은 같은 쓰기를 막는다. 다른 페이지 읽기는 uncertainty를 풀지 않고 같은 scope discovery만 푼다. 끝난 결과의 재전송은 거절되며 native-started는 없다.

## 변경 파일과 인터페이스

tests/test_rd08_operation_transitions.py만 추가했다. tools/figma_control.py는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd08_operation_transitions로 실행한다.

## 설계 이유와 출처

RD-08 작업 1은 현재 상태 전이를 fixture로 고정한다. 새 queue나 operation ID를 만들기 전에 claim 전과 후의 timeout이 다르고 native-started를 꾸며내지 않는다는 기준을 남긴다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 요청 스키마를 바꾸지 않는다. 기존 uncertainty blocking과 recovery_read 판정은 그대로다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `current operation transitions must be pinned before lifecycle changes`다. 실제 Figma 읽기와 서버 재시작은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 plugin 응답이다. 구현은 별도 커밋 4dc23d6d98a7953572228b6bbf829e54c5417d13에서 검사 blob을 유지한 채 추가한다. AC-01의 실제 화면 표시는 통과로 기록하지 않는다.
