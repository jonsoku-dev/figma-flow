# Add scoped read-only operation detail and keyboard return path to the History panel

## 문제와 계기

History 패널 UI에서 사용자가 특정 작업의 인과 diff·선행 링크를 읽기 전용으로 열어보고 백스택으로 돌아가며 키보드 포커스를 원래 행으로 복구할 인터페이스가 없었다.

## 결과 동작

커밋 `016a777e0bc582414c2062a122dfae553851eefc`는 `panel-ui/src/operationDetail.mjs`, `panel-ui/src/Workspace.jsx`, `panel-ui/src/styles/workspace.css`, `figma-bridge/locales/workspace.json`, `figma-bridge/assets/panels.{js,css}` 번들 및 `tests/test_nf03_panel_ui.cjs`를 추가해 History 패널 내 읽기 전용 상세 보기, 선행 artifact 백스택, 페이지 전환 시 1-poll 주기 스테일 무효화 안내, `Enter`/`Back` 키보드 포커스 복귀를 구현했다.

## 변경 파일과 인터페이스

`panel-ui/src/operationDetail.mjs`(신규), `panel-ui/src/Workspace.jsx`, `panel-ui/src/styles/workspace.css`, `figma-bridge/locales/workspace.json`, `figma-bridge/assets/panels.css`, `figma-bridge/assets/panels.js`, `figma-bridge/assets/panels.js.LEGAL.txt`, `tests/test_nf03_panel_ui.cjs`(신규)를 수정·추가했다.

## 설계 이유와 출처

[NF-03 설계서](../../next-roadmap/NF-03-causal-history.md)의 읽기 전용 보장·키보드 접근성·백스택·스테일 상태 분리 요구사항을 패널 번들과 소스 모두에 반영했다.

## 호환성·이관·복구

`panels.js` 번들 에셋이 함께 커밋되어 Node 오프라인 환경에서도 플러그인 UI 로딩이 가능하다. `tests/test_nf03_panel_ui.cjs`와 `panel-ui` 빌드는 `panel-ui/node_modules`(`esbuild`)를 필요로 한다.

## 검증과 미검증

`cfc7fbd` pre-freeze 런타임에서 Figma Desktop 실제 패널 인터랙션(Gate C: `borderRadius 8->16` diff 렌더링, 선행 artifact 이동·복귀, 페이지 전환 1-poll 스테일 무효화, `Enter`/`Back` 포커스 복귀)을 직접 통과했고 `e6f4fd8` CI Run `43599181267` 전체 Python/Node 빌드가 통과했다. 단, `e6f4fd8` 정본 커밋 위에서의 수동 패널 UI 재클릭 자체는 `manual_panel_ui_verified: false`로 구분해 기록한다.

## 한계와 후속 개선

`panel-ui/node_modules`가 없는 bare 오프라인 체크아웃에서는 `tests/test_nf03_panel_ui.cjs`를 건너뛰며 CI에서 전체 빌드를 검증한다.
