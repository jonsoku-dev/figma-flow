# feat: link local disclosure trigger hotspots in the Figma web design bridge

## 문제와 계기

이 커밋은 disclosure 적용 계획을 받아 각 관측 클릭을 Figma의 실제 트리거 위치에 연결하는 hotspot 적용을 추가한다.

## 결과 동작

Python과 Figma 브리지 검증기는 항목·상태·전이의 모양, 답변과 캡처 핀, 유일한 트리거, 화면 경계를 확인한다.

## 변경 파일과 인터페이스

각 간선은 해당 상태 화면의 트리거 프레임 위치에 투명한 top-level hotspot을 만든다. 이름은 열기, 닫기, 전환 동작과 질문 라벨을 표시한다. 관련 변경: `figma-bridge/web_design.js`, `figma-bridge/workspace_control.js`, `figma-bridge/workspace_host.js`.

## 설계 이유와 출처

hotspot에는 즉시 `ON_CLICK` 탐색을 연결하고 상태별 plugin data 키를 저장한다. 질문·답변 텍스트와 화살표는 편집 가능한 레이어로 남긴다.

## 호환성·이관·복구

기존 브라우저 캡처는 `aria-expanded` 트리거를 disclosure frame으로 취급해 위치 정보를 보존하고, 일반 버튼의 재사용 처리에는 disclosure trigger를 포함하지 않는다.

## 검증과 미검증

Workspace host와 control 흐름은 적용 또는 readback 영수증에 disclosure 결과가 있으면 기존 interaction 요약 경로에 연결한다.

## 한계와 후속 개선

직접 diff에는 적용 검증, 롤백과 plugin data 검사를 위한 Node 테스트 및 workspace host 테스트가 추가됐다. 로컬 FAQ 보고서는 동일한 프레임 ID를 재사용한 세 상태를 기록한다.

## 관련 기록
