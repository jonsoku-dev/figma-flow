# feat: inspect scoped Design services, styles and native return values with exact member evidence

## 문제와 계기

기존 scene getter로는 Design 서비스와 스타일·변수 반환값 등 많은 공식 멤버에 근거를 연결할 수 없었다.

## 결과 동작

등록한 개발 플러그인이 생성하는 소유 표본에서 각 실제 호출을 정확한 선언 키로 기록한다.

## 변경 파일과 인터페이스

변경 파일은 `library/figma-recipes/inspection/members.json`, `library/figma-recipes/inspection/services.js`, `specs/design-inspection/service-observations.json`, `tests/test_design_service_inspection.py`, `tools/design_api_inspect.py`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

member 이름과 수신자·종류를 모두 고정하고 실제 결과에는 성공·미제공·오류를 분리한다. 값과 개인 식별자는 공개하지 않는다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

269개 항목을 시도해 241개 성공, 15개 값 미제공, 13개 런타임 오류를 기록했다. 생성 후 재실행에서 같은 표본 프레임을 선택했다.

## 한계와 후속 개선

위 관측은 명시된 사용 장면에 해당한다. 다른 파일의 권한이나 실제 런타임 결과는 그 환경의 별도 영수증으로 확인한다.
