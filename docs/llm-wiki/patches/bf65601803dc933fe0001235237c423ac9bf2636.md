# test: require a fresh native read without a stored snapshot

## 문제와 계기

문서 변경 이벤트를 확인하지 않은 session cache가 저장된 snapshot을 돌려줄 수 있었다. 이 커밋 bf65601803dc933fe0001235237c423ac9bf2636의 검사는 `native read keeps no session snapshot`이 없어 `native read must not serve a stored snapshot`으로 실패한다.

## 결과 동작

tests/rd06_fresh_read.cjs는 그 문구가 없으면 위 assertion으로 끝난다. 구현이 있으면 nativeReadSessionSnapshot은 null이고, width를 12에서 21로 바꾼 뒤 full과 summary는 21을 다시 읽는다. page.loadAsync는 네 번 호출된다. clientStorage는 없다.

## 변경 파일과 인터페이스

tests/rd06_fresh_read.cjs를 추가했다. docs/development-roadmap/RD-06-native-read/tasks.md에 session cache를 넣지 않는다는 결정을 적었다. 제품 reader는 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-06 작업 4는 실제 documentchange coverage를 확인한 경우에만 cache를 추가한다. TTL은 coverage가 아니다.

## 호환성·이관·복구

검사와 작업서만 추가한다. 인자 없는 full 호출은 그대로다.

## 검증과 미검증

이 기준 트리에서 `node tests/rd06_fresh_read.cjs`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma documentchange는 보지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. cache를 넣지 않는 구현은 다음 커밋에 있다.
