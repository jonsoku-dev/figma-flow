# RC3 검증기 패키지 호환성 기록

커밋 `a78ad0149bdd8d81419e6f14f031a9e353bf6975`

## 문제와 계기

릴리스 검사에서 두 도구를 패키지로 불러오는 경로가 실패했다.

## 결과 동작

RC3 검증 기록에서 단독 실행과 패키지 import의 검사 결과를 추적할 수 있다.

## 변경 파일과 인터페이스

CHANGELOG.md에 유지보수 검사와 패치 검사의 호환성을 기록했다.

## 설계 이유와 출처

동일한 도구를 직접 실행하거나 tools 패키지에서 가져오는 실제 호출자를 기준으로 삼았다.

## 호환성·이관·복구

기존 RC3 버전에서 읽던 작업공간과 큐 데이터에는 변경이 없다.

## 검증과 미검증

검증기 재실행은 패키지 경로를 확인하며 Figma 실행 결과는 별도 자료에 있다.

## 한계와 후속 개선

실제 배포 아카이브와 공개 태그는 소스 기록 후에 각각 확인한다.

## 관련 기록

[릴리스 버전과 변경 근거](../releases.md#v1.1.0)에서 해당 버전의 검증 범위를 확인한다.
