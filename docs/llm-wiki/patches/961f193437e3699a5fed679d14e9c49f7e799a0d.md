# feat: publish graph-owned booking styles and trace cancellation policy impact

## 문제와 계기

작은손 앱의 취소 정책과 화면의 관계는 graph에 있었지만 변경 검토와 실제 구현 근거를 묶기 어려웠다. 예약 버튼의 이전 브라우저 실험은 임시 CSS에 의존했다.

## 결과 동작

취소 정책 변경에 연결한 화면·행동·근거와 이전 결정을 다시 검토할 조건을 표시한다. 앱은 정본에서 생성한 예약 CTA 스타일을 Django static 자산으로 배포하고 DOM에 대응 graph SHA를 노출한다.

## 변경 파일과 인터페이스

`tools/policy_impact.py`는 이전·현재 graph와 업무 근거를 비교한다. `apps/little-hands/design/publish_design_system.py`가 CSS·모듈·매니페스트를 작성하며 Django context와 수업 상세 template에서 이를 소비한다.

## 설계 이유와 출처

예약 색과 취소 정책의 소유 주체가 다르다. 같은 색을 쓰는 danger·hover를 의미가 다른 그래프 토큰에 연결하지 않고, 예약 색의 primitive → semantic alias → 선택자만 선언했다.

## 호환성·이관·복구

배포 시 생성된 정적 파일을 함께 커밋하고 collectstatic 및 앱 worker 재시작을 수행한다. 구버전 화면 캡처는 과거 근거로 남는다.

## 검증과 미검증

실제 정책의 직접 화면 4개, 명시한 행동 6개, 테스트 근거 2개를 확인했다. PostgreSQL의 별도 테스트 DB에서 booking·config 59건이 통과했다. 실제 브라우저에서 예약 링크의 계산색과 data-graph-sha를 확인했다.

## 한계와 후속 개선

런타임에서 확인한 예약 링크와 모든 로그인 상태·운영 앱 화면을 구분한다. 최초의 구두점 CSS 변수와 캐시된 static manifest 실패를 수정한 후 브라우저를 다시 읽었다. 최종 양방향 동기화 근거는 후속 패치에 있다.
