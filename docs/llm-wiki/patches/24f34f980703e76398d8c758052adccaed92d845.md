# test(native-read): pin Figma-like sandbox diagnostic and UTF-8 byte oracle

## 문제와 계기

실기 diagnostic v2가 Figma 플러그인 sandbox에서 `'TextEncoder' is not defined`로 실패했다. Node 검사는 host 전역이 있어 이를 재현하지 못했다.

## 결과 동작

커밋 `24f34f980703e76398d8c758052adccaed92d845`는 `tests/p2_native_read_sandbox_globals.cjs`를 추가했다. 생성된 discovery bundle을 `TextEncoder`, `TextDecoder`, `Buffer`, `performance`, `process`, `require`가 없는 vm context에서 실행한다. `utf8JsonBytes`를 host `Buffer.byteLength` 기준과 ASCII, 한국어, emoji, lone surrogate, escape된 JSON으로 비교하고 `readNativeSemantics` 본문을 고정한다.

## 변경 파일과 인터페이스

새 `tests/p2_native_read_sandbox_globals.cjs`.

## 설계 이유와 출처

실기 실패를 저장소 검사로 먼저 재현한 뒤 수정을 별도 커밋으로 분리했다.

## 호환성·이관·복구

검사 파일 하나만 추가했다. 생성 bundle과 reader 코드는 이 커밋에서 바뀌지 않는다.

## 검증과 미검증

커밋 메시지에 따르면 수정 전 소스에서 진단이 실기와 같은 `TextEncoder is not defined`로 실패한다. 이 기록에서는 수정 뒤 통과만 다시 확인했다.

## 한계와 후속 개선

vm context는 Figma sandbox의 전역 부재만 흉내 내며 Figma API 동작 전체를 대표하지 않는다.
