# fix: retain the original field order when checking unversioned native scene digests

## 문제와 계기

Unversioned scene fingerprints serialize object fields in a fixed order. Adding mask state at the end of the object changed the serialized digest even when a legacy screen was still current, so exact same-screen reuse could be misclassified as a change.

## 결과 동작

For unversioned imports, mask fields are now serialized in their original field position before the legacy digest is checked. New versioned fingerprints continue to include mask state; old fingerprints without masks remain eligible for compatibility only when no live mask exists.

## 변경 파일과 인터페이스

`figma-bridge/web_design.js` adds an explicit unversioned serialization mode. `library/figma-api/coverage-baseline.json` refreshes its source digest. The native bridge regression tests exercise legacy reuse, masks and canonical typography.

## 설계 이유와 출처

Object key order is part of the old serialized fingerprint contract. The fix reproduces that order instead of weakening the digest comparison or ignoring mask state on current imports.

## 호환성·이관·복구

New v2 scene fingerprints remain unchanged. Unversioned frames with masks must match the mask-inclusive legacy digest; genuinely changed or masked scenes without matching evidence are not reused.

## 검증과 미검증

`node tests/test_web_design.cjs` passed 19 tests on the frozen candidate. The final review also verified the original screen identities across the initial reapply; full remote release CI and installer validation are still pending.

## 한계와 후속 개선

This change addresses serialized fingerprints only. A matching digest does not prove pixel-level equivalence, native VIDEO availability or support for effects outside the bounded allowlist.
