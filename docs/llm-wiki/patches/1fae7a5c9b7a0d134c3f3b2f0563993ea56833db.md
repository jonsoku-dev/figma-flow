# release: update manifests and install guide to 0.35.0

## 문제와 계기

G1·FAQ 구현으로 설치 대상이 바뀌어 기존 0.34용 설치 예제를 구분해야 했다.

## 결과 동작

두 플러그인 매니페스트에서 같은 0.35.0을 반환하며 가이드의 태그 설치 예제와 버전 확인 문구가 일치한다.

## 변경 파일과 인터페이스

plugin.json, .codex-plugin/plugin.json, README.md 및 docs/guide.md가 이 버전 변경의 접점이다.

## 설계 이유와 출처

버전 표시는 설치 사실과 별개다. 실제 태그, ZIP, 설치 파일 및 열린 플러그인 런타임을 별도 단계에서 확인한다.

## 호환성·이관·복구

이전 릴리스 태그와 복구 원본은 보존한다. 새 버전을 사용하려면 기존 등록 경로의 업데이트 절차를 따른다.

## 검증과 미검증

두 매니페스트가 0.35.0인 것을 직접 읽었다. 이 커밋 시점에는 원격 ZIP 게시나 실제 설치 인수는 수행하지 않았다.

## 한계와 후속 개선

설명에 적힌 버전만으로 캐시 또는 Figma 플러그인의 코드가 바뀌었다고 판정할 수 없다.
