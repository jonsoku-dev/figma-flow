# Figma 패널 Graph 품질 검사와 도구 마이그레이션

커밋 `014095da897ccb87cac5e439910ad053c1f64720`

## 문제와 계기

기존 패널 구조 검사는 일부 소스 경계를 검사했고 CI는 현재 산출물에 덮어쓴 뒤 Git 차이를 읽었다. 삭제된 관계의 영향, 가상 진입점을 포함한 도달성, 파일 집합과 테스트 증거까지 묶은 비교가 필요했다. 사용자 요청에 따라 Graph SSoT and Code Quality Constitution 1.0.0을 채택하고 세 도구를 프로젝트에 설치했다.

## 결과 동작

패널 정본과 관측을 분리하고 실제 import, 네트워크 어댑터와 호스트 경계, 산출물 파일 집합을 확인한다. 이전과 현재 선언의 영향 경로를 따르고 Git 기준·인덱스·작업 트리의 증거와 변경된 패널 심볼을 출력한다. 필수 테스트 누락과 건너뛰기, 새 미사용 후보, 문서 재검토 필요는 집계를 실패시킨다.

## 변경 파일과 인터페이스

`library/panel-design/governance.json`은 도메인 ID·관계·검증을, `tools/maintenance-contract.json`은 권한 경계와 산출물 목록을 소유한다. `tools/graph_governance.py`의 `observe`, `impact --base`, `verify --base`, `write-doc`을 연결했다. `panel-ui/package.json`과 각 도구 설정, 생성된 워크플로와 CODEOWNERS를 반영했다.

## 설계 이유와 출처

Acorn/esbuild를 실제 패널 진입점, 가상 화면 등록부, 구문 증거에 재사용했다. Biome은 JSON 포맷과 CSS·JSON 검사, Oxlint는 JS·React, Knip은 생산 단위와 개발 의존성을 담당한다. 패널 테스트가 소비하는 export 다섯 개를 정확한 경로로 기록했다. 토큰과 패널 자산, 정형 경계 표를 깨끗한 위치에서 생성해 제출본과 비교한다.

## 호환성·이관·복구

기존 패널 빌드 명령은 그대로 사용할 수 있다. 도구는 `.nvmrc`의 Node 26.13.0에서 로컬로 설치한다. 이 변경은 플러그인 설치 캐시나 Figma 작업공간을 변경하지 않는다. 원본과 새 검사 설정은 같은 변경에서 되돌린 다음 패널 의존성을 다시 설치하고 산출물을 재생성할 수 있다.

## 검증과 미검증

`python3 -B tools/graph_governance.py verify --base origin/main --json`에서 기준 `e8855f9227d3487fb427339323527060ea32be8d`, 소스 `014095da897ccb87cac5e439910ad053c1f64720`, 범위 지문 `1657f7b4627d2ea3426b1f1a9be10eb67e0bdc92384e75d90a26c8b197fc0edf`로 9단계와 계약 테스트 8건이 통과했다. Python 관련 44건과 Node 관련 62건이 통과했고 Node 검사에는 실제 Chromium으로 생성 패널을 여는 테스트가 포함됐다. 공유 화면 등록자 import의 구문 변경으로 처음 두 권한 검사가 실패했다. 기존과 새 import 구문을 지원하도록 맞춘 후 44건이 통과했다. 독립 검수에서 생성물·테스트·npm 검사 우회를 재현하고 교정 후 차단을 확인했다. 참고 자료 비교는 기준과 변경 모두 기존 세 검출이 같았으며 신규 검출은 없었다. 원격 새 실행과 병합 보호는 미적용 상태다.

## 한계와 후속 개선

관측은 패널 JavaScript·JSX와 확인된 외부 진입점에 적용된다. 호출 대상, DB나 외부 앱의 데이터 흐름, 동적 등록 전체를 증명하지 않는다. 실행 시간 개선은 측정하지 않았다. 원격에 코드가 올라간 뒤 필수 체크와 독립 코드 소유자 리뷰를 활성화하려면 GitHub 운영자가 협업 권한을 갖춘 계정과 브랜치 정책을 지정해야 한다.
