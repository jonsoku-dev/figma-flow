# docs(roadmap): narrow P2 baseline to the full discovery workload

## 문제와 계기

계약은 full과 summary 두 workload를 측정 대상으로 적었다. 독립 검토와 root는 그래프가 요구하는 라이브 기준선이 고정 범위의 fresh full discovery 하나라고 판정했다. summary 라이브 측정은 구현 범위에 없었다.

## 결과 동작

커밋 `bb443799f1e91b44f68c4dafc430ac27fb685514`는 기준 workload를 `discovery-full-default` 하나로 정했다. `discovery-full-timed`는 같은 읽기의 관측 overhead로만, 진단 counts는 median 밖 별도 단위로 적는다. summary 수치와 reader의 end-to-end 비중을 후속 browse 캐시 근거로 쓰지 않는다. discovery 결과의 `coverage_complete`는 `null`이다. 소유 표에 러너와 검사 파일을 넣었다.

## 변경 파일과 인터페이스

`docs/next-roadmap/p2-wave1-acceptance.md`, `docs/next-roadmap/capability-review.md`의 계약 링크 문장.
