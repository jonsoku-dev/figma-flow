# 현재 패널 검사 설정의 승인 근거 추가

커밋 `07befb0bfc019d46ef53b1dcc76311f14873bb90`

## 문제와 계기

이전 패널 검토는 41개 파일 범위였고 현재 작업의 검사 설정과 관측기 네 개에는 파일별 근거가 필요했다.

## 결과 동작

활성 Biome·Oxlint 규칙과 실제 빌드 경계의 통과 및 거절을 알려진 입력으로 검증한다.

## 변경 파일과 인터페이스

release/authority.json에 등록된 현행 설정을 연결하고 tests/test_panel_quality_witness.py 및 tests/test_graph_generated.py에 이름이 있는 검사를 추가했다.

## 설계 이유와 출처

기존 정책의 원본을 그대로 사용한다. CSS 속성·JSON 중복 키와 React 조건부 Hook 증거는 실제 호출로 확인한다.

## 호환성·이관·복구

패널 실행 인터페이스를 유지하고 독립 검증과 Graph 소유권 정보만 추가했다.

## 검증과 미검증

Biome·Oxlint의 두 실제 도구 사례와 네트워크 우회를 주입한 실제 빌드 사례가 통과했다. 삭제나 우회를 검증할 때는 긍정 입력도 검증한다.

## 한계와 후속 개선

확인한 구성의 명시된 검사에 적용되며 Figma 네이티브 호스트는 별도 인수 범위다.
