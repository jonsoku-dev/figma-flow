# test: require shared component fields to keep the same main component

## 문제와 계기

같은 token을 쓰는 컴포넌트 필드를 함께만 적용하고 기존 main component를 유지하는 선택이 고정되어 있지 않았다. 이 커밋 80742c55590c46e85ca8289298abc0a58371a9a8의 검사는 commit_component_fields가 없어 `component field selection must keep the main component`로 실패한다.

## 결과 동작

tests/test_rd04_component_fields.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 tests/fixtures/rd04/component-fields.json의 paddingLeft와 paddingRight만 12가 되고 fontSize는 14로 남는다. node_id와 main_component_id는 main-1이다. paddingLeft만 고르면 partial component closure다. before와 다른 관측값은 stale before value로 거절된다.

## 변경 파일과 인터페이스

tests/test_rd04_component_fields.py와 tests/fixtures/rd04/component-fields.json을 추가했다. 제품 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd04_component_fields로 실행한다.

## 설계 이유와 출처

RD-04 작업 5는 토큰 왕복 뒤에 component field 선택을 추가한다. 공유 token closure는 원자적으로 고른다.

## 호환성·이관·복구

이 커밋은 fixture와 검사를 고정한다. 기존 token 선택과 전체 적용 경로는 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `component field selection must keep the main component`다. Figma 컴포넌트 적용은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 필드다. 구현은 별도 커밋 f5e853a2056798c94b5cf5419484255998f6bd85에서 검사와 fixture blob을 유지한 채 적용을 추가한다.
