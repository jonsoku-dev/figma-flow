# test: keep parameterized editor harnesses out of standalone discovery

## 문제와 계기

전체 Node 검사에서 두 editor fixture가 컴파일된 SDK 경로 인자 없이 실행되어 종료했다. Python에서 인자를 주는 원래 경로는 성공했다.

## 결과 동작

매개변수가 필요한 editor harness를 기존 helpers 폴더에 배치하고 두 Python 호출자가 새 경로로 불러온다. 독립 Node 테스트와 빌드 연계 테스트가 본래 계약대로 실행된다.

## 변경 파일과 인터페이스

`tests/helpers/figma_figjam_review_harness.cjs`, `tests/helpers/figma_slides_review_harness.cjs`, `tests/test_review_selection_identity.py`, `tests/test_slides_flow_review_recipe.py`의 참조를 이관했다.

## 설계 이유와 출처

런타임 fixture는 단독 실행을 지원하는 Node test가 아니다. 검사 조건을 없애는 대신 매개변수가 필요한 실제 호출자를 유지하고 원본 위치를 제거했다.

## 호환성·이관·복구

제품 CLI와 설치 형식은 변하지 않는다. 기존 개발자가 직접 harness를 실행하려면 helpers 하위 경로와 생성한 SDK 코드 경로를 전달한다.

## 검증과 미검증

최초 전체 Node 결과는 실패 2건이었다. 호출자 세 검사가 실제 TS 빌드 후 통과했고, 전체 Node 319건 중 318건 통과·1건 건너뜀을 별도의 깨끗한 checkout에서 확인했다.

## 한계와 후속 개선

fixture 기반 이상 입력 검사는 현장 관측 근거를 대체하지 않는다. 실제 Figma에서 세 에디터의 생성·재사용·구버전 이관을 대조한 기록은 제품 커밋에 있다.
