# 기존 패널 동작을 Codex에서 실행하고 선택 정보를 표시

## 문제와 계기

패널을 뷰어로 바꾼 뒤 일부 적용, 새 복사본, 실행 이력, 레이어 선택 등 기존 동작을 Codex에서 어떻게 수행하는지 확인할 필요가 있었다.

## 결과 동작

`33aff6692660a7c212e576a719dff3709cd9ae01`에서 부분 적용·새 복사본·요약 및 검증한 프로토타입 시작점 명령, 디바이스 이력·표시 언어·선택 읽기 경로를 추가했다.

## 변경 파일과 인터페이스

`tools/figma_control.py`와 `figma-bridge/workspace_control.js`는 서명한 작업의 옵션을 전달한다. `tools/figma_workspace.py`와 `tools/workspace_report.py`는 저장된 작업과 이력을 조회한다. `panel-ui/src/RelayViewer.jsx`는 TanStack Query와 Table을 사용한다.

## 설계 이유와 출처

계정 정책과 프로젝트 graph를 유지하고, Figma의 실제 장면이 필요한 작업과 Codex가 요청·확인하는 동작을 대조표에 구분했다.

## 호환성·이관·복구

기존 revision, 파일·페이지 고정, 현재 파일의 로컬 설정과 저장 이력을 사용한다. 선택 본문은 명시적인 요청에서만 첨부한다.

## 검증과 미검증

고정한 검사와 영향받는 자동 검사, Chromium에서 세션·표·언어·좁은 폭을 확인했다. Figma Desktop에서 Codex로 기존 인스턴스 두 개를 선택하고 실제 치수를 읽은 뒤 원래 선택과 언어를 복원했다.

## 한계와 후속 개선

모든 가져오기와 변경 옵션을 모두 사용자 원본에 기록하는 검증은 하지 않았다. 실제 프레젠테이션 재생, 유료 Dev Mode 권한과 사용자의 시각적 승인은 별도의 관찰이다.
