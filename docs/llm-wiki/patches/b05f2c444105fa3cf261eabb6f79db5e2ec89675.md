# test: keep only the public runtime boundary symbols

## 문제와 계기

전송을 옮긴 뒤에도 예전 위치 설명이 남아 공개 이름이 고정되지 않았다. 이 커밋 b05f2c444105fa3cf261eabb6f79db5e2ec89675의 검사는 public_runtime_symbols가 없어 `runtime boundary must keep only its public symbols`로 실패한다.

## 결과 동작

tests/test_rd07_public_symbols.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 공개 이름 여덟 개를 반환하고, controlRequest 정의는 workspace_transport.js 하나다. 예전 발행 이어 붙이기와 Transport stays in place 문구는 없다.

## 변경 파일과 인터페이스

tests/test_rd07_public_symbols.py를 추가했다. docs/development-roadmap/RD-07-runtime-boundaries/tasks.md에 범위를 적었다. 제품 함수는 이 커밋에서 지우지 않는다.

## 설계 이유와 출처

RD-07 작업 5는 구 경로를 지우고 필요한 공개 심볼만 남긴다.

## 호환성·이관·복구

검사와 작업서만 추가한다. wire format은 그대로다.

## 검증과 미검증

이 기준 트리에서 `python3 -B -m unittest tests.test_rd07_public_symbols`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 플러그인 재로드는 하지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. 문구 삭제와 공개 목록은 구현 커밋에 있다.
