# feat(little-hands): align family targets and exporter with nf01-contract

## 문제와 계기

## 결과 동작

커밋 `b40278221d8c023249462cd628edbdc51c0b041f`는 `apps/little-hands/design/family-targets.json`, `apps/little-hands/design/source.py`, `apps/little-hands/design/test_source.py`, `apps/little-hands/design/README.md`를 갱신해 `nf01-contract` 스키마에 맞춘 6개 패밀리 매핑과 검증 테스트를 정렬했다.

## 변경 파일과 인터페이스

`apps/little-hands/design/family-targets.json`, `apps/little-hands/design/source.py`, `apps/little-hands/design/test_source.py`, `apps/little-hands/design/README.md`를 수정했다.

## 설계 이유와 출처
