# test: pin flat layers apart from declared containers

## 문제와 계기

RD-02는 선언한 컨테이너만 만들어야 한다. 구현 전에 컨테이너가 없는 레이어와, Frame·Auto Layout·Group을 선언한 트리를 서로 다른 fixture로 고정하지 않으면 이후 변경이 둘을 섞을 수 있다.

## 결과 동작

tests/fixtures/rd02/flat-layers.json은 같은 leaf 다섯 개와 빈 containers를 가진다. declared-containers.json은 card Frame, copy와 actions Auto Layout, ornament Group만 선언한다. Group에는 layout·fill·clip이 없다. 부모와 children 목록이 일치하고 leaf id와 container key는 겹치지 않는다. 네이티브 트리는 아직 만들지 않는다.

## 변경 파일과 인터페이스

tests/fixtures/rd02/flat-layers.json, tests/fixtures/rd02/declared-containers.json, tests/test_rd02_layer_fixtures.py, docs/development-roadmap/RD-02-layer-structure/tasks.md. 부모는 d5b26f079e3b2a38ba141877eca8b5782a1bd895다. 런타임은 바꾸지 않는다.

## 설계 이유와 출처

RD-02 작업서의 첫 단위는 fixture 고정이다. 설계서의 container 예시는 parent null이 화면 Frame이고 Group에 layout을 두지 않는다는 경계를 그대로 담는다. 좌표가 비슷하다는 이유로 그룹을 추정하지 않는다.

## 호환성·이관·복구

기존 방향 패킷과 화면 prototype은 이 커밋에서 바뀌지 않는다. containers가 없는 패킷의 동작도 바꾸지 않는다.

## 검증과 미검증

tests.test_rd02_layer_fixtures 1개가 통과했다. 실제 Figma 레이어 트리, prototype 왕복, resize는 관찰하지 않았다. 이 fixture는 이후 Python 검증의 입력이다.

## 한계와 후속 개선

선언한 트리를 네이티브 Group·Frame·Auto Layout으로 쓰는 일은 다음 단위다. 이 커밋만으로 AC-01을 통과했다고 기록하지 않는다.
