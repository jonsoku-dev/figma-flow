# test: require declared parents to reuse authored leaves

## 문제와 계기

기준 직전에는 선언한 컨테이너를 검증만 하고, 이미 만든 leaf의 부모를 붙이는 함수가 없었다. 이 커밋의 검사는 그 함수가 없어 `declared parents must reuse authored leaves`로 실패한다.

## 결과 동작

tests/rd02_container_placement_oracle.cjs는 placeDeclaredLayerParents가 함수가 아니면 위 문구로 끝난다. 함수가 있으면 평평한 containers는 leaf 부모를 유지하고, 선언한 트리는 card Frame, copy·actions Auto Layout, ornament Group을 만든다. leaf의 화면 기준 위치, semantic key, 문자, raster plugin data, prototype destination은 유지된다. 없는 target은 쓰기 전에 거절하고, Group 생성이 실패하면 새 컨테이너를 제거한 뒤 leaf를 원래 부모와 좌표로 되돌린다.

## 변경 파일과 인터페이스

tests/rd02_container_placement_oracle.cjs만 추가했다. figma-bridge/direction_review.js는 이 커밋에서 바꾸지 않았다. 검사는 node tests/rd02_container_placement_oracle.cjs로 직접 실행한다.

## 설계 이유와 출처

RD-02 작업 3은 기존 leaf 작성 경로를 재사용하고 부모 배치만 추가한다. 화면 Frame의 ID·크기·clip과 선언하지 않은 노드는 그대로 둔다. 설계서의 parent null은 화면 Frame이다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 네이티브 노드를 만들지 않는다. containers가 비어 있는 기존 방향 패킷의 작성 경로는 이 파일만으로는 바뀌지 않는다.

## 검증과 미검증

로컬 실행은 종료 코드 1이고 stderr의 마지막 assertion은 `declared parents must reuse authored leaves`다. 실제 Figma 레이어 트리, prototype 왕복, resize는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 mock 부모 배치다. 구현은 별도 커밋 9a465e535cafbf7e8be7fd4d7a2693b70ada4400에서 검사 blob을 유지한 채 추가한다. AC-01의 실제 트리 관찰은 통과로 기록하지 않는다.
