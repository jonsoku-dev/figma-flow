# 아카이브 검사 중 그래프 잠금 파일 격리

## 문제와 계기

앱 토큰 공개 테스트가 검증 대상으로 받은 후보 트리에 잠금 파일을 남겨 정확한 아카이브 검사가 차단됐다.

## 결과 동작

`2c762e74fc27db91fc60712405e91a5e83caf5f8`에서 실제 원본 그래프의 바이트를 임시 디렉터리에 복사한 뒤 두 번 공개한다.

## 변경 파일과 인터페이스

`tests/test_little_hands_design_system.py`와 앱 영역 검토 영수증을 갱신했다.

## 설계 이유와 출처

후보 파일 변경 탐지를 그대로 두고 임시 경로를 사용하는 테스트 쪽에서 파일 소유권을 고쳤다.

## 호환성·이관·복구

공개 CSS와 모듈과 원본 그래프에 적용하는 동일한 단언을 유지했다.

## 검증과 미검증

격리 아카이브에서 앱 검사가 원본을 변경하지 않고 통과했으며, 그 시점의 다른 미검토 영역 7개로 메이저 패키징은 계속 차단됐다.

## 한계와 후속 개선

다른 영역까지 통과했다는 결과로 사용하지 않는다.
