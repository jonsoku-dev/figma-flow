# 1f8d203 · 비공개 설치와 Figma 온보딩 문서

이 기록은 원본 커밋 `1f8d203dff972a1c98b8b2a49d5d0d20a838d80e`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

비공개 저장소 설치, 패키지 접근과 Figma 첫 연결은 공개 저장소 기준 안내만으로 설명하기 어려웠다.

## 결과 동작

docs/installation-and-updates.md, docs/npm-environment.md, docs/private-repository.md, skills/figma-plugin-setup/SKILL.md를 추가하고 .npmrc/.nvmrc 및 무시 설정을 마련했다. setup prompt와 README도 신규 절차를 가리킨다.

## 변경 파일과 인터페이스

설치 스킬은 초기 설치·업데이트 절차를 설명하고 .nvmrc가 Node 버전을, .npmrc가 npm 레지스트리 설정을 표현한다. docs는 private clone과 문제 해결의 안내 표면이다.

## 설계 이유와 출처

개인 저장소 권한과 npm 환경을 제품 파일에 하드코딩하지 않고 별도 문서·호스트 설정으로 안내한다.

## 호환성·이관·복구

비공개 저장소 접근 권한 및 사내 패키지 자격증명은 사용자의 환경이 필요하다. 문서 추가는 기존 공개 clone 경로를 삭제하지 않는다.

## 검증과 미검증

실행 로그나 사용자의 실제 설치 성공을 포함하지 않는다. 문서 절차의 현재 유효성은 당시 상태만 기술한다.

## 한계와 후속 개선

레지스트리·Node 버전·호스트 UI는 변경될 수 있다. 인증값은 저장소에 기록하지 말고 설치 환경에서 관리해야 한다.
