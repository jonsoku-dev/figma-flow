# 감사, 그래프 입력, 리뷰 패널과 릴리스 변이 검증

## 문제와 계기

원시 JSON 읽기, 화면과 네트워크의 결합, 저널 입력의 제한된 사례가 반복될 배경을 감사했다.

## 결과 동작

감사 위치를 재현할 수 있고 공통 디코더·패널 전송 경계·저널 속성 검증이 실제 유지보수 명령과 릴리스 실행에 연결된다.

## 변경 파일과 인터페이스

`docs/maintenance-audit.md`, `tools/maintenance-contract.json`, `panel-ui/architecture.cjs`, `tests/test_journal_properties.py`와 실제 소비 코드를 갱신했다.

## 설계 이유와 출처

등록 그래프 입구에 엄격한 디코더를 적용하고 리뷰 패널의 로컬 전송을 단일 어댑터로 통과시킨다. 저널 거절·순서·멱등성·페이지 격리를 검사한다.

## 호환성·이관·복구

기존 예시 테스트와 그래프 정체성을 유지한다. 검증 프로필은 사용자 Design 파일이나 라이브 변경 기록을 쓰지 않는다.

## 검증과 미검증

다섯 프로필이 통과했다. 릴리스는 그래프 6,000건과 저널 4,000건을 실행했다. Chromium 패널 전후 PNG는 SHA-256 7a7592e7318b9b10f6e23eaa75743cbccfad137652e2d569da8b5eedde2daa14로 같았다.

## 한계와 후속 개선

감사는 Git 추적 규칙과 Python 후보를 제공한다. 실제 Design 승인과 자동 후보의 의미 판정은 별도 증거를 사용한다. 별도 패널 로더의 초기 복사본 재현 실패는 다음 수정에서 확인한다.
