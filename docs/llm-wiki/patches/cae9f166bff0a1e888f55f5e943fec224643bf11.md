# CLI 진단 1차 RC 근거

## 문제와 계기

제어 CLI에 추가한 세 진단을 배포 기록에서 찾고 실제 후보 실행과 연결할 필요가 있었다.

## 결과 동작

1.1.0 변경 이력과 소스별 페이지에 고정 재현, 수정, 실제 Desktop 검수의 범위를 남겼다.

## 변경 파일과 인터페이스

CHANGELOG.md, Wiki 대조표 및 세 패치 페이지를 갱신한 기록 커밋이다.

## 설계 이유와 출처

부모의 제품 소스와 이 커밋의 diff로 문서 전용이라는 점을 확인할 수 있다.

## 호환성·이관·복구

같은 제품 소스의 실행 증거를 보존하며 이후 수정은 새 커밋과 새 제품 지문으로 식별한다.

## 검증과 미검증

이 시점의 Wiki 검사는 소스 이력 538개와 기록 전용 후속 커밋 1개를 확인했다.

## 한계와 후속 개선

최종 RC에는 설정 쓰기와 API 정적 근거가 추가되므로 이 버전의 Desktop 영수증을 별도로 유지한다.
