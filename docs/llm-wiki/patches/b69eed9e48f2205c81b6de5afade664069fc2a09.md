# test: verify value evidence replays after joining the default graph

## 문제와 계기

typed value-path plan은 Figma file, page, plugin ID, service receipt에서 private scope를 이어받는다. 이 경로가 exact scope를 유지하면서도 어떤 값을 다시 기록하는지 공개 영수증에 누출하지 않는지 회귀 검사가 필요했다.
## 결과 동작

새 runner test는 temporary `.figma-flow` 경로에 private scope와 service receipt를 만든 뒤 `values.prepare`를 호출한다. 준비된 plan의 file/page/plugin ID, 선택 capabilities, private directory와 code mode, network `none`을 확인한다.
## 변경 파일과 인터페이스

`tests/test_native_value_paths.py`에 `test_private_runner_reuses_exact_scope_without_printing_it`를 추가했다. 검사 대상은 `values.prepare`의 private bundle 출력과 manifest다.
## 설계 이유와 출처

각 실행은 source graph, API audit와 exact scope를 고정해야 한다. Test는 scope id가 그대로 복사되는지와 output mode를 검사하고, 실제 사용자 문서에 fixture를 만들지 않는다.
## 호환성·이관·복구

Test는 temporary private directory를 사용하고, Git 작업 파일이나 Figma 문서를 수정하지 않는다. 실제 API getter runtime 근거는 `d934a20`의 value observation graph에 별도로 기록한다.
## 검증과 미검증

`NativeValuePathTests.test_private_runner_reuses_exact_scope_without_printing_it`은 준비된 plan이 `private-file`, `88:1`, `123456`을 보존하고 code와 manifest가 owner-only/network-denied 상태임을 확인한다. 이 테스트는 plugin을 Figma에서 실행하지 않는다.
## 한계와 후속 개선

이 회귀는 scope 전달과 private bundle 생성만 확인한다. Getter 결과와 normalized value 지원 범위는 별도 runtime receipt에서 확인한다.
