# 네이티브 아카이브에서 Compose 설정 증거 실행

소스 커밋 `79ba8f68c9d95d035b28e4fe78fa68a9a8a73207`

## 문제와 계기

macOS 아카이브 게이트의 마지막 차단이 예약 예제의 Compose 배포 파일을 읽는 검사의 실행 환경에서 발생했다.

## 결과 동작

러너 전용 Docker CLI와 Compose 플러그인이 설정을 해석할 수 있으며, 이 검사를 전체 아카이브보다 먼저 실행한다.

## 변경 파일과 인터페이스

`library/delivery/reference-guard.yml.in`과 생성 워크플로 `.github/workflows/reference-guard.yml`을 갱신했다.

## 설계 이유와 출처

Docker 엔진이나 외부 서비스가 필요 없는 구성 검사를 실제 클라이언트로 재현한다.

## 호환성·이관·복구

기존 예약 DB 인수, Figma 플러그인과 클러스터 사용 범위는 유지한다.

## 검증과 미검증

로컬 Compose·배포 검사 11건이 통과했다. 원격의 준비 조건과 같은 후보의 전체 게이트를 재실행한다.

## 한계와 후속 개선

공식 ZIP은 해당 Git 소스의 원격 검사가 통과하고 바이트를 확인한 뒤 발행한다.
