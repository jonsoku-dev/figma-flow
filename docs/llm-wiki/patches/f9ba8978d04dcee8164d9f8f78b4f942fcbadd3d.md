# test(semantic-components): verify unconditional owned-component-families and graph repeat-apply integration

## 문제와 계기

`709f1104`의 `tests/nf01_semantic_family_runtime.cjs` 통합 테스트는 `examples/owned-component-families/design.json` 또는 `compile_graph_component_families`가 없으면 skip하도록 작성돼, 두 요소가 `main`에 통합된 뒤에도 조건부 skip이 실제 통합 회귀를 가릴 수 있었다.

## 결과 동작

커밋 `f9ba8978d04dcee8164d9f8f78b4f942fcbadd3d`는 조건부 skip과 `node:fs` 의존을 제거하고, 테스트를 `compiles real examples/owned-component-families/design.json and preserves live overrides/placement on static repeat apply`로 바꿔 실제 자체 예제를 `compile_graph_component_families`로 컴파일한 뒤 정적 반복 적용에서 사용자 오버라이드와 배치가 보존되는지를 항상 검사한다.

## 변경 파일과 인터페이스

`tests/nf01_semantic_family_runtime.cjs`만 수정했다(54줄 추가, 21줄 삭제). 제품 런타임 인터페이스는 바뀌지 않았다.

## 설계 이유와 출처

선택적 skip은 브랜치 통합 전 임시 조치였으므로, 통합 뒤에는 자체 공개 예제와 정본 그래프 컴파일러가 반드시 함께 동작함을 테스트가 보장해야 한다는 [NF-01 설계서](../../next-roadmap/NF-01-component-families.md)의 반복 적용 보존 조건을 따랐다.

## 호환성·이관·복구

테스트 전용 변경이다. 예제나 컴파일러가 빠진 체크아웃에서는 이제 skip이 아닌 실패로 드러난다.

## 검증과 미검증

이 suite는 이후 P1 Node 집중 검사(`36/36`)와 `e6f4fd8` CI Run `43599181267` Node 전체 실행에 포함돼 통과했다. 이 테스트는 Figma 모의 런타임 기반이며 실기 반복 적용 보존은 `c208a3f3` 영수증의 실제 Figma 근거로 별도 확인했다.
