# feat: show one-step predecessors and successors for the selected task

## 문제와 계기

기준 ee61c93b47d9938c6379d1ea1b638d449338b48a는 dependencyView가 없어 `selected dependency view must list predecessors and successors`로 실패했다.

## 결과 동작

dependencyView는 선택 task의 uses-output 한 단계만 선행과 후속으로 돌려준다. 각 항목은 상대 제목·key, relation, artifact, hash, 고정 revision, 그 대상의 현재 revision을 갖고 텍스트 한 줄로 같은 내용을 적는다. edge가 없으면 `연결된 선행·후속이 없습니다`만 보여 준다. nearby relation과 같은 project는 선이 되지 않는다. 없는 선택은 `unknown selected task`다. public_task_metadata는 공개 필드와 edge 다섯 필드만 복사하고, workspaceDependencyEdges는 그 edge만 작업 목록 payload에 싣는다. DependencyText는 그 텍스트와 정적 SVG를 그리며 버튼은 선택만 바꾼다.

## 변경 파일과 인터페이스

panel-ui/src/dependencyView.mjs에 dependencyView를 추가했다. panel-ui/src/Workspace.jsx와 panel-ui/src/styles/workspace.css가 그 보기와 320px에서 그래프를 숨기는 텍스트 목록을 쓴다. figma-bridge/assets/panels.js와 figma-bridge/assets/panels.css는 그 원본의 생성 번들이다. figma-bridge/workspace_host.js가 depends_on을 거르고, figma-bridge/locales/workspace.json에 선행과 후속 제목을 추가했다. tools/figma_workspace.py의 public_task_metadata가 발행 metadata에 edge를 싣는다. docs/development-roadmap/RD-03-task-dependencies/tasks.md에 범위를 적었다. tests/test_rd03_dependency_view.py blob은 기준과 같다.

## 설계 이유와 출처

RD-03은 UI adjacency를 catalogue edge의 projection으로 둔다. 한 단계만 펼치고, 텍스트 목록은 같은 필드를 문장으로 보여 준다. 관계 조회와 작업 열기를 분리해 native mutation이 생기지 않게 한다.

## 호환성·이관·복구

depends_on이 없는 task는 metadata와 목록 payload에 필드를 만들지 않는다. 기존 열기·이력 버튼은 그대로다. 시각화를 숨겨도 텍스트 목록과 catalogue edge는 남는다.

## 검증과 미검증

종료 게이트는 `python3 -B -m unittest tests.test_rd03_dependency_view`를 기준 ee61c93b47d9938c6379d1ea1b638d449338b48a에서 종료 코드 1, 대상 ef624aadc2e99029e227c62d57d7b6b56df21c5e에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 마지막 assertion은 `selected dependency view must list predecessors and successors`다. 조건은 RD-03-AC-05다. 같은 구현에서 workspace host 검사도 종료 코드 0이었다. 320px 브라우저, 키보드 이동, Figma 패널은 관찰하지 않았다.

## 한계와 후속 개선

stale·retired·orphan 표시는 아직이다. AC의 화면 관찰은 통과로 기록하지 않는다.
