# docs: record 0.29 graph workflows and real editor receipts

## 문제와 계기

정본에서 파생한 검토 기능과 실제 에디터 관측 범위를 공개해야 했다. 입력 자료의 오프라인 매핑과 개별 API의 상태를 사용자에게 전달할 수 있는 버전 기록을 만들었다.

## 결과 동작

0.29.0 릴리스 기록에서 실제 Design·FigJam·Slides 인수, 네 외부 템플릿의 브라우저 흐름, 현재 관측과 미확인의 차이를 확인할 수 있다.

## 변경 파일과 인터페이스

`docs/llm-wiki/releases.md`와 `docs/llm-wiki/catalog.json`, 세 patch 문서를 작성했다. 제품 소스는 앞선 b1e4a06 커밋이다.

## 설계 이유와 출처

쿼리가 다른 웹 자산, 동일 그래프의 다른 부분 선택, 실제 에디터 노드와 테스트 더블 결과를 각각 구분해서 기록했다.

## 호환성·이관·복구

이 문서 발행본은 이전 버전 태그 또는 원본 프로젝트를 수정하지 않는다. 후속 검증에서 발견한 문제가 있을 경우 해당 패치를 적용하고 새 태그를 발행한다.

## 검증과 미검증

Wiki verify는 기록 240개와 문서 발행 1개, 보관 계보 39페이지의 구조를 확인했다. Python 전체 1,195건 중 2건 건너뜀. 이후 Node 전체 실행에서 Python이 호출해야 하는 helper 두 개를 단독으로 실행한 문제를 발견했다.

## 한계와 후속 개선

이 시점의 문서만으로 새 패키지의 최종 원격 CI 결과나 설치 상태를 확정하지 않는다. 저장소 검사를 전체 실행해 후속 실패를 함께 기록한다.
