# nf01: author TEXT/BOOLEAN/INSTANCE_SWAP properties, swap ranges, and repeat-apply rollback in code.js

## 문제와 계기

Figma 플러그인 메인 스크립트(`figma-bridge/code.js`)가 `COMPONENT`/`COMPONENT_SET`의 `TEXT`, `BOOLEAN`, `INSTANCE_SWAP` 선언형 속성과 `preferredValues` 스왑 범위, 반복 적용 실패 시 롤백을 처리하지 못했다.

## 결과 동작

커밋 `cfc7fbd1a2867d2665c29e9eaa066b4b18eac254`는 `figma-bridge/code.js`에 선언형 컴포넌트 속성 생성·바인딩·`INSTANCE_SWAP` 허용 범위 작성·실패 시 생성 노드 롤백을 구현하고, 기존 `verifyDeclaredComponentReadback`·`bindDeclaredComponentProperties`를 확장하며 `reapplyDeclaredComponents`·`componentLayoutMode`를 추가하고 `tests/nf01_component_properties.cjs` 단위 테스트를 신설했다.

## 변경 파일과 인터페이스

`figma-bridge/code.js`, `tests/nf01_component_properties.cjs`(신규)를 수정·추가했다.

## 설계 이유와 출처

[NF-01 설계서](../../next-roadmap/NF-01-component-families.md)의 선언형 컴포넌트 속성 계약을 실제 Figma Plugin API(`addComponentProperty`, `componentPropertyDefinitions`) 호출 시퀀스로 구현하기 위함이다.

## 호환성·이관·복구

선언형 속성 메타데이터가 없는 기존 플랜은 영향받지 않는다. 중복 표시명·Figma 자동 정규화 `#suffix` 키 및 최상위 롤백 root 처리 결함은 후속 `974b5de7` 커밋에서 보강됐다.

## 검증과 미검증

`node --test tests/nf01_component_properties.cjs` 및 `e6f4fd8` Node suite가 통과했고 pre-freeze NF-03 Gate C 패널 검증도 이 런타임 세대 위에서 동작했다. 단, NF-01 중복 표시명 실기 첫 적용 실패·충돌 안전 키 수정은 후속 `974b5de7` 커밋에서 해결됐다.

## 한계와 후속 개선

당시 구현은 `addComponentProperty` 반환 실제 키(`actualKey`) 충돌 회피와 비파괴 `declared_property_contracts` 기록이 미흡해 `974b5de7`에서 수정됐다.
