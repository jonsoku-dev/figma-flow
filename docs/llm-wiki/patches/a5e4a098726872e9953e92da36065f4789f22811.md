# fix(benchmark): count read-only native objects and require a valid diagnostic

## 문제와 계기

live-001 진단 회차가 `proxy: inconsistent get`으로 실패했는데 러너가 기준선을 기록한 거짓 양성이었다.

## 결과 동작

커밋 `a5e4a098726872e9953e92da36065f4789f22811`에서 getter-count Proxy는 빈 facade를 대상으로 삼고 읽기와 호출을 native 객체에 receiver·this로 넘긴다. 읽기 전용 non-configurable 멤버가 get 불변식을 깨지 않는다. 세는 대상은 같다. 러너는 진단이 실행·성공했고, 허용된 모든 페이지의 유효한 counts가 있으며, 샘플과 scope·content가 같을 때만 기준선과 native proof를 기록한다. counts 없는 진단은 보고서를 깨뜨리지 않고 `invalid-counts`가 된다. 실패한 진단은 `samples.jsonl`에 남는다.

`figma-bridge/native_read_measurement.js`, `tools/native_read_benchmark.py`, `docs/next-roadmap/NF-02-incremental-native-read.md`.
