# docs: connect native SVG evidence and observed web states to the design graph

## 문제와 계기

벡터 색 보정의 적용 조건 및 성공·한계를 정본 그래프와 가이드에서 찾을 수 있어야 했다.

## 결과 동작

브라우저 SVG 필터의 지원 범위, 실제 로고 비교와 편집 가능성, 재적용 근거를 문서와 인수 그래프에 연결했다.

## 변경 파일과 인터페이스

변경 파일: `docs/next-roadmap/NF-09-interactive-web-design.md`, `docs/web-design-capture.md`, `docs/web-svg-fidelity-0322.md`, `specs/editable-web/graph.json`, `specs/interactive-web/graph.json`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

색도 판정은 표본의 독립 검증 수단이다. 임의 이미지의 성공 기준이나 모든 픽셀의 일치로 사용하지 않는다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

보존된 원본에서 같은 요소 ID·RGB 영역·벡터 자손과 첫 적용 및 재사용 프레임을 비교했다. 플러그인으로 생성한 다른 54개 프레임은 별개 Chrome에서 원래 ID와 치수를 대조했다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
