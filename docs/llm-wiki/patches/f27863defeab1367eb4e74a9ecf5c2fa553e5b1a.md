# release: version the observed tab prototype workflow as 0.34.0

## 문제와 계기

탭 기능을 0.34.0으로 발행하려면 버전 표기를 맞춰야 했다.

## 결과 동작

두 플러그인 매니페스트와 README, 가이드의 버전·태그 문자열을 0.34.0으로 바꿨다.

## 변경 파일과 인터페이스

`plugin.json`, `.codex-plugin/plugin.json`, `README.md`, `docs/guide.md`를 바꿨다.

## 설계 이유와 출처

0.33.0 발행 커밋과 같은 위치를 갱신했다.

## 호환성·이관·복구

버전 문자열만 바꿨다. 0.33.0 설치본은 그대로 동작하며, 새 태그를 받은 설치만 0.34.0으로 표시된다.

## 검증과 미검증

`git grep`으로 남은 0.33.0 설치 문자열이 없음을 확인했다. 태그와 설치본 검증은 발행 단계에서 따로 기록한다.

## 한계와 후속 개선

문서의 버전 문자열은 설치나 게시 완료를 뜻하지 않는다.
