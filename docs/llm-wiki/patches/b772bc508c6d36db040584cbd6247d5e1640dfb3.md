# 실제 탭 버튼 클릭을 위한 브라우저 회귀 기준

## 문제와 계기

일반 HTML 버튼은 캡처 시 편집 가능한 버튼 컴포넌트가 되지만 기존 탭 입력 경로는 프레임만 허용했다.

## 결과 동작

`b772bc508c6d36db040584cbd6247d5e1640dfb3`에서 Chromium으로 로컬 탭·디스클로저·캐러셀을 실제 조작하는 독립 명령 검사를 보존했다.

## 변경 파일과 인터페이스

`tests/test_interactive_capture_release.py`는 격리 서버에서 상태, 전환, 서로 다른 관측 이미지를 읽는다.

## 설계 이유와 출처

실제 클릭 위치와 캡처된 요소의 정체성을 함께 고정한다.

## 호환성·이관·복구

외부 URL, 계정 및 사용자 Figma 캔버스 대신 일회성 로컬 화면을 사용한다.

## 검증과 미검증

수정 전 탭 버튼이 하나의 프레임이 아니라는 원인으로 거절됐다. 나머지 두 입력 경로는 별도로 확인했다.

## 한계와 후속 개선

브라우저 전환 근거와 네이티브 재생은 서로 다른 검사다.
