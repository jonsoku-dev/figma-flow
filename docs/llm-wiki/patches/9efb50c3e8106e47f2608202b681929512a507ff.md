# 로컬 그래프와 메이저 검사의 관계 정의 통합

## 문제와 계기

로컬 그래프와 배포 검사기가 같은 관계의 노드 타입 규칙을 별도로 선언했다.

## 결과 동작

`9efb50c3e8106e47f2608202b681929512a507ff`에서 로컬 관계를 공용 원본으로 삼고 배포 검사가 기존 명세에서 지원하는 별도 관계를 덧붙인다.

## 변경 파일과 인터페이스

`skills/figma-flow/scripts/graph.py`, `tools/spec_graph_coverage.py`, `tests/test_graph_vocabulary_owner.py`를 갱신했다.

## 설계 이유와 출처

관계의 소유자와 명세에 필요한 범위 차이를 명시적으로 표현한다.

## 호환성·이관·복구

등록 그래프의 ID와 합법적인 기존 명세 관계가 유지된다.

## 검증과 미검증

원본 관계를 바꾼 격리 실행에서 배포 검사기가 이를 읽고 verified-by에도 반영하는지 검증했다.

## 한계와 후속 개선

관계 정의의 유효성 외에 행동 검증은 각 증거와 스킬 문서의 범위를 따른다.
