# test: require control transport to move without domain checks

## 문제와 계기

제어 HTTP 전송과 kind, scope, revision 검사가 한 파일에 있었다. 이 커밋 2db4fdafa3e8e337c68cdb4d4dd53f9d1f30a797의 검사는 workspace_transport.js의 controlRequest가 없어 `pure transport must leave domain checks in place`로 실패한다.

## 결과 동작

tests/rd07_transport_move.cjs는 전송 함수가 없으면 위 문구로 끝난다. 함수가 있으면 workspace_control.js에는 async function controlRequest가 없고 poll, native-started, result 호출과 controlExecute, controlAllowed는 남는다. 발행 소스는 workspace_transport.js를 workspace_control.js보다 앞에 둔다.

## 변경 파일과 인터페이스

tests/rd07_transport_move.cjs를 추가했다. docs/development-roadmap/RD-07-runtime-boundaries/tasks.md에 이동 범위를 적었다. 제품 파일은 이 커밋에서 나누지 않는다.

## 설계 이유와 출처

RD-07 작업 2는 순수 전송만 옮기고 domain validator 호출 위치를 유지한다.

## 호환성·이관·복구

검사와 작업서만 추가한다. wire format은 그대로다.

## 검증과 미검증

이 기준 트리에서 `node tests/rd07_transport_move.cjs`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 플러그인 재로드는 하지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. 함수 이동은 구현 커밋에 있다.
