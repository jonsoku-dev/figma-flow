# test: require a partial apply to leave skipped values and the baseline

## 문제와 계기

고른 token만 바꾸고 나머지와 baseline을 그대로 두는 적용이 고정되어 있지 않았다. 이 커밋 5caacfd96b70a03abd80d331a5a8b5317a38e2bf의 검사는 commit_selective_apply가 없어 `selective apply must keep skipped values and limit the baseline`로 실패한다.

## 결과 동작

tests/test_rd04_selective_apply.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 color/action과 color/quiet만 새 값이 되고 space/gap은 8로 남는다. baseline에는 그 두 값만 있다. before와 다른 관측값은 stale before value로 거절되고 입력은 바뀌지 않는다. 빈 선택과 alias 반쪽 선택도 거절한다. JS commitGraphSelection은 같은 결과를 낸다.

## 변경 파일과 인터페이스

tests/test_rd04_selective_apply.py를 추가했다. 제품 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd04_selective_apply로 실행한다.

## 설계 이유와 출처

RD-04 작업 4는 Python과 JS가 같은 선택을 검증하고, 적용·readback·baseline을 그 범위로 제한한다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. selection이 없는 기존 전체 적용은 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `selective apply must keep skipped values and limit the baseline`이다. Figma readback은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 값이다. 구현은 별도 커밋 95c8714f29ec1af8094e88896f14b114c4afa63c에서 검사 blob을 유지한 채 적용을 추가한다. component field 선택은 아직 없다.
