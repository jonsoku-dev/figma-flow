# docs: record 0.35 SaaS FAQ disclosure path, graph, and G1 release mapping

## 문제와 계기

FAQ 브라우저 관찰과 실제 읽기·프레젠테이션 근거를 세 직군이 같은 경로에서 찾을 필요가 있었다.

## 결과 동작

실행 안내와 설계 그래프가 질문 두 개의 닫힘·열림·전환과 확인한 범위를 기록한다.

## 변경 파일과 인터페이스

specs/interactive-web/graph.json 및 disclosure.md에 사건/상태/역할과 사용 시나리오를 연결하고 docs/web-disclosure-input.md의 도달 조건을 수정했다.

## 설계 이유와 출처

디자이너의 레이어 편집, 기획자의 상태 재생, 개발자의 관측 그래프를 하나의 설계 표본에 연결했다.

## 호환성·이관·복구

탭과 캐러셀 경로를 보존하고 새 인터랙션 설명을 추가했다. 이 문서 자체는 기존 Design 파일을 바꾸지 않는다.

## 검증과 미검증

정본에 닫힘·첫 질문·두 번째 질문과 각 상태에서 다른 상태로 가는 여섯 전이가 기록된다. 실제 캡처와 Figma 인수는 FAQ 병합 기록에 있다.

## 한계와 후속 개선

최초 문서의 선택자와 시작점 표시 이름·탐색 방식은 c01f895에서 실제 관측에 맞게 정리했다.
