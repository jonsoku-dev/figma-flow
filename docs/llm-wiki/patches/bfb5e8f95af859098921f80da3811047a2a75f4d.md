# fix: preserve orphan candidates across blocked source epochs

## 문제와 계기

소스에서 제거한 항목의 분류를 보존하던 source-status.json이 stylesheet epoch 차단 때 후보 목록 없는 상태 파일로 바뀌었다.

## 결과 동작

blocked-final-source-epoch 상태에도 이전 orphan_candidates를 함께 기록한다. 이후 정상 실행이 이전 후보를 작성자 추가 항목으로 오분류하지 않는다.

## 변경 파일과 인터페이스

apps/little-hands/design/source.py의 generate가 차단 상태를 만들 때 기존 prior_orphans를 전달한다.

## 설계 이유와 출처

실패 상태를 기록하면서도 다음 성공 실행이 필요로 하는 직전 후보의 노드·관계·검토 메모를 보존한다.

## 호환성·이관·복구

기존 상태에 목록이 없으면 빈 목록으로 시작한다. 차단 시 기존 graph와 cached proposal의 바이트가 유지된다.

## 검증과 미검증

독립 빌드의 종료 코드는 0→1→0이었다. 노드 3개와 관계 10개, 총 13개 레코드 전체가 세 단계에서 동일했다. 작성자 항목으로 오분류된 후보는 없었고 관련 디자인 테스트 24개도 통과했다.

## 한계와 후속 개선

검증 대상은 G1 소스 재생성이다. 이 커밋은 기존 v0.34.0 설치본에 들어 있지 않다.
