# Add owned public Design handoff baseline and provenance manifest

## 문제와 계기

기존 참고 사례나 외부 템플릿·폰트·네트워크 자산에 의존하지 않고, 출처·소유권·공유 경계가 명시된 자체 제작 공개 Design handoff 기준 입력과 회귀 테스트가 필요했다.

## 결과 동작

`examples/owned-design-baseline/` 아래 단일 정본 `graph.json`과 `manifest.json`(`figma-flow-owned-design-baseline-manifest-v1`)을 추가했다. `renderer.js`는 런타임에 `./graph.json`과 `./manifest.json`만 읽어 두 개의 단일 열림 handoff 아코디언(`Token & Typography Handoff Gate`, `Single-Collapsible Transition Parity`)을 렌더링하며, `reference-input`(`public-contract-only`), `owned-public-baseline`(`public`, MIT), `generated-private-output`(`private`, Git 미추적)의 3계층 경계를 강제한다.

## 변경 파일과 인터페이스

`examples/owned-design-baseline/README.md`, `graph.json`, `manifest.json`, `index.html`, `styles.css`, `renderer.js`와 `tests/test_owned_design_baseline.py`를 추가했다. `tests/test_owned_design_baseline.py`는 정본 그래프 유효성(3개 도달 상태, 6개 방향 전이), MIT 라이선스·무외부자산(`external_media_assets=0`, `external_font_requests=0`, `external_network_requests=0`), `index.html`/`styles.css`/`renderer.js`/`manifest.json` 내 semantic ID·문구 중복 금지 및 개인 경로 미포함을 검사한다.

## 설계 이유와 출처

외부 템플릿명·URL·스크린샷·복사 문구를 기록하지 않는 `zero-external-template-trace` 정책과 단일 그래프 정본 구조를 적용해, 공개 저장소에서 재사용 가능한 자체 Design 검토 기준선을 확보하기 위해 작성했다.

## 호환성·이관·복구

기존 `v0.35.0` FAQ 사례와 보호 참고 자료를 변경·덮어쓰지 않는 독립 예제다. 첫 초안(`86/104/104` 캡처)은 캡처 보정 후 폐기(superseded)되고 최종 확정 입력으로 새로 고정되었으며, 실행 생성물(`disclosure-capture`, `disclosure-plan.json`, `prepared-bundle`)은 저장소 바깥의 비공개 디렉터리에만 저장한다.

## 검증과 미검증

`6c9c6e454d826347971d4f7e612abcd43b8a306b` 체크아웃에서 `tests.test_owned_design_baseline`(4건)과 `skills/figma-flow/scripts/graph.py validate examples/owned-design-baseline/graph.json --strict-local` 통과를 직접 확인했다. 통합 인수 보고 기준 독립 Chromium(1440×900)에서 7클릭·3상태·6방향 전이·10/10 PNG 바이트 일치를 확인했고, 설치된 자체 플러그인 Figma Desktop 실행(`apply`·반복 `apply`·`read` 모두 `current`)에서 3상태 `85/103/103` 편집 가능 노드, 동일 3개 프레임 ID 보존, `6/6` `ON_CLICK` 연결 및 `6/6` 실제 Figma Present 재생을 확인했다. 공식 Figma MCP는 사용하지 않았으며 클라우드 동기화는 인수 조건으로 보장하지 않는다.

## 한계와 후속 개선

P0 단계의 2개 아코디언 자체 기준 입력이므로 복잡한 프로덕션 규모 입력, 모바일 뷰포트·키보드 접근성 확장은 P2 백로그 과제로 남긴다.
