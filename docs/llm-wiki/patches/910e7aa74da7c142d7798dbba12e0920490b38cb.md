# test: run every generated bundle task kind

## 문제와 계기

생성된 공유 런타임이 discover, import, native-edit, review, sync와 오류, uncertainty를 한 검사에서 실행하지 않았다. 이 커밋 910e7aa74da7c142d7798dbba12e0920490b38cb의 검사는 bundle_task_kinds가 없어 `generated bundle must run every task kind`로 실패한다.

## 결과 동작

tests/test_rd07_bundle_kinds.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 assemble_shared_runtime bundle을 tests/rd07_bundle_kinds.cjs가 실행한다. 다섯 kind의 성공 읽기, discover 오류의 failed 이력, 결과 전송 실패의 uncertain 상태를 구분한다.

## 변경 파일과 인터페이스

tests/test_rd07_bundle_kinds.py와 tests/rd07_bundle_kinds.cjs를 추가했다. docs/development-roadmap/RD-07-runtime-boundaries/tasks.md에 범위를 적었다. 제품 프로토콜은 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-07 작업 4는 실제 생성 bundle의 모든 task kind와 오류, uncertainty를 비교한다. wire format은 유지한다.

## 호환성·이관·복구

검사와 작업서만 추가한다. 허용 operation은 그대로다.

## 검증과 미검증

이 기준 트리에서 `python3 -B -m unittest tests.test_rd07_bundle_kinds`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 플러그인 재로드는 하지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. kind 목록 함수는 구현 커밋에 있다.
