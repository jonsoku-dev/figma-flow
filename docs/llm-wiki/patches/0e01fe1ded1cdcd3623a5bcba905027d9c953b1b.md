# 직접 검증 진입점의 임시 XDG 소유권

커밋 `0e01fe1ded1cdcd3623a5bcba905027d9c953b1b`

## 문제와 계기

검증기를 직접 호출하는 사용자가 외부에서 실행기를 한 번 더 감싸야만 설정 격리가 이뤄졌다.

## 결과 동작

유지보수 단계, 릴리스 증인과 나머지 Node 스위트가 각각 새 0700 설정 경로를 생성해 자식에 전달하고 반환·실패 후 정리한다.

## 변경 파일과 인터페이스

tools/maintenance.py, tools/major_release.py, tools/graph_governance.py가 tools/test_env.py의 private_test_config를 공유한다. 기여 안내와 유지보수 문서·검토 지문, 인수 그래프를 연결했다.

## 설계 이유와 출처

공용 문맥 관리자로 임시 경로 수명을 소유하되 명령 구성, 증인 해시 검사, 시간 제한 및 기존 종료 코드 처리는 각 검증기에 유지한다.

## 호환성·이관·복구

검증기 API의 인자와 결과 형식이 유지된다. 기존 CI 진입점과 직접 호출 모두 부모의 PC 설정을 그대로 유지한다.

## 검증과 미검증

고정 재현에서 각 경로의 자식 설정은 전용 0700이었고 임시 위치는 종료 후 사라졌다. 의도적으로 실패한 증인, Node suite, 유지보수 명령도 기존 실패 판정을 유지했다.

## 한계와 후속 개선

제품 전체와 출시 패키지는 별도 릴리스 검수에서 확인한다. 환경 변수 분리는 OS 접근 거부와 구분한다.
