# 직접 검증 자식 환경의 고정 재현

커밋 `5a23f947043e5721f3ff849c46400691f45193f0`

## 문제와 계기

전체 검사 실행기에서는 격리돼도 릴리스 증인, 단일 유지보수 단계, 나머지 Node 제품군을 직접 호출하면 부모 설정 경로를 받았다.

## 결과 동작

실제 Python·Node 자식이 본 경로와 권한을 기록한다. 부모 sentinel 바이트, 명령의 성공·실패 판정 및 해당 경로가 종료 후 사라지는지를 확인한다.

## 변경 파일과 인터페이스

tests/test_verification_config.py는 maintenance.run_step, major_release.rerun_witness, graph_governance.test_other_suites를 각각 호출한다.

## 설계 이유와 출처

각 검증기를 직접 진입점으로 호출해야 CI 외부 실행도 보호하는지 알 수 있다. 자식이 관측한 경로를 검사한다.

## 호환성·이관·복구

고정된 아카이브 증인의 검증과 종료 코드 판정을 그대로 사용한다. 입력과 로그는 각 검사의 임시 디렉터리에 한정한다.

## 검증과 미검증

기준 커밋에서 각 검사의 자식이 부모의 XDG를 그대로 보고했다. 독립 프로브에서도 세 경로 모두 private 및 cleaned가 false였다.

## 한계와 후속 개선

테스트 명령은 외부 서비스 또는 실제 사용자 설정을 요구하지 않는다. 이 검수에서는 macOS 파일 접근 차단 하에 실행했다.
