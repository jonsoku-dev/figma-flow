# 212cb0b · 연결된 타이포그래피의 범위 채택과 롤백

## 문제와 계기
Graph token sync가 연결된 텍스트 스타일을 직접 수정하면 공유 소비자에게 영향이 갈 수 있고 실패 시 원래 스타일을 복구하기 어려웠다.

## 결과 동작
`figma-bridge/graph_token_sync.js`가 `fontFamily`와 `fontSize` range binding을 지원한다. 스타일에 연결된 텍스트는 기존 profile/binding을 읽어 노드별 스타일을 만들고 필요한 변수만 적용한다. 혼합 속성, 기존 override, 변경된 입력, 필수 API 부재는 사전 검사에서 거부한다. 실패 시 생성 스타일과 노드 연결을 조건부로 되돌리며 충돌은 readback에 진단한다.

## 변경 파일과 인터페이스
`graph_token_sync.js`, `workspace_host.js`, CJS 테스트, Graph SSOT 예제와 기록 이미지. 성공 입력 schema는 유지되며 rollback 진단에 `binding_diagnostics`가 추가될 수 있다.

## 설계 이유와 출처
근거: 전체 커밋 `212cb0b57719410694bd369823c679d6a26bdbf8`; `graphSyncTextState`, `graphSyncTextStyles`, `graphSyncRollbackError`, graph token sync 테스트. 대상 노드 범위로 변경을 제한한다.

## 호환성·이관·복구
기존 override가 있는 텍스트는 자동 병합하지 않고 중단한다. 성공 시 노드별 text style이 추가될 수 있다. 다른 편집자가 바꾼 상태는 강제로 덮지 않으며 충돌을 확인해 수동 조치한다.

## 검증과 미검증
연결 스타일 성공/rollback 관련 테스트가 추가됐다. 실행 로그와 실 Figma 문서 round-trip은 미검증이다.

## 한계와 후속 개선
스타일 복제는 스타일 수를 늘린다. 롤백이 충돌을 발견하면 자동 정리가 보장되지 않고 진단 이후 수동 복구가 필요할 수 있다.
