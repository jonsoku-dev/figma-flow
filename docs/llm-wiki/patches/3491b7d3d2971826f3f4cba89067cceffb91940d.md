# feat: prioritize safe typed Figma reads and record 39 newly observed members

## 문제와 계기

0.30 우선순위 큐에는 실측 근거가 없는 항목 1,232개가 남았다. 기존 안전 getter를 다시 실행하는 것만으로는 아직 관측하지 않은 멤버를 효율적으로 분리하기 어려웠다.

## 결과 동작

프로브는 남은 큐 순서대로 안전한 멤버를 선택하고 role match·priority score·이유를 계획 그래프에 담는다. 추가된 scalar와 bounded summary projections, text range font-weight getter를 자체 플러그인으로 읽었다. 응답은 exact member key 기준으로 receipt overlay에 저장된다.

## 변경 파일과 인터페이스

`tools/native_api_probe.py`는 `api_priority` 큐에서 실행 가능한 미관측 멤버를 고른다. `figma-bridge/native_api_probe.js`는 고정 allowlist와 정적 getter 호출만 사용한다. `tools/review_api_coverage.py`는 0.30 기준과 0.31 candidate overlay를 분리하고 `specs/responsive-web/api-observations.json`은 sanitized evidence를 제공한다.

## 설계 이유와 출처

후보 이름을 자유 호출하지 않고 공식 API audit의 exact member key, receiver type, 공개 큐 우선순위에 묶는다. Opaque style IDs는 assigned/unassigned 상태만, collection 값은 bounded count나 허용된 enum 요약만 반환한다. 텍스트 본문과 원시 벡터 payload는 반환하지 않는다.

## 호환성·이관·복구

0.30 baseline과 기존 editable-web overlay를 보존하고 새 responsive-web overlay만 더한다. `api_priority.build()`의 기존 baseline-only 호출 동작은 유지했다. API source와 두 manifest는 이 커밋에서 갱신하지 않아 플러그인 버전은 여전히 0.30.0이며 0.31은 아직 후보 상태다.

## 검증과 미검증

네이티브 Figma 플러그인의 네 signed read batch는 488 getter 시도를 기록했다: 성공 473, unavailable 10, receiver에 없는 property 5, blocked 0. 중복 키를 제외하고 39개 멤버를 새로 관측했다. coverage report에서 0.30은 150개 관측·1,232개 미관측, candidate 누적은 189개 관측·1,193개 미관측이다. API 우선순위·프로브 테스트 14개가 고정 checkout에서 통과했다.

## 한계와 후속 개선

39개 신규 키는 이전 잔여의 약 3.2%다. 1,193개 항목은 계속 미관측이며, 큐 점수는 실행 지원을 보증하지 않는다. 기록은 관측한 실제 receiver와 허용 projection에 한정되고 전체 Plugin API 지원이나 모든 editor 조건의 통과로 해석하면 안 된다.
