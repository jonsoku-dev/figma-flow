# feat: import editable native masks, effects, gradient text and source-backed media

## 문제와 계기

정적 웹 캡처는 일부 shadow, blur, mask, text gradient와 외부 asset을 제한으로 남겼다. 지원 결과를 편집 가능한 Figma layer로 만들고, 재적용할 때 mask·effects·paint 변경을 감지할 계약이 필요했다.

## 결과 동작

캡처는 bounded box/inset shadow·blur·drop-shadow, 90°/180° linear alpha mask, text linear gradient와 hash-backed media를 기록한다. Import는 효과를 native Figma paint/effects로 만들고 mask를 editable sibling wrapper로 보존한다. SVG는 검증된 내부 gradient와 clip path를 지원한다. Video는 native VIDEO paint가 허용되면 사용하고 거부되면 고정된 fallback asset을 쓴다. Scene fingerprint는 mask state와 media hash를 포함한다.

## 변경 파일과 인터페이스

`tools/web_design_capture.js`는 CSS 효과·gradient·media 후보를 읽는다. `tools/web_design.py`가 bounded graph schema와 SVG reference를 검증한다. `figma-bridge/web_design.js`가 native effects, mask, editable gradient text와 video fallback을 만들고 재사용 상태를 확인한다. `library/figma-api/coverage-baseline.json`, `tests/test_web_design.py`, `tests/test_web_design.cjs`, `docs/guide.md`가 계약·검사를 갱신한다.

## 설계 이유와 출처

구현은 공개 API의 명시 allowlist를 사용한다. Text range fills로 실제 gradient를 읽어 적용 결과를 확인한다. Scene hash schema version을 올려 새 import에서 mask changes를 검증하고 legacy fingerprint는 mask가 없는 경우에만 호환한다. SVG local reference는 id uniqueness와 resolution을 확인한다.

## 호환성·이관·복구

기존 local image, supported frame/text import와 API baseline을 유지한다. 이전 fingerprint에 mask state가 없으면 mask가 없는 실제 scene만 기존 ID로 재사용한다. Native video entitlement 거부는 실패를 숨기지 않고 hash-pinned raster fallback을 기록한다. Unsupported effect는 임의로 보정하지 않는다.

## 검증과 미검증

Frozen candidate에서 관련 Python 67개, web-design Node 19개, workspace-control Node 9개가 통과했다. 27 browser cases(20 ZIP pages와 7 error states)에서 54 signed renderings를 확인했다. Figma에서 paid-team native video paint가 거절된 것은 관찰되어 pinned fallback이 사용됐다.

## 한계와 후속 개선

일반 CSS filter·mask, 외부 SVG paint/reference와 미검토 effects는 지원하지 않는다. 현재 관찰의 video fallback은 native video fidelity가 아니다. 0.31.0 source commit은 생성됐지만 Git tag, 원격 release CI와 설치 검증은 아직 완료되지 않았다.
