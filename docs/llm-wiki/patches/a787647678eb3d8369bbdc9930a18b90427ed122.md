# a787647 · Unslop 리뷰와 이식 가능한 브라우저 설정

이 기록은 원본 커밋 `a787647678eb3d8369bbdc9930a18b90427ed122`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

디자인 리뷰 절차와 브라우저 허용 설정의 근거·재사용 위치가 정리되어 있지 않았고 호스트 경로가 설정에 섞일 위험이 있었다.

## 결과 동작

skills/figma-flow/references/unslop.md 및 design-review.md를 추가·연결하고 browser-access.md와 tools/browser_access.py로 프로젝트별 설정 생성·검증 로직을 마련했다. AGENTS.md/ignore 및 테스트를 동반한다.

## 변경 파일과 인터페이스

browser_access.py가 실제 브라우저 설정 파일을 찾아 허용 항목을 적용·확인하며, tests/test_browser_access.py는 설정 변형을 검증한다. 스킬은 이식 가능한 절차 문서를 참조한다.

## 설계 이유와 출처

설정 적용과 디자인 비평을 실행 가능한 코드와 명시적 참고 문서로 분리하고, 사용자 홈 경로를 공유 설정에 넣지 않는 의도가 보인다.

## 호환성·이관·복구

테스트는 설정 생성·검증 로직의 예상값을 다루지만 사용자 브라우저의 실제 권한·접근을 보장하지 않는다. 파일 쓰기는 프로젝트 설정에 한정된 흐름이다.

## 검증과 미검증

테스트 실행은 미상이다. 실제 browser config를 사용하는 호스트별 통합 및 사이트 접속은 미검증이다.

## 한계와 후속 개선

허용 사이트 목록은 정책 변경 시 재검토해야 하며, 페이지 접근 허용은 사이트 내 행위 권한을 뜻하지 않는다.
