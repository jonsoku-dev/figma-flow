# 모호한 그래프 입력의 회귀 기준

## 문제와 계기

동일 그래프에 같은 키가 두 번 있거나 무한수가 숨어도 일부 입력 경로가 값을 해석했다.

## 결과 동작

9e3968dfcdfa3bc01e887e64619b6a40094d498e에서 여러 그래프 입력 경로에 같은 위반 파일을 주는 독립 검사를 고정했다.

## 변경 파일과 인터페이스

`tests/test_graph_input_boundary.py`가 배포되는 graph CLI와 명세·토큰·리뷰의 입력 함수를 호출한다.

## 설계 이유와 출처

키의 최종 값만 대조하면 입력의 모호성을 놓치므로 입력 단계의 거절을 관찰한다.

## 호환성·이관·복구

격리된 자료로 검사한다. 기존 고객 자료와 Figma 캔버스를 변경하지 않는다.

## 검증과 미검증

기존 구현은 모호한 입력을 수용해 예상 단언에서 실패했다. 구현 이후 동일 Git blob으로 재실행할 수 있다.

## 한계와 후속 개선

이 사례는 등록된 입력 경계와 유한 수를 검사한다.
