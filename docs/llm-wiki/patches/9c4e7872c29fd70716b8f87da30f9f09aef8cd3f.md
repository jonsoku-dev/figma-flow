# test(benchmark): pin native descriptor and diagnostic acceptance requirements

## 문제와 계기

root의 실기 live-001에서 timed·default 샘플은 성공했지만 진단 회차가 실제 Figma Proxy에서 `proxy: inconsistent get`으로 실패했다. 러너는 이를 막지 않고 기준선과 native proof를 기록했다. root는 이 결과를 거절했다.

## 결과 동작

커밋 `9c4e7872c29fd70716b8f87da30f9f09aef8cd3f`는 두 요구를 검사로 고정했다. 읽기 전용·non-configurable 속성을 가진 native 객체에서도 getter-counts가 동작해야 한다. 기준선과 native proof는 유효한 진단이 있을 때만 기록된다.

## 변경 파일과 인터페이스

새 `tests/p2_native_read_measurement_descriptors.cjs`, `tests/test_native_read_benchmark_diagnostic.py`.

## 설계 이유와 출처

실패를 먼저 검사로 고정하고 수정을 별도 커밋으로 분리했다. 진단 검사는 진단 누락, 실패, counts 누락, 페이지 누락, 다른 scope, 다른 content를 각각 차단 사례로 둔다.

## 호환성·이관·복구

검사 파일 두 개만 추가했다. 제품 코드와 기존 검사 파일은 바뀌지 않는다.

## 검증과 미검증

수정 커밋 [a5e4a09](a5e4a098726872e9953e92da36065f4789f22811.md) 이후 이 검사들은 통과한다. 이 커밋 시점 코드에서의 실패 출력은 이 기록에서 다시 실행하지 않았다.

## 한계와 후속 개선

실제 Figma Proxy 동작은 단위 검사가 흉내 낸 descriptor 범위만 대표한다.
