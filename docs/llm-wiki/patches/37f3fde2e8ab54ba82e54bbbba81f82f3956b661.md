# release: version 0.32.0 for the Design-specialized authoring tools

## 문제와 계기

제작 범위와 네이티브 검사 변경을 새 설치본에서 식별할 버전이 필요했다.

## 결과 동작

두 플러그인 manifest와 설치 가이드 예제에서 0.32.0을 지정한다.

## 변경 파일과 인터페이스

변경 파일은 `.codex-plugin/plugin.json`, `README.md`, `docs/guide.md`, `plugin.json`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

버전과 설치 출처를 대조할 수 있도록 설치 명령과 문서의 기준을 일치시켰다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

manifest 사이 버전 일치를 대조했다. 이 커밋 시점의 버전 번호만으로 GitHub 발행과 설치본 작동을 증명하지 않는다.

## 한계와 후속 개선

위 관측은 명시된 사용 장면에 해당한다. 다른 파일의 권한이나 실제 런타임 결과는 그 환경의 별도 영수증으로 확인한다.
