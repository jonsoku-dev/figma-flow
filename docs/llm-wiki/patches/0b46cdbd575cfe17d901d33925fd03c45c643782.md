# test: require conflict detail to keep the observed value and plan hash

## 문제와 계기

실패한 native edit의 충돌이 관측 값과 plan hash를 한 조회로 보존하지 않았다. 이 커밋 0b46cdbd575cfe17d901d33925fd03c45c643782의 검사는 conflict_detail이 없어 `conflict detail must keep the observed value and plan hash`로 실패한다.

## 결과 동작

tests/test_rd08_conflict_detail.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 target, field, planned before 16, after 18, observed 20, rollback 이유, plan hash를 돌려준다. observed는 after로 바뀌지 않는다. 후속 동작은 save-evidence와 read-scope뿐이고 rerun과 apply는 없다. plan hash가 없거나 target이 operation과 맞지 않으면 거절한다.

## 변경 파일과 인터페이스

tests/test_rd08_conflict_detail.py만 추가했다. tools/figma_control.py와 figma-bridge/native_edit.js는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd08_conflict_detail로 실행한다.

## 설계 이유와 출처

RD-08 작업 5는 충돌 상세와 저장·읽기 동작을 추가하고 재실행 버튼을 제공하지 않는다. 사용자가 바꾼 값은 계획 값으로 자동 덮어쓰지 않는다.

## 호환성·이관·복구

이 커밋은 검사를 고정할 뿐 기존 rollback 판정을 바꾸지 않는다. recovery_read는 rollback_conflicts가 있으면 복구하지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `conflict detail must keep the observed value and plan hash`다. 실제 Figma 충돌 화면은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 receipt다. 구현은 별도 커밋 b91d26553b3343a61f8094a1ac041e3043506787에서 검사 blob을 유지한 채 추가한다. 화면 표시는 통과로 기록하지 않는다.
