# 문구 생성으로 서명된 예약 작업 입력 유지

## 문제와 계기

공통 서비스 문구로 전환하면서 이미 준비된 예약 작업이 참조하는 템플릿의 바이트가 바뀌어 새 세대 준비가 거절됐다.

## 결과 동작

`d6b32a64bffc0004267f1b09fbc456443862f967`에서 예약 상세의 승인된 기본 HTML을 문구와 원본 템플릿에서 다시 생성했다.

## 변경 파일과 인터페이스

`apps/little-hands/design/publish_copy.py`와 `apps/little-hands/design/session-detail.html.in`에서 원본과 출력을 확인하며 입력 지문을 재생성한다.

## 설계 이유와 출처

공통 문구의 소유권과 이미 서명한 콘텐츠의 정체성을 함께 보존했다.

## 호환성·이관·복구

기존 문구에서 생성한 출력은 승인된 템플릿의 바이트와 같다. 변경한 문구의 새로운 결과는 해당 작업의 정식 준비 절차를 거친다.

## 검증과 미검증

기본 소스가 이전 지문과 일치했다. 문구를 바꾼 격리 Django 환경에서 오래된 출력을 탐지한 뒤 다시 생성하고 실제 웹 응답에서 값을 확인했다.

## 한계와 후속 개선

사용자 계정이나 캔버스에는 쓰지 않았다. 갱신된 Figma 읽기와 작업 목록의 결과는 후보 검증에 기록한다.
