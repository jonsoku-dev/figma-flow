# feat: compile observed single-collapsible disclosure states into web graphs

## 문제와 계기

이 커밋은 브라우저에서 관측한 single-collapsible disclosure 상태와 클릭을 기존 웹 그래프에 연결하는 입력 형식과 컴파일러를 추가한다.

## 결과 동작

`tools/native_edit.py web-disclosure`는 관측 JSON을 기존 WEB 화면 그래프와 결합하고 새 그래프를 쓴다. `web-design`은 그 그래프 해시에 묶인 Figma 적용 계획을 만든다.

## 변경 파일과 인터페이스

계약은 항목 2–16개, 상태 2–16개, 전이 1–80개를 허용한다. 상태는 전체 닫힘 또는 하나의 항목만 열린 상태이고 답변과 화면 캡처 해시를 고정한다. 관련 변경: `docs/web-disclosure-input.md`, `tests/test_web_design.py`, `tools/native_edit.py`.

## 설계 이유와 출처

전이는 실제 클릭으로 관측한 `open`, `close`, `switch`만 받으며 이전 항목의 자동 닫힘 여부와 트리거 프레임 ID를 검사한다.

## 호환성·이관·복구

검증은 중복 상태와 간선, 자기 루프, 잘못된 답변 해시, 화면 밖 트리거, 초기 상태이거나 적어도 하나의 전이 목적지가 아닌 상태를 거부한다. 참조 PNG와 출력 경로도 확인한다. 실제 그래프 도달성 검사는 후속 회귀 수정에서 강화됐다.

## 검증과 미검증

같은 공개 API는 한 계획에서 carousel, tabs, disclosure 중 하나만 허용한다. 적용 계획 생성 자체는 브라우저나 Figma를 실행하지 않는다.

## 한계와 후속 개선

직접 diff에는 관측 입력 문서, `tools/web_design.py`, `tools/native_edit.py`, 그리고 Python 검사가 추가됐다. 보고된 24개 Python 테스트 통과는 이 기능 범위의 검사 결과다.
