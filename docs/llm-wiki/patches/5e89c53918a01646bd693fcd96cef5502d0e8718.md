# docs: publish SVG fidelity comparisons, plugin limits and fork notes

## 문제와 계기

0.32.2의 SVG 색·불투명도 변경을 포크에서 추적하려면 당시 소스와 별도 발행 기록을 연결해야 했다.

## 결과 동작

CHANGELOG에 0.32.2 사용자 변화 3줄을 추가했다. releases.md에는 v0.32.2 절을, docs/llm-wiki/patches/에는 8개 커밋 페이지를 추가했다. catalog.json에는 각 커밋의 부모·파일·diff 해시·트리·매니페스트 버전 항목을 넣고 changelog_versions에 0.32.1을 보충했다. 변경은 CHANGELOG·catalog·releases·patches 페이지 8개, 모두 11개 문서 파일에 한정된다. 코드·테스트·배포 매니페스트는 바꾸지 않았다.

## 변경 파일과 인터페이스

변경 경로는 `CHANGELOG.md`, `docs/llm-wiki/catalog.json`, `docs/llm-wiki/patches/1d0b5c0f176dc089f82fd1100cecd13c90996fc8.md`, `docs/llm-wiki/patches/ef00dddce6ed5d06701b2c6c870762f9e14f6029.md`, `docs/llm-wiki/patches/09ea462e817112edc790234f6482cc19e7c7e4a2.md`, `docs/llm-wiki/patches/9a8321f9349969e990f1238d2616f21d4e4c6195.md`, `docs/llm-wiki/patches/ec9eb9ba1610ddad2bf568c8ec528aa44c1fbf43.md`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

발행 커밋을 구현 커밋과 분리해 구현 diff 해시가 문서 갱신으로 바뀌지 않게 했다. 포크는 릴리스 절이 제시한 순서(캡처·바인딩 기준 3d72453, 루트 투명도 기준 6b448d9, 네이티브 적용 ec9eb9b, 바인딩 구현 09ea462)대로 기준과 구현을 나눠 선택 적용할 수 있다. 릴리스 절은 NF-09 상호작용 로드맵이 아직 제안 단계이고 0.32.2가 모션·스와이퍼 자동 변환을 제공하지 않는다고 적는다. 이어지는 0.33 캐러셀 작업과의 경계를 문서로 나눈 것이다.

## 호환성·이관·복구

이 변경은 기록 발행이다. 이전 설치본은 v0.32.2로 재현할 수 있다.

## 검증과 미검증

이번 재검토에서 `python3 -B tools/patch_knowledge.py verify --ref 5e89c53 --committed-only`가 커밋 310개와 문서 발행 커밋 1개를 통과했다. 작업 트리에 다른 에이전트의 미커밋 변경이 있어 커밋 객체만 검사했다. `git show --stat`으로 변경 범위가 위 11개 문서 파일뿐임을 확인했다. 같은 명령을 0.33 구간 HEAD에 실행하면 1046524에서 '기록되지 않은 비문서 커밋'으로 멈춘다. 이 기록 검사는 구조만 보장하며, 0.32.2 기능의 Figma 동작은 이번 검토에서 다시 실행하지 않았다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
