# 독립 패널 렌더러의 의존성 복구

소스 커밋 `e3634ad2c9254c101b1db93a8ff50aea1ec0598d`

## 문제와 계기

공통 그래프 디코더를 독립 패널 렌더러에 연결하자 축소 복사본에서 로더가 없는 스킬 파일을 참조했다.

## 결과 동작

독립 렌더러가 기존 패키지 구성을 통해 작동하고 본래의 그래프 입력 보호 범위는 그대로 적용된다.

## 변경 파일과 인터페이스

`tools/plugin_panel.py`와 `tools/maintenance-contract.json`의 독립 렌더러 등록을 복구했다.

## 설계 이유와 출처

패널 뷰 등록 설정과 그래프 저작물의 경계를 유지해 배포 구성에서 불필요한 관계를 없앤다.

## 호환성·이관·복구

기존 브라우저·컴포넌트 패키지의 명령 및 증거 파일은 같은 독립 테스트로 검증한다.

## 검증과 미검증

FamilyAuthorityTests의 독립 컴파일과 standalone Design 뷰의 Chromium 테스트에서 첫 실패를 관찰했고 구현 수정 뒤 각각 통과했다.

## 한계와 후속 개선

이 수정은 별도 패널 뷰 등록 파일의 로딩을 다룬다. React 전송 경계 검사는 이전과 동일하게 빌드에서 적용한다.
