# feat: preserve measured canvas pixels, crop provenance and native circular mask geometry

## 문제와 계기

canvas가 빈 영역이 되었고 브라우저가 생략한 기본 중심을 가진 래디얼 채우기도 누락됐다.

## 결과 동작

origin-clean canvas 바이트, 크기, DPR, 해시를 연결한다. 읽기 거절 시 명시한 스크린샷의 해당 영역을 추출한다.

## 변경 파일과 인터페이스

변경 파일은 `docs/web-design-capture.md`, `tests/test_web_design.cjs`, `tests/test_web_design_canvas.cjs`, `tests/test_web_design_canvas.py`, `tools/web_design_canvas_crop.py`, `tools/web_design_capture.js`, `tools/web_design_source.py`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

문서 좌표와 뷰포트 좌표를 구분한다. 합성 스크린샷의 출처를 원시 canvas와 다르게 기록한다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

실제 Magic UI SaaS의 800×800 PNG와 원형 마스크를 읽었다. 교차 출처 예제의 240×120 crop은 원본 스크린샷의 해당 픽셀과 일치했다.

## 한계와 후속 개선

위 관측은 명시된 사용 장면에 해당한다. 다른 파일의 권한이나 실제 런타임 결과는 그 환경의 별도 영수증으로 확인한다.
