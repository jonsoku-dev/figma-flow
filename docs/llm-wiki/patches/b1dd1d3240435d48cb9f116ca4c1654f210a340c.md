# b1dd1d3 · 상류 요청 경계 테스트 수정 유지

이 기록은 원본 커밋 `b1dd1d3240435d48cb9f116ca4c1654f210a340c`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

앞선 요청 경계 테스트 보완을 0.21.1 릴리스에 반영하며 이전에 확인된 업스트림 수정을 보존할 필요가 있었다.

## 결과 동작

이 커밋은 제목상 upstream request-boundary test fix를 보존하고 0.21.1 버전·변경기록을 갱신한다. 실제 변경은 tests/test_serve_design_routes.py의 초과 Content-Length 전송 전 413 확인과 route 미호출 단언이 핵심이다.

## 변경 파일과 인터페이스

제품 인터페이스는 유지된다. POST /plan의 MAX_BODY 경계 테스트 및 plugin version metadata만 갱신된다.

## 설계 이유와 출처

수정 내용을 릴리스에서 잃지 않도록 기록한 패치다. upstream 출처의 구체적인 PR/커밋 정보는 diff상 확인되지 않아 미상으로 둔다.

## 호환성·이관·복구

0.20.1에서 도입된 응답/경계 의미를 유지한다. 새로운 데이터 형식이나 마이그레이션 경로는 없다.

## 검증과 미검증

테스트 코드의 단언은 정적 증거이며 CI 결과는 미검증이다.

## 한계와 후속 개선

실제 payload 전송을 피하는 테스트이므로 업로드 중 단절 상황까지 입증하지 않는다.
