# 네이티브 배포 환경의 검증 기록 연결

소스 커밋 `8a3fbe4f6f85704a79c4acebbe4284613055b837`

## 문제와 계기

릴리스 아카이브를 검증하는 러너의 플랫폼과 도구 설치가 바뀌어 배포·도구 증거 지문을 갱신해야 했다.

## 결과 동작

실행 검사에 사용하는 Codex CLI의 고정 지문과 실패 통제가 현재 설정에 연결된다.

## 변경 파일과 인터페이스

`release/reviews/delivery.json`과 `release/reviews/tooling.json`의 영역별 증거를 현재 구성에 연결했다.

## 설계 이유와 출처

macOS용 바이너리 필드를 정본으로 집어 검사에서 정상 아카이브와 손상 아카이브를 직접 대조한다.

## 호환성·이관·복구

예제와 패널의 실제 기능 검사 및 기존 배포 차단 조건을 유지한다.

## 검증과 미검증

변경된 배포·도구 리뷰를 해당 Git 아카이브에서 재실행해 통과했다. 이전 Ubuntu의 차단 세 건은 실행 이력으로 보존한다.

## 한계와 후속 개선

공개 ZIP은 새 GitHub 아카이브 검사까지 통과한 소스를 사용한다.
