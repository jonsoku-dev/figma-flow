# feat: load the legacy catalogue apart from the declared dependency fixture

## 문제와 계기

기준 7bff2100bccf6db00203cc5351c8773026783d72는 fixture 로더가 없어 `prepared dependency fixtures must stay explicit`로 실패했다.

## 결과 동작

load_task_dependency_fixtures는 두 JSON을 읽어 같은 normalizer에 통과시킨다. legacy 세 task에는 depends_on이 없다. 선언한 fixture는 import-task가 review의 code.js를 uses-output으로 가리키는 edge 하나만 가진다. review와 notes에는 edge가 없고 notes로 가는 선도 없다.

## 변경 파일과 인터페이스

tools/figma_workspace.py에 load_task_dependency_fixtures를 추가했다. docs/development-roadmap/RD-03-task-dependencies/tasks.md에 fixture 범위를 적었다. tests/test_rd03_task_fixtures.py와 tests/fixtures/rd03의 두 JSON blob은 기준과 같다.

## 설계 이유와 출처

RD-03은 선언한 edge만 관계로 저장한다. 같은 project라는 사실만으로 edge를 추정하지 않는다. fixture는 그 구분을 서명 로직과 같은 함수로 고정한다.

## 호환성·이관·복구

로더는 fixture를 정규화해 돌려줄 뿐 catalogue를 다시 서명하지 않는다. edge 없는 task 객체는 depends_on 필드를 만들지 않는다.

## 검증과 미검증

종료 게이트는 `python3 -B -m unittest tests.test_rd03_task_fixtures`를 기준 7bff2100bccf6db00203cc5351c8773026783d72에서 종료 코드 1, 대상 19b6e1a9d879272179c120cd9c0d303a3e765910에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 마지막 assertion은 `prepared dependency fixtures must stay explicit`다. 조건은 RD-03-AC-01이다. 작업 목록 UI, 브라우저, Figma 패널은 관찰하지 않았다.

## 한계와 후속 개선

선행과 후속 보기, 텍스트 대체 목록은 아직이다. AC의 화면 표시는 통과로 기록하지 않는다.
