# Record 0.35 FAQ playback and G1 retry evidence in the patch wiki

## 문제와 계기

`v0.35.0` 병합과 매니페스트 갱신 이후, 단일 열림 SaaS FAQ 프로토타입의 브라우저·Figma 재생 결과, 독립 게이트 검증, 그리고 `v0.34.0` 이후 통합된 G1 소스 재생성 기록을 `CHANGELOG.md`와 Wiki에 발행할 필요가 있었다.

## 결과 동작

`CHANGELOG.md`에 `0.35.0` 사용자 변화와 G1 미배포 연결을 반영하고, `docs/llm-wiki/releases.md`에 `v0.35.0`과 `#g1-source-regeneration` 절을 추가했으며 `docs/llm-wiki/catalog.json`과 11개 패치 페이지를 동기화했다.

## 변경 파일과 인터페이스

`CHANGELOG.md`, `docs/llm-wiki/catalog.json`, `docs/llm-wiki/releases.md`, `docs/llm-wiki/patches/` 아래 `494f63f` 등 11개 커밋 페이지를 갱신한 문서 전용 발행 커밋이며 제품 코드나 테스트 인터페이스는 바꾸지 않았다.

## 설계 이유와 출처

커밋 자신은 자기 전체 SHA를 포함할 수 없으므로 제품·문서 기준 커밋 `494f63f` 이후에 문서 전용 커밋으로 기록을 묶어 발행하는 `docs/llm-wiki/integration.md` 계약을 따랐다.

## 호환성·이관·복구

`v0.35.0` 태그의 기록 발행 지점으로 동작하며, 후속 P0 작업의 `sync` 시 전체 조상 목록에 포함돼 계속 검증된다.

## 검증과 미검증

`494f63f`까지의 기록 발행 커밋으로 `patch_knowledge.py verify` 기준을 맞추었으며, 이후 추가된 P0 가드·기준 입력·로드맵 변경의 검증은 후속 미배포 커밋들에서 별도로 기록한다.

## 한계와 후속 개선

이 커밋은 `v0.35.0` 시점의 패치 지식 발행만 다루며, 이후 `main`에 추가된 P0 기준 자료 보호와 API 우선순위 재검증은 후속 P0 기록에서 갱신한다.
