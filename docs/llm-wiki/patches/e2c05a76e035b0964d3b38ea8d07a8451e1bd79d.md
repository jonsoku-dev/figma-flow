# 검증 원본 즉시 회수와 작은 영수증

소스 커밋 `e2c05a76e035b0964d3b38ea8d07a8451e1bd79d`

## 문제와 계기

저장 공간 부족 조사에서 Figma Flow의 검증·백업 파일이 실제 작업공간과 같은 상위 디렉터리에 쌓인 상황이 확인됐다.

## 결과 동작

검증 러너가 자체 임시 디렉터리를 할당하고 종료될 때 정리한다. 리비전·실행·해시를 담은 작은 JSON을 남긴다.

## 변경 파일과 인터페이스

`CONSTITUTION.md`와 `tools/maintenance.py` 및 두 유지보수 스킬을 갱신했다. `tools/change_journal.py`에서 비문자열 필드를 거절한다.

## 설계 이유와 출처

검증 임시 공간과 사용자가 지정한 결과 위치의 수명을 분리한다. 검증 원본을 검사한 뒤 바이트 수와 SHA-256을 기록한다.

## 호환성·이관·복구

사용자가 명시한 최종 산출물과 활성 Figma 공간은 기존 소유 계약을 따른다. 변경 저널은 기존 정상 데이터와 재처리를 지원한다.

## 검증과 미검증

1MB 합성 자료가 성공·오류·시간 초과 뒤 삭제되고 인접 사용자 파일은 유지됐다. UI는 캡처 지문만 남겼다. 저널은 잘못된 자료를 쓰지 않았다.

## 한계와 후속 개선

검증 명령 외부에 수동 생성한 자료는 실행 소유권을 확인해 정리한다. 전원 장애·강제 종료 때는 임시 경로의 복구 절차를 따른다.
