# 역방향 조회 없이 시작하는 제어 서버 검사

커밋 `d33465669a67665f2914cedfbad6a6456b5528fe`

## 문제와 계기

macOS 제품 검사에서 레지스트리 검증 프로세스가 서버 준비를 기다리다 종료됐다.

## 결과 동작

준비 응답이 오기 전 역방향 조회에 의존하면 실제 CLI 자식의 시작 검사가 실패한다.

## 변경 파일과 인터페이스

tests/test_control_loopback_startup.py에서 임시 작업공간과 전용 포트를 사용한다.

## 설계 이유와 출처

운영체제 이름 해석기만 실패시키고 서버 실행과 인증된 HTTP 요청은 그대로 사용한다.

## 호환성·이관·복구

외부 DNS 서버나 실제 사용자 등록 없이 동일한 조건을 재현할 수 있다.

## 검증과 미검증

수정 전 CLI에서 준비 배너가 없다는 예상 실패를 확인했다.

## 한계와 후속 개선

이 검사는 역방향 조회 의존성을 검출하며 운영체제별 전체 제품 검사는 CI에서 수행한다.

[릴리스 버전과 변경 근거](../releases.md#v1.1.1)에서 해당 버전의 검증 범위를 확인한다.
