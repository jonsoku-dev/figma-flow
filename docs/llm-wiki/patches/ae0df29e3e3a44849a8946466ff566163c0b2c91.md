# chore: ignore local reference archives, private dirs, and ephemeral outputs

## 문제와 계기

로컬 참고 ZIP, 압축 해제 디렉터리, 비공개 작업 폴더, 임시 증거 출력이 실수로 `git add`나 배포 트리에 섞이는 경로를 차단할 필요가 있었다.

## 결과 동작

환경 설정, 비공개·임시·참고 아카이브 디렉터리, 백업·체크섬 임시 파일, 릴리스 tar 및 플러그인·참고 ZIP 산출물을 Git 추적 제외 규칙에 추가한다.

## 변경 파일과 인터페이스

`.gitignore`에 `.env`, `.env.*`(`!.env.example`), `/.herdr/`, `/.private/`, `/private/`, `/.local/`, `/.references/`, `/_references/`, `/reference-zips/`, `/local-reference/`, `/scratch/`, `/tmp/`, `/.tmp/`, `/evidence/`, `/captures/`, `/receipts/`, `*.tmp`, `*.bak`, `*.orig`, `*.sha256`, `release.tar`, `figma-flow-plugin-*.zip` 등을 추가했다.

## 설계 이유와 출처

정본과 무관한 로컬 참고 입력과 일회성 실행 산출물이 작업 트리에서 기본적으로 무시되도록 해 배포 가드와 함께 이중 방어를 구성한다.

## 호환성·이관·복구

`.env.example` 예외를 유지해 기존 공개 환경 예제는 보존한다. 이미 Git에 추적된 파일은 `.gitignore`만으로 제거되지 않으므로 가드 검사로 별도 차단한다.

## 검증과 미검증

합성 단위 테스트(`tests/test_reference_distribution_guard.py`)에서 보호 디렉터리와 참고 아카이브 패턴의 무시 동작을 확인했다. 과거 커밋 이력 자체를 다시 쓰지는 않는다.

## 한계와 후속 개선

무시 규칙은 작업 트리 실수만 줄이며 추적된 파일이나 배포 ZIP은 후속 커밋 `976a966c1b497890aae12dd1a63b1dd6b05ee763`의 가드 CLI로 검사한다.
