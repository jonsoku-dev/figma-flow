# docs(roadmap): record verified NF-03 causal history acceptance receipt

## 문제와 계기

NF-03 인과 이력 상세(`3e7b44cc`, `e7b1efbd`, `ce1bc7d2`, `016a777e`, `4e2539eb`)의 실제 Figma·패널 인수 결과를 정본 그래프와 공개 영수증에 연결해야 했다.

## 결과 동작

커밋 `bf65bf084304acebeb59b5d7d8aff8383d2f31e7`는 [P1 인수 영수증](../../next-roadmap/p1-acceptance.md)을 신설하고 `docs/next-roadmap/backlog.graph.json`의 `p1-causal-review-history`를 `verified`로 바꿨다. 영수증에는 FRAME 대상 초기 거절(캔버스 무변경), 자체 `MAIN` 컴포넌트에서 같은 태스크 2개 리비전(`borderRadius` `0→8→16`), `before=8`/`after=16` diff, 선행 링크·백스택, 페이지 전환 무효화, `Enter`/`Back` 포커스 복귀, 정본 요청·영수증 `1,226`개 파일 무변경을 기록했다.

## 변경 파일과 인터페이스

`docs/next-roadmap/p1-acceptance.md`(신규), `docs/next-roadmap/backlog.graph.json`, `docs/next-roadmap/capability-review.md`, `docs/next-roadmap/README.md`, `tests/test_next_roadmap_backlog.py`를 수정했다.

## 설계 이유와 출처

P0와 같은 방식으로 비공개 파일 키·노드 ID·개인 경로를 빼고 실행 핀과 관찰 결과만 공개 영수증에 남겨 그래프 상태의 근거를 추적 가능하게 했다.

## 호환성·이관·복구

문서·그래프·로드맵 테스트 변경이며 제품 런타임은 바뀌지 않는다. NF-01 노드는 이 커밋에서 아직 검증 전 상태로 남았다.

## 검증과 미검증

당시 영수증의 음수 HTTP 항목은 missing-auth를 `401`로 적었으나, 실제 라이브 프로브는 `403`이었으며 `fac5f7a4`에서 정정했다. 이 커밋의 `401` 표기는 당시 기록으로 남기고 현재 근거로 쓰지 않는다. 로드맵 테스트는 이후 `452acf1` 기준 `tests.test_next_roadmap_backlog` 등 55개 테스트 통과에 포함된다.

## 한계와 후속 개선

패널 Gate C는 `cfc7fbd` pre-freeze 런타임에서 확인했고 `e6f4fd8`에서는 HTTP 프로브로 재확인했다(`e6f4fd8` 위 수동 패널 재클릭은 하지 않음).
