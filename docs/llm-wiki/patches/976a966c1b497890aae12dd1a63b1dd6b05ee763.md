# feat: integrate hardened reference distribution guard CLI and synthetic tests

## 문제와 계기

Git 커밋, 인덱스, 작업 트리, 배포 ZIP에 금지된 비공개 경로, 임시 실행 증거, 참고 아카이브 원본이나 CRLF·이름 변경 복사본, 고유 인용 문구가 섞이는지 비공개 원문을 노출하지 않고 검사할 도구가 필요했다.

## 결과 동작

`tools/reference_distribution_guard.py`가 `--ref`, `--staged`, `--worktree`, `--target-zip` 대상을 검사한다. 선택 입력(`--reference-zip`, `--reference-literals`) 없이 실행하면 금지 경로와 임시 증거만 점검하고 `mode=paths-only`, `status=paths_only_clear`로 구분 보고하며, 선택 입력을 주면 원 ZIP 해시, 파일명 변경·CRLF/LF 변환된 멤버 SHA-256, 1줄 고유 인용 일치까지 차단하고 경로·SHA-256·규칙 ID·건수만 출력한다.

## 변경 파일과 인터페이스

`tools/reference_distribution_guard.py`에 `run_guard`, `format_text`, `main`(종료 코드 `0` 통과, `1` 차단, `2` 입력/Git/ZIP 오류)을 구현하고, `tests/test_reference_distribution_guard.py`에 합성 단위 테스트 12건을 추가했다. `skill_dependencies`와 연계해 고정된 외부 의존 라이선스·파일을 구분 보존하며 손상·위조 핀은 fail-closed로 차단한다.

## 설계 이유와 출처

비공개 참고 목록이나 원문 문구, 개인 경로를 저장소 코드나 테스트에 직접 넣지 않으면서도, 오프라인 환경에서 실제 참고 ZIP·리터럴 규칙과 대조할 수 있고 CI에서는 `paths-only` 모드로 안전 경계를 검증하도록 설계했다.

## 호환성·이관·복구

기존 제품 코드와 `v0.35.0` 배포 기능에는 변경이 없다. 128바이트 이하 또는 흔한 보일러플레이트 일치는 `ambiguous_reference_matches`로, 빈/무의미 파일은 `trivial_empty_skipped`로 분리해 정상 트리의 오탐을 방지한다.

## 검증과 미검증

macOS 로컬 합성 단위 테스트 12건(`tests.test_reference_distribution_guard`) 통과, 통합 검증 기준 현재 `HEAD`와 배포 ZIP 총 3,342개 파일 스캔 `clear`, 4개 비공개 참고 아카이브·67개 가드 규칙 대조(구 0.34 원본 ZIP 60건 findings 차단 포함) 및 4개 외부 참고 ZIP·보존 사본 SHA-256 변동 0건 확인이 보고되었다. 반면 GitHub Actions Linux 러너에서는 `git init` 기본 브랜치 명명 차이로 실패 1건이 확인되어 당시 원격 CI 실행은 통과로 간주하지 않으며 `b9495234cdbc4547f083f5ee21cbd623c67a381f`에서 수정됐다. 브라우저 및 Figma 네이티브 런타임 검증은 이 도구의 범위 밖이다.

## 한계와 후속 개선

`--reference-zip`과 `--reference-literals` 없이 실행하는 공개 CI의 `paths-only` 모드는 로컬 비공개 참고 목록 대조를 대신하지 않는다. 또한 도구 검사는 외부 자산 사용권의 법적 승인을 대체하지 않는다.
