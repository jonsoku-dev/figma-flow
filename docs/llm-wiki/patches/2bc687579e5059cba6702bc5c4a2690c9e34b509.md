# 2bc6875 · revision 기준 obsolete task 보관

## 문제와 계기
사용하지 않는 prepared task를 catalogue에서 제거해도 원본 revision과 복구 단서를 보존할 방법이 필요했다.

## 결과 동작
`figma_workspace.py retire`는 retirement selection schema를 엄격 검증하고, key/revision이 현재 catalogue와 일치하는지 확인한다. publication이 idle이며 불확실 mutation이 없어야 한다. 선택 task와 catalogue snapshot을 private `.retired` record에 먼저 저장한 뒤 잔여 task를 publish한다. 실패 시 catalogue bytes를 되돌린다.

## 변경 파일과 인터페이스
`tools/figma_workspace.py`의 `retire()` 및 CLI `retire --workspace --tasks`, 가이드/스펙, `tests/test_figma_workspace.py`. 신규 selection schema는 `figma-flow-workspace-retirement-v1`이다.

## 설계 이유와 출처
근거: 전체 커밋 `2bc687579e5059cba6702bc5c4a2690c9e34b509`; `retire`, `require_idle_publication`, `task_artifacts`, `publish`, workspace tests. stale revision은 거부하고 작업 내용을 복구 가능한 private record로 남긴다.

## 호환성·이관·복구
기존 prepare/list/replay는 유지되며 신규 retire 명령만 추가된다. stale revision 오류 시 task를 다시 나열해야 한다. record 기반 복구 전용 명령이 추가됐다는 증거는 없다.

## 검증과 미검증
retirement 관련 테스트 137줄이 추가됐다. 실행 로그 및 파일시스템 실패 복구 실행은 미검증이다.

## 한계와 후속 개선
기록 저장은 복구 단서를 제공하지만 직접 restore UX는 별도 작업일 수 있다. 동시 외부 파일 변경 경합은 publish 계약에 달려 있다.
