# fix(native-read): count UTF-8 JSON bytes without TextEncoder

## 문제와 계기

Figma 플러그인 sandbox에 `TextEncoder`가 없어 공유 `utf8JsonBytes`가 실기 getter-count 진단에서 실패했다.

## 결과 동작

커밋 `3b3fa8f0d986ee3d2b8dae1d37b2a7e2f377965e`의 `utf8JsonBytes`는 UTF-16 code unit에서 UTF-8 bytes를 센다. surrogate pair는 4 bytes, lone surrogate는 `TextEncoder`와 같이 3 bytes인 U+FFFD로 센다. `readNativeSemantics`와 필드는 그대로이고, 기본 discovery bundle은 이 helper 본문만 다르다.

## 변경 파일과 인터페이스

`figma-bridge/native_semantic_read.js`의 `utf8JsonBytes` 본문.

## 설계 이유와 출처

[P2 1차 실행 계약](../../next-roadmap/p2-wave1-acceptance.md)의 계측 조건에 따라 새 전역 polyfill이나 중복 helper 대신 기존 공유 함수를 최소로 고쳤다. 파일 blob은 바뀌지만 reader 본문과 full 필드 범위는 기준 `9962afa`와 같다.

## 호환성·이관·복구

bytes 값은 `TextEncoder` 결과와 같다.

## 검증과 미검증

[24f34f9](24f34f980703e76398d8c758052adccaed92d845.md)의 sandbox·UTF-8 기준 검사가 통과한다. root는 이 소스에서 live-002를 측정했고 진단 회차가 성공했다.

## 한계와 후속 개선

이 변경으로 static API coverage baseline의 reader digest를 [9669bc5](9669bc53007b544dc7ca49d6760e59786dd52f1a.md)에서 갱신했다.
