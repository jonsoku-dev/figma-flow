# test: pin web tracking and first image preview regressions

## 문제와 계기

0.32.0은 CSS 자간 값을 입력하면 검증에서 거절했고, 첫 canvas 미리보기에는 다시 내보내야만 보이는 영역이 있었다.

## 결과 동작

글자 간격이 음수인 입력과 필드 없는 입력, 새 이미지 프레임의 최초 내보내기 결과를 재현 기준으로 고정했다.

## 변경 파일과 인터페이스

tests/test_web_design_tracking.py는 그래프와 계획을 통과시킨다. tests/test_web_design.cjs는 서로 다른 첫 번째와 두 번째 export 결과를 내는 모의 환경으로 공개 apply 경로를 검사한다.

## 설계 이유와 출처

기준 파일과 실행 모드를 먼저 Git에 저장해 제품 코드와 별개로 같은 assertion을 재실행했다.

## 호환성·이관·복구

테스트만 추가했다. 이 커밋을 단독으로 설치해도 기존 가져오기 동작은 바뀌지 않는다.

## 검증과 미검증

이전 코드에서 자간은 Unsupported observed text fields로 거절되고 최초 export가 첫 번째 바이트를 그대로 돌려줬다. 후속 구현 뒤 같은 테스트 파일로 다시 확인했다.

## 한계와 후속 개선

모의 export는 제품 경로의 분기 확인이다. 실제 렌더 여부에는 별도의 Figma PNG 비교가 필요하다.
