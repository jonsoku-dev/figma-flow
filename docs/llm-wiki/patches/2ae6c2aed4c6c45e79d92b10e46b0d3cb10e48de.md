# test: resolve panel dependencies from helper directory

## 문제와 계기

직전 하네스 이동 후 lifecycle helper의 React 및 ReactDOM require가 여전히 tests 기준 상대경로여서 tests/helpers에서 잘못 해석될 수 있었다.

## 결과 동작

helper가 ../../panel-ui/node_modules에서 React와 react-dom/server를 읽는다. 실제 Workspace의 정적 렌더링 검사에 도달하도록 경로만 복구한다.

## 변경 파일과 인터페이스

tests/helpers/finalize_lifecycle_runtime.cjs의 두 require 문자열만 변경했다. esbuild 경로는 앞선 이동 커밋에서 이미 보정되었다.

변경 경로: [tests/helpers/finalize_lifecycle_runtime.cjs](../../../tests/helpers/finalize_lifecycle_runtime.cjs).

## 설계 이유와 출처

Node의 상대 require는 실행 cwd가 아니라 helper 파일 위치를 기준으로 한다. 함수·패키지·fallback을 추가하지 않고 이동된 파일의 깊이를 반영했다.

## 호환성·이관·복구

panel-ui에 설치된 기존 의존성을 사용한다. 패키지나 제품 번들은 바꾸지 않으며 해당 의존성이 설치되어 있어야 렌더링 하네스가 작동한다.

## 검증과 미검증

Git diff로 두 경로 보정을 확인했다. 이는 module-not-found라는 하네스 오류를 제거하는 기준 변경이며, canonical journal이 실제 UI까지 투영되는지의 통과 증거와 구분한다.

## 한계와 후속 개선

의존성 설치 여부와 실제 렌더링 실행은 이번 정적 기록 작업에서 확인하지 않았다. Figma 실행도 포함하지 않는다.
