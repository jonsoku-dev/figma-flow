# feat: compare declared container links with the native reader

## 문제와 계기

기준 8421b31163333c0b75e24e096ad6975d07138a33는 선언한 컨테이너의 명세, 주석, prototype, geometry를 실제 reader와 대조하는 함수가 없어 `declared container links must match the native reader`로 실패했다.

## 결과 동작

readDeclaredContainerLinks는 readNativeSemantics로 화면 Frame과 선언한 부모, leaf를 읽는다. card는 Frame이고 copy의 부모이며, ornament Group은 layout이 없고, title의 화면 기준 상자는 배치 전과 같다. save의 주석과 명세 상태는 leaf 행에 남고 prototype destination은 화면 Frame이다. destination이 새 컨테이너 ID이면 실패한다. makeDraft는 containers가 있을 때만 부모 배치 다음에 이 함수를 호출한다.

## 변경 파일과 인터페이스

figma-bridge/direction_review.js에 readDeclaredContainerLinks를 추가하고 makeDraft에서 호출한다. docs/development-roadmap/RD-02-layer-structure/tasks.md에 대조 범위를 적었다. tests/rd02_container_readback_oracle.cjs blob은 기준과 같다.

## 설계 이유와 출처

RD-02는 prototype target이 내부 Group으로 이동하면 실패로 본다. 부모 체인의 x,y 합으로 화면 기준 geometry를 계산해 작성기 좌표와 분리한다. 명세 wrapper가 깨져도 그 상태는 leaf 행에만 남는지 본다.

## 호환성·이관·복구

containers가 없으면 이 대조를 호출하지 않는다. 기존 화면 Frame의 ID·크기·clip과 containers가 없는 패킷의 leaf 부모는 유지된다.

## 검증과 미검증

종료 게이트가 기준 8421b31163333c0b75e24e096ad6975d07138a33의 종료 코드 1과 대상 946717804fcf45d0d4c85c3e624132ed0c48455f의 종료 코드 0을 다시 실행했다. 실제 Figma 레이어 트리, prototype 왕복, resize와 긴 한글 문구는 관찰하지 않았다.

## 한계와 후속 개선

이 단위는 mock reader 대조다. hug/fill/fixed가 문구 증가와 resize에서 유지되는지는 아직 확인하지 않았다. AC-02의 실제 prototype 왕복은 통과로 기록하지 않는다.
