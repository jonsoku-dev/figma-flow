# 0ee0a24 · 마운트된 앱 화면들에서 컴포넌트 증거 확인

## 문제와 계기
웹 동기화의 컴포넌트 proof가 여러 앱 화면에 마운트된 상태를 충분히 확인하지 못했고 native 컨트롤 정렬 계약도 약했다.

## 결과 동작
`tools/graph_sync.py`가 mounted app screen 기준으로 proof 수집/검증을 확장한다. `figma_draft.py`와 `design_directions.py`가 해당 증거를 품질 경로에 연결한다. `direction_review.js`는 컨트롤 정렬을 읽고 검증한다. Regression program fixture는 여러 앱/화면 입력을 제공한다.

## 변경 파일과 인터페이스
16개 파일: `graph_sync.py`, `figma_draft.py`, `design_directions.py`, bridge, regression fixtures 및 scoped web proof/native alignment 테스트. proof 계약에 화면 범위가 반영된다.

## 설계 이유와 출처
근거: 전체 커밋 `0ee0a24c5955e52dfb6f8f183bb6ac813252b446`; `tests/test_scoped_web_proof.py`, native alignment tests, graph sync 및 regression program. 한 화면의 증거를 전체 앱 범위로 오인하지 않게 한다.

## 호환성·이관·복구
기존 proof가 새 화면 범위를 포함하지 않으면 증거 부족으로 거부될 수 있으며 현재 화면을 대상으로 다시 수집해야 한다. 사용자 Figma 데이터 변경은 없다.

## 검증과 미검증
scope와 native alignment 관련 테스트가 추가됐다. 테스트 실행 및 브라우저 실앱 검증은 미검증이다.

## 한계와 후속 개선
fixture 화면 수가 실제 동적 route 전체를 보장하지 않는다. 적용 범위가 제품 acceptance 요구와 맞는지 별도 확인해야 한다.
