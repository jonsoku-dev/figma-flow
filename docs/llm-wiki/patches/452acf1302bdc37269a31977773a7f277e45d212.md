# docs(roadmap): record verified NF-01 owned-example browser accessibility evidence

## 문제와 계기

NF-01 영수증에는 자체 예제의 브라우저 DOM 접근성 대응이 관찰되지 않았다는 문구가 남아 있었으나, root가 로컬 loopback 자체 예제 화면에서 실제 확인한 근거가 확보됐다.

## 결과 동작

커밋 `452acf1302bdc37269a31977773a7f277e45d212`는 `docs/next-roadmap/backlog.graph.json`과 `docs/next-roadmap/p1-acceptance.md`에 `examples/owned-component-families/` 실제 화면 근거를 반영했다. `label` 클릭 포커스, checkbox 전환, radio 형제 상태 분리와 `ArrowUp`, 표 두 번째 행 `Enter` 선택, `caption`, 열 헤더 `2`개·행 헤더 `2`개, 조건부 `hidden`/`aria-hidden`, 비활성 필드, 미선언 동작 보존을 확인했고 외부 요청과 콘솔·페이지 오류는 없었다.

## 변경 파일과 인터페이스

`docs/next-roadmap/backlog.graph.json`, `docs/next-roadmap/p1-acceptance.md`만 수정했다.

## 설계 이유와 출처

원시 URL·개인 경로·예제 인물 이름을 공개하지 않고 관찰 결과만 남겨, 브라우저 근거 범위를 자체 예제 로컬 loopback으로 한정했다.

## 호환성·이관·복구

문서·그래프 정정이며 제품 소스와 예제는 바뀌지 않는다.

## 검증과 미검증

`452acf1` 기준 `tests.test_next_roadmap_backlog`, `tests.test_design_specialization`, `tests.test_graph` 55개 통과와 `reference_distribution_guard.py --ref HEAD` `paths_only_clear`(`forbidden_paths=0`)를 확인했다. 외부 사이트나 다른 브라우저 범위는 주장하지 않는다.

## 한계와 후속 개선

브라우저 근거는 자체 예제 한정이며 실제 서비스 화면 접근성은 별도 인수가 필요하다.
