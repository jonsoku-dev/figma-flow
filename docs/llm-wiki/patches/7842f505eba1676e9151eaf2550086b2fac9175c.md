## 문제와 계기

유지보수 작업이 끝난 뒤 원시 산출물 없이 실제 명령 결과를 기록해야 했다.

## 결과 동작

전체 단위 검사, 변이 검사, 저장 공간 회귀와 클러스터를 제외한 메이저 후보 판정이 남는다.

## 변경 파일과 인터페이스

## 설계 이유와 출처

PostgreSQL을 제외한 시점의 인수는 기존 예제의 DB 검사 때문에 막혔다는 관측을 보존한다.

## 호환성·이관·복구

검증용 원본과 설치물을 정리했다. 운영 데이터에는 영향을 주지 않았다.

## 검증과 미검증

커밋 뒤 같은 Git 카탈로그와 두 발행 커밋을 검증했다.
