# feat(provision): add scope-pinned NF-01 component-families native-edit plan and runtime wiring

## 문제와 계기

6패밀리 시맨틱 런타임(`709f1104`)을 사용자 경로에서 쓰려면, 등록된 파일·페이지 범위에 고정된 native-edit 계획과 실행 연결이 필요했다.

## 결과 동작

커밋 `8af6db43123e03bdf6b28456944243cf487da3fd`는 `tools/family_provision.py`로 범위 고정 NF-01 component-families 계획을 만들고, `tools/native_edit.py`와 `figma-bridge/native_provision.js`로 런타임 실행·읽기를 연결했다. 범위 불일치, 개인 로컬 경로 유출, 형제 drift, 겹치는 추가 대상은 거부한다.

## 변경 파일과 인터페이스

`tools/family_provision.py`(신규), `tools/native_edit.py`, `figma-bridge/native_provision.js`, `tests/test_family_provision.py`, `tests/test_family_provision_runtime.cjs`를 추가·수정했다.

## 설계 이유와 출처

[NF-01 설계서](../../next-roadmap/NF-01-component-families.md)의 가산 적용과 범위 경계를 계획 단계에서 강제해 승인되지 않은 페이지 변경을 막는다.

## 호환성·이관·복구

기존 native-edit 경로와 별도 계획 유형이다. 실패 분류와 중복 보상 제거는 `63b35558`에서 보완됐다.

## 검증과 미검증

`tests/test_family_provision.py`와 `tests/test_family_provision_runtime.cjs`가 `e6f4fd8` P1 집중 suite와 CI에서 통과했다. 실기 첫 적용의 중복 표시명 실패는 이후 `63b35558`·`974b5de7`에서 수정됐다.

## 한계와 후속 개선

이 커밋의 wrapper는 실패 시 core 롤백 뒤 중복 보상을 시도할 수 있어 `63b35558`에서 제거됐다.
