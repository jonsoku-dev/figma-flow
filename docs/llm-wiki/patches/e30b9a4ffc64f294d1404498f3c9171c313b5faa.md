# e30b9a4 · 0.21.0 그래프 SSOT 통합 릴리스

이 기록은 원본 커밋 `e30b9a4ffc64f294d1404498f3c9171c313b5faa`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

첫 부모 0173535의 vendored 바이트 보존과 둘째 부모 3c6a0f0의 Graph SSOT 진입 문구를 0.21.0 릴리스로 통합해야 했다. merge는 양쪽 커밋의 차이를 보존하며 새로운 부모를 덮어쓰지 않는다.

## 결과 동작

Graph SSOT 도구/브리지/예제·테스트를 릴리스 메타데이터와 함께 통합한다. 변경 파일은 tools/graph_sync.py, graph_design_system.py, figma-bridge/graph_token_sync.js, example, tests와 README/CHANGELOG다.

## 변경 파일과 인터페이스

이전 4a6314c에 구현된 동기화 API가 릴리스 패키지에서 제공되고 0173535의 .gitattributes 설정이 함께 남는다. plugin.json은 버전 0.21.0을 표시한다.

## 설계 이유와 출처

실제 병합 관계가 중요하다: 0173535는 vendor checkout 보존, 3c6a0f0은 Graph SSOT 릴리스 안내다. 통합은 둘을 Graph SSOT 릴리스에 포함한다.

## 호환성·이관·복구

기존 패키지 사용자는 버전 메타데이터가 갱신되며 Graph SSOT를 사용할 때는 example의 준비·검증·충돌 복구 절차를 새로 따라야 한다. 기존 토큰을 자동 변환했다고 볼 수 없다.

## 검증과 미검증

tests/test_graph_sync.py, test_graph_design_system.py, test_graph_token_sync.cjs는 코드 변경 동반 정적 테스트다. 실행 결과와 실제 Figma/web 통합은 이 커밋에서 미검증이다.

## 한계와 후속 개선

기능은 명시된 컴포넌트/토큰 범위로 한정된다. 새 릴리스 통합이 모든 기존 디자인 시스템의 이전을 증명하지 않는다.
