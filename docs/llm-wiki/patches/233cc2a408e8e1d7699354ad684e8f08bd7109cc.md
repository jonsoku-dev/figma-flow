# 로컬 Figma Flow 1.0.0 태그와 배포 기록

소스 커밋 `233cc2a408e8e1d7699354ad684e8f08bd7109cc`

## 문제와 계기

정본과 MySQL 인수를 갖춘 1.0.0 후보를 현재 배포 기록에 연결해야 했다.

## 결과 동작

배포 검토와 예약 예제의 근거를 Git 기록과 사용 안내에서 찾을 수 있다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`, `docs/llm-wiki/releases.md`와 후보의 실행 기록을 발행했다.

## 설계 이유와 출처

ZIP은 태그가 가리키는 Git 트리에서 만들고 저장소의 패키징·배포 검사를 그대로 실행했다.

## 호환성·이관·복구

검증용 스키마와 ZIP 풀기 자료는 정리했다. 승인된 최종 산출물 ZIP과 체크섬은 로컬 산출물로 남는다.

## 검증과 미검증

배포 영역 16개와 파일 2,549개를 검사해 차단 0건이었다. 실제 ZIP에서 워크숍, 대기 상태와 Design 매니페스트 생성을 확인했다.

## 한계와 후속 개선

태그와 로컬 패키지는 원격 게시 및 기존 사용자 환경의 설치 인수와 구분한다.
