# 뷰어에 표시되는 실제 정렬 기준 고정

## 문제와 계기

기존 패널에서 320px와 400px 폭의 본문과 헤더·표 시작선이 달랐다.

## 결과 동작

`1c58e3a92b867fdd37dee6c8255a0d90f6a600e6`에 빌드된 뷰어를 브라우저에 띄우고 선택 표까지 펼쳐 확인하는 회귀 검사를 먼저 보존했다.

## 변경 파일과 인터페이스

`tests/test_relay_alignment.py`는 `tests/helpers/relay_alignment.mjs`가 Chromium에서 측정한 값을 확인한다.

## 설계 이유와 출처

CSS 선언만 확인하면 다른 레이아웃 규칙으로 인해 실제 시작선이 틀어진 경우를 놓칠 수 있다.

## 호환성·이관·복구

테스트용 선택 데이터를 사용한다. 설치된 Figma의 문서나 설정을 편집하지 않는다.

## 검증과 미검증

변경 전 실행에서 320px 화면 헤더와 본문 사이의 1px 편차로 기대한 단언이 실패했다.

## 한계와 후속 개선

로컬 테스트는 CSS 요소의 경계를 측정한다. 글리프의 광학적 무게와 실제 Figma 편집기 상태는 별도 관찰이다.
