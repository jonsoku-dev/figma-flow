# fix: preserve native text metrics when reusing captured web controls

## 문제와 계기

브라우저에서 박스·색·역할이 같고 줄 높이가 다른 버튼이 한 main을 공유했다. 기존 Figma 결과는 가운데 레이블까지 20px로 표시했다.

## 결과 동작

캡처는 역할을 기록하고 플러그인은 실제 글꼴·크기·줄 높이·채우기와 정렬로 같은 main을 사용할지 결정한다. 인스턴스의 레이블도 네이티브 범위 getter로 확인한다.

## 변경 파일과 인터페이스

`tools/web_design_capture.js`의 역할 키를 단순화하고 `figma-bridge/web_design.js`의 컴포넌트 분류·텍스트 검증을 수정했다. `tests/test_web_design.cjs`에서 재사용과 잘못된 스타일을 함께 검증한다.

## 설계 이유와 출처

컴포넌트 키가 같은 사용자 입력에도 전체 타이포그래피를 검사한다. 텍스트 내용이 다르더라도 같은 시각적 규칙인 버튼은 인스턴스로 유지한다.

## 호환성·이관·복구

원본 그래프와 이전 Figma 산출물은 보존한다. 다른 테스트 그래프로 수정 전 결과와 수정 후 결과를 같은 페이지에서 대조했다.

## 검증과 미검증

실제 브라우저 버튼 세 개의 줄 높이 20·24·20px를 확인했다. 수정 전 자체 플러그인은 20·20·20px를 만들었다. 수정 후 2개 main과 1개 instance를 만들고 줄 높이 및 재실행 시 같은 ID를 확인했다.

## 한계와 후속 개선

이 커밋에서 기능 실측은 새로 만든 프레임에서 수행했다. 과거의 잘못된 스타일을 보존한 프레임을 재검사하는 동작은 후속 근거를 참조한다.
