# docs: document offline reference distribution guard in release guides

## 문제와 계기

기여자와 배포 담당자가 `paths-only` 모드와 오프라인 참고 ZIP·비공개 인용 목록 대조 절차를 일관되게 실행할 수 있도록 릴리스·사용 문서에 명령과 구분 기준을 안내할 필요가 있었다.

## 결과 동작

`CONTRIBUTING.md`에 `--ref HEAD` 기반 `paths-only` 확인 명령, `--worktree --reference-zip ... --reference-literals ...` 오프라인 대조 명령, 태그 ZIP 생성 직후 `--target-zip` 검증 단계를 추가하고, `docs/guide.md`의 배포 전 점검 문단에 로컬 참고 ZIP·추출 파일·비공개 인용 목록 제외 및 가드 실행 안내를 반영했다.

## 변경 파일과 인터페이스

`CONTRIBUTING.md`(8줄 추가)와 `docs/guide.md`(1줄 갱신)를 수정했다. CLI 인터페이스나 출력 스키마 변경은 없다.

## 설계 이유와 출처

공유 문서에는 개인 경로와 비공개 목록 없이 플레이스홀더 경로(`/path/to/reference.zip`, `/path/to/literals.json`)만 사용해 어느 환경에서나 동일한 릴리스 안전 절차를 따를 수 있도록 했다.

## 호환성·이관·복구

문서 변경이므로 기존 CLI·플러그인·디자인 그래프와의 하위 호환성을 깨뜨리지 않는다.

## 검증과 미검증

`git diff`로 문서 명령과 옵션(`--ref`, `--worktree`, `--target-zip`, `--reference-zip`, `--reference-literals`, `paths_only_clear`)이 `tools/reference_distribution_guard.py` 실제 구현과 일치함을 대조했다. 이 커밋 자체에 대한 별도 브라우저/네이티브 실행은 없다.

## 한계와 후속 개선
