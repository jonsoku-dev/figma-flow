# 6969e5d · 네이티브 텍스트 intrinsic 측정 격리

## 문제와 계기
자연 폭 측정이 원본 clone의 제약·부모 layout 영향을 받으면 실제 text 크기와 달라질 수 있었다.

## 결과 동작
`measureDraftNaturalWidth()`가 임시 숨김 frame을 만들고 복제 텍스트의 width/height 제약을 푼 뒤 폭을 측정한다. probe와 frame은 finally에서 제거하고 실패하면 null 및 오류 정보를 반환한다.

## 변경 파일과 인터페이스
`figma-bridge/direction_review.js`, `tests/test_direction_native_limits.cjs`, 신규 `tests/test_native_text_measurement.cjs`. 미측정 상태는 null/error로 표현한다.

## 설계 이유와 출처
근거: 전체 커밋 `6969e5dafccef185256c6f02f42b66b9f3636074`; `measureDraftNaturalWidth`, native text measurement tests. 측정용 문맥을 격리해 입력 노드와의 간섭을 줄인다.

## 호환성·이관·복구
packet 변경은 없다. 미지원/실패 상태를 실제 숫자처럼 취급하지 않는다. 임시 노드 제거 실패는 status에 남긴다.

## 검증과 미검증
측정 테스트가 71줄 추가됐다. 실행 성공 및 Figma 측정값 정확성은 미검증이다.

## 한계와 후속 개선
이후 수정에서 clone 기반 접근이 새 텍스트 구성으로 바뀐다. 본 커밋만으로 font/range state 측정의 완전성은 보장되지 않는다.
