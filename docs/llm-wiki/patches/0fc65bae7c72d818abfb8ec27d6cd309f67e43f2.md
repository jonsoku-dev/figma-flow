# fix: expose a validated replay link after the Present action

## 문제와 계기

클릭 처리 요청을 보낸 것만으로는 사용자가 열린 플레이어를 찾을 수 없고, 열린 탭이 보이지 않을 때 다시 쓸 링크가 없었다.

## 결과 동작

호스트가 검증해 반환한 재생 URL을 현재 작업과 실행 이력에 맞춰 확인한 뒤, 열기 또는 복사하는 동작을 제공한다.

## 변경 파일과 인터페이스

변경 경로는 `figma-bridge/assets/panels.js`, `figma-bridge/locales/workspace.json`, `panel-ui/src/CarouselPresentLink.jsx`, `panel-ui/src/Workspace.jsx`, `panel-ui/src/WorkspaceActivity.jsx`, `panel-ui/src/carouselPresentation.mjs`, `tests/test_carousel_present_link.cjs`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

재생 주소는 현재 파일·페이지·시작 프레임과 정확히 맞아야 한다. 외부 링크 호출 자체를 재생 관찰로 기록하지 않는다.

## 호환성·이관·복구

포크는 이 커밋과 부모의 변경 경로를 대조해 적용할 수 있다. 캐러셀 CMS나 외부 계정 연결은 필요하지 않다. 원본 화면과 사설 영수증은 로컬에 보존한다.

## 검증과 미검증

수정본을 실제 Figma에서 다시 연 뒤 홈 Present를 눌러 새 Desktop 재생 탭, 일치하는 시작 노드와 카드 표시를 확인했다. URL 형식·다른 작업/프레임 거부와 안내 렌더도 테스트했다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
