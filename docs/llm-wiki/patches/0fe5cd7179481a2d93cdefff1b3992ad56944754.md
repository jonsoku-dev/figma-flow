# 단일 그래프 디코더와 실행 근거 프로필

## 문제와 계기

그래프 검사 조건을 산문으로만 관리하면 CLI와 다른 소비 경로에서 동일 입력이 다르게 처리될 수 있다.

## 결과 동작

0fe5cd7179481a2d93cdefff1b3992ad56944754에서 휴대용 디코더로 경계를 모으고 원시 디코더 우회를 정적 검사에서 검출한다.

## 변경 파일과 인터페이스

`tools/graph_document.py`, `tools/maintenance.py`, `tools/maintenance-contract.json`과 CI·저장소 규칙·스킬의 실행 경로를 바꿨다.

## 설계 이유와 출처

중복 키와 비유한 수를 데이터가 해석되기 전에 거절한다. CLI·그래프·UI의 검증 결과는 로그, 지문, 캡처로 저장한다.

## 호환성·이관·복구

그래프의 기존 바이트 지문과 정상 경로를 유지하고 실패 및 미실행을 근거에서 확인할 수 있게 한다.

## 검증과 미검증

위반 코드 주입, 실패 실행 기록, 공개 CLI와 그래프 소비 경로를 검사했다. 6,000개 그래프 생성·변이 입력을 고정 시드로 실행했다.

## 한계와 후속 개선

현재 정적 검사는 등록된 여섯 입력 파일에 적용된다. 생성 테스트는 지원하는 그래프 형태의 유한한 입력을 다룬다.
