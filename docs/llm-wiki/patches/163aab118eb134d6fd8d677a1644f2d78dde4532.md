# 두 프로세스의 설정 변경 재현

커밋 `163aab118eb134d6fd8d677a1644f2d78dde4532`

## 문제와 계기

서로 다른 소스의 메트릭스 설정 및 두 작업공간 등록이 모두 성공한 뒤 디스크에는 마지막 결과 하나만 남았다.

## 결과 동작

한 프로세스의 실제 파일 교체를 잠시 보류하고 두 번째 프로세스에서 정상 CLI 또는 레지스트리 진입점을 호출한다.

## 변경 파일과 인터페이스

tests/test_config_transactions.py가 임시 XDG 설정, 프로세스별 종료 코드, 최종 값과 0600 권한을 검사한다.

## 설계 이유와 출처

호출 횟수가 아닌 파일에 남은 두 값이 성공 조건이다. 첫 교체 전 다른 파일에 대한 명령의 완료도 확인한다.

## 호환성·이관·복구

사용자 설정과 외부 수집기는 사용하지 않는다. 실패한 설정 변경 뒤 같은 프로세스가 살아 있는 동안 새 쓰기가 가능한지도 검사한다.

## 검증과 미검증

제품 수정 전 두 소스, 강제 초기화 순서, 두 등록 보존 검사가 모두 실패했다. 원래 파일 교체 동작은 그대로 실행했다.

## 한계와 후속 개선

프로세스 경합 테스트는 POSIX용이다. Windows의 파일 잠금은 이번 실행에서 확인하지 않았다.
