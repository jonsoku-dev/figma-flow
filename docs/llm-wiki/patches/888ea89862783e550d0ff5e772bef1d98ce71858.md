# docs(roadmap): align P2 baseline ownership with flag-gated instrumentation

## 문제와 계기

[1214f48](1214f4848619f09cb1f625c5b3486ea71bc54aa1.md)의 파일 소유 표는 두 writer 모두 코어 플러그인을 바꾸지 못하게 했다. root의 초기 배정은 baseline writer에게 `figma-bridge/native_semantic_read.js`와 필요한 최소 discovery 호출부를 허용했으므로 계약과 배정이 어긋났다.

## 결과 동작

커밋 `888ea89862783e550d0ff5e772bef1d98ce71858`는 baseline writer의 소유를 새 `figma-bridge/native_read_measurement.js`, `figma-bridge/native_semantic_read.js`, `tools/graph_sync.py`·`tools/figma_workspace.py`의 최소 discovery 호출부, 새 측정 검사, NF-02 측정 부록으로 정했다. 기존 파일 변경은 세 조건을 지킨다. flag 없는 기본 경로의 시그니처·반환값·getter가 기준과 같다. 계측은 명시적 선택 flag에서만 동작한다. 동결된 RD-06 검사와 `tests/test_graph_sync.py`가 blob·모드 변경 없이 통과한다. Native·패널 UI·원본 작업 페이지의 실제 실행은 root만 한다. fixture writer는 여전히 코어 캡처·컴파일러·플러그인을 바꾸지 않는다.

## 변경 파일과 인터페이스

`docs/next-roadmap/p2-wave1-acceptance.md`만 바꿨다.

## 설계 이유와 출처

측정에는 reader 내부 시계와 discovery 호출부의 선택 경로가 필요할 수 있다. 기본 경로를 고정하고 flag 뒤로 계측을 격리하면 생산 읽기와 RD-06 기준을 바꾸지 않고 측정할 수 있다.

## 호환성·이관·복구

문서만 바뀌었다. full 전용 기준선과 문서의 profile 범위 정렬은 원본 그래프 최소 요구와 독립 판정 뒤로 미뤘다.

## 검증과 미검증

`python3 -B -m unittest tests.test_next_roadmap_backlog` 3개 통과, `git diff --check` 통과. baseline 후보 커밋의 diff는 이 기록 범위에서 검토하지 않았다.

## 한계와 후속 개선

baseline 후보가 통합되면 기본 경로 불변과 oracle blob을 root가 독립 검사로 확인한 뒤 노드 `commands`에 새 측정 검사를 넣는다.
