# fix: summarize tab readback and click controls in the plugin home

## 문제와 계기

플러그인 홈은 캐러셀 읽기 결과만 요약했다. 0.33 요약은 읽기 결과에 없는 `control.reactions`를 읽어 이전/다음 버튼 전이를 빠뜨렸다.

## 결과 동작

홈이 tabs 읽기 결과도 같은 요약에 붙인다. 컨트롤 항목의 trigger와 목적지로 전이를 만든다. 프로토타입 제목·상태 목록·Present 라벨이 캐러셀에 한정되지 않는 문구로 바뀌었다.

## 변경 파일과 인터페이스

`figma-bridge/workspace_host.js`(`workspaceCarouselSummary`, `workspaceObserve`), `figma-bridge/workspace_control.js`, `figma-bridge/locales/workspace.json`, `tests/test_workspace_host.cjs`를 바꿨다.

## 설계 이유와 출처

0.33 패치 페이지가 기록한 컨트롤 간선 누락을 같은 요약 경로에서 고쳤다. 요약 스키마와 함수 이름은 유지해 저장된 이력을 그대로 읽는다.

## 호환성·이관·복구

저장된 `figma-flow-carousel-summary-v1` 형식은 바뀌지 않았다. 패널 빌드 산출물 변경은 없다.

## 검증과 미검증

호스트 테스트 25개가 통과했다. 새 테스트는 tabs hotspot 요약과 캐러셀 next 컨트롤 요약을 함께 확인하며, 후자는 이전 코드에서 간선이 비어 실패한다.

## 한계와 후속 개선

클래스·메시지 이름에는 carousel이 남아 있다.
