# test: pin one HTML task input record and its safe summary

## 문제와 계기

HTML 작업의 입력 record hash와 개인 경로가 빠진 요약이 고정되어 있지 않았다. 이 커밋 904175b5b8ed48f6c2a3bd5f8c23ed0066dfb3c2의 검사는 summarize_input_record가 없어 `html task input record must keep its hash and a safe summary`로 실패한다.

## 결과 동작

tests/test_rd05_html_input_record.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 v3 record의 sha256이 canonical 바이트와 같고, 요약의 상태는 present·404·rejected·external-unverified·rejected 순이다. 외부 주소는 query와 fragment가 없고, 요약에는 실제 개인 홈 경로가 없다. record가 없는 discover task에는 input_record 필드가 없다.

## 변경 파일과 인터페이스

tests/test_rd05_html_input_record.py를 추가했다. 제품 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd05_html_input_record로 실행한다.

## 설계 이유와 출처

RD-05 작업 2는 한 HTML task에 hash-pinned input record와 안전한 요약을 둔다. 원시 record와 요약은 다르다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. record가 없는 prepare의 revision은 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `html task input record must keep its hash and a safe summary`다. 브라우저 로딩은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 record다. 구현은 별도 커밋 f12b84f03a916c2aed744db43eb7699c95094034에서 검사 blob을 유지한 채 복사와 요약을 추가한다. 자산 목록 UI는 아직 없다.
