# test: keep one font when two stylesheets import it and mark byte changes stale

## 문제와 계기

같은 글꼴의 두 유입 경로와 바이트 변경 뒤의 stale이 한 fixture로 고정되어 있지 않았다. 이 커밋 dbd4c0eb275a75dd5519e924c3c209716aa0578d의 검사는 자산에 sources가 없어 `duplicate font ingress must stay one asset and a byte change must go stale`로 실패한다.

## 결과 동작

tests/test_rd05_asset_freshness.py는 sources가 없으면 위 문구로 끝난다. 구현 뒤에는 fonts/body.woff2 자산이 하나이고 출처는 css/a.css와 css/b.css다. 같은 hash의 record는 current이고, 바이트를 바꾸면 stale이며 changed는 fonts/body.woff2다.

## 변경 파일과 인터페이스

tests/test_rd05_asset_freshness.py를 추가했다. 제품 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd05_asset_freshness로 실행한다.

## 설계 이유와 출처

RD-05 작업 4는 freshness 변화와 유입 경로 중복을 회귀 fixture로 고정한다. 같은 파일은 한 항목이고 출처 목록은 남는다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 기존 freshness 반환 필드는 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `duplicate font ingress must stay one asset and a byte change must go stale`이다. 브라우저 로딩은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 임시 로컬 파일이다. 구현은 별도 커밋 29198999ebfe2aa9975576dc5792939315fbc850에서 검사 blob을 유지한 채 출처를 합친다. 실제 CSS 간접 사진 대조는 아직 없다.
