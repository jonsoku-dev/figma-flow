# 루프백 전송 검사의 TCP와 Host 경계 고정

소스 커밋 `0d344a1f55f15a20a9d6057c79cface9c2aae13c`

## 문제와 계기

GitHub 아카이브 재검증은 루프백 전송 사례와 예약 예제의 품질 검사를 다시 요구했다.

## 결과 동작

전송 검사는 실제 로컬 HTTP를 쓰며 연결 주소는 IPv4 루프백, Host는 등록된 localhost를 사용한다. 아카이브 준비 단계에서 예약 예제의 품질 검사와 전송 사례를 독립 실행한다.

## 변경 파일과 인터페이스

`tests/test_control_transport_authority.py`, `library/delivery/reference-guard.yml.in`과 생성된 워크플로를 갱신했다.

## 설계 이유와 출처

이름 확인 방식과 연결 유지 시간의 영향을 줄이면서 서버 인증·용량·거절·큰 결과 경로 단언을 유지한다.

## 호환성·이관·복구

개발 플러그인의 실제 fetch 전송과 서버의 보호 경계는 같은 계약을 적용한다.

## 검증과 미검증

전송·워크플로 검사 11건 및 실제 Chromium 색상 검사를 로컬에서 통과했다. GitHub와 같은 Pillow·fonttools 입력으로 예약 핸드오프 재생성도 통과했다.

## 한계와 후속 개선

원격의 새 실행은 당시 실패 결과와 별도로 기록한다.
