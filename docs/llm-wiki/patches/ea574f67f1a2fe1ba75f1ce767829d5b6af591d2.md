# ea574f6 · CSS 문자열 손실 없이 브라우저 픽셀 측정

## 문제와 계기
Computed CSS values 직렬화가 numeric float 정밀도를 잃게 해 graph 값과 browser proof를 비교할 때 거짓 불일치가 생길 수 있었다.

## 결과 동작
`tools/graph_sync.py`는 Typed OM `computedStyleMap()`에서 px numeric value를 우선 읽고, 지원되지 않으면 px 문자열을 parse한다. 검증은 FLOAT를 유한 숫자로 제한하고 exact 값 또는 해당 float32 표현과 비교한다. width/height는 기존 처리 경로를 유지한다.

## 변경 파일과 인터페이스
`tools/graph_sync.py`, regression server, precision/rendering tests, guide/example docs. proof JSON 구조는 유지된다.

## 설계 이유와 출처
근거: 전체 커밋 `ea574f67f1a2fe1ba75f1ce767829d5b6af591d2`; `web_probe()`, `verify_web_proof()`, `tests/test_web_probe_precision.py`. 문자열 변환에서 생기는 측정 손실을 줄인다.

## 호환성·이관·복구
기존 proof 입력을 그대로 읽는다. 브라우저 Typed OM 부재 시 문자열 fallback이며 비숫자·비유한 값은 계속 거부된다.

## 검증과 미검증
precision 테스트 110줄이 추가됐다. 테스트 실행 및 여러 브라우저 엔진의 실측 비교는 미검증이다.

## 한계와 후속 개선
float32 표현 허용은 해당 browser 변환 오차만 고려한다. 개별 CSS 속성의 Typed OM 지원은 달라질 수 있다.
