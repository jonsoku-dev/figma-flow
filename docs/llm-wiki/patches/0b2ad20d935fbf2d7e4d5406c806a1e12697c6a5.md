# 0b2ad20 · 투명 컨트롤과 분산 간격 보존

## 문제와 계기
검토용 native controls가 의도하지 않은 불투명 배경을 얻거나 분산형 레이아웃 간격을 보존하지 못할 수 있었다.

## 결과 동작
`direction_review.js`가 control 스타일과 native geometry를 맞추고 `design_quality.py`, `draft_token_plan.py`, `figma_draft.py`가 색/투명도 및 draft 값을 반영한다. Python/CJS 테스트가 투명성을 별도로 검사한다.

## 변경 파일과 인터페이스
`figma-bridge/direction_review.js`, `tools/design_quality.py`, `tools/draft_token_plan.py`, `tools/figma_draft.py`, `tests/test_control_transparency.py`, `tests/test_native_control_transparency.cjs`, `docs/guide.md`, CHANGELOG.md의8개 파일이다. 명시적인 fill:null을 투명으로 유지하고 실제 합성 배경 대비를 검사한다. HUG의 space-between 최소 간격은 실측 고정 너비로 보존하며 양 끝·패딩·순서·간격을 대조한다. 기존 packet 구조는 유지한다.

## 설계 이유와 출처
근거: 전체 커밋 `0b2ad20d935fbf2d7e4d5406c806a1e12697c6a5`; `direction_review.js`, `design_quality.py`, `figma_draft.py`, transparency tests. 구성 값과 실제 native 표시 계약을 같은 방향으로 둔다.

## 호환성·이관·복구
기존 packet 형식은 유지한다. 이미 생성된 문서는 자동으로 변환되지 않으며 다시 생성하면 새 스타일이 사용된다.

## 검증과 미검증
투명도 검증 코드가 추가됐으나 실행 기록과 실제 Figma 표시 검증은 미검증이다.

## 한계와 후속 개선
투명도·geometry 검사가 전체 시각 품질이나 사용자 선택을 보증하지 않는다.
