# 브라우저 테마를 적용한 뒤 CSS 측정

소스 커밋 `503a532696a7c9f912824d80c3157ee11eaefcd0`

## 문제와 계기

GitHub Chromium에서 어두운 테마 전환을 요청한 직후 읽으면 직전 밝은 테마 스타일이 관측됐다.

## 결과 동작

브라우저가 해당 색상 모드를 알리고 렌더 프레임을 처리한 뒤 같은 CSS 속성을 읽는다.

## 변경 파일과 인터페이스

`tests/helpers/relay_palette.mjs`의 밝은 모드와 어두운 모드의 측정 준비를 갱신했다.

## 설계 이유와 출처

렌더링 준비 상태를 확인한 뒤 측정한다. 스타일 기대값과 결정 조건은 유지한다.

## 호환성·이관·복구

제품 UI나 플러그인의 테마 관련 입력을 변경하지 않았다.

## 검증과 미검증

동일한 Chromium 팔레트 테스트를 네 번 연속 실행해 모든 색과 두 폭의 치수·간격이 일치했다.

## 한계와 후속 개선

최종 패키지 소스는 새 전체 CI 결과로 확인한다.
