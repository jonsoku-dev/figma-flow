# test: keep stale retired and orphan dependencies read only

## 문제와 계기

개정 불일치, 은퇴 기록, 없는 대상이 읽기 전용 라벨로 고정되어 있지 않았다. 이 커밋 d93b801dad2cfd6fdb853cb8d8a01f01c26538ba의 검사는 dependencyFreshness가 없어 `stale retired and orphan dependencies must stay read only`로 실패한다.

## 결과 동작

tests/test_rd03_dependency_freshness.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 import-task는 stale, notes의 현재 edge는 current, draft의 없는 대상은 orphan, history의 은퇴 대상은 retired다. nearby relation은 라벨이 되지 않고 execution은 unchanged다. 입력 status는 finished로 남는다.

## 변경 파일과 인터페이스

tests/test_rd03_dependency_freshness.py를 추가했다. 패널 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd03_dependency_freshness로 실행한다.

## 설계 이유와 출처

RD-03 작업 5는 stale·retired·orphan 표시와 읽기 전용 동작이다. 조회가 자동 실행이 되면 안 된다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 기존 dependencyView 문장과 task revision은 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `stale retired and orphan dependencies must stay read only`다. Figma 패널은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 catalogue와 은퇴 목록이다. 구현은 별도 커밋 1c813e3b05c271f043b1360247864ebd216102ae에서 검사 blob을 유지한 채 라벨을 추가한다.
