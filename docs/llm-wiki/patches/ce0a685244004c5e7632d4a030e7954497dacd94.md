# 네이티브 런타임 전에 시작 옵션 해석

## 문제와 계기

부분 설치의 진단 CLI가 도움말을 처리하기 전에 네이티브 런타임을 불러오고 실패했다.

## 결과 동작

`ce0a685244004c5e7632d4a030e7954497dacd94`에서 직접 CLI 실행 시 옵션 해석을 먼저 한다. 정상 진단 경로에서는 설치 식별자와 런타임을 계속 검사한다.

## 변경 파일과 인터페이스

`tools/plugin_startup.py`가 도움말과 운영 진입점을 제공하고 `tests/finalize_runtime_contract_matrix.py`가 패키지 복사본의 실제 필수 소스를 사용한다.

## 설계 이유와 출처

도움말을 조회할 수 없어 진단하기 어려운 문제를 CLI 진입 지점에서 해결한다.

## 호환성·이관·복구

기존 check, ensure, native 요청의 인수 및 설치 보호 조건은 유지했다.

## 검증과 미검증

독립 도움말 재현, 패키지 바이트 보존, 정상 업데이트 보호 및 이전 런타임 주장 거절을 확인했다.

## 한계와 후속 개선

도움말 검사 자체는 실제 Figma 접속을 검증하지 않는다.
