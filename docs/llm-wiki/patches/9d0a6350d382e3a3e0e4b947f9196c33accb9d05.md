# MySQL 실측을 배포 소유권 검사에 연결

소스 커밋 `9d0a6350d382e3a3e0e4b947f9196c33accb9d05`

## 문제와 계기

예제의 이전 PostgreSQL 검토는 새 MySQL 구현의 패키지 근거가 될 수 없었다.

## 결과 동작

예제의 파일, DB 설정과 현재 재실행 가능한 테스트를 같은 배포 검토에 묶었다.

## 변경 파일과 인터페이스

`release/reviews/application.json`과 `release/reviews/evidence/mysql-existing/application-1.json`을 갱신했다.

## 설계 이유와 출처

기록은 후보 Git 아카이브에서 실제 테스트를 재실행하고 통과한 결과를 사용한다.

## 호환성·이관·복구

정본 그래프의 연결과 과거 화면 근거는 각 소스에 연계된다.

## 검증과 미검증

앱 검토를 임시 Git 아카이브에서 재실행해 통과했다. 실행 소유 스키마와 계정이 남지 않았고 기존 DB 설정을 다시 읽어 동일함을 확인했다.

## 한계와 후속 개선

ZIP의 전체 인수는 각 배포 영역과 해당 후보 Git 해시를 다시 대조한다.
