# feat(examples): govern disclosure and rail behaviour with graph contracts

## 문제와 계기

`61b895d`의 fixture는 gate disclosure의 열림 상태와 evidence rail의 스크롤 위치를 그래프 밖 로컬 UI 상태로 두었다. 그래프가 화면·상태·동작의 정본이라는 계약과 어긋났다.

## 결과 동작

커밋 `13551acbd622510721c128bcfea14f5be1c78d6c`는 gate disclosure와 evidence rail의 규칙을 fixture 그래프의 `planned` 상태·동작 노드로 옮겼다. renderer는 화면 전이와 같은 `follow` 조회로 이 노드를 따른다. disclosure는 모든 gate가 닫힌 상태에서 시작하고, 열기·닫기·전환 동작은 활성화한 gate의 관계(`closed`, `open`, `other`)를 결과로 받는다. rail은 `initial_position` 카드에서 시작하고 이전·다음 동작이 `step`만큼 움직이며 양 끝에서 멈춘다(`bounds: clamp`). 페이지 메모리에는 현재 열린 gate와 rail 상태만 남는다. 동작 노드를 지우면 그 입력은 아무 일도 하지 않고, step이나 시작 위치를 바꾸면 동작이 바뀐다. UI, asset, 기존 동작은 그대로다.

## 변경 파일과 인터페이스

`examples/owned-production-workspace/graph.json`, `renderer.js`, `manifest.json`, `README.md`. 새 검사 `tests/test_owned_production_workspace_interactions.py`, `tests/test_owned_production_workspace_rail_memory.py`와 그 Node 드라이버 `tests/owned_production_workspace_interactions.mjs`, `tests/owned_production_workspace_rail_memory.mjs`.

## 설계 이유와 출처

[P2 1차 실행 계약](../../next-roadmap/p2-wave1-acceptance.md) A절의 그래프 단일 정본 조건이다. 별도 상태 엔진을 두지 않고 기존 화면 전이 조회를 재사용했다. 새 기능 범위는 더하지 않았다.

## 호환성·이관·복구

manifest digest와 그래프 digest가 바뀌었다. 기존 사용자 화면과 asset은 바뀌지 않는다. 이전 fixture 관측은 이 소스의 관측이 아니다.

## 검증과 미검증

`tests.test_owned_production_workspace_interactions`는 그래프 규칙이 disclosure와 rail을 움직이는지 확인한다. `tests.test_owned_production_workspace_rail_memory`는 rail 위치가 다시 그려도 유지되고 새 review에서 초기화되는지 확인한다. fixture 검사 25개가 통과한다. root는 실제 mobile 화면에서 rail을 다음 카드로 옮긴 뒤 gate를 열어도 rail의 스크롤 위치와 카드 순번이 유지됨을 확인했다. 이 소스의 최종 브라우저·native 인수는 [8a7ed88](8a7ed888276d3bdb885d437e3b019603fe02c5c3.md)에 있다.

## 한계와 후속 개선

그래프의 disclosure·rail 상태와 동작은 `planned` 계약이며 관측된 전이 그래프가 아니다. FAQ 전체 키보드 인수와 복합 렌더 fidelity는 후속 노드의 범위다.
