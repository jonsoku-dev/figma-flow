# fix: preserve source pin order, CSS clipping and radial placement in native imports

## 문제와 계기

Actual screen graphs exposed import mistakes in source order, clipping, and radial gradient placement. A native frame could differ from browser stacking or include hidden content beyond the source clip.

## 결과 동작

Native import now retains source pin ordering, enforces clipped geometry, and maps supported radial gradients to native radial fills. The capture result preserves ordering required to bind image layers at their observed position.

## 변경 파일과 인터페이스

Changes cover `tools/web_design.py`, `tools/web_design_capture.js`, `figma-bridge/web_design.js`, native edit input pins, and expanded Python test cases.

## 설계 이유와 출처

The correction follows observed page stacking and clipping, then maps only a supported radial-gradient form. Unsupported CSS masks, filters, shadows and external media remain explicit limits.

## 호환성·이관·복구

Graph file format and screen IDs remain stable; updated source pins identify changed captures. Existing user edits and pages are preserved by the owned-frame and rollback boundary.

## 검증과 미검증

The final Figma review verified four Codeforge native radial fills and shipping readbacks for all four pages. Focused web tests passed eight Python and four Node cases. The 0.30 release full local suite passed separately.

## 한계와 후속 개선

Visual comparison was performed on four final PNG previews; it is not a pixel-equality measurement. Three external Portfolio SVGs remain unimported. Devtool font family alias notices remain in receipts.
