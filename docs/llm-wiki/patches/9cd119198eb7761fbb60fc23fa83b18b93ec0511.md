# Merge verified SaaS FAQ disclosure graph and editable prototype

## 문제와 계기

두 독립 브랜치가 각각 작은손 소스 재생성과 SaaS FAQ 상태 전이를 구현했다. 양쪽 이력을 보존하면서 주 브랜치에 통합할 필요가 있었다.

## 결과 동작

G1이 보존된 main에서 관측된 아코디언 입력을 정본 그래프로 결합하고, 자체 플러그인이 상태 프레임과 클릭 영역으로 변환한다.

## 변경 파일과 인터페이스

첫 부모 대비 tools/web_disclosure_capture.mjs와 tools/native_edit.py, figma-bridge/web_design.js 및 호스트 메타데이터와 관련 검사가 포함됐다.

## 설계 이유와 출처

시작점에서 도달 가능한 관측 전이만 링크한다. 서로 단절된 두 순환을 제출하는 회귀 검사에서 이전 구현의 잘못된 승인을 재현했다.

## 호환성·이관·복구

재적용 전후 같은 세 Figma 프레임 ID를 확인했다. 기존 생성 그래프, Figma 원본과 사용자 편집 데이터를 삭제하지 않는다.

## 검증과 미검증

실제 SaaS에서 두 질문을 일곱 번 눌러 여섯 전이를 얻었다. 별도 브라우저 재측정의 입력 결과와 10장 PNG가 원 관측과 일치했다. Figma Present에서 같은 여섯 전이를 확인했고, 수정 컴파일러로 원 관측을 재생성한 그래프와 계획은 기존 바이트와 일치했다.

## 한계와 후속 개선

5개 질문의 모든 조합을 인수한 것은 아니다. 키보드, 여러 답변을 동시에 여는 아코디언, CSS 높이 보간은 범위 밖이다.
