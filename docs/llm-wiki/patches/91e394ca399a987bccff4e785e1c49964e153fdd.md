# fix: preserve legacy component identities during carousel workspace updates

## 문제와 계기

이미 생성된 Portfolio의 JSON 튜플 키를 이미지 키와 같은 정규식으로 검사해 기존 작업 재준비가 실패했다.

## 결과 동작

기존 component 키는 이전 문자열 계약을 유지하고, 새로운 공유 이미지 키에만 그 형식 제약을 적용한다.

## 변경 파일과 인터페이스

변경 경로는 `tests/test_web_design.py`, `tools/web_design.py`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

서로 다른 두 종류의 식별자에 동일한 이름 검사를 강제하면 기존 캡처가 거부된다.

## 호환성·이관·복구

포크는 이 커밋과 부모의 변경 경로를 대조해 적용할 수 있다. 캐러셀 CMS나 외부 계정 연결은 필요하지 않다. 원본 화면과 사설 영수증은 로컬에 보존한다.

## 검증과 미검증

보존된 Portfolio 입력을 준비하고, 92개 기존 작업의 전체 재생과 기존 generation 1,162개 보존을 확인했다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
