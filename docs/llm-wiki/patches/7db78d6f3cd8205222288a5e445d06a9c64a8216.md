# feat: model intersecting gradient masks, ordered CSS filters and canvas observations

## 문제와 계기

서로 다른 그라디언트를 결합한 마스크가 사라지고 CSS 필터 체인이 일부만 남을 수 있었다.

## 결과 동작

선형·래디얼 교차를 중첩한 네이티브 마스크로 만들고, 단색 면의 색 함수를 CSS 순서대로 계산한다.

## 변경 파일과 인터페이스

변경 파일은 `examples/web-design-css-effects/index.html`, `figma-bridge/web_design.js`, `tests/test_web_design.cjs`, `tests/test_web_design.py`, `tools/web_design.py`, `tools/web_design_capture.js`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

구성 효과를 전부 표현할 수 있을 때만 해당 체인을 승인한다. 캡처가 읽은 canvas 정보는 이후 자산 결합에서 사용한다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

공개 기준 함수 회귀를 통과했다. 실제 렌더 비교에서 발견한 기본 중심 생략과 원형 좌표계 보완은 bd20be5에서 이어졌다.

## 한계와 후속 개선

위 관측은 명시된 사용 장면에 해당한다. 다른 파일의 권한이나 실제 런타임 결과는 그 환경의 별도 영수증으로 확인한다.
