# 브라우저 팔레트 측정 시점의 패치 기록

소스 커밋 `ef21c1b47e63649a54d9b1aad2d1ae0409d8f1ac`

## 문제와 계기

원격 Chromium의 테마 적용 시점과 제품 CSS 기대값을 구분한 교정을 기록해야 했다.

## 결과 동작

기존 색과 레이아웃을 그대로 검사하는 렌더링 대기 조건을 확인할 수 있다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`과 팔레트 측정 패치 기록을 갱신했다.

## 설계 이유와 출처

같은 검사를 새 후보에서 재실행해 비동기 전환에 대한 회귀를 확인한다.

## 호환성·이관·복구

사용자가 보는 패널의 실제 테마나 그래프 값은 동일하다.

## 검증과 미검증

Wiki가 500개 소스 커밋을 검증했다. Chromium의 실제 색과 치수 검사는 변경 직후 로컬에서 네 번 통과했다.

## 한계와 후속 개선

원격 후보의 실제 게이트 결과는 이후 실행과 태그에 연결한다.
