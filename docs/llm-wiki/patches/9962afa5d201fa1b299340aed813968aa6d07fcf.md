# docs(wiki): record public origin provenance in patch catalog

## 문제와 계기

카탈로그의 원격 출처가 `[redacted-private-or-local-remote]`로 기록돼 공개 저장소 출처를 대조할 수 없었다.

## 결과 동작

커밋 `9962afa5d201fa1b299340aed813968aa6d07fcf`는 `docs/llm-wiki/catalog.json`의 원격 출처 두 곳을 공개 경로 `github.com/jonsoku-dev/figma-flow.git`로 바꿨다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`의 두 줄만 바꿨다.

## 설계 이유와 출처

[기록 계약](../README.md#배포와-개인정보)은 원격 주소의 자격 증명과 로컬 경로를 제거하고 host/저장소 경로를 보존한다. 공개 저장소 경로는 그 범위 안이다. 원격 관측은 출처 정보이며 소유권 인증이 아니다.

## 호환성·이관·복구

카탈로그 메타데이터만 바뀌었다. 이후 `sync`는 작업 clone의 로컬 Git 설정을 단일 공개 origin으로 맞춘 뒤 실행한다. 프로세스 환경 변수로 원격을 주입하면 기존 값에 더해져 비공개 표시가 함께 기록되므로 쓰지 않는다.

## 검증과 미검증

이 커밋 시점의 실행 출력은 보존돼 있지 않아 미검증이다. 후속 기록 커밋의 `verify --ref HEAD`가 카탈로그를 다시 대조한다.

## 한계와 후속 개선

원격 주소가 공개라는 사실을 도구가 인증하지 않는다.
