# docs: record the shared import label property

## 문제와 계기

일반 가져오기 문구 속성의 제품 커밋은 자신의 전체 SHA를 같은 커밋의 Wiki에 넣을 수 없다. 1f80e5d9896e85afb865919aad7dad3572be932e와 그 기준 7260d2995764d65d736aed031ddc63323ecf4e0c의 상세 기록이 필요했다.

## 결과 동작

cb19ac749989bafeda8ca5a75505ebe86abed802는 CHANGELOG 0.26.3에 문구 속성 변화를 적고, 세 커밋의 상세 페이지와 릴리스 대조를 발행한다. 플러그인 동작은 바꾸지 않는다.

## 변경 파일과 인터페이스

CHANGELOG.md, docs/llm-wiki/catalog.json, docs/llm-wiki/releases.md와 패치 페이지 1f80e5d, 3a3d68e, 7260d29다. 런타임과 검사 파일은 포함하지 않는다.

## 설계 이유와 출처

기록 커밋은 제품 커밋 뒤에 두고 docs/llm-wiki와 CHANGELOG만 담는다. 실제 Figma 속성 패널은 관찰하지 못했으므로 통과로 적지 않았다.

## 호환성·이관·복구

기존 패치 본문과 0.26.3 버전 문자열을 유지한다. 이 커밋은 태그나 설치를 만들지 않는다.

## 검증과 미검증

발행 전 `verify --ref HEAD`가 당시 카탈로그를 통과했다. 이 페이지는 그 발행 커밋의 파일 목록을 대조해 나중에 작성했다. 새로운 제품 관찰은 없다.

## 한계와 후속 개선

문구 속성 외 RD-01 단위는 이 발행의 범위가 아니다. 이후 너비 공유는 별도 커밋이다.
