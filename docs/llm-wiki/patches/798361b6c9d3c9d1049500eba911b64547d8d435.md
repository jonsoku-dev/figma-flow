# 호스팅된 글꼴 조판 의존성으로 품질 판정 일치

소스 커밋 `798361b6c9d3c9d1049500eba911b64547d8d435`

## 문제와 계기

GitHub 러너에서 기본 Pillow 측정 모드가 사용되어 예약 예제의 글자 넘침 165건이 보고됐다.

## 결과 동작

프리뷰와 품질 실행 전에 FriBiDi를 준비하고 실제 조판 엔진이 로드된 상태로 같은 품질 검사를 실행한다.

## 변경 파일과 인터페이스

`library/delivery/graph.json`의 글꼴 조판 패키지와 생성된 두 테스트 워크플로를 변경했다.

## 설계 이유와 출처

로컬에서 기본 모드를 강제하면 같은 165건과 처음 여섯 레이어 ID가 재현됐다. 측정 알고리즘과 승인 임계값을 유지하고 실행 환경을 바로잡았다.

## 호환성·이관·복구

피그마 패널의 글꼴·사용자 캔버스와 이미 보존된 디자인 입력을 수정하지 않았다.

## 검증과 미검증

조판이 활성화된 로컬에서는 품질 오류 0건이었다. 실제 GitHub에서 조판 모드 검사와 전체 게이트를 다시 실행한다.

## 한계와 후속 개선

공개 배포의 통과 여부는 새 러너 실행 결과를 사용한다.
