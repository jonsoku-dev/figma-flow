# test: pin a legacy catalogue apart from one declared dependency edge

## 문제와 계기

명시적 edge fixture와 edge 없는 legacy catalogue가 같은 로더로 고정되어 있지 않았다. 이 커밋 7bff2100bccf6db00203cc5351c8773026783d72의 검사는 load_task_dependency_fixtures가 없어 `prepared dependency fixtures must stay explicit`로 실패한다.

## 결과 동작

tests/test_rd03_task_fixtures.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 tests/fixtures/rd03/legacy-tasks.json에는 depends_on이 없고, tests/fixtures/rd03/declared-edges.json은 import-task에서 review의 code.js로 가는 uses-output edge 하나만 가진다. notes는 같은 project여도 edge가 없다.

## 변경 파일과 인터페이스

tests/test_rd03_task_fixtures.py, tests/fixtures/rd03/legacy-tasks.json, tests/fixtures/rd03/declared-edges.json을 추가했다. tools/figma_workspace.py는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd03_task_fixtures로 실행한다.

## 설계 이유와 출처

RD-03 작업 3은 선언한 edge와 edge 없는 legacy를 따로 고정한다. 같은 project는 dependency가 아니다.

## 호환성·이관·복구

이 커밋은 fixture와 검사를 고정할 뿐 기존 catalogue를 바꾸지 않는다. edge 없는 task는 필드를 추가하지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `prepared dependency fixtures must stay explicit`다. 작업 목록 UI는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 JSON fixture다. 구현은 별도 커밋 19b6e1a9d879272179c120cd9c0d303a3e765910에서 검사와 fixture blob을 유지한 채 로더를 추가한다. 화면의 edge 목록은 아직 없다.
