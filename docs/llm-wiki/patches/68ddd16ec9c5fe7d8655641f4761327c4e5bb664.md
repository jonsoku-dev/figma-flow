# 공용 MySQL의 트리거 설치 권한 명시

소스 커밋 `68ddd16ec9c5fe7d8655641f4761327c4e5bb664`

## 문제와 계기

일반 스키마 소유자와 다른 계정이 트리거를 설치하는 조건을 운영 안내에 구체적으로 남길 필요가 있었다.

## 결과 동작

MySQL의 DEFINER 지정 권한과 설치 후에 사용할 스키마 계정의 범위를 문서에서 확인할 수 있다.

## 변경 파일과 인터페이스

`apps/little-hands/README.md`의 초기 설치 절차를 갱신했다.

## 설계 이유와 출처

기존 서버의 전역 바이너리 로깅 제약을 읽고 설치 작업과 실행 계정의 권한을 구분한다.

## 호환성·이관·복구

스키마와 웹 권한에 필요한 기존 절차는 유지한다.

## 검증과 미검증

기존 MySQL에서 스키마 소유자를 실행 계정으로 가진 트리거 8개와 웹 계정의 실제 쓰기를 확인했다.

## 한계와 후속 개선

일반 웹 계정에는 이 설치 권한을 부여하지 않는다.
