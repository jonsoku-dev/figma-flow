# feat: run every generated bundle task kind

## 문제와 계기

기준 910e7aa74da7c142d7798dbba12e0920490b38cb는 bundle_task_kinds가 없어 `generated bundle must run every task kind`로 실패했다. 조립된 런타임의 다섯 kind와 오류, uncertainty가 한 검사에 없었다.

## 결과 동작

bundle_task_kinds는 discover, import, native-edit, review, sync를 반환한다. tests/test_rd07_bundle_kinds.py가 assemble_shared_runtime 결과를 tests/rd07_bundle_kinds.cjs에 넘긴다. discover, sync, review, native-edit, import의 읽기 또는 create가 값을 반환한다. 잘못된 discover readback은 expected native evidence로 거절되고 failed 이력이 남는다. 결과 POST가 실패하면 workspace-control-state의 outcome은 uncertain이고 finished는 아니다.

## 변경 파일과 인터페이스

tools/figma_workspace.py에 bundle_task_kinds를 추가했다. tests/test_rd07_bundle_kinds.py와 tests/rd07_bundle_kinds.cjs blob은 기준과 같다.

## 설계 이유와 출처

RD-07-AC-05는 생성된 bundle 실행 검사를 요구한다. 이 실행은 mock Plugin API와 mock fetch이며 제어 프로토콜을 바꾸지 않는다.

## 호환성·이관·복구

wire format, 허용 operation, task closure는 그대로다. 플러그인 버전은 0.26.3이다.

## 검증과 미검증

종료 게이트는 `python3 -B -m unittest tests.test_rd07_bundle_kinds`를 기준 910e7aa74da7c142d7798dbba12e0920490b38cb에서 종료 코드 1, 대상 c4f8338c4803f88807fab96f58607d8e9f2652df에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 assertion은 `generated bundle must run every task kind`다. 조건은 RD-07-AC-05다. 실제 Figma 플러그인 재로드와 네이티브 쓰기는 하지 않았다.

## 한계와 후속 개선

mock 실행은 라이브 플러그인 재로드를 대신하지 않는다. 공개 심볼을 더 좁히는 정리는 다음 단위다.
