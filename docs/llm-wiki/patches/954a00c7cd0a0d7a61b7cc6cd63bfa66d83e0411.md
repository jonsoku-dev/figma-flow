# test: measure full and summary native reads on one fixture

## 문제와 계기

같은 fixture의 full과 summary를 getter 이름과 UTF-8 JSON 크기로 대조하는 기록이 없었다. 이 커밋 954a00c7cd0a0d7a61b7cc6cd63bfa66d83e0411의 검사는 compareNativeReadProfiles가 없어 `native read comparison must report measured bytes`로 실패한다.

## 결과 동작

tests/rd06_read_comparison.cjs는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 요청한 width가 같고, summary getter에는 rect.width가 있고 rect.fills는 없으며 개수는 full보다 적다. 바이트는 각 결과의 UTF-8 JSON 길이와 같다. invalidation은 unmeasured이고 wallClockMs는 없다.

## 변경 파일과 인터페이스

tests/rd06_read_comparison.cjs를 추가했다. docs/development-roadmap/RD-06-native-read/tasks.md에 실측 범위를 적었다. 제품 reader는 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-06 작업 5는 실측한 범위만 보고한다. 0.26.2의 반복 사진 크기를 재사용하지 않는다.

## 호환성·이관·복구

검사와 작업서만 추가한다. 기존 읽기 호출은 그대로다.

## 검증과 미검증

이 기준 트리에서 `node tests/rd06_read_comparison.cjs`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 지연은 측정하지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. 측정 함수는 구현 커밋에 있다.
