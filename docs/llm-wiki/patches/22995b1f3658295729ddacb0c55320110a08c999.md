# chore(api): rebuild recipe bundle and refresh coverage baseline for NF-01 native runtime

## 문제와 계기

`709f1104`·`8af6db43`로 NF-01 네이티브 런타임이 추가된 뒤 레시피 번들(`library/figma-recipes/`)과 정적 API coverage baseline이 최신 소스 해시와 어긋났다.

## 결과 동작

커밋 `22995b1f3658295729ddacb0c55320110a08c999`는 `library/figma-recipes/component-properties.helpers.js`와 `library/figma-recipes/bundled/design-component-properties.js`를 재빌드하고, `library/figma-recipes/bundle.json`의 `helpersSha256`·`productionSourceSha256`·`jsSha256` 및 `validateDeclaredComponentProperties`, `markImportedInstanceSlots`, `bindDeclaredComponentProperties`, `applyDeclaredInstanceProperties` 함수 해시를 갱신했다. `library/figma-api/coverage-baseline.json`은 `no-static-reference` `670→664`, `unresolved-receiver-name-reference` `642→648`(`qualified-static-reference` `70` 유지, 합계 `1,382`)로 바뀌었다.

## 변경 파일과 인터페이스

`library/figma-api/coverage-baseline.json`, `library/figma-recipes/bundle.json`, `library/figma-recipes/bundled/design-component-properties.js`, `library/figma-recipes/component-properties.helpers.js`를 갱신했다.

## 설계 이유와 출처

레시피 번들은 `figma-bridge/code.js`의 선언형 속성 함수를 추출한 산출물이므로 원본과 해시가 일치해야 `workspace_recipes.py verify-helpers`가 통과한다. coverage는 정적 AST 출현만 기록하고 `implementation`·`runtime_acceptance`는 `unverified`로 유지한다.

## 호환성·이관·복구

생성 산출물 동기화이며 `build.py` 재실행으로 재생성할 수 있다. `974b5de7` 수리 후 `a7378b82`에서 다시 동기화됐다.

## 검증과 미검증

최종 `e6f4fd8` 기준 레시피 재빌드 후 `git diff --exit-code -- library/figma-recipes`, `verify-helpers`, `test-rollback.cjs`, API inventory/coverage/audit(`1,382`건) 검사가 통과했다. coverage 수치 변화는 런타임 지원 증거가 아니다.

## 한계와 후속 개선
