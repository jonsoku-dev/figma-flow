# 공개한 1.0.0 태그와 아카이브 검증 기록

## 문제와 계기

검증한 Git 커밋과 공개 ZIP의 관계를 제품 기록에 추가해야 했다.

## 결과 동작

1.0.0 릴리스 항목에서 태그, 아카이브 지문과 검사로 이동할 수 있다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`과 `docs/llm-wiki/releases.md`를 갱신했다.

## 설계 이유와 출처

검증한 Git 트리의 파일 바이트를 릴리스 ZIP에 연결한다.

## 호환성·이관·복구

기존 0.x 릴리스과 태그 기록을 보존한다.

## 검증과 미검증

태그 배포 검사가 통과했다. 공개 ZIP과 체크섬을 다시 다운로드하고 SHA-256을 대조했다.

## 한계와 후속 개선

페이지별 변경 감지와 정본 반영은 별도 런타임 검증으로 확인한다.
