# test(components): add regression tests for duplicate display names, auto-rename keys, and top-level rollback

## 문제와 계기

실기 첫 적용에서 중복 표시명(`Cell`) 속성이 Figma 고유 키로 남지 않아 실패·롤백됐다. 수정 전에 실패를 재현하는 고정 회귀 검사가 필요했다.

## 결과 동작

커밋 `578ffc3c51ae6e9664f03c6f71ae3d1c18a922ec`는 `tests/test_property_repair_regression.cjs`(859줄)를 추가했다. 실제 Figma 모드별로 `semantic_components.js`와 `code.js`가 중복 `Cell` 표시명을 처리하고 오버라이드를 보존하는지, fallback 문법과 같은 이름의 고유 속성 보존, 보호된 자손 삭제 거부 시 최상위 생성 노드만 롤백(기존 `COMPONENT` radius16 보존), 반복 적용 롤백, 비보존 시 안전한 진단(`nativeName`, `actualKey`, `status`, `defCount`)을 검사한다.

## 변경 파일과 인터페이스

`tests/test_property_repair_regression.cjs`(신규)만 추가했다. 이 파일의 blob은 `70d47f890d8865a8bce9d2713d91533a990e00f0`이며 수정 커밋 `974b5de7`에서도 바뀌지 않는다.

## 설계 이유와 출처

패치 기록 계약의 실패 기반 개선 절차에 따라 검사를 먼저 커밋하고, 같은 검사로 수정 전 실패와 수정 후 통과를 비교하도록 했다.

**공개 재현 대응.** 비공개 개선 gate(`437aa0485e85dd2e2dcef621f570847317759b63` → `3e3f4e42b884cb64cc32c9d9f5d9173ec8bbb550`, `NODE-REPAIR-RC` 12/12 + Python adapter를 거친 `PY-REPAIR-RC` 1/1)의 base/target ref는 비공개 작업 이력에만 있어 공개 clone에서 바로 checkout할 수 없다. 공개 재현은 대응 공개 커밋 `578ffc3c51ae6e9664f03c6f71ae3d1c18a922ec` → `974b5de74bc99d645926afd5595f21f155356203`으로 한다. `figma-bridge/code.js`(`11aee85cbcc03ad58bbf6c6ba34066d9ec9b5567` → `1d581e9a7c26f96102a8b8d5c830924605b9ed8e`), `figma-bridge/semantic_components.js`(`d3aaedc0c90895abf9df2c6081a25ee75f37b311` → `0e6309f7d034d547d90555479e9354fbe336dcfe`), `tests/test_property_repair_regression.cjs`(base·target 모두 고정 blob `70d47f890d8865a8bce9d2713d91533a990e00f0`)가 각각 비공개 base/target 파일과 byte 동일함을 root가 검증했으며, 파일별 전체 blob 대응표는 저장소 밖 비공개 증거(`repair-public-equivalence.json`)에 보존한다. 공개 재현 명령은 각 공개 ref에서 `node --test tests/test_property_repair_regression.cjs`이다. 이는 공개 Node 회귀 재현이며, Python adapter를 포함한 비공개 gate 실행 자체와 구별한다. 이 기록 커밋에서는 공개 ref 위 Node 재실행을 따로 수행하지 않았고, 근거는 byte 동일성 검증과 비공개 gate 결과다.

## 호환성·이관·복구

테스트 전용 커밋이다. 이 커밋 시점 제품 코드에서는 검사가 실패하는 것이 의도된 기준선이다.

## 검증과 미검증

비공개 gate는 base 실패 → target 통과(`NODE-REPAIR-RC` 12/12, `PY-REPAIR-RC` 1/1)를 확인했다. 최종 `e6f4fd8` P1 Node 집중 suite와 CI Run `43599181267`에서 이 파일이 통과했다. 공개 ref 위 base 실패 재실행은 이 기록에서 별도로 수행하지 않았다.
