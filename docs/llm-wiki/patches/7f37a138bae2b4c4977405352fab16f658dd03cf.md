# feat: export scoped offline handoffs with native and browser provenance

## 문제와 계기

오프라인 인계에서 그래프 버전·네이티브 getter·웹 증거를 연결하고 허용한 컴포넌트 범위만 전달할 방법이 필요했다.

## 결과 동작

선택한 실제 컴포넌트 또는 명세를 독립 HTML과 JSON으로 내보낸다. 다른 graph·파일·page·부분 읽기·오래된 웹 모듈을 거절하고, 기획 결정과 관측 시점이 다르면 차이를 표시한다.

## 변경 파일과 인터페이스

`tools/native_handoff.py --component-key --offline-pack`가 graph_sync pairing, 최신 원본 getter, 실제 web module과 비교한다. 인수 확인용 fixture는 `tests/test_native_handoff.py`, 공개 타입 바이트 고정은 `.gitattributes`, 감사 보고서의 native 소스 해시 분리는 `tools/figma_workspace.py`에 있다.

## 설계 이유와 출처

Figma 문서의 모든 텍스트를 전달하면 허용한 범위를 넘는다. 컴포넌트 키와 실제 노드 ID로 범위를 제한하고 인계에 포함될 문구 확인을 명시한다. HTML은 동일 JSON을 포함하고 별도 서버 리소스에 의존하지 않는다.

## 호환성·이관·복구

기존 옵션은 예전 세 출력만 작성한다. 팩을 요청하면 새 디렉터리에 두 출력을 더 만들며 이전 버전의 인계 자료는 유지한다.

## 검증과 미검증

실제 작은손 CTA에서 그래프·웹 모듈·Figma page와 같은 소유 main·instance를 가진 팩을 작성했다. 요약 또는 출처 충돌로 통과하지 않도록 검사했다. 후속 검증에서는 HTML 내 JSON과 별도 JSON의 내용 일치, 외부 리소스 0개를 확인했다.

## 한계와 후속 개선

무료 계정의 컴포넌트 샘플 범위를 기록했다. 모든 제품 화면에 주석이 있다는 뜻은 아니다. 사용자가 실제로 편집한 파일 revision을 getter가 주지 않으면 미확인 상태로 표시한다.
