# bf04926 · 준비된 Figma 작업과 Codex 채팅 연결

이 기록은 원본 커밋 `bf049266356987b6abbf62533a5d3b0f9c549b8b`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

사용자는 Figma 작업 방향·검토·가져오기·그래프 동기화를 수행하지만 각각 진입 UI가 나뉘어 작업 자료와 Codex 대화를 함께 찾기 어렵다.

## 결과 동작

figma-bridge에 graph-panel.html, workspace_chat.html/js, workspace_home.html, workspace_host.js 및 panel.css를 추가하고 ui.html/code.js/direction_review.js/graph_token_sync.js를 연결했다. 설치·사용 문서와 화면 캡처를 갱신했다.

## 변경 파일과 인터페이스

workspace_chat.js는 현재 작업/채팅과 요청을 연결하고 workspace_host.js가 호스트 측 메시지를 처리한다. ui.html이 화면 탭을 통합하며 graph-panel.html에서 graph sync를 호출한다. 세부 요청은 workspace/chat endpoint 계약에 따른다.

## 설계 이유와 출처

기존의 독립 Figma 제작·검토/가져오기 경로를 한 작업 공간에서 찾게 하고 준비된 작업을 Codex 대화와 연결하려는 변경이다.

## 호환성·이관·복구

기존 plugin 명령이 새 UI를 거치도록 바뀔 수 있어, 호스트 메시지 스키마와 workspace 경로가 이전 버전과 호환되는지는 해당 bridge 코드 기준으로 확인해야 한다. 채팅 요청은 실행 결과 영수증이 필요하다.

## 검증과 미검증

대규모 UI/호스트 코드와 문서가 추가됐지만 커밋에 브라우저/Figma 실제 실행 기록은 없다. 이미지가 추가됐다는 사실만으로 각 흐름 검증을 주장할 수 없다.

## 한계와 후속 개선

Figma 플러그인 호스트와 Codex 대화 연결은 플랫폼별 실행·오류 회복 확인이 필요하다.
