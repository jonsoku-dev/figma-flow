# docs: record final graph release regression checks

## 문제와 계기

0.29.0에서 graph review, 실제 앱 입력, 편집기 결과, API 관측이 여러 patch와 실행 로그에 나뉘어 있었다. 완료한 변경과 아직 확인하지 못한 범위를 함께 찾아야 했다.

## 결과 동작

릴리스 기록에 Design·FigJam·Slides 결과, 네 개 웹 앱의 실제 브라우저 경로, API 조사 범위, 남은 한계를 연결했다. 관련 per-commit patch 페이지와 실제 graph를 링크했다.

## 변경 파일과 인터페이스

이 commit은 `docs/llm-wiki/releases.md`, `docs/llm-wiki/catalog.json`, 그리고 0.29 graph-workflow patch 기록을 갱신한다. 사용자 실행 경로나 제품 함수는 바꾸지 않는다.

## 설계 이유와 출처

기능은 정본 graph와 patch별 기록을 따라갈 수 있다. 숫자는 실제 편집기와 브라우저 receipt의 범위에 묶고 기록 코드와 UI 값을 같은 것으로 취급하지 않는다.

## 호환성·이관·복구

문서 전용 변경이다. 0.29 제품 태그와 설치본은 기존 기록을 따른다. 새 설치나 원격 실행을 요구하지 않는다.

## 검증과 미검증

릴리스 표는 four app browser flows, native graph projections, API coverage, and unverified scope를 각 항목으로 분리한다. 이 commit은 새 앱 검사를 실행하지 않았다.

## 한계와 후속 개선

기록한 검증은 각 연결된 과거 실행의 범위에 한정한다. 전체 제품 출시, 모든 prototype 경로, 미측정 API 멤버를 통과로 승격하지 않는다.
