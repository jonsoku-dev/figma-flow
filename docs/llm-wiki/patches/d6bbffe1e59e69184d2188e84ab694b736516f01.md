# 아카이브와 브라우저 검토의 새 실행 근거

소스 커밋 `d6bbffe1e59e69184d2188e84ab694b736516f01`

## 문제와 계기

Compose 클라이언트 설치와 브라우저 실행 방식이 바뀌어 관련 배포·도구 증거를 현재 파일에 연결해야 했다.

## 결과 동작

현재 정본과 아카이브에 묶인 명명 사례를 실행해 검토 기록을 갱신했다.

## 변경 파일과 인터페이스

`release/reviews/delivery.json`과 `release/reviews/tooling.json`의 입력 지문과 체크 시점이 바뀌었다.

## 설계 이유와 출처

이전 검사로 성공을 추정하지 않고 영향받은 두 범위를 실제 Git 아카이브에서 실행했다.

## 호환성·이관·복구

패널의 그래프·컴포넌트 관계와 예약 앱의 데이터 및 권한 정책은 같은 검사를 실행한다.

## 검증과 미검증

현재 배포·도구 검토가 통과했다. 실브라우저의 두 테마를 로컬에서 독립 프로필로 검증했다.

## 한계와 후속 개선

공식 공개 버전은 동일 후보의 GitHub 검사와 첨부 파일 검증을 통과한 뒤 발행한다.
