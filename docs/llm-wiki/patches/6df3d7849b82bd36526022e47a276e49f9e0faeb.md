# test: resolve the platform temporary root before asserting private output admission

## 문제와 계기

macOS 임시 경로가 심볼릭 링크여서 검사 자체의 임시 폴더가 private path 검증에서 거절됐다.

## 결과 동작

테스트가 운영체제의 실제 임시 경로를 해석한 후 프로젝트 출력을 준비한다.

## 변경 파일과 인터페이스

변경 파일은 `tests/test_design_service_inspection.py`이며 전체 목록은 이 페이지의 Git 메타데이터에 있다.

## 설계 이유와 출처

설치 코드의 심볼릭 링크·기존 파일 보존 경계를 유지한다. 테스트의 정상 입력만 교정한다.

## 호환성·이관·복구

원본 및 복구 자료를 유지한다. 이 변경 이후 현재 제품 동작과 이전 릴리스 근거는 각각 해당 소스 커밋에서 확인한다.

## 검증과 미검증

Design 서비스 생성기의 정상 파일·페이지 바인딩과 비정상 범위 거절 테스트를 재실행했다.
