# docs: link verified full-suite results to editable screen acceptance

## 문제와 계기

0.30.0 screen, native import, and API evidence had a verified graph, but the final stable-clone suite totals and feature index were not attached to that acceptance record.

## 결과 동작

The editable-web verification now records the full local suite results. The feature index points to the graph, and the graph points to the verification record.

## 변경 파일과 인터페이스

This docs-only commit updates `docs/editable-web-verification.md`, `specs/README.md`, and `specs/editable-web/graph.json`. It changes no runtime code or Figma data.

## 설계 이유와 출처

Place the suite result beside the acceptance it checks, while keeping browser observations, native apply/readback, and API evidence as separate nodes.

## 호환성·이관·복구

The evidence is a local stable-clone run. No release tag, remote CI, or public installation result is inferred.

## 검증과 미검증

The stable clone passed 1215 Python tests, 323 Node tests, 75 finalize tests, 18 design tests, and 2 demo tests, all with zero skips. The graph links these totals to the screen acceptance record.

## 한계와 후속 개선

These suite totals do not prove visual parity for every website, complete API support, or remote CI success.
