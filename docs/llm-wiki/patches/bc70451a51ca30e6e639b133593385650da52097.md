# docs: attach the native line-height reproduction to the acceptance graph

## 문제와 계기

줄 높이 재사용 결함이 해결된 뒤 새 실측과 기존 산출물 사이의 관계를 인수 그래프에서 추적할 필요가 있었다.

## 결과 동작

올바른 메인 선택, 실제 범위 스타일 읽기, 같은 입력 재실행을 하나의 기능 인수 기준과 실측 결과로 연결했다.

## 변경 파일과 인터페이스

`specs/editable-web/graph.json`과 `docs/editable-web-verification.md`에 실제 브라우저 및 자체 플러그인 결과를 추가했다.

## 설계 이유와 출처

로컬 실험을 추가하는 것만으로 전체 템플릿 측정 수량이 바뀌지 않도록 별도 테스트 노드에 등록했다.

## 호환성·이관·복구

변경 범위는 인수 기록이다. 기존 네 템플릿의 공개 수량과 개인 원본 경로의 보존 정책을 그대로 따른다.

## 검증과 미검증

정본 그래프 검증을 통과했고 1,215개 Python 및 326개 Node 검사, 별도 finalize 75개·디자인 18개·데모 2개의 성공 결과를 기록했다.

## 한계와 후속 개선

기존 프레임에 남은 이전 줄 높이의 자동 복구는 이 문서 커밋에서 관측한 항목에 포함되지 않는다. 신규 재현의 실제 측정값을 소스 확인에 사용한다.
