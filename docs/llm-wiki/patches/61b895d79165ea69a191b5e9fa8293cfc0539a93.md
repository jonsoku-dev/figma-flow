# feat(examples): add graph-owned production workspace with verified asset boundaries

## 문제와 계기

`p2-rights-cleared-fixture`는 이후 FAQ mobile·keyboard와 복합 렌더 fidelity가 공유할 production-like 공개 입력이 필요했다. 외부 템플릿이나 실제 사용자 자료를 쓰지 않아야 했다.

## 결과 동작

커밋 `61b895d79165ea69a191b5e9fa8293cfc0539a93`는 `examples/owned-production-workspace/`를 추가했다. manifest schema는 `figma-flow-owned-production-workspace-manifest-v1`이고 9개 파일(그래프, HTML, CSS, renderer, 자체 SVG 4개, README)을 경로·역할·layer·권리·보존·SHA-256과 함께 나열한다. `tools/owned_production_workspace.py verify`는 허용 목록, digest, 텍스트 정책, 그래프를 검사하고 비공개 receipt에 입력·출력 digest를 남긴다. `serve`는 verify가 통과한 manifest snapshot의 승인 파일만 loopback으로 제공한다.

## 변경 파일과 인터페이스

새 `examples/owned-production-workspace/**`, `tools/owned_production_workspace.py`, `tests/test_owned_production_workspace.py`, `tests/test_owned_production_workspace_boundaries.py`, `tests/test_owned_production_workspace_hostforms.py`.

## 설계 이유와 출처

[P2 1차 실행 계약](../../next-roadmap/p2-wave1-acceptance.md) A절. 사용 근거는 현재 사용자의 P2 진행 승인, 저장소 자체 저작, 저장소 MIT 라이선스다. 제3자 자산은 넣지 않았다. 이 기록은 법률 검토가 아니다.

## 호환성·이관·복구

새 예제와 도구다. 기존 예제와 캡처·컴파일러·플러그인은 바꾸지 않았다.

## 검증과 미검증

검사는 바뀐 bytes, 미선언 파일, bytes가 같은 symlink, manifest 경로 탈출, 외부·민감 텍스트, scheme-relative·escape된 외부 주소, stylesheet 네트워크 fetch를 거절한다. verify가 승인한 manifest snapshot만 제공하고, 그래프의 상태 도달·전이 단일성, renderer의 그래프 문구 비반복, 그래프 token만 쓰는 스타일, manifest 권리와 저장소 라이선스 일치를 확인한다. root는 이 소스에서 브라우저로 데스크톱 UI 흐름과 mobile smoke를 관측했고, 승인된 요청 8건이 200이며 console 오류가 0건이었다.
