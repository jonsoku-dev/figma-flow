# 실제 피그마 프레임과 화면이 공유하는 관측 검증

## 문제와 계기

기존 그래프의 상태·코드·관측 관계 일부가 일반 테스트 연결 표기와 충돌했다.

## 결과 동작

`13ebd029c7d197cb7a0c6fbfbcd6cac7063a527b`에서 화면·프레임·관측의 실제 역할을 구분하고 크기와 재적용 영수증을 함께 대조한다.

## 변경 파일과 인터페이스

`tools/spec_graph_coverage.py`, `specs/responsive-web/graph.json`, 탭 상태와 프로필·릴레이의 그래프를 갱신했다.

## 설계 이유와 출처

기존 ID와 원래 근거를 유지하고 구현 모듈만 있는 인수 조건을 테스트 성공으로 처리하지 않는다.

## 호환성·이관·복구

과거 관측의 범위를 확대하지 않았으며 후보에 있는 근거만 검증한다.

## 검증과 미검증

54개의 화면·프레임 쌍을 대조했고 다른 화면의 영수증, 해시 차이, 크기 차이, 사라진 연결을 독립 검사에서 거절했다. 관련 117건의 기존 타입 경고가 없어졌다.

## 한계와 후속 개선

화면 재생·원격 Figma 응답의 현재 상태는 추가적인 런타임 인수 근거가 필요하다.
