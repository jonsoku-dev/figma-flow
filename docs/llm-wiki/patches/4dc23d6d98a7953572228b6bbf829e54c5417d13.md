# feat: replay current control transitions without inventing native-started

## 문제와 계기

기준 dc8c23c4357aba18dc6a074b00107d52c8a1d7a9는 현재 제어 전이를 다시 실행하는 함수가 없어 `current operation transitions must be pinned before lifecycle changes`로 실패했다.

## 결과 동작

pinned_operation_transitions는 기존 enqueue, poll, result, status를 임시 workspace에서 다시 실행한다. 읽기는 pending, claimed, ok다. claim 전 timeout은 expired이고 claim 후 timeout은 uncertain이다. 읽기 timeout은 다음 명령을 막지 않는다. claim된 mutation timeout은 같은 쓰기를 막고, 다른 페이지 읽기는 uncertainty를 풀지 않는다. 같은 scope의 discovery 읽기만 풀며, 끝난 결과의 재전송은 거절한다. native-started는 어느 상태에도 없다.

## 변경 파일과 인터페이스

tools/figma_control.py에 pinned_operation_transitions를 추가했다. docs/development-roadmap/RD-08-operation-lifecycle/tasks.md에 고정한 전이를 적었다. tests/test_rd08_operation_transitions.py blob은 기준과 같다. 요청 스키마와 상태 파일 구성은 바꾸지 않았다.

## 설계 이유와 출처

RD-08은 기존 save, poll, result 경계에 사건을 더하고 새 queue를 만들지 않는다. native-started는 인증된 runtime의 명시적 event가 있어야 하며, timeout만으로 추정하지 않는다. 이 단위는 그 추정 전의 현재 동작을 기준점으로 남긴다.

## 호환성·이관·복구

기존 status, uncertainty marker, recovery_read 판정은 유지된다. 재실행 함수는 호출자가 준비한 workspace의 요청을 소비하므로 제품 서버 루프에는 연결하지 않았다.

## 검증과 미검증

종료 게이트가 기준 dc8c23c4357aba18dc6a074b00107d52c8a1d7a9의 종료 코드 1과 대상 4dc23d6d98a7953572228b6bbf829e54c5417d13의 종료 코드 0을 다시 실행했다. 같은 구현에서 기존 제어 검사 30개도 통과했다. 실제 Figma 읽기, 서버 재시작, 플러그인 재실행은 관찰하지 않았다.

## 한계와 후속 개선

서버 operation ID와 phase journal은 아직 없다. AC-01의 화면 표시는 통과로 기록하지 않는다. 합성 응답은 실제 plugin 결과와 같지 않다.
