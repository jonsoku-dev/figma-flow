# docs(roadmap): split P2 ownership into new and existing paths

## 문제와 계기

파일 소유 절은 나열한 경로가 모두 기준 커밋 `9962afa`에 없다고 적었다. baseline writer에게 배정된 기존 파일 변경과 모순됐다.

## 결과 동작

커밋 `2c7c2928119a080d84270a3a27c635fc5ded4c99`는 소유 표를 신규 경로와 기존 경로로 나눴다. 기존 경로는 `native_semantic_read.js`의 공유 `utf8JsonBytes`, `graph_sync.py`·`figma_workspace.py`의 최소 discovery 호출부, NF-02 부록이다. 실제로 통합된 검사 파일과, 공식 generator 출력인 coverage baseline을 기록했다.

## 변경 파일과 인터페이스

`docs/next-roadmap/p2-wave1-acceptance.md`.

## 설계 이유와 출처

`git cat-file`로 각 경로의 `9962afa` 존재 여부를 확인해 분류했다.

## 호환성·이관·복구

소유 표 문서만 바뀌었다. 각 writer가 이미 만든 커밋의 범위는 바뀌지 않는다.
