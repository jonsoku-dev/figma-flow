# test: pin partial native summary coverage

## 문제와 계기

요청한 node와 field만 읽는 summary profile과 partial coverage가 고정되어 있지 않았다. 이 커밋 e0f34c2d2db5673cc17a63bf8bb99489445c2492의 검사는 schema 문자열이 없어 `summary profile must name its partial coverage`로 실패한다.

## 결과 동작

tests/rd06_summary_coverage.cjs는 figma-flow-native-read-summary-v1이 없으면 위 문구로 끝난다. 함수가 있으면 coverage.complete는 false이고, rect.width는 같은 fixture의 full 값 12와 같다. fills 요청은 summary schema가 아닌 full snapshot으로 돌아간다. summary getter 목록에는 rect.width가 있고 rect.fills는 없으며 목록은 full보다 짧다. ImportPanel의 NativeSummary는 부분 읽기만 보여주고 send하지 않는다.

## 변경 파일과 인터페이스

tests/rd06_summary_coverage.cjs를 추가했다. docs/development-roadmap/RD-06-native-read/tasks.md에 native summary coverage 범위를 적었다. 제품 reader는 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-06 작업 2는 요약 projection과 coverage를 한 읽기 전용 UI에 연결하기 전에 실패를 고정한다. 기존 readNativeSemantics(figma, page) 서명은 유지한다.

## 호환성·이관·복구

검사 파일만 추가한다. 인자 없는 full 호출의 기대는 그대로다.

## 검증과 미검증

이 기준 트리에서 `node tests/rd06_summary_coverage.cjs`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 화면은 보지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. 요약 반환과 패널 연결은 구현 커밋에 있다.
