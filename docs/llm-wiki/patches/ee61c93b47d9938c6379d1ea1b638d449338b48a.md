# test: require one-step predecessor and successor text for the selected task

## 문제와 계기

선택한 작업의 명시적 선행·후속과 같은 내용의 텍스트 목록이 고정되어 있지 않았다. 이 커밋 ee61c93b47d9938c6379d1ea1b638d449338b48a의 검사는 dependencyView가 없어 `selected dependency view must list predecessors and successors`로 실패한다.

## 결과 동작

tests/test_rd03_dependency_view.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 import-task는 review 선행 하나와 notes 후속 하나만 보여주고, review의 후속은 import-task뿐이며 notes의 nearby relation과 같은 project는 선이 되지 않는다. alone은 `연결된 선행·후속이 없습니다`만 보여 준다. 조회는 입력 task를 바꾸지 않고 secret을 복사하지 않는다.

## 변경 파일과 인터페이스

tests/test_rd03_dependency_view.py를 추가했다. 패널과 catalogue 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd03_dependency_view로 실행한다.

## 설계 이유와 출처

RD-03 작업 4는 선택 node의 한 단계 선행·후속과 텍스트 대체 목록이다. 선은 uses-output edge에만 그린다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 기존 task 목록 payload와 revision은 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `selected dependency view must list predecessors and successors`다. 작업 목록 UI는 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 catalogue다. 구현은 별도 커밋 ef624aadc2e99029e227c62d57d7b6b56df21c5e에서 검사 blob을 유지한 채 보기와 번들을 추가한다. stale·retired·orphan 표시는 아직 없다.
