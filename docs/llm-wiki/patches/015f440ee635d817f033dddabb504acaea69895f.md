# test: pin the diagnostic audit export

## 문제와 계기

진단 기록을 한곳에 모아 비밀값을 가리는 내보내기가 고정되어 있지 않았다. 이 커밋 015f440ee635d817f033dddabb504acaea69895f의 검사는 buildAuditRecord가 없어 `audit export must keep the diagnostic record`로 실패한다.

## 결과 동작

tests/rd09_audit_log.cjs는 figma-bridge/audit_log.js에 buildAuditRecord, renderAuditExport, schema figma-flow-audit-log-v1이 없으면 위 문구로 끝난다. 함수가 있으면 토큰과 홈 경로를 가리고 노드 ID, 리비전, 오류, 작업 식별자는 남긴다. 소스에 postMessage, innerHTML, fetch(는 없다.

## 변경 파일과 인터페이스

tests/rd09_audit_log.cjs를 추가했다. docs/development-roadmap/RD-09-audit-log/feature.md, design.md, tasks.md와 docs/development-roadmap/README.md, docs/development-roadmap/CURSOR_HANDOFF.md에 범위를 적었다. 제품 내보내기는 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-09는 그래프 패널의 읽기 전용 진단 기록을 만들기 전에 실패를 고정한다. 내보내기는 문서, 네이티브 쓰기, 페어링을 바꾸지 않는다.

## 호환성·이관·복구

검사와 제안 문서만 추가한다. 플러그인 버전은 0.26.3이다.

## 검증과 미검증

이 커밋을 따로 연 깨끗한 트리에서 `node tests/rd09_audit_log.cjs`는 종료 코드 1이었다. 이후 개선 게이트가 같은 커밋을 기준으로 다시 실행했을 때도 종료 코드는 1이고 assertion은 `audit export must keep the diagnostic record`였다. 실제 Figma 패널은 보지 않았다.
