# nf01: compile canonical component families, properties, and readback checks

## 문제와 계기

Figma `COMPONENT_SET`/`COMPONENT`와 선언형 속성(`BOOLEAN`, `TEXT`, `INSTANCE_SWAP`), 변형 축, 읽기 대조(readback)를 일관되게 검증할 Python 측 정본 컴파일러 및 브리지 비교 계층이 없었다.

## 결과 동작

커밋 `ad26c908c5db034ef58d253e4c125df3e2afe469`는 `tools/design_system.py`에 패밀리 컴파일·유효성 검사를 구현하고, `tools/figma_bridge.py`에 정본 패밀리 표 `CANONICAL_COMPONENT_FAMILIES`(`field`, `input`, `checkbox`, `radio`, `table-row`, `table-cell`)와 `reject_secret_like_text`를 추가하며 `validate_component_properties`·`compare_declared_component_properties`를 확장했고 `tests/fixtures/nf01/six-families.json`·`invalid-cases.json` 픽스처를 고정했다.

## 변경 파일과 인터페이스

`tools/design_system.py`, `tools/figma_bridge.py`, `tests/test_component_families.py`, `tests/fixtures/nf01/six-families.json`, `tests/fixtures/nf01/invalid-cases.json`을 추가·수정했다.

## 설계 이유와 출처

[NF-01 설계서](../../next-roadmap/NF-01-component-families.md)의 선언적 패밀리·속성·읽기 대조 요구사항을 단일 결정론적 계약으로 고정해 플러그인 JS 런타임과 양방향 검증이 가능하도록 했다.

## 호환성·이관·복구

선언형 컴포넌트 섹션이 없는 기존 design JSON은 기존 경로를 그대로 탄다. 이후 `e6f4fd848a11cd292d9f8d9f50dad54ccb53ea10`에서 `compare_declared_component_properties`가 중복 표시명 충돌 회피/Figma 정규화 실제 키(`name#id`)를 허용하도록 보완됐다.

## 검증과 미검증

`tests/test_component_families.py` 등 NF-01 Python 단위 suite는 최종 `e6f4fd8`까지 `24/24 OK`로 통과했다. 커밋 당시에는 Python 정본 스키마·픽스처 검증까지만 수행했으며 실제 Figma Desktop 적용은 후속 런타임(`cfc7fbd1`, `709f1104`, `974b5de7`)에서 검증됐다.

## 한계와 후속 개선

초기 `compare_declared_component_properties`는 `display#suffix` 접두 개수 일치를 엄격 요구해 중복 표시명 충돌 안전 키를 거절하는 한계가 있었으며 `f88643bc`·`e6f4fd84`에서 해결됐다.
