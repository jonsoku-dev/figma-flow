# 임시 Git 아카이브의 패널 증거 실행 환경 보강

커밋 `15051541950b339c5f23dd246f4910e794a597c9`

## 문제와 계기

Node ESM 검토 사례가 npm 의존성이 없는 추출 트리에서 정상 설치본을 찾지 못했다. NODE_PATH만 설정하던 재현 환경에 빈틈이 있었다.

## 결과 동작

출시 실행기가 증거 실행 중에만 현재 패널 의존성을 후보 아카이브 내부로 연결한다. 실행 뒤 링크가 사라지고 파일 집합과 바이트가 일치해야 한다.

## 변경 파일과 인터페이스

tools/major_release.py의 audit_archived_tree 경로와 tests/test_release_archive_dependencies.py의 실제 ESM 증거를 추가했다.

## 설계 이유와 출처

실제 Figma 작업공간이나 소스 폴더를 수정하지 않고 아카이브 검증에서 같은 도구를 실행한다.

## 호환성·이관·복구

출시 명령과 기존 판정 조건을 유지한다. 후보에 이미 같은 이름의 의존성이 있거나 실행기가 임시 링크를 바꾸면 검토를 중단한다.

## 검증과 미검증

기존 도구로 아카이브에서 새 사례 다섯 개가 실패하는 것을 독립 확인했다. 명명 ESM 사례가 연결 없이 실패하고 실제 출시 어댑터를 통해 성공하는 것을 검증했다.

## 한계와 후속 개선

실행에 필요한 패널 의존성은 설치 환경에서 제공한다. 배포 산출물에는 임시 링크가 포함되지 않는다.
