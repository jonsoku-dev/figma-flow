# feat: label stale retired and orphan dependencies without executing them

## 문제와 계기

기준 d93b801dad2cfd6fdb853cb8d8a01f01c26538ba는 dependencyFreshness가 없어 `stale retired and orphan dependencies must stay read only`로 실패했다.

## 결과 동작

dependencyFreshness는 uses-output edge마다 라벨을 만든다. 대상의 현재 revision이 pin과 다르면 stale, 은퇴 목록에만 있으면 retired, 활성 catalogue와 은퇴 목록 어디에도 없으면 orphan, pin과 현재 revision이 같으면 current다. 반환 execution은 unchanged이고 read_only는 true다. nearby relation은 빠진다. DependencyText는 선택과 관련된 라벨을 오래됨·은퇴·대상 없음으로 보여 주고 그 목록에서 작업을 열지 않는다.

## 변경 파일과 인터페이스

panel-ui/src/dependencyView.mjs에 dependencyFreshness를 추가했다. panel-ui/src/Workspace.jsx와 panel-ui/src/styles/workspace.css가 workspace-dependency-state 목록을 그린다. figma-bridge/assets/panels.js와 figma-bridge/assets/panels.css는 그 생성 번들이다. docs/development-roadmap/RD-03-task-dependencies/tasks.md에 범위를 적었다. tests/test_rd03_dependency_freshness.py blob은 기준과 같다.

## 설계 이유와 출처

RD-03은 revision 변화를 stale로 보여주고 조회만으로 실행·승인 상태를 바꾸지 않는다. 은퇴 뒤에도 pin이 남으면 역사 edge를 읽는다. 없는 대상은 추정 task로 만들지 않는다.

## 호환성·이관·복구

dependencyView의 반환 필드는 그대로다. freshness는 입력을 복사하거나 수정하지 않는다. 은퇴 목록이 없으면 활성 catalogue만 본다.

## 검증과 미검증

종료 게이트는 `python3 -B -m unittest tests.test_rd03_dependency_freshness`를 기준 d93b801dad2cfd6fdb853cb8d8a01f01c26538ba에서 종료 코드 1, 대상 1c813e3b05c271f043b1360247864ebd216102ae에서 종료 코드 0으로 다시 실행했다. 기준 stderr의 마지막 assertion은 `stale retired and orphan dependencies must stay read only`다. 조건은 RD-03-AC-02다. 같은 구현에서 dependency view 검사와 workspace host 검사도 종료 코드 0이었다. Figma 패널의 은퇴 목록은 관찰하지 않았다.

## 한계와 후속 개선

은퇴 기록은 패널 메시지가 넘길 때 보인다. 선택 적용은 RD-04의 다음 단위다. AC의 화면 관찰은 통과로 기록하지 않는다.
