# test: keep the asset list apart from the files a browser actually loads

## 문제와 계기

목록의 present와 브라우저가 실제로 받은 파일이 따로 고정되어 있지 않았다. 이 커밋 a069898acd764f726494c713c2b742cb834fcd0b의 검사는 contrast_css_browser_loading이 없어 `css asset list and browser loading must stay separate`로 실패한다.

## 결과 동작

tests/test_rd05_browser_contrast.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 photos/mark.png, fonts/body.woff2, fonts/spare.woff2는 목록에서 present다. 브라우저 요청에는 사진과 사용된 글꼴만 있고 spare.woff2는 없다.

## 변경 파일과 인터페이스

tests/test_rd05_browser_contrast.py를 추가했다. 제품 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd05_browser_contrast로 실행한다.

## 설계 이유와 출처

RD-05 작업 5는 간접 CSS의 사진·서체를 목록과 브라우저 로딩으로 나눠 대조한다. present만으로 로드를 통과시키지 않는다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. 목록 필터와 html_channel의 상태 값은 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `css asset list and browser loading must stay separate`다. 함수가 없으므로 Chrome은 실행되지 않았다.

## 한계와 후속 개선

실패 기준은 임시 로컬 페이지다. 구현은 별도 커밋 56839c3af04e0be13fa306bc2f743a4d0bbde87d에서 검사 blob을 유지한 채 headless Chrome 대조를 추가한다.
