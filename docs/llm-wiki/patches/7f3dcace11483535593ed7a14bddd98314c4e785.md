# docs: connect the implemented import and remaining roadmap to reproducible graph commands

## 문제와 계기

The web import and API priority code had examples and roadmap text but the normal guide did not explain the path from capture graph to native import, and roadmap commands had drifted from the implemented workflow.

## 결과 동작

The guide now describes the supported web-design graph and native-edit plan entry point. Roadmap references distinguish implemented command paths from proposed follow-up work.

## 변경 파일과 인터페이스

This is a documentation-only change to `docs/web-design-capture.md`, `docs/api-priority.md`, and the web import roadmap page.

## 설계 이유와 출처

Use existing commands, actual graph identifiers and their pinned source files. Keep architecture proposals in the roadmap and leave unimplemented tasks marked proposed.

## 호환성·이관·복구

No runtime behavior or manifest changed. Existing help and import paths remain the source of truth for the guide.

## 검증과 미검증

Links and command lines were checked against the implemented CLI and associated docs. There is no new browser or native Figma receipt in this documentation commit.

## 한계와 후속 개선

A guide describes the available path; it does not establish installer publication, visual parity, or browser behavior for unsupported CSS and media.
