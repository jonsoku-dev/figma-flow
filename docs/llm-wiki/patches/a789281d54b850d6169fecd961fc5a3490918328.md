# ARM 러너 전환과 릴레이 상태 CSS 측정 안정화

소스 커밋 `a789281d54b850d6169fecd961fc5a3490918328`

## 문제와 계기

처음 공개 CI에서 브라우저·제어 테스트 두 건이 시간 초과됐고, 손인계 품질 검증과 릴레이 상태 색이 기준을 벗어났다.

## 결과 동작

아카이브와 전체 테스트를 동일한 네이티브 러너 설정에서 실행한다. 릴레이 팔레트 검사의 스타일 표본은 React 상태 재렌더링의 영향을 피한다.

## 변경 파일과 인터페이스

`library/delivery/graph.json`, `.github/workflows/test.yml`, `tests/helpers/relay_palette.mjs`를 수정했다.

## 설계 이유와 출처

두 워크플로에 같은 runner 값을 투영한다. 호스트 테스트 응답을 계속 보내며 오류 상태 스타일은 실제 제품 CSS가 적용되는 독립 표본에서 측정한다.

## 호환성·이관·복구

릴레이 제품 CSS와 색상 기대값은 보존했다. 검증에 사용하는 너비·실측 정책도 동일하다.

## 검증과 미검증

실패했던 영역을 포함한 17개 로컬 테스트가 통과했다. 새 GitHub 러너에서 전체 배포 기준을 재실행한다.

## 한계와 후속 개선

이번 수정은 테스트 환경과 검증 재현성을 다룬다.
