# 로드한 Design 페이지의 변경 구독과 응답 범위

소스 커밋 `e2c2ab6071bc7513d3b22b472b607b57054e6bcb`

## 문제와 계기

페이지 로딩 전에 등록이 성공해도 실제 콜백이 없을 수 있었고, 같은 페이지를 가리키는 객체가 바뀌면 이벤트가 누락됐다.

## 결과 동작

지정 페이지가 로드된 뒤 콜백을 등록하고 파일·페이지·세대·세션이 정확히 맞는 이벤트만 처리한다.

## 변경 파일과 인터페이스

`figma-bridge/workspace_changes.js`와 `figma-bridge/workspace_control.js`의 감시 및 인증 폴링을 갱신했다.

## 설계 이유와 출처

이동 전에 보낸 변경의 확인 응답은 요청에 사용한 버퍼로 전달한다. API 이벤트에서 노드 ID만 추출한다.

## 호환성·이관·복구

이벤트 범위·속성 예산을 유지하며 범위가 일시적으로 비어도 기존 미확인 이벤트를 보존한다.

## 검증과 미검증

런타임·호스트 관련 Node 검사와 저널·그래프 반영 경로의 Python 검사 50건이 통과했다.

## 한계와 후속 개선

현재 P1 직접 편집과 실제 그래프 반영은 Desktop 세션을 사용할 수 있을 때 확인한다.
