# 1.1.0 준비 이력

커밋 `0ab3b4d188928ae91b58baf6e2740321db1c1eca`

## 문제와 계기

1.1.0에서 추가된 멀티탭 제어, 패널 연결 진단, 메트릭 및 검사 변경을 한 버전에서 찾을 수 있도록 기존 main에 기록을 모았다.

## 결과 동작

버전 대조표와 검증 기록이 네 개의 소스 커밋에 연결된다. 이 커밋은 제품 실행 파일을 바꾸지 않았다.

## 변경 파일과 인터페이스

docs/llm-wiki/catalog.json, releases.md, verification.md와 patches/의 네 페이지가 바뀌었다.

## 설계 이유와 출처

git show --stat 및 각 부모 대비 diff로 당시 기록의 소유 범위를 확인했다.

## 호환성·이관·복구

이후 RC는 이 커밋에서 분기했다. 원래 main과 배포 버전을 보존했다.

## 검증과 미검증

이번 RC에서 기존 기록의 Git 객체와 변경 경로를 확인했다. 과거에 실행한 전체 검사를 다시 실행한 기록은 아니다.

## 한계와 후속 개선

태그 생성과 게시 여부는 별도 릴리스 작업에서 확인할 사항이다.

## 관련 기록

[1.1.0 버전 대조표](../releases.md#v1.1.0)와 [검증 이력](../verification.md)을 함께 본다.
