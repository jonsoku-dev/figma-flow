# test: require one runtime module list for publish and trust

## 문제와 계기

발행이 붙이는 공유 런타임과 trusted_sources가 확인하는 모듈 목록이 한 선언이 아니었다. 이 커밋 5fb446a3ea368317de9b56df62f93597a25a6251의 검사는 runtime_module_names가 없어 `publisher assembly and trusted sources must share one module list`로 실패한다.

## 결과 동작

tests/test_rd07_runtime_assembly.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 목록은 workspace_chat.js, workspace_transport.js, workspace_control.js, workspace_host.js다. assemble_shared_runtime은 그 순서로 잇고, trusted_sources와 publish가 그 선언을 쓴다.

## 변경 파일과 인터페이스

tests/test_rd07_runtime_assembly.py를 추가했다. docs/development-roadmap/RD-07-runtime-boundaries/tasks.md에 범위를 적었다. 제품 조립은 이 커밋에서 바꾸지 않는다.

## 설계 이유와 출처

RD-07 작업 3은 publisher 조립과 trusted_sources를 같은 변경에서 한 목록으로 옮긴다.

## 호환성·이관·복구

검사와 작업서만 추가한다. 해시 입력은 그대로다.

## 검증과 미검증

이 기준 트리에서 `python3 -B -m unittest tests.test_rd07_runtime_assembly`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 실제 Figma 플러그인 재로드는 하지 않았다.
