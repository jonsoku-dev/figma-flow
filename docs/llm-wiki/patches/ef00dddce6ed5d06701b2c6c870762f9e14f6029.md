# release: prepare Figma Flow 0.32.2 and pin vector source evidence

## 문제와 계기

새 SVG 처리 범위와 패키지 설치 예제를 0.32.1에서 구별해야 했다.

## 결과 동작

두 플러그인 manifest와 가이드에서 0.32.2를 명시하고 SDK 소스 위치 기준을 새 파일 해시와 일치시켰다.

## 변경 파일과 인터페이스

변경 파일: `.codex-plugin/plugin.json`, `README.md`, `docs/guide.md`, `library/figma-api/coverage-baseline.json`, `plugin.json`. 전체 경로는 이 커밋 메타데이터에서 확인한다.

## 설계 이유와 출처

커버리지 해시는 실제 API 관측을 대신하지 않는다. 소스 해시가 바뀐 항목만 갱신했다.

## 호환성·이관·복구

포크는 이 패치 이전의 Git 객체나 설치본을 유지한 채 해당 변경을 선택적으로 적용할 수 있다. 사용자 원본과 비공개 증거는 공유 산출물에서 제외한다.

## 검증과 미검증

원격 배포와 설치는 이 버전 문자열만으로 판정하지 않는다. Git 태그·원격 ZIP 재다운로드·설치본 읽기로 검증한다.

## 한계와 후속 개선

관찰한 입력과 환경의 결과다. 표본 이외의 파일이나 장치 및 웹 사용자 동작의 자동 복원을 보증하지 않는다.
