# chore(api): refresh static API coverage baseline for P2 read measurement

## 문제와 계기

`figma-bridge/native_read_measurement.js`가 추가되자 `tools/figma_api_inventory.py coverage --check-baseline`가 "Static API reference baseline differs"로 실패했다.

## 결과 동작

커밋 `954f1985531a0b73c80db76ecff393b73ca658eb`는 `library/figma-api/coverage-baseline.json`의 검토 대상 source 목록에 새 파일과 SHA-256을 추가했다. member 분류, count, declaration digest는 바뀌지 않았다.

## 변경 파일과 인터페이스

`library/figma-api/coverage-baseline.json` 4줄 추가.

## 설계 이유와 출처

생성물은 공식 generator(`coverage --write-baseline`, TypeScript 5.9.3 parser)로만 갱신한다. CI는 같은 버전으로 `--check-baseline`을 실행한다.

## 호환성·이관·복구

생성 메타데이터만 바뀌었다. 되돌리면 CI의 `coverage --check-baseline`이 다시 불일치로 실패한다.

## 검증과 미검증

갱신 전 `--check-baseline` 실패, `--write-baseline` 성공, 갱신 후 `--check-baseline` 통과. 추가한 digest는 파일 bytes와 같다.

## 한계와 후속 개선

이후 측정 파일과 reader가 바뀌어 [9669bc5](9669bc53007b544dc7ca49d6760e59786dd52f1a.md)이 digest를 다시 갱신했다.
