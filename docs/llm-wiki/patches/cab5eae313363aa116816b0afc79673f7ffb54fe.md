# MySQL 웹 계정의 기존 관리자 기능 보존

소스 커밋 `cab5eae313363aa116816b0afc79673f7ffb54fe`

## 문제와 계기

MySQL의 웹 계정 허용 목록을 만들면서 기존 Django 관리 흐름의 그룹 쓰기와 관리자 로그 테이블을 빠뜨릴 수 있었다.

## 결과 동작

기존 Django admin의 계정·그룹·권한 관리와 로그 쓰기 경로를 앱 계정에서도 사용할 수 있다.

## 변경 파일과 인터페이스

`apps/little-hands/config/deployment.json`의 역할별 테이블 목록과 생성된 `apps/little-hands/deploy/grants.sql`을 보완했다.

## 설계 이유와 출처

배포 설정이 실제 DB 권한의 정본이다. 감사·멱등 기록은 append-only에, 마이그레이션과 회차 보조 테이블은 스키마 계정에 둔다.

## 호환성·이관·복구

새 예제 스키마와 기존 앱의 권한 관리 동작을 대조한다. 외부 DB 사용자나 권한은 변경하지 않았다.

## 검증과 미검증

배포 계약 네 사례가 통과했다. 실제 MySQL에서 그룹을 추가하고 감사·스키마 쓰기를 거절하는 검사도 DB 인수에 연결했다.

## 한계와 후속 개선

실제 MySQL 계정 인수에는 사용 가능한 전용 검증 서버가 필요하다.
