# 명명된 Node 계약 실행의 자식 환경 재현

커밋 `d0a5c9fdbc21ccc6d4c20470cff79387427e50af`

## 문제와 계기

유지보수 단계·아카이브 증인·나머지 Node 스위트가 격리된 후에도 graph_governance.verify의 명명된 계약 검사는 부모 설정 루트를 상속했다.

## 결과 동작

ContractConfigTests가 실제 node:test 파일을 실행하고 그 자식의 XDG 경로와 권한을 읽어 성공·실패 및 정리를 확인한다.

## 변경 파일과 인터페이스

tests/test_graph_governance.py에 독립 테스트 클래스를 추가했다. 기존 PanelGovernanceTests의 집계 기준과 TAP 판정은 유지했다.

## 설계 이유와 출처

서로 다른 Node 실행 경로가 같은 그래프 검증기 안에 있어 test-other-suites만으로는 누락을 발견할 수 없었다.

## 호환성·이관·복구

검사 자료는 임시 테스트 파일로 한정한다. PC의 실제 레지스트리와 사용자 설치 상태를 테스트 입력으로 사용하지 않는다.

## 검증과 미검증

수정 전 명명된 케이스의 자식은 부모의 설정 경로를 반환했고 isolation assertion이 실패했다. 기존 세 경로의 성공 근거는 보존했다.

## 한계와 후속 개선

합성 TAP의 결과와 실제 Figma 패널 연결은 별도로 검수한다. 이 테스트는 Node 제품 전체의 성공을 의미하지 않는다.
