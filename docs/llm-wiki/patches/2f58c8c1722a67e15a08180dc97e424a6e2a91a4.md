# fix: route carousel actions from the file home and translate playback notices

## 문제와 계기

홈의 시작 프레임 선택과 Present 요청이 task 화면용 메시지로만 처리돼 클릭해도 반응하지 않았다. 이력에는 내부 상태값이 그대로 노출됐다.

## 결과 동작

홈과 작업 화면 각각의 이벤트 형태를 처리하며, 작업·리비전·실행·Figma 실제 시작점이 일치할 때만 선택 및 재생 동작을 허용한다.

## 변경 파일과 인터페이스

변경 경로는 `figma-bridge/assets/panels.js`, `figma-bridge/workspace_host.js`, `panel-ui/src/Workspace.jsx`, `panel-ui/src/WorkspaceActivity.jsx`, `tests/test_workspace_carousel_ui.cjs`, `tests/test_workspace_host.cjs`이다. 전체 경로와 diff 해시는 이 페이지의 Git 기록에 있다.

## 설계 이유와 출처

홈에서는 최상위 메시지를 보내므로 내부 payload를 기다리면 실행되지 않는다. 이력과 홈은 같은 번역 함수를 사용한다.

## 호환성·이관·복구

포크는 이 커밋과 부모의 변경 경로를 대조해 적용할 수 있다. 캐러셀 CMS나 외부 계정 연결은 필요하지 않다. 원본 화면과 사설 영수증은 로컬에 보존한다.

## 검증과 미검증

실제 플러그인의 홈에서 페이지 선택이 올바른 첫 프레임 ID로 바뀌었다. 단순 openExternal 호출 후 화면 전환이 확인되지 않은 건은 후속 재생 링크 검증으로 이어졌다.

## 한계와 후속 개선

여기서 확인한 결과는 해당 입력과 검증 범위에 해당한다. 브라우저의 연속 스크롤 관성이나 물리 모바일 기기의 동작은 별도의 관찰이 필요하다.
