# build: refresh the scoped typography recipe from the observed priority graph

## 문제와 계기

API evidence changed the priority inventory and graph projection, but the bundled scoped typography recipe still held the earlier graph, selection and compilation hashes. A release build diff could therefore disagree with the observed source evidence.

## 결과 동작

The checked-in `library/figma-recipes/bundle.json` now pins the regenerated graph projection SHA, graph SHA, selection SHA, priority inventory SHA and compiled SHA for the scoped typography recipe.

## 변경 파일과 인터페이스

This is a deterministic data rebuild of `library/figma-recipes/bundle.json`; the recipe source, graph template and external interface are unchanged.

## 설계 이유와 출처

Regeneration makes the packaged recipe trace back to the current reviewed priority graph instead of preserving stale generated hashes. No hand-edited hash is accepted as proof; the graph source and compiler output remain authoritative.

## 호환성·이관·복구

Existing recipe selection, source contract and plugin runtime remain the same. The bundled generated artifact is replaced in place by its new content-addressed projection and compiled hashes.

## 검증과 미검증

`library/figma-recipes/bundle.json` was rebuilt from the observed priority graph; the current recipe graph and compiled output are pinned by their new SHA values. This commit itself contains no Figma mutation or installation run.

## 한계와 후속 개선

This fixes the local build-diff drift. It does not assert that unrelated recipes changed or that the refreshed recipe was independently installed in Figma.
