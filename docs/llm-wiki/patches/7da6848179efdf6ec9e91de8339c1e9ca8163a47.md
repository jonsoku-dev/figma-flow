# test: pin the public screen-scoped import receipt contract

## 문제와 계기

여러 화면 그래프의 가져오기 경로가 공개되어도 `web-design` CLI에서 화면만 대상으로 한 읽기 범위를 제공한다는 계약이 회귀로 사라질 수 있었다.

## 결과 동작

새 회귀 검사는 `tools/native_edit.py web-design --help`에 `--readback-scope`가 노출되는지 확인한다. 이 커밋은 테스트만 추가하며 런타임 동작은 바꾸지 않는다.

## 변경 파일과 인터페이스

`tests/test_web_route_readback.py`의 `RouteReadbackTest.test_public_scope_option`은 실제 CLI 도움말을 `python -B` 하위 프로세스로 읽고 공개 옵션을 검사한다.

## 설계 이유와 출처

외부 호출자가 사용하는 CLI 경계를 고정한다. 구체적인 screen receipt 구조와 일치 검증은 뒤따르는 구현 커밋의 책임이다.

## 호환성·이관·복구

기존 계획과 파일은 변경하지 않는다. 읽기 범위 옵션이 사라지면 나중 구현 테스트까지 도달하기 전에 CLI 계약 테스트가 실패한다.

## 검증과 미검증

최신 고정 소스에서 `python3 -B -m unittest tests.test_web_route_readback` 1개가 통과했다. 이는 옵션의 존재만 검증하며 실제 Figma 읽기나 응답 내용을 증명하지 않는다.

## 한계와 후속 개선

테스트는 CLI 플래그 노출만 확인한다. 선택 화면만 읽는지, 정확한 graph hash와 screen ID를 확인하는지는 다음 두 구현 기록과 실측 근거에서 다룬다.
