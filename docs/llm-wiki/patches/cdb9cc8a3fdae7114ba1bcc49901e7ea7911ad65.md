# 초기 패널 Graph 마이그레이션 근거 기록

커밋 `cdb9cc8a3fdae7114ba1bcc49901e7ea7911ad65`

## 문제와 계기

패널 Graph를 처음 채택한 소스와 검증 범위를 버전·패치 기록에서 찾을 수 있도록 남길 필요가 있었다.

## 결과 동작

`CHANGELOG.md`의 미출시 항목과 검증 근거를 같은 소스 커밋에 연결했다. 이전 P1 Design 편집 기록도 당시 확인한 범위를 보존했다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`, `CHANGELOG.md`, 그리고 초기 구현과 P1 관측에 해당하는 두 패치 페이지를 갱신했다.

## 설계 이유와 출처

로컬 로직 검사와 원격 브랜치 보호 상태를 분리해 기록했다. 기존 실행의 Git 기준과 관련 테스트를 각 기록에서 확인할 수 있다.

## 호환성·이관·복구

기능 코드는 소스 커밋에서 추적한다. 이 기록은 문서와 카탈로그를 연결하며 기존 릴리스와 작업공간의 이력을 보존한다.

## 검증과 미검증

초기 구현 페이지에 로컬 집계 9단계와 별도 Chromium 검증 범위를 기록했다. 원격 실행과 병합 보호는 적용되지 않은 상태였다.

## 한계와 후속 개선

기록은 당시 실행의 범위만 설명한다. 새 Graph 또는 도구 설정을 검증할 때는 현재 소스와 기준 커밋을 사용해야 한다.
