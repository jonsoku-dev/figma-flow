# test: require declared containers to be normalized before authoring

## 문제와 계기

선언한 Frame·Auto Layout·Group을 쓰기 전에 cycle, 중복 부모, 없는 target, Group fill을 거절하는 경계가 없다.

## 결과 동작

tests/test_rd02_layer_normalize.py는 normalize_layer_containers가 없으면 `declared containers must be normalized before authoring`으로 실패한다. 함수가 있으면 평평한 fixture의 containers는 비어 있고, 선언한 트리는 card·copy·ornament-cluster·actions 순이다. 이 커밋에는 함수가 없다.

## 변경 파일과 인터페이스

새 파일은 tests/test_rd02_layer_normalize.py다. 부모는 7a1bb8345246b0c0aafd3c30ee9e21557366c4f2다. 런타임은 바꾸지 않는다.

## 설계 이유와 출처

종료 게이트는 검사 파일 blob이 구현 전후에 같아야 한다. 고정된 rd02 fixture를 입력으로 두고 네이티브 작성 전에 검증만 요구한다.

## 호환성·이관·복구

기존 방향 패킷과 화면 prototype은 이 커밋에서 바뀌지 않는다.

## 검증과 미검증

이 커밋의 unittest는 종료 코드 1이다. 실제 Figma 레이어 트리는 관찰하지 않았다.

## 한계와 후속 개선

구현은 108ecded7a1e99ee040a4c4b067a837a85d4d67c에서 검사 파일을 유지한 채 이어진다. 네이티브 부모 배치는 그 다음이다.
