# 1.0.0 앱 배포 검토 갱신

소스 커밋 `0f4761e270a554324fbb29831d232e8564ad6ad2`

## 문제와 계기

독립 검토 뒤 트리거 설치 권한과 운영 안내가 바뀌어 예제 리뷰의 지문을 갱신해야 했다.

## 결과 동작

실제 MySQL에 연결하는 예제 검증을 유지하면서 운영 안내와 배포 기록의 출처가 일치한다.

## 변경 파일과 인터페이스

`release/reviews/application.json`과 해당 앱 검증 영수증을 갱신했다.

## 설계 이유와 출처

명명된 테스트를 현재 Git 아카이브에서 실행한 뒤 배포 증거를 기록한다.

## 호환성·이관·복구

기존 스키마·서비스와 전역 MySQL 설정을 보존한다.

## 검증과 미검증

현재 1.0.0 매니페스트가 든 Git 아카이브에서 애플리케이션 검토를 통과했다. 실행이 만든 스키마·계정은 모두 정리했다.

## 한계와 후속 개선

검증은 기존 MySQL 8.4의 검증 스키마를 사용한다. 운영 트래픽과 공개 Figma 인수는 대상 환경의 별도 조건이다.
