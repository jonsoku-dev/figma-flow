# test: model the generated panel document faithfully

## 문제와 계기

새 selective-sync 하네스의 가짜 document에는 생성 panel script가 참조하는 documentElement.dataset이 없어 실제 선택 처리에 도달하기 전에 실패할 수 있었다.

## 결과 동작

VM document에 documentElement: {dataset: {}}를 추가하여 생성된 HTML panel의 문서 루트 접근을 모델링한다. 선택 검증이나 production 함수를 대체하지 않는다.

## 변경 파일과 인터페이스

당시 tests/finalize_selective_sync.cjs의 context 객체 한 줄만 수정했다. 파일은 후속 2cf4ce7에서 tests/helpers/finalize_selective_sync.cjs로 이동한다.

변경 경로: [tests/finalize_selective_sync.cjs](../../../tests/helpers/finalize_selective_sync.cjs).

## 설계 이유와 출처

환경 객체의 누락으로 발생한 TypeError와 제품 선택 프로토콜 결함을 구분하기 위한 최소 하네스 수정이다. 원래 config/checkbox/postMessage/handler 경로를 그대로 실행한다.

## 호환성·이관·복구

공개 API·product DOM·dependency에 변화가 없다. dataset의 빈 초기값만 제공하며 manifest·identity·CAS·rollback 기대는 낮추지 않는다.

## 검증과 미검증

Git diff에서 문서 루트 속성 추가만 확인했다. 이 변경 자체는 선택 동기화 성공이나 실제 브라우저 DOM 동작의 증거가 아니다.

## 한계와 후속 개선

간략한 Element/document 모형은 browser layout·접근성·반응형 표시를 보증하지 않는다. 실제 브라우저 관찰은 별도이며 이번 작업은 정적 검사만 했다.
