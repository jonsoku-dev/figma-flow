# docs: publish detailed 0.26.2 patch records

## 문제와 계기

0.26.2의 CSS 추적, 래스터 테이블, 중단 검토 보호와 근거 보존을 fork가 이어 가려면 실제 변경별 상세 설명이 필요했다. 제품 소스 기준 1cfe00b 뒤의 기록 발행 커밋이다. 원문은 첫 부모 1cfe00b16c17ebeaa4b4cc8bddbede6ecc64222d 대비 Git diff다.

## 결과 동작

canonical52개와 보존 계보39개의 총91개 상세 기록을 제공하고 0.26.2 변경·검증·한계를 버전 대조표와 연결했다. 이 커밋은 제품 실행 코드를 바꾸지 않는다. 실제 v0.26.2 태그가 이 발행 커밋을 가리킨다.

## 변경 파일과 인터페이스

`docs/llm-wiki/catalog.json`, `docs/llm-wiki/releases.md`와 `docs/llm-wiki/verification.md`, 새 패치 본문, releases와 verification 기록을 갱신했다. 기존 입력·native readback·설치 API와 검사 기준은 변경하지 않았다. 제품 기준과 기록 발행 접미사를 구분한다.

## 설계 이유와 출처

자기 Git SHA를 같은 커밋 내용에 넣을 수 없어 제품과 기록을 분리했다. 기존 패치 본문을 보존하고 새 CSS·이미지·부분 페이지·근거 변경의 설계와 이관을 원문에 연결했다. 근거는 이 커밋의 Git 파일 목록과 당시 카탈로그 source_commit이다.

## 호환성·이관·복구

Git clone에서 기록 도구로 원문을 대조한다. ZIP은 Git 객체 검증을 대신하지 않는다. 보존39개 원본 Git 객체를 갖지 않은 fork는 structural-only로 검사한다. 개인 witness·control 값과 설치 경로는 이 배포에 포함하지 않았다.

## 검증과 미검증

0.26.2 발행에서 Git 기록 검사, 제품 CI와 Wiki CI, ZIP SHA 대조와 실제0.26.2 설치가 별도로 확인됐다. 이 문서 커밋 자체의 제품 동작 검사는 당시 제품 소스 기준의 기록과 구분한다. 새로운 실행이나 전체61개 회귀 완료를 여기서 주장하지 않는다.

## 한계와 후속 개선
