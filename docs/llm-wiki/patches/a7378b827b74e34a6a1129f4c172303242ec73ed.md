# chore(api): sync recipe build helpers, bundle, and coverage baseline for NF-01 repair

## 문제와 계기

`974b5de7`이 `figma-bridge/code.js`에 새 helper를 추가하면서 레시피 추출 목록·번들·coverage 해시가 원본과 다시 어긋났다.

## 결과 동작

커밋 `a7378b827b74e34a6a1129f4c172303242ec73ed`는 `library/figma-recipes/build.py` 추출 목록에 `hasValidPropertyKey`, `resolveCollisionSafePropertyName`, `addDeclaredPropertySafely`를 추가하고, `library/figma-recipes/bundle.json`의 helper 목록·함수 해시와 `bindDeclaredComponentProperties` 해시, 레시피 산출물, `library/figma-api/coverage-baseline.json`의 대상 파일 해시를 갱신했다. coverage 집계는 `664/70/648`(합계 `1,382`)로 유지되고 모든 `unverified` 상태를 보존했다.

## 변경 파일과 인터페이스

`library/figma-recipes/build.py`, `library/figma-recipes/bundle.json`, `library/figma-recipes/bundled/design-component-properties.js`, `library/figma-recipes/component-properties.helpers.js`, `library/figma-api/coverage-baseline.json`을 갱신했다.

## 설계 이유와 출처

레시피 번들이 수리된 원본 함수와 동일해야 recipe 경로에서도 충돌 안전 키 처리가 일관된다.

## 호환성·이관·복구

생성 산출물 동기화이며 `build.py` 재실행으로 재현할 수 있다.

## 검증과 미검증

`e6f4fd8` 기준 TypeScript 5.9.3 레시피 재빌드 후 `git diff --exit-code -- library/figma-recipes`, `verify-helpers`, `test-rollback.cjs`, API inventory/coverage/audit 검사가 통과했다. `main` `a7378b82`에서 재컴파일한 같은 태스크 새 리비전의 실기 반복 적용·읽기가 staged 결과와 정확히 일치했다(`main_recompiled_repeat_exactly_matches = true`).

## 한계와 후속 개선

coverage는 정적 출현 기록일 뿐 런타임 지원 증거가 아니다.
