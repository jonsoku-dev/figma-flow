# Codex 보고서에 native-edit 대상의 이전 값과 변경 값 포함

## 문제와 계기

기존 편집 작업의 계획은 속성 목록, 사양 대상, 변수 편집 등 서로 다른 형태로 기록될 수 있었다.

## 결과 동작

`42d1c1893bc3325c029ff36dedbe399b04b69bbe`은 준비된 작업 보고서에서 기존 사양 대상과 변수 편집에 대해 기록된 이전 값과 변경 값을 읽도록 했다.

## 변경 파일과 인터페이스

`tools/workspace_report.py`의 native-edit 계획 자료 투영과 `tests/test_workspace_report.py`의 검증을 확장했다.

## 설계 이유와 출처

전체 적용 방식인 native-edit에 부분 적용이 가능하다고 표시하지 않으면서 계획에 저장된 변경 내용을 보여 준다.

## 호환성·이관·복구

서명한 작업과 의미 그래프의 데이터에는 쓰지 않는다.

## 검증과 미검증

실제 로컬 번들 해시 검증을 거친 보고서의 이전 값 12와 변경 값 20, 부분 적용 불가 표시를 검사했다.

## 한계와 후속 개선

계획에 기록된 값의 조회이며 실제 캔버스에 적용한 결과로 해석하지 않는다.
