# PluginAPI.pluginId의 정적 참조 투영 갱신

커밋 `97f1e29baba2695995705b8001115f774d31214a`

## 문제와 계기

기준 커밋에서 고정 컴파일러로 생성한 정적 참조 결과가 저장된 coverage-baseline.json과 달라 기존 릴리스 증인이 실패했다.

## 결과 동작

PluginAPI.pluginId#4의 정적 상태를 qualified-static-reference로 반영했다. 이 선언의 구현과 런타임 인수는 모두 unverified다.

## 변경 파일과 인터페이스

library/figma-api/coverage-baseline.json의 선언 한 행, 집계 두 값, 읽은 브리지 소스 네 개의 SHA-256을 갱신했다.

## 설계 이유와 출처

상위에서 TypeScript 5.9.3으로 생성한 패치를 사용했다. 같은 컴파일러로 기존 비교 검사를 실행해 전체 투영이 일치함을 확인했다.

## 호환성·이관·복구

플러그인 타입 및 실행 코드는 바뀌지 않는다. 기존 검사와 판정 기준도 그대로 유지했다.

## 검증과 미검증

패치를 적용하기 전 같은 증인이 실패했고 적용 후 통과했다. figma_api_audit.py verify는 1,382개 멤버와 보고서를 확인했다.

## 한계와 후속 개선

정적 참조는 해당 API의 실제 호출 성공을 증명하지 않는다. 이 변경으로 구현·실행 검증률을 올리지 않는다.
