# test: require the asset list to filter status and keep the relative source

## 문제와 계기

상태 필터와 상대 출처가 있는 자산 목록이 고정되어 있지 않았다. 이 커밋 325e122cb48aebe61663333db337e093bc6a1429의 검사는 assetInventory가 없어 `asset inventory must filter status and show the relative source`로 실패한다.

## 결과 동작

tests/test_rd05_asset_inventory.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 404와 external-unverified가 present보다 앞에 오고, 상태 필터 뒤에도 source는 index.html이다. 빈 목록은 empty이고 ready가 아니다. 공개 metadata는 /Users 행과 input_record를 빼는다.

## 변경 파일과 인터페이스

tests/test_rd05_asset_inventory.py를 추가했다. 패널 코드는 이 커밋에서 바꾸지 않았다. 검사는 python3 -B -m unittest tests.test_rd05_asset_inventory로 실행한다.

## 설계 이유와 출처

RD-05 작업 3은 자산 목록과 상태별 필터·상대 출처 표시다. 목록 열기는 네트워크 요청이 아니다.

## 호환성·이관·복구

이 커밋은 검사만 고정한다. input_summary가 없는 작업 payload는 바꾸지 않는다.

## 검증과 미검증

로컬 unittest는 종료 코드 1이고 stderr의 마지막 assertion은 `asset inventory must filter status and show the relative source`다. 브라우저 로딩은 관찰하지 않았다.

## 한계와 후속 개선

실패 기준은 합성 요약이다. 구현은 별도 커밋 306f26c7454a310f9f9b61f5ddb8b9f557d71318에서 검사 blob을 유지한 채 목록을 추가한다.
