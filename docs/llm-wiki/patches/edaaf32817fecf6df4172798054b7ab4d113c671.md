# 패널 Graph의 실제 소비와 검사 증거 보강

커밋 `edaaf32817fecf6df4172798054b7ab4d113c671`

## 문제와 계기

기존 설치 환경을 사용해 세 요청을 다시 대조했다. 기준 커밋의 관측 의존성과 실제 함수 호출은 영향 계산에 없었고, 사용 판정 경로나 지정 테스트 파일이 빠져도 일부 결과로 통과할 수 있었다. 개발 Knip의 제한된 분석에는 진입점이 없는 도구 파일이 드러나지 않았다.

## 결과 동작

전후의 실제 import·re-export·확인된 호출·외부 소비를 추적하고, Graph에 묶인 검증 작업까지 계산한다. 실행 위치와 import 바인딩이 있는 직접 호출을 필수 관계로 검증한다. 사용 기록은 관측 경로를 요구하며, 계약 테스트 이름은 지정 파일에서 확인한다. 생산과 개발 Knip은 분석 목적을 나누고 겹치는 진단은 한 번 표시한다.

## 변경 파일과 인터페이스

`tools/graph_governance.py`와 `tools/graph_impact.py`, `panel-ui/observed-graph.cjs`에서 관측과 영향을 대조한다. `tools/maintenance-contract.json`의 산출물 역할을 빌더와 `tools/panel_artifacts.py` 및 패널 호스트가 소비한다. `.github/workflows/test.yml`에 독립 `Panel Graph Governance` 잡을 생성한다.

## 설계 이유와 출처

현재 관측 인덱스를 기준판의 대용으로 추정하지 않고, 바뀐 입력이 있을 때 정해진 Git 기준의 패널 입력만 임시 위치에 꺼낸다. 선언과 관측 경로를 구분하고, 해당 리비전에서 확인한 경로만 Graph ID의 작업에 연결한다. 번들 이름은 정본 역할에서 파생되어 생성기와 실제 로더 사이에 별도 이름 목록이 생기지 않는다.

## 호환성·이관·복구

기존 번들 파일명과 실행 명령을 유지했다. 역할 계약, 소비자와 생성물을 같은 변경에서 복구할 수 있다. 외부에 게시하거나 설치된 플러그인과 작업공간을 다시 설정하지 않았다. 과거 관측은 현재 분석기와 기준판의 소스로 실행하며 기준 런타임 패키지 버전을 재현할 수 없으면 보고한다.

## 검증과 미검증

Node 26.13.0, Biome 2.6.8, Oxlint 1.94.0, Knip 6.48.0을 확인했다. 기준 `e8855f9227d3487fb427339323527060ea32be8d` 대비 집계 9단계, 관련 Python 77개와 Node 20개가 통과했다. 실제 Chromium과 산출물 이름 변경을 검증했다. import만 있는 경우, 누락된 사용 경로, 잘못된 파일의 테스트, 새 고아 도구, 고장 난 import 및 사라진 생성물은 차단했다. 독립 검수가 찾은 사용 경로 누락과 변경 CJS 필터를 보강한 뒤 집계와 회귀를 실행했다. 로컬 비교와 후보에서 배포 참고 자료 검출 3건이 동일했고, 원격 실행과 필수 상태 체크는 미적용이다.

## 한계와 후속 개선

정적 보장의 범위는 패널 JS·JSX와 확인한 외부 소비이다. 동적 함수 대상이나 외부 데이터 사용에는 별도의 근거가 필요하다. 원격에서 강제하려면 게시 권한 범위와 독립적으로 승인할 수 있는 코드 소유자가 필요하다. 전이 패키지를 고정하는 lockfile 정책은 별도 결정으로 남는다.
