# Codex에서 레이어 선택과 조회를 검증하는 기준 고정

## 문제와 계기

이전 패널의 보기를 Codex 명령으로 옮겼을 때 실제 대상과 읽기 값이 일치해야 했다.

## 결과 동작

`edf83777ae28b6cf771e895073d5d0b6f11bf3f6`에 서명된 discover 작업을 준비하고 발행된 JS 호스트를 실행하는 검사를 먼저 고정했다.

## 변경 파일과 인터페이스

`tests/test_codex_viewer_parity.py`가 테스트 Design 문서의 텍스트 선택, 크기, 본문 포함 여부, 다른 페이지 거절, 언어 저장을 검사한다.

## 설계 이유와 출처

입력 이름만 검사하지 않고 실제 선택된 노드와 clientStorage에 기록된 값을 대조한다.

## 호환성·이관·복구

공개 테스트 데이터로 실제 계정과 프로젝트 파일에 쓰지 않는다.

## 검증과 미검증

같은 Git blob을 개선 전후에 실행한 결과는 개선 대상 패치에 기록했다.

## 한계와 후속 개선

이 검사의 Figma 객체는 로컬 테스트 구현이다. 실제 Figma에서 관측한 결과는 별도 근거다.
