# 0173535 · Git 체크아웃에서 vendored 바이트 보존

이 기록은 원본 커밋 `01735351c2d82f1372442192b9bf14fa6f049a74`의 실제 diff와 파일 경로를 기준으로 작성했다.

## 문제와 계기

Git checkout의 기본 텍스트 정규화가 동봉 원문의 줄바꿈·바이트를 바꿀 수 있어 byte-identical snapshot 계약과 충돌할 수 있었다.

## 결과 동작

.gitattributes를 수정해 vendor 자료에 적용되는 체크아웃 변환을 조정한다. 변경은 속성 파일 3줄에 한정된다.

## 변경 파일과 인터페이스

vendor/skills/impeccable/**, vendor/skills/design-taste-frontend/**, vendor/skills/unslop/** 세 패턴에 -text -whitespace를 지정한다. 애플리케이션 함수나 API는 변경되지 않는다.

## 설계 이유와 출처

외부 스킬 스냅샷의 바이트와 공백을 checkout에서도 그대로 보존하는 것이 목적이다.

## 호환성·이관·복구

체크아웃 결과가 달라질 수 있으므로 이후 checkout에서만 효과가 나타난다. 기존 파일을 복구해야 할 경우 커밋 객체의 blob을 기준으로 다시 checkout해야 한다.

## 검증과 미검증

diff로 속성 설정 변경만 확인 가능하다. 다양한 OS 및 Git 설정에서 실제 바이트 보존을 재검증한 실행 기록은 없다.

## 한계와 후속 개선

패턴이 실제 vendor 파일 전체에 적용되는지와 줄바꿈 외 필터 동작은 추가 확인 대상이다.
