# 0.36.0 후보의 소스와 인수 기록

## 문제와 계기

버전 선언과 Design 프레젠테이션 문구를 바꾼 세 커밋이 릴리스 카탈로그에 연결되어야 했다.

## 결과 동작

기록 커밋 `159f3ae64bca897fe04734929bd406744b27932f`에서 0.36.0 후보의 변경 경로와 실제로 확인한 실행 범위를 한곳에서 따라갈 수 있게 했다.

## 변경 파일과 인터페이스

`CHANGELOG.md`, `docs/llm-wiki/catalog.json`, 세 개별 패치 페이지와 릴리스 색인을 갱신했다.

## 설계 이유와 출처

버전 선언을 올린 변경과 그 뒤 범위를 정정한 변경을 독립된 Git 패치로 설명했다.

## 호환성·이관·복구

기존 플러그인 설치·입력·출력 형식은 이 문서 발행의 영향을 받지 않는다.

## 검증과 미검증

원본 Git diff에서 여섯 파일의 변경을 확인했다. 당시 네이티브 실행 근거의 범위는 릴리스 기록에 보존돼 있다.

## 한계와 후속 개선

설치용 패키지의 게시 여부와 실기 인수는 소스 문서 변경 내역만으로 판단할 수 없다.

## 관련 기록

[후보의 릴리스 기록](../releases.md#v0.36.0)에서 개별 소스와 버전 근거를 확인할 수 있다.
