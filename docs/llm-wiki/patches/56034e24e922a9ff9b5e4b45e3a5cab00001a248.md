# test: pin the current runtime transport trace

## 문제와 계기

제어 전송 경로와 source pin 범위가 모듈 책임과 함께 고정되어 있지 않았다. 이 커밋 56034e24e922a9ff9b5e4b45e3a5cab00001a248의 검사는 load_runtime_boundary_trace가 없어 `runtime boundary trace must pin transport and source pins`로 실패한다.

## 결과 동작

tests/test_rd07_runtime_boundary.py는 함수가 없으면 위 문구로 끝난다. 함수가 있으면 schema figma-flow-runtime-boundary-v1이 poll, native-started, result와 POST Bearer, kind별 operation, tools·figma-bridge·library pin을 반환한다. workspace_control.js의 controlAllowed와 controlRequest 호출은 그대로다.

## 변경 파일과 인터페이스

tests/test_rd07_runtime_boundary.py를 추가했다. docs/development-roadmap/RD-07-runtime-boundaries/tasks.md에 모듈 책임 표를 적었다. 제품 전송은 이 커밋에서 옮기지 않는다.

## 설계 이유와 출처

RD-07 작업 1은 순수 전송을 옮기기 전에 현재 trace와 source pin을 고정한다. 도메인 검사는 workspace_control에 남긴다.

## 호환성·이관·복구

검사와 작업서만 추가한다. wire format은 그대로다.

## 검증과 미검증

이 기준 트리에서 `python3 -B -m unittest tests.test_rd07_runtime_boundary`는 종료 코드 1이다. 구현 후 통과는 별도 커밋의 게이트에서 다시 실행한다. 생성된 bundle과 실제 Figma 플러그인 재로드는 보지 않았다.

## 한계와 후속 개선

이 커밋은 실패 기준이다. fixture와 loader는 구현 커밋에 있다.
