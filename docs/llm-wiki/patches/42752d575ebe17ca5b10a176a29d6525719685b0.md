# fix: source booking instance labels from their actual template branches

## 문제와 계기

실제 G5 팩을 열기 전 텍스트를 대조하면서 회원과 비회원 CTA가 모두 임시 메인 레이블을 쓰는 것을 발견했다. 템플릿의 두 분기 문구가 달랐다.

## 결과 동작

원본 템플릿에서 읽은 문구와 해시를 계획에 고정한다. 기존 소유 프레임의 두 임시 문구만 새 값으로 이관하며 이미 수정된 사용자 override는 검토할 충돌로 남긴다.

## 변경 파일과 인터페이스

`tools/starter_cta.py`와 `tools/native_handoff.py`에서 같은 템플릿 판독기를 사용한다. `tools/native_edit.py`가 소스 해시를 확인하고 사적인 경로는 runtime에서 제거한다. `figma-bridge/native_provision.js`의 제한된 쓰기와 `tests/test_native_provision.cjs`를 추가했다.

## 설계 이유와 출처

기획 원문, 실제 템플릿 분기, 실제 Figma 렌더링 문구는 다른 관측이다. 소유 instance를 정확히 찾고 원래의 임시값을 비교한 후에만 텍스트를 쓴다.

## 호환성·이관·복구

이전 계획 형식을 계속 읽을 수 있다. 기존 세션 노드·컴포넌트·변수 ID를 유지하고 자체 작업 이후 사용자가 바꾼 텍스트를 덮어쓰지 않는다.

## 검증과 미검증

실제 Figma에서 두 레이블을 수정하고 동일 요청 재적용 결과 0을 확인했다. 전체 getter가 회원·비회원 분기 모두의 새 문구를 반환했다. 다시 작성한 인계 팩이 색·문구·현재 정책 버전에서 일치했다. Node 회귀 6건, 관련 Python 검사 통과.

## 한계와 후속 개선

배경색은 실제 브라우저에서 양방향으로 확인했다. 비회원 링크의 문구는 실제 브라우저와 getter로 확인했고 회원 제출 버튼은 템플릿 원본·Figma getter를 대조했다.
