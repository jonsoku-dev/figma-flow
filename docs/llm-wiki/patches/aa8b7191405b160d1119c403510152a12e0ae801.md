# fix: declare WOFF2 font prerequisites

## 문제와 계기

선택 의존성 목록에 `fonttools`는 있었지만 WOFF2 읽기·변환에 필요한 Brotli 제공 extra가 선언되지 않았다. 기존 clean Git archive 검사는 global Python 환경에 이미 설치된 Brotli를 가져다 써서 새 설치 환경의 의존성 누락을 드러내지 못했다. 원격 전체 검사 run `43339869559`에서 WOFF2 글꼴 변환이 Brotli 모듈 부재로 실패했다.

## 결과 동작

선택 의존성 항목을 `fonttools>=4,<5`에서 `fonttools[woff]>=4,<5`로 바꿔 WOFF 지원 extra와 그 의존성을 함께 설치하도록 한다. 사용자가 별도 설치 명령으로 Brotli를 알아내지 않아도 선언된 optional requirements를 설치한 환경에서 WOFF2 입력을 처리할 수 있게 한다.

## 변경 파일과 인터페이스

첫 부모 `6178905a1f182e5fcfe7b3fdf22fc57116544ea3` 대비 `requirements-optional.txt`의 의존성 한 줄과 `CHANGELOG.md` 한 줄만 수정됐다. 런타임 코드, 폰트 파일, 필수 의존성 목록은 바뀌지 않았다. 실제 diff는 `git show aa8b7191405b160d1119c403510152a12e0ae801`로 대조했다.

## 설계 이유와 출처

현재 코드의 WOFF2 변환 경로는 FontTools의 WOFF 지원 모듈을 사용하므로 선택 의존성 명세가 해당 기능의 설치 요건을 함께 밝혀야 한다. `fonttools[woff]`는 새 추상화나 별도 설치 단계를 추가하지 않고 기존 dependency 파일에서 누락된 선택 기능을 선언하는 최소 수정이다. clean archive에서 global site-packages가 새 환경을 가장하지 않도록 분리해 검사한다.

## 호환성·이관·복구

기본 설치 사용자는 여전히 optional requirements를 설치하지 않으면 글꼴 변환 기능을 사용할 수 없다. optional requirements를 설치하는 환경에서는 FontTools WOFF extra 의존성도 설치 대상이 된다. Python 코드나 기존 데이터 형식의 이관은 없고, 되돌릴 때는 해당 파일의 extra 표기만 복구하면 된다.

## 검증과 미검증

선행 실패 run `43339869559`는 실제 WOFF2 처리에서 Brotli가 빠졌음을 보였다. 기존 clean archive 검사는 global Python의 Brotli 설치 때문에 이 문제를 가렸다. 후속 확인은 clean archive와 시스템 site-packages를 차단한 새 가상환경에서 수행 중이다. 선언된 optional 의존성 설치와 React build 및 typed build는 통과했다. 실제 Hahmlet WOFF2 변환, design 16, Python 전체 검사, finalize 75, Node 299, demo 2의 현재 실행은 아직 완료 전이므로 성공으로 기록하지 않는다. 0.27.1 원격 CI·tag/ZIP/install/native 재읽기도 이 문서 발행 시점에는 별도 영수증이 필요하다.

## 한계와 후속 개선

이 변경은 FontTools WOFF 기능의 의존성 설치를 선언하며 임의의 손상된 폰트 파일이나 모든 글꼴 형식의 처리를 보장하지 않는다. 새 환경을 검증할 때는 global Python·시스템 site-packages가 선택 의존성을 우연히 채워주지 않도록 격리하고, 실제 WOFF2 입력으로 변환 경로를 확인한다.
