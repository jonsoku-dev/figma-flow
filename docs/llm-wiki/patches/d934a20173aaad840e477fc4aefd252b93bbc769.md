# feat: inspect typed native return paths and record 62 additional Design member observations

## 문제와 계기

기존 bounded property probe는 node scalar와 safe summaries를 읽었지만, Figma가 effect·transition·grid·variable 같은 typed data object에서 반환하는 discriminated values를 재현할 수 없었다.
## 결과 동작

새 Design 전용 value-path runner는 exact typed getters를 호출하고, 실제 반환 객체를 enum·number·color·geometry 요약으로 정규화한다. 같은 getter에서 여러 native sample을 읽으면 여러 sample을 보존한다. 사용자 텍스트·node ID·변수 ID와 원시 이미지 바이트는 영수증에서 제외한다.
## 변경 파일과 인터페이스

`library/figma-recipes/inspection/values.json`은 허용된 getter route, owner field와 union branch를 고정한다. `values.js`는 owned fixture node에서 이를 실행한다. `tools/native_value_paths.py`는 pinned audit/source와 service receipt를 검사하고 private plan·plugin을 준비하며, 결과를 exact API member edge graph로 정규화한다. 62개 native value field의 관측은 `specs/design-inspection/value-observations.json`에 있다.
## 설계 이유와 출처

각 getter는 pinned declaration에 연결된 static route로 접근한다. Union 결과는 discriminator allowlist만 남긴다. 재생성한 value graph를 기존 API priority inventory에 합칠 때 member ID로 중복을 제거하므로 같은 API key를 다시 세지 않는다.
## 호환성·이관·복구

실행 전 service receipt와 exclude receipt를 검사하고, 새 private output 경로를 사용한다. 실행은 plugin-data marker로 소유한 fixture node만 바꾼다. 입력 파일, 개발 플러그인 ID, Figma file/page ID는 private plan에 남고 공유 graph에서는 제거된다.
## 검증과 미검증

고정 route와 receipt 정규화는 `tests/test_native_value_paths.py`가, 실제 typed getter의 safe projection은 `tests/test_native_value_paths.cjs`가 검증한다. 결과에는 실제 repeated getter가 돌려준 값을 기록하며, 할당한 상수를 반환값으로 대체하지 않는다.
## 한계와 후속 개선

62개는 관측한 typed fields 수이지 62개의 새 unique API member라는 뜻은 아니다. 일부 member는 scene·service graph에 이미 있다. Unsupported union branch와 제공되지 않은 반환값은 success로 세지 않는다.
