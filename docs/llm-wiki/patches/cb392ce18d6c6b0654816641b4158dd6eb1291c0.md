# test: use synthetic design identifiers in distributable probe fixtures

## 문제와 계기

A probe test fixture used an actual Figma file locator in selection metadata. The test only needs receiver and node-shape examples, so a live file identifier exposed more data than its behavior required.

## 결과 동작

The API-priority receiver test now uses synthetic file, page, and node identifiers. It still checks exact `GROUP` and `FRAME` receiver candidates and vector field selection.

## 변경 파일과 인터페이스

The commit changes six fixture values in `tests/test_api_priority.py`. No runtime probe code, token, API response, or user Figma data was added.

## 설계 이유와 출처

The probe planner validates selection shape and receiver type; these unit cases do not call Figma. Synthetic values isolate the behavior under test from an actual user file.

## 호환성·이관·복구

The correction is a normal follow-up commit. It removes the locator from the current source tree and normal source archive without rewriting Git history.

## 검증과 미검증

The final stable-clone suite passed 1215 Python tests with zero skips. The test continues to cover the GROUP and FRAME candidate path using the synthetic selection.

## 한계와 후속 개선

An earlier intermediate Git commit still contains the locator in its historical blob. No API token was present. The current Wiki omits the locator and all raw response data.
