# test: reject disconnected disclosure cycles at public entrypoints

## 문제와 계기

이 커밋은 제품 코드를 바꾸지 않고 disclosure의 공개 진입점에서 끊어진 상태 순환을 거부하는 회귀 검사를 추가한다.

## 결과 동작

검사 그래프에는 초기 상태에서 도달할 수 없는 두 상태가 서로 전환하는 cycle이 있다. 모든 상태가 초기 상태에서 접근 가능한 것처럼 처리되는 버그를 겨냥한다.

## 변경 파일과 인터페이스

Python 검사와 Node의 `webApply` 검사는 같은 부정 사례를 각각 그래프 컴파일 및 Figma 적용 API 경계에서 제출한다. 관련 변경: `tests/test_web_design.cjs`, `tests/test_web_design.py`.

## 설계 이유와 출처

컴파일 경로는 실패 상태를 반환하고 출력 그래프 파일을 만들지 않아야 한다. 적용 경로는 명시 오류로 거부하고 캔버스에 부분 생성물을 남기지 않아야 한다.

## 호환성·이관·복구

이전 검증 로그에서 Python 공개 진입점은 끊어진 cycle을 종료 코드 0으로 받아들였고 테스트는 예상 종료 코드 1과 다르다고 실패했다.

## 검증과 미검증

이 커밋은 그 실패를 재현 가능한 기준으로 고정한다. 검사 코드를 추가한 것 자체는 구현 결함을 고친 결과가 아니다.

## 한계와 후속 개선

후속 수정은 간선의 목적지만 집합에 넣던 검증 대신 초기 상태에서 outgoing edge를 따라 실제 도달 가능한 상태를 계산해야 한다.
