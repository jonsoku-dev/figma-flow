# feat: capture rendered web screens as editable graph geometry

## 문제와 계기

웹 화면을 Figma로 옮길 때 screenshot만으로는 텍스트·기하·컨트롤을 편집 가능한 객체로 다시 만들 수 없었다. 브라우저가 현재 렌더링한 값에 근거한 bounded input이 필요했다.

## 결과 동작

`captureWebDesign`은 페이지 evaluation context에서 보이는 텍스트와 CSS, 요소 위치, 간단한 SVG와 같은 출처 이미지 요청을 versioned capture로 반환한다. 제한된 문서·viewport 범위와 layer budget을 받으며 숨은 input value·cookie·storage를 읽거나 요청을 만들지 않는다.

## 변경 파일과 인터페이스

`tools/web_design_capture.js`는 `captureWebDesign({screenId, extent, maxLayers})`를 export한다. `docs/web-design-capture.md`에는 Playwright `page.evaluate` 호출과 새 파일 저장 예제가 있다.

## 설계 이유와 출처

현재 페이지의 DOM과 computed style을 읽어 geometry·style·text record로 내보내면 정적 screenshot보다 편집 가능한 native plan을 만들 수 있다. 같은 페이지라도 다른 viewport·login state는 별도 screen ID로 기록한다.

## 호환성·이관·복구

새 utility module과 guide만 추가한다. Figma 파일과 기존 plugin command를 변경하지 않으며 캡처 JSON은 caller가 새 경로에 쓴다.

## 검증과 미검증

이 commit은 capture function과 사용 예제를 도입했다. 통합 0.30.0 관찰에서는 네 템플릿의 실제 browser capture를 만들고 후속 native-import 결과로 연결했다. 단위 및 final release 수치는 [editable-web verification](../../editable-web-verification.md)에 기록한다.

## 한계와 후속 개선

캡처는 화면에 보이는 content와 style의 bounded projection이다. unsupported media, complex SVG, CSS effect와 browser rendering 차이는 직접 변환된다고 보장하지 않는다.
