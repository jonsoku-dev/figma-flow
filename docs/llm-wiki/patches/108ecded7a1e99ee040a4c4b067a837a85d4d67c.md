# feat: validate declared layer containers before authoring

## 문제와 계기

기준 86e30fb66bb998158034c3c887782f131e269b0f는 선언한 컨테이너를 정규화하는 함수가 없어 `declared containers must be normalized before authoring`으로 실패했다.

## 결과 동작

normalize_layer_containers는 평평한 fixture의 빈 containers를 유지한다. 선언한 트리는 card Frame, copy와 actions Auto Layout, ornament Group 순으로 반환한다. cycle, 중복 부모, 없는 target, Group의 fill·layout·clip은 ValueError로 거절한다. 좌표로 그룹을 추정하지 않는다. 네이티브 노드는 만들지 않는다.

## 변경 파일과 인터페이스

tools/design_directions.py에 normalize_layer_containers를 추가했다. docs/development-roadmap/RD-02-layer-structure/tasks.md에 검증 범위를 적었다. tests/test_rd02_layer_normalize.py blob은 기준과 같다.

## 설계 이유와 출처

RD-02는 선언한 부모 하나만 허용하고 Group에 배치·채우기 책임을 두지 않는다. 검증을 네이티브 작성보다 앞에 둔다. 설계서의 parent null은 화면 Frame이다.

## 호환성·이관·복구

containers가 없으면 기존 leaf 목록을 바꾸지 않는다. 실패는 새 노드를 만들기 전에 반환한다. 기존 방향 패킷의 prototype과 semantic key는 이 함수가 수정하지 않는다.

## 검증과 미검증

종료 게이트가 기준 unittest 종료 코드 1과 대상 108ecded7a1e99ee040a4c4b067a837a85d4d67c의 종료 코드 0을 다시 실행했다. fixture 고정 검사와 design direction 검사 8개도 통과했다. 실제 Figma 레이어 트리, prototype 왕복, resize는 관찰하지 않았다.

## 한계와 후속 개선

이 단위는 Python 검증이다. 기존 JS leaf 경로에 부모를 배치하는 일과 geometry 보존은 아직이다. AC-01의 네이티브 트리 관찰은 통과로 기록하지 않는다.
