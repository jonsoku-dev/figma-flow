# test: replay all three optional cases with pinned original evidence

## 문제와 계기

Three tests were normally skipped because the clean checkout lacks two private project fixtures and operator-supplied native readback evidence. Passing the suite with those cases silently skipped did not exercise their original inputs.

## 결과 동작

`tools/replay_optional_tests.py` accepts explicit fixture and native-evidence paths, creates a temporary checkout with links to the original fixtures, runs the three cases, and records a path-free SHA receipt. It does not count skipped tests as passed. The root Python CI command now includes `-v` so skip IDs and reasons are visible.

## 변경 파일과 인터페이스

The commit adds the replay CLI, a three-case unit test, usage documentation, and one CI command-line change. Native inputs include a directions manifest, pinned readback, original renderer packet and generated code, and six renderer sources.

## 설계 이유와 출처

The exact earlier cases remain conditional in normal clean CI. A local replay supplies their genuine original inputs without checking private project data into the repository. The renderer snapshot is created beside a temporary manifest.

## 호환성·이관·복구

The runner does not overwrite a receipt or conflicting snapshot. Fixture directories remain outside the temporary checkout and are read through symbolic links. No project or user files are copied into the source tree.

## 검증과 미검증

All three original cases passed with zero skips: the Shadow Troupe Python case 1/1, native readback/tampering Python case 1/1, and the Moss Choir Node file 16/16. The runner itself has three tests for skip classification, symlink rejection, and concurrent checkout isolation.

## 한계와 후속 개선

The readback replay verifies consistency with supplied native evidence, not who produced it. Clean CI still lacks private fixtures and optional operator evidence and therefore shows the documented skip reasons.
