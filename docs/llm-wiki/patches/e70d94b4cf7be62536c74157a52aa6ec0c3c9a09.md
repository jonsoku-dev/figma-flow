# 부분 설치 환경에서 시작 진단 도움말의 독립 검사

## 문제와 계기

시작 진단 도움말을 보려면 네이티브 도구까지 로드해야 해서 설치가 덜 끝난 환경에서 진단을 열기 어려웠다.

## 결과 동작

`e70d94b4cf7be62536c74157a52aa6ec0c3c9a09`에서 시작 CLI 파일만 복사한 상태로 일반 인터프리터의 도움말 동작을 요청한다.

## 변경 파일과 인터페이스

`tests/test_startup_help_boundary.py`에 도움말 표시와 파일 집합 및 바이트 보존을 검사한다.

## 설계 이유와 출처

누락된 런타임 의존성 앞에서도 접근할 수 있는 진단 진입점을 확인한다.

## 호환성·이관·복구

실제 설치나 사용자 작업공간을 변경하지 않는 격리 검사다.

## 검증과 미검증

기준 소스에서 도움말 진입 실패를 재현하고, 동일 사례를 수정 소스에 실행한다.

## 한계와 후속 개선

이 검사는 시작 옵션에 한정된다. 실제 네이티브 설정과 통신은 별도 검사로 검증한다.
