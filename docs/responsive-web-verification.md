# Magic UI 반응형 웹 가져오기 검증

공급된 ZIP의 페이지 파일과 실제 글 슬러그를 대조하고 각 경로를 Chromium에서 390×844와 1440×900 CSS 픽셀로 열었다. 측정 전 스크롤해 지연 로딩과 등장 애니메이션을 실행했다. 페이지 본문 전체를 그래프에 고정해 기존 Design 파일에서 등록된 Figma Flow로 적용했다. 스크롤바가 차지하는 폭은 원래 브라우저 측정값에 포함되어 있다.

| 템플릿 | ZIP 페이지 | 오류 경로 | Figma 프레임 | 편집 요소 | 인스턴스 |
|---|---:|---:|---:|---:|---:|
| Portfolio | 9 | 2 | 22 | 3,306 | 2 |
| Codeforge | 1 | 1 | 4 | 1,138 | 48 |
| Devtool | 5 | 2 | 14 | 1,652 | 22 |
| Saas | 5 | 2 | 14 | 1,385 | 16 |
| **합계** | **20** | **7** | **54** | **7,481** | **88** |

인스턴스는 편집 요소에 포함된다. 네이티브 VECTOR 자식 1,435개는 이 합계와 별도로 읽었다. 같은 입력을 재적용해 54개 모두 같은 프레임 ID와 main 연결을 확인했다. 메타데이터·OG 응답은 화면 집계에서 제외했다. 일반 미등록 주소는 네 앱에서 404였다. 없는 블로그 글을 요청하면 Portfolio는 404를, DevTool과 SaaS의 공급 원본은 HTTP 500 오류 화면을 표시했다.

## 화면 비교

각 브라우저 전체 페이지 PNG와 네이티브 프레임의 내보내기 PNG를 같은 콘텐츠 폭과 종횡비로 맞춰 비교했다. 채널별 절대 차이의 평균은 0~255 척도에서 0.29~24.13였다. 이 값은 글꼴 래스터화·줄바꿈, 애니메이션 시점, 원본의 canvas와 지원하지 않는 CSS에 함께 영향을 받는다. 개별 이미지의 SHA-256과 좌표별 비교 결과는 [인수 그래프](../specs/responsive-web/graph.json)에 보관한다. 원본 화면·그래프 내용과 실제 Figma 파일 식별자는 로컬에 보관한다.

- 디자이너는 네이티브 TEXT, 외부 로고에서 생성된 VECTOR, 연결된 인스턴스, 마스크와 효과를 각각 편집할 수 있다. DevTool 제목의 투명 글자가 검게 표시되던 문제는 135° 6개 색 정지점을 가진 편집 가능한 선형 그라디언트 텍스트로 수정했다.
- 개발자는 서명된 파일·페이지·그래프 해시와 선택된 화면에 한정된 결과를 읽을 수 있다. 실제 읽기에서 ALPHA 마스크 72개, DROP_SHADOW 1,978개, INNER_SHADOW 4개, LAYER_BLUR 106개를 확인했다. 별도 기준 그림의 세로 마스크 상단·중앙·하단은 브라우저와 Figma의 RGB 각 채널 차이가 최대 1이었다.
- 기획자는 원본 경로에서 모바일·데스크톱 화면과 검증 결과까지 따라갈 수 있다. 인증 화면은 폼을 제출하지 않고 확인했다. 서버 오류 화면도 원본 HTTP 상태에 연결했다.

## 미디어와 경계

108개 출처·요청 URL 조합의 로컬 파일을 해시와 대조했다. 세로·가로 클리핑 마스크, 지원 가능한 그림자와 블러, 안전한 로컬 SVG clipPath·그라디언트 참조를 처리한다. 복합 마스크, 임의 필터·SVG, canvas 및 상호작용 중 시간에 따른 움직임은 자동 복원을 보장할 수 없다.

Portfolio 영상 네 개는 원본 전체 길이 MP4와 0.5초 정지 프레임을 별도로 고정했다. 원본·인코딩 결과·대체 PNG의 해시를 저장했다. 현재 Figma 파일은 `createVideoAsync`에서 유료 팀의 비초안 파일 조건으로 거절됐다. 두 크기에서 모두 대체 IMAGE 채우기와 거절 사유를 읽었다. 실제 Figma VIDEO 채우기의 재생은 이 파일에서 미검증이다.

## API 관측

0.30.0 기준 미관측 1,232개에서 순위·실제 수신 객체·지원되는 읽기 방법으로 대상을 골랐다. 자체 플러그인의 488회 호출 중 473회 성공, 10회 값 미제공, 5회 수신 객체에서 미지원이었다. 조회한 고유 멤버 중 39개에 새 실행 근거가 생겼다. 누적 189/1,382개, 남은 1,193개다. [API 관측 그래프](../specs/responsive-web/api-observations.json) · [재집계 방법](api-priority.md)

## 재현

[브라우저 측정과 가져오기 명령](web-design-capture.md#경로와-반응형-화면)을 사용한다. ZIP의 원본과 화면별 증거를 가진 환경에서 같은 route 및 viewport를 지정하고, Figma 재실행 결과의 `frame_id`, `component_mains`, `reused`와 이미지·효과 읽기를 대조한다.
