# 모음 아이디어 기획서

작성일 2026-11-05. 이 문서는 자동화 실험을 위해 만든 가상의 최초 기획서다.

## 아이디어

작은 생각을 놓치지 않도록 제목과 메모를 간단히 저장하고, 나중에 검색해 다시 찾는 개인용 웹 앱을 만든다. 이름은 **모음**이고 첫 화면 문구는 ‘흩어진 생각을 한곳에’다.

## 대상과 범위

개인이 같은 브라우저에서 아이디어를 기록한다. 회원가입, 계정 동기화, 서버 API, 협업, 삭제와 편집은 첫 예제 범위 밖이다. 저장은 현재 브라우저의 로컬 저장소를 사용하므로 다른 기기로 자동 동기화되지 않는다.

## 요구사항

- **REQ-001 아이디어 목록:** 저장된 아이디어의 제목, 내용과 작성일을 보여 준다. 저장된 아이디어가 없으면 처음 사용자를 안내한다.
- **REQ-002 아이디어 추가:** 제목과 내용을 입력해 저장한다. 제목은 필수이고 최대 60자다. 내용은 선택이며 최대 500자다. 공백만 있는 제목은 허용하지 않는다.
- **REQ-003 검색:** 목록에서 제목 또는 내용의 검색어를 대소문자 구분 없이 찾는다. 결과가 없을 때 별도 안내를 보여 준다.
- **REQ-004 로컬 저장:** 저장 성공 후 목록으로 돌아간다. 브라우저 저장에 실패하면 성공으로 처리하지 않고 오류 메시지를 보여 주며 입력을 보존한다.
- **REQ-005 접근성과 반응형:** 입력 레이블, 명확한 오류, 키보드 포커스를 제공한다. 데스크톱과 모바일 폭에서 기능을 사용할 수 있어야 한다.

## 화면과 동작

- **SCR-001 목록:** 헤더 `모음`, 소개 `흩어진 생각을 한곳에`, 검색 필드, `아이디어 추가` 버튼, 카드 목록. 상태는 `STATE-001 비어 있음`, `STATE-002 목록 있음`, `STATE-003 검색 결과 없음`.
- **SCR-002 작성:** 제목 필수 입력, 내용 선택 입력, `저장`, `취소`. 상태는 `STATE-004 기본`, `STATE-005 제목 오류`, `STATE-006 저장 오류`.
- **ACT-001:** 목록의 `아이디어 추가` → 작성 기본 화면.
- **ACT-002:** 작성 화면의 `취소` → 목록. 작성 도중 입력을 저장하지 않는다.
- **ACT-003:** 유효한 내용의 `저장` → 저장 후 목록. 실패하면 작성 화면과 입력을 유지한다.
- **ACT-004:** 빈 제목의 `저장` → 작성 화면에서 제목 오류를 보여 주고 입력에 포커스를 둔다.
- **ACT-005:** 검색어 변경 → 제목·내용 기준으로 보이는 카드를 갱신한다.

## 검수 기준

1. 새 브라우저 저장소에서 빈 상태가 보인다.
2. 제목이 공백이면 저장되지 않고 오류와 포커스가 표시된다.
3. 제목을 넣어 저장하면 목록에 생기고 새로고침 후 유지된다.
4. 검색이 제목·내용을 찾고, 일치하지 않으면 검색 결과 없음이 보인다.
5. 취소하면 새 아이디어가 추가되지 않는다.
6. 데스크톱과 모바일, 키보드로 주요 동작을 확인한다.
7. 저장 불가능한 상황을 확인할 수 있다면 오류와 입력 유지 여부를 기록한다.
