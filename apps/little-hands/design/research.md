# 제작 근거와 미확인 범위

이 문서는 현재 구현을 Figma Flow 정상 경로에 전달하기 위한 소스 분석이다. 브라우저·Figma 시각 관측은 아직 이 문서로 증명하지 않는다.

- 제품. 회원의 커피 수업 예약과 운영자의 같은 수업 데이터 관리를 돕는 Operate 화면이다. ../ARCHITECTURE.md와 booking/views.py를 읽었다.
- 성격. 한국어 설명, 명확한 상태, 확인 후 실행이 중심이다. 인원·가격·정책을 요청 전에 보이며409는 서버가 만든 복구 URL로 돌아간다.
- 세계관. 종이색·크림·적갈색, Hahmlet Regular/Bold, 붉은 바탕 위 흰 잔과 긴 그림자 사진을 기존 tokens.json/UI_CONTRACT.md에서 유지한다. 공방 내부·원두 사진으로 묘사하지 않는다.
- 강조할 장면. 회원 첫 화면의 실제 수업과 일정 확인, 운영 화면의 실제 예정 인원·대기 현황을 우선한다. 랜딩 장식을 운영 표에 추가하지 않는다.
- 고유 디테일. 커피 수업의 소요 시간, 테이블/바 공간, 예약 당시 단가와 현장 결제 안내를 실제 Django 데이터에서 표시한다.

동봉 Impeccable은 작업형 Operate의 읽기 순서·실제 오류·명확한 조작을 적용한다. design-taste-frontend의 문서는 데이터 표와 다단계 제품 UI를 제외하므로 랜딩 취향을 운영 화면에 강제하지 않는다. 내장 Unslop은 간격·색·아이콘·문구·서체·구성·디테일·이미지·모션 순서로 실제 최종 캡처를 비평할 때 사용한다. 이 분석은 그 비평의 완료 기록이 아니다.

폰트·사진의 출처는 ../static/littlehands/sources.json과 ../static/littlehands/fonts/OFL.txt다. 두 굵기의 실제 한국어 줄바꿈·글꼴 로딩은 실제 브라우저 캡처에서 확인해야 한다. 측정은 글리프 높이를 텍스트 상자로 쓰지 않고 CSS 행간으로 줄 상자를 작성한다.

새로운 아트 방향을 사용자가 선택했다는 근거는 없다. direct는 현재 실제 사용자의 새 앱 전체 테스트 요청을 원문으로 보존하는 단일 제안 경로이며 실제 관리 사용자 이벤트를 부모가 확보한 뒤 admit-direct로 검사한다. 이 문서는 승인 파일이 아니다.

## 실제 미리보기 래스터와 CSS 뷰포트

부모가 저장한 실제 JPEG는 desktop1185×889, mobile375×923 픽셀이다. 실제 DOM 측정의 CSS 뷰포트는1200×900과390×960이다. candidate-spec의 width/height는 실제 JPEG 파일 크기를 기록하며 css_viewport에 DOM 크기를 따로 보존한다. 픽셀을 확대·자르거나 합성하지 않았다. 이 차이의 캡처 API 내부 원인은 여기서 단정하지 않는다. 네이티브 좌표는 실제 CSS DOM 측정을 유지한다.
